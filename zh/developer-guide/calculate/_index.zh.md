通过 Aspose.Cells Cloud REST API，自动对 Excel 工作表执行 **SUM**（求和）、**COUNT**（计数）、**AVERAGE**（平均值）、**MIN**（最小值）和 **MAX**（最大值）等计算——无需手动筛选或使用本地电子表格软件。该 API 由 **Aspose.Cells Cloud** 提供支持，采用标准身份验证方式（OAuth 2.0 或 JWT），结果以 JSON 格式返回，并针对无效范围或身份验证问题提供明确的错误代码。如需了解详细请求语法，请参阅官方 REST API 参考文档。

- **[按单元格颜色计算](https://docs.aspose.cloud/cells/aggregate-cells-by-color/)** – 通过单次请求，按背景色或字体颜色分组获取汇总结果。
- **[电子表格快速计算](https://docs.aspose.cloud/cells/math-calculate/)** – 瞬间对任意区域执行 SUM、COUNT、AVERAGE、MIN、MAX（及基础数学运算）。
