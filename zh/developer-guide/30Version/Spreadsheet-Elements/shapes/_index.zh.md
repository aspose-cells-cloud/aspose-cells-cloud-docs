## 处理 Excel 文件中的形状

形状代表绘图对象，例如线条、矩形、文本框和图像，可放置在 Excel 工作表上。它们有助于可视化数据、添加注释，或在电子表格中创建交互式元素。本页提供最常见形状相关操作的快捷链接，每个链接均附有简要说明。

**前置条件：** 要使用形状操作，您必须拥有有效的 Aspose.Cells Cloud API 密钥，并已将工作簿上传至云端。

- [如何获取 Excel 工作表上的所有形状。](/zh/cells/shapes/get-all/) – 检索工作表中存在的完整形状集合。
- [如何按索引获取 Excel 工作表上的某个形状。](/zh/cells/shapes/get/) – 返回位于指定索引处的形状。
- [如何在 Excel 工作表上添加形状。](/zh/cells/shapes/add/) – 向工作表中插入一个新形状（例如矩形、线条或图像）。
- [如何删除 Excel 工作表上的所有形状。](/zh/cells/shapes/clear/) – 一次性删除工作表中的所有形状。
- [如何按索引删除 Excel 工作表上的某个形状。](/zh/cells/shapes/delete/) – 删除给定索引处的形状。
- [如何将 Excel 工作表上的形状转换为图像。](/zh/cells/shapes/conversion/) – 将所选形状转换为图像文件（PNG、JPEG 等），以便外部使用。
