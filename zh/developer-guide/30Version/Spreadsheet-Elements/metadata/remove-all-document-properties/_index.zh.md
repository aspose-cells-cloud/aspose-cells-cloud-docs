此 REST API 将删除所有自定义文档属性，并清除内置属性。

## REST API

```bash
DELETE http://api.aspose.cloud/v3.0/cells/{name}/documentproperties
```

### 请求参数

| 参数名称     | 类型   | 位置 | 描述           |
| ------------ | ------ | ---- | -------------- |
| name         | string | path | 文档名称。     |
| folder       | string | query| 文档所在文件夹。|
| storageName  | string | query| 存储名称。     |

[OpenAPI 规范](https://apireference.aspose.cloud/cells/#/Properties/DeleteDocumentProperties) 定义了一个公开可用的编程接口，您可以直接从 Web 浏览器发起 REST 交互。

您可以使用 cURL 命令行工具轻松访问 Aspose.Cells Web 服务。以下示例展示了如何使用 cURL 调用云 API。

```bash

  -X DELETE \

  -H "Authorization: Bearer <jwt token>"
```
