Excel 中的超链接使用户能够创建指向工作表、文件、文件夹或网页的快捷方式，从而快速导航到特定位置。

**前置条件：**有效的 API 令牌（参见[身份验证指南](/zh/authentication/)）以及已安装 Cells.Cloud SDK。

## 处理 Excel 文件中的超链接

- [如何从 Excel 工作表获取超链接描述](/zh/cells/hyperlinks/get/) – 检索单个超链接的详细信息，包括其地址和显示文本。  
- [如何从 Excel 工作表获取所有超链接描述](/zh/cells/hyperlinks/get-all/) – 列出工作表中定义的每个超链接及其对应属性。  
- [如何向 Excel 工作表添加超链接](/zh/cells/hyperlinks/add/) – 向工作表中插入一个新的超链接，指定目标 URL 和单元格范围。  
- [如何更新 Excel 工作表中的超链接](/zh/cells/hyperlinks/update/) – 修改现有超链接的地址、显示文本或目标单元格。  
- [如何从 Excel 工作表中删除所有超链接](/zh/cells/hyperlinks/clear/) – 一次性删除工作表中的所有超链接。  
- [如何从 Excel 工作表中删除超链接](/zh/cells/hyperlinks/delete/) – 删除由索引或单元格引用标识的特定超链接。
