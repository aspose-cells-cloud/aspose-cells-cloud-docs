## Excel 文本操作 API

Aspose.Cells Cloud 提供了一系列 REST 接口，可用于操作 Excel 工作表中的文本内容。这些操作涵盖日常任务，例如裁剪空白字符、拆分字符串、转换大小写、提取子字符串以及删除不需要的字符。

**前置条件：** 所有请求必须使用有效的访问令牌进行身份验证，并将该令牌置于 `Authorization` 请求头中。有关获取和使用令牌的详细信息，请参阅身份验证指南。
