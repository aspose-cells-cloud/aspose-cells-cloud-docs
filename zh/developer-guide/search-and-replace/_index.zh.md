Aspose.Cells Cloud API 的**搜索与替换**功能使开发者能够以编程方式定位并替换存储于云端的 Excel 工作簿中的文本、公式或超链接。

- **[替换远程电子表格中的内容](https://docs.aspose.cloud/cells/replace-content-in-remote-spreadsheet/)** —— 替换存储于 Aspose Cloud 存储空间中工作簿内的指定字符串的所有出现位置。  
- **[替换远程电子表格中指定范围的内容](https://docs.aspose.cloud/cells/replace-content-in-remote-range/)** —— 替换远程工作簿中指定单元格区域内的内容。  
- **[替换电子表格内容](https://docs.aspose.cloud/cells/replace-spreadsheet-content/)** —— 提供针对整个电子表格的批量替换操作。  
- **[替换远程电子表格中工作表的内容](https://docs.aspose.cloud/cells/replace-content-in-remote-worksheet/)** —— 替换远程工作簿中特定工作表内的文本。  
- **[搜索远程电子表格中指定范围内的断开链接](https://docs.aspose.cloud/cells/search-broken-links-in-remote-range/)** —— 查找并报告指定范围内存在的断开超链接。  
- **[搜索远程电子表格中工作表的断开链接](https://docs.aspose.cloud/cells/search-broken-links-in-remote-worksheet/)** —— 检测整个工作表范围内的断开链接。  
- **[搜索远程电子表格中的内容](https://docs.aspose.cloud/cells/search-content-in-remote-spreadsheet/)** —— 在远程工作簿中搜索特定文本、公式或值。  
- **[搜索远程电子表格中的断开链接](https://docs.aspose.cloud/cells/search-broken-links-in-remote-spreadsheet/)** —— 扫描多个工作簿，查找断开的超链接。  
- **[搜索远程电子表格中指定范围内的内容](https://docs.aspose.cloud/cells/search-content-in-remote-range/)** —— 在特定单元格范围内进行搜索。  
- **[搜索电子表格中的断开链接](https://docs.aspose.cloud/cells/search-spreadsheet-broken-links/)** —— 提供整个电子表格中所有断开链接的完整列表。  
- **[搜索电子表格内容](https://docs.aspose.cloud/cells/search-spreadsheet-content/)** —— 对整个电子表格进行通用内容搜索。  
- **[搜索远程电子表格中工作表的内容](https://docs.aspose.cloud/cells/search-content-in-remote-worksheet/)** —— 在特定工作表中搜索内容。
