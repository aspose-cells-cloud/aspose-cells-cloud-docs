- 为数据组装 API 添加了区域参数（region-parameter）。  
- 为文件合并 API 添加了区域参数（region-parameter）。  
- 为文件拆分 API 添加了区域参数（region-parameter）。  
- 为数据导入 API 添加了区域参数（region-parameter）。  
- 为水印 API 添加了区域参数（region-parameter）。  
- 为清除对象 API 添加了区域参数（region-parameter）。  
- 为反向数据 API 添加了区域参数（region-parameter）。  
- 为旋转数据 API 添加了区域参数（region-parameter）。

- 优化了 XML 数据导入 Excel 文件的功能。

- 移除了已弃用的函数、类及测试用例。  

## 版本 23.10 的增强功能

- 修复了工作簿保护请求（protect workbook request）。  
- 修复了区域复制 API（range copy API）。  
- 优化了工作簿保护 API（workbook protect API）。

- 为区域控制器（range controller）添加了数据排序支持。  
- 为列表对象（list objects）添加了重复数据删除功能。  
- 为列表对象（list objects）添加了切片器插入功能。  
- 优化了列表对象及相关组件。  

## 版本 23.8 的增强功能

- 优化了保护 API（protect API）。  

## Aspose.Cells Cloud 23.7
