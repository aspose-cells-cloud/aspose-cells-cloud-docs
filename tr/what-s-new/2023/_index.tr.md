Aspose.Cells Cloud belgelerinde yeni olanlara hoş geldiniz. Bu sayfa, **Aspose.Cells Cloud 2023 yeni özelliklerini** vurgular ve en son değişiklikleri hızlıca bulmanızı sağlar.

**Son güncelleme:** Temmuz 2026  

## 23.12.0 Sürümündeki Geliştirmeler

- Dönüştürme API’sine bölge-parametresi eklendi.  
- Koruma API’sine bölge-parametresi eklendi.  
- Veri Birleştirme API’sine bölge-parametresi eklendi.  
- Dosyaları Birleştirme API’sine bölge-parametresi eklendi.  
- Dosyaları Bölme API’sine bölge-parametresi eklendi.  
- Veri İçe Aktarma API’sine bölge-parametresi eklendi.  
- Filigran API’sine bölge-parametresi eklendi.  
- Nesne Temizleme API’sine bölge-parametresi eklendi.  
- Veriyi Ters Çevirme API’sine bölge-parametresi eklendi.  
- Veriyi Döndürme API’sine bölge-parametresi eklendi.  

## 23.11 Sürümündeki Geliştirmeler

- Excel dosyalarına XML veri içe aktarma işlemi optimize edildi.  
- Excel dosyalarına JSON veri içe aktarma işlemi optimize edildi.  
- Kullanımdan kaldırılan fonksiyonlar, sınıflar ve test senaryoları kaldırıldı.  

## 23.10 Sürümündeki Geliştirmeler

- Çalışma kitabını koruma isteği düzeltildi.  
- Aralık kopyalama API’si düzeltildi.  
- Çalışma kitabını koruma API’si optimize edildi.  

## 23.9 Sürümündeki Geliştirmeler

- Aralık denetleyicisinde veri sıralama desteği eklendi.  
- Liste nesneleri için yinelenen veri kaldırma desteği eklendi.  
- Liste nesneleri için filtre çubuğu (slicer) ekleme desteği eklendi.  
- Liste nesnesi ve ilgili bileşenler optimize edildi.  

## 23.8 Sürümündeki Geliştirmeler

- Kilidi açma API’si desteği eklendi.  
- Korumayı açma API’si optimize edildi.  

## Aspose.Cells Cloud 23.7

- Dosya onarımı desteği eklendi.  
- Dönüştürme işlevleri optimize edildi.  

## Aspose.Cells Cloud 23.6

- Birden fazla dosya için toplu kilitleme desteği eklendi.  
- Birden fazla dosya için toplu kilidi açma desteği eklendi.  
- Birden fazla dosya için toplu koruma desteği eklendi.  
- Birden fazla dosya için toplu bölme desteği eklendi.  
- PUT belge özelliği API’si düzeltildi.  

## Aspose.Cells Cloud 23.5

- Yanlış yazılmış yöntem adları düzeltildi.  

## Aspose.Cells Cloud 23.4

- XML veri içe ve dışa aktarma desteği eklendi.  

## Aspose.Cells Cloud 23.3

- Bağlantı (hyperlink) özellikleri optimize edildi.  

## Aspose.Cells Cloud 23.2

- Değiştirme (replace) API’si optimize edildi.  
- Swagger UI optimize edildi.  

## Aspose.Cells Cloud 23.1

- PostCellCharacters yöntemindeki hata düzeltildi.  

Daha ayrıntılı bilgi için her sürümün tam sürüm notlarına bakın veya Aspose.Cells Cloud API referansına gidin.
