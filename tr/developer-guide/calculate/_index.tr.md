Aspose.Cells Cloud REST API'si aracılığıyla Excel çalışma sayfalarında **SUM**, **COUNT**, **AVERAGE**, **MIN** ve **MAX** gibi hesaplamaları otomatik olarak gerçekleştirin—elle filtreleme veya yerel elektronik tablo yazılımına gerek yoktur. API, **Aspose.Cells Cloud** içinde desteklenir, standart kimlik doğrulama (OAuth 2.0 veya JWT) kullanır, sonuçları JSON formatında döndürür ve geçersiz aralıklar veya kimlik doğrulama sorunları için açık hata kodları sağlar. İsteğin ayrıntılı sözdizimi için resmi REST API referansına bakın.

- **[Hücre Renklerine Göre Hesapla](https://docs.aspose.cloud/cells/aggregate-cells-by-color/)** – Tek bir istekte arka plan veya yazı tipi rengine göre gruplanmış toplamları alın.
- **[Elektronik Tablo Hızlı Hesaplama](https://docs.aspose.cloud/cells/math-calculate/)** – Herhangi bir aralıkta SUM, COUNT, AVERAGE, MIN, MAX (ve temel matematik işlemlerini) anında hesaplayın.
