**Önkoşullar**  
Uç noktayı çağırmadan önce, uygun izinlere sahip aktif bir Aspose Cloud erişim belirteci ve API sürümünün (`v3.0`) alınması gerekir.

### Aspose.Cells Cloud REST API ile kağıt boyutu nasıl ayarlanır

```bash
curl -X PUT "https://api.aspose.cloud/v3.0/cells/Workbook/worksheets/Sheet1/pageSetup" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{"PaperSize":"PaperA4"}'
```

**İstek Detayları**  
- **Yöntem:** `PUT`  
- **Uç Nokta:** `/cells/Workbook/worksheets/{sheetName}/pageSetup`  
- **Yol Parametreleri:** `sheetName` – çalışma sayfasının adı (dize, zorunludur).  
- **İstek Gövdesi:** `PaperSize` özelliğini içeren JSON nesnesi. Değer, yukarıdaki tabloda listelenen sabitlerden biri olmalıdır, örneğin `"PaperA4"`.

**Yanıtlar**  
- `200 OK` – Sayfa ayarı başarıyla güncellendi.  
- `400 Bad Request` – Geçersiz `PaperSize` değeri.  
- `401 Unauthorized` – Kimlik doğrulama başarısız oldu veya belirteç eksik.  
- `404 Not Found` – Belirtilen çalışma sayfası mevcut değil.

**Örnek SDK (C#)**  
```csharp
var api = new CellsApi("client_id", "client_secret");
var request = new PageSetup { PaperSize = PaperSizeEnum.PaperA4 };
api.PutWorksheetPageSetup("Book1.xlsx", "Sheet1", request);
```

Tam bir OpenAPI tanımı için bkz. <a href="https://api.aspose.cloud/v3.0/swagger.json" target="_blank" rel="noopener">Aspose.Cells Cloud Swagger specification</a>.
