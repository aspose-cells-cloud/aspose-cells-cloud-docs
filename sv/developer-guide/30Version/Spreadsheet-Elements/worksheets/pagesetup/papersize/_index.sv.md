**Förutsättningar**  
En aktiv Aspose Cloud-åtkomsttoken med lämpliga behörigheter och API-versionen (`v3.0`) måste erhållas innan slutpunkten anropas.

### Hur man ställer in en pappersstorlek med Aspose.Cells Cloud REST API

```bash
curl -X PUT "https://api.aspose.cloud/v3.0/cells/Workbook/worksheets/Sheet1/pageSetup" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{"PaperSize":"PaperA4"}'
```

**Förfrågningsinformation**  
- **Metod:** `PUT`  
- **Slutpunkt:** `/cells/Workbook/worksheets/{sheetName}/pageSetup`  
- **Sökvägsparametrar:** `sheetName` – namnet på kalkylarket (sträng, obligatoriskt).  
- **Förfrågningsbody:** JSON-objekt som innehåller egenskapen `PaperSize`. Värdet måste vara en av konstanterna i tabellen ovan, t.ex. `"PaperA4"`.

**Svar**  
- `200 OK` – Sidinställningen har uppdaterats framgångsrikt.  
- `400 Bad Request` – Ogiltigt `PaperSize`-värde.  
- `401 Unauthorized` – Autentisering misslyckades eller token saknas.  
- `404 Not Found` – Det angivna kalkylarket finns inte.

**Exempel på SDK (C#)**  
```csharp
var api = new CellsApi("client_id", "client_secret");
var request = new PageSetup { PaperSize = PaperSizeEnum.PaperA4 };
api.PutWorksheetPageSetup("Book1.xlsx", "Sheet1", request);
```
