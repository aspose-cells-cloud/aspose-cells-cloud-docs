Denna REST API rensar objekten i en Excel-fil.

## REST API

```bash
POST https://api.aspose.cloud/v3.0/cells/clearobjects
```

### Parametrar för begäran

| Parameter  | Typ    | Plats      | Obligatoriskt | Standard | Tillåtna värden                                                                                                                                                                                        | Beskrivning                                         |
| ---------- | ------ | ---------- | ------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------- |
| file       | fil    | form‑data  | Ja            | —        | —                                                                                                                                                                                                      | Den Excel-fil som ska laddas upp                   |
| objecttype | string | frågeparameter | Nej           | —        | `duplicaterows`, `blankcolumns`, `blankrows`, `formula`, `content`, `style`, `chart`, `comment`, `picture`, `shape`, `listobject`, `hyperlink`, `oleobject`, `pivottable`, `validation`, `background` | Objekttyper som ska rensas (kommaseparerade)       |

[OpenAPI-specifikationen](https://apireference.aspose.cloud/cells/#/LightCells/PostClearObjects) definierar ett offentligt tillgängligt programmeringsgränssnitt och låter dig utföra REST-interaktioner direkt från en webbläsare.

Du kan använda kommandoradsverktyget cURL för enkelt att komma åt Aspose.Cells webbtjänster. Följande exempel visar hur man gör anrop till moln-API:et med cURL.

  -H "Accept: application/json" \
  -H "Authorization: Bearer <jwt token>" \
