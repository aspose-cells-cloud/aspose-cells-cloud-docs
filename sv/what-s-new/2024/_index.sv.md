Välkommen till "Vad är nytt" i dokumentationen för Aspose.Cells Cloud. Använd den här sidan för snabbt att hitta de senaste ändringarna. Den här ändringsloggen sammanfattar de viktigaste förbättringarna, felrättningarna och de nya API:er som introducerats i varje release av Aspose.Cells Cloud under 2024.

## Förbättringar i version 24.12

- Lägg till den nya **Remove Duplicates API**.  
- Lägg till den nya **Extract Text API**.  
- Fixade ett fel där skapande av pivotfilter kunde misslyckas.

## Förbättringar i version 24.11

- Lägg till en textkonverteringsfunktion i `TextProcessingController`.

## Förbättringar i version 24.10

- Lägg till en funktion för borttagning av tecken i `TextProcessingController`.

## Förbättringar i version 24.9

- Lägg till en funktion för ändring av skiftläge i `TextProcessingController`.  
- Stöd för att exportera ett kalkylark till HTML med celladresser eller ID:n.

## Förbättringar i version 24.8

- Lägg till en funktion för textbeskärning i Cells Cloud Services.

## Förbättringar i version 24.7

- Introducera API:et **AddTextContent** för att infoga godtycklig text i ett kalkylark.  
- Lägg till möjlighet att erhålla en åtkomsttoken med hjälp av klient-ID och klienthemlighet.

## Förbättringar i version 24.6.1

- Fixa utökade frågeparametrar för API:er.

## Förbättringar i version 24.6.0

- Optimera datakonverteringssteg.  
- Optimera dataladdningsfunktionen för datatransformation.  
- Utökat stöd för .NET Framework 4.2.5 och .NET Standard 2.0.

## Förbättringar i version 24.5.1

- Lägg till en metod för sammanfogning av frågor vid dataloadning i datatransformation.  
- Optimera datamodellen för diagram.  
- Uppdatera endpoint för åtkomsttoken.

## Förbättringar i version 24.4

- Stöd för datatransformationsfunktion i Aspose.Cells Cloud Services.

## Förbättringar i version 24.3

- Stöd för deduplicering av data (förbättrad version).  
- Stöd för att fylla i data.  
- Stöd för att ta bort ofärdiga rader.  
- Stöd för datarengöring.

## Förbättringar i version 24.2.1

- Stöd för deduplicering av data (första stödversion, vidareutvecklad i senare versioner).

## Förbättringar i version 24.1.1

- Fixade stavfel i flera funktioner.  
- Lägg till metoden `PostFitTallToPages` i PageSetupController.  
- Lägg till metoden `PostFitWideToPages` i PageSetupController.  
- Optimera alternativ för sidindelad sparning.
