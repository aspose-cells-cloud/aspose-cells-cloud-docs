## Aspose.Cells Cloud teknisk support

Aspose erbjuder obegränsad gratis teknisk support för alla sina produkter. Supporten är tillgänglig för alla användare, inklusive de som testar tjänsten.

Om du behöver hjälp med Aspose.Cells Cloud kan du använda följande resurser:

- Den primära supportkanalen är [Aspose Cloud Forum](https://forum.aspose.cloud/). Posta din fråga i [Aspose Cells Cloud Forum](https://forum.aspose.cloud/c/cells), där den besvaras av Aspose.Cells Cloud-utvecklingsteamet inom några timmar.  
- Observera att telefonstöd är begränsat till försäljnings- och köpfrågor; tekniska problem måste hanteras via forumet.  
- Vid väntan på svar från forumet, ta hänsyn till tidszonedifferenser.
