مرحبًا بكم في قسم "ما الجديد" في مستندات Aspose.Cells Cloud. تُبرز هذه الصفحة **الميزات الجديدة في Aspose.Cells Cloud لعام 2023** وتمكّنكم من العثور بسرعة على أحدث التغييرات.

**آخر تحديث:** يوليو 2026

## التحسينات في الإصدار 23.12.0

- أُضيف معامل "المنطقة" (region-parameter) إلى واجهة برمجة التطبيقات للتحويل (Conversion API).  
- أُضيف معامل "المنطقة" (region-parameter) إلى واجهة برمجة التطبيقات للحماية (Protection API).  
- أُضيف معامل "المنطقة" (region-parameter) إلى واجهة برمجة التطبيقات لAssembly Data API.  
- أُضيف معامل "المنطقة" (region-parameter) إلى واجهة برمجة التطبيقات لدمج الملفات (Merge Files API).  
- أُضيف معامل "المنطقة" (region-parameter) إلى واجهة برمجة التطبيقات لتقسيم الملفات (Split Files API).  
- أُضيف معامل "المنطقة" (region-parameter) إلى واجهة برمجة التطبيقات لاستيراد البيانات (Import Data API).  
- أُضيف معامل "المنطقة" (region-parameter) إلى واجهة برمجة التطبيقات للعلامة المائية (Watermark API).  
- أُضيف معامل "المنطقة" (region-parameter) إلى واجهة برمجة التطبيقات لمسح الكائنات (Clear Object API).  
- أُضيف معامل "المنطقة" (region-parameter) إلى واجهة برمجة التطبيقات لعكس البيانات (Reverse Data API).  
- أُضيف معامل "المنطقة" (region-parameter) إلى واجهة برمجة التطبيقات لتدوير البيانات (Rotate Data API).  

## التحسينات في الإصدار 23.11

- تمت تحسين عملية استيراد بيانات XML إلى ملفات Excel.  
- تمت تحسين عملية استيراد بيانات JSON إلى ملفات Excel.  
- تمت إزالة الدوال والفئات وحالات الاختبار القديمة.  

## التحسينات في الإصدار 23.10

- تم إصلاح طلب حماية دفتر العمل (protect workbook request).  
- تم إصلاح واجهة برمجة التطبيقات لنسخ النطاق (range copy API).  
- تم تحسين واجهة برمجة التطبيقات لحماية دفتر العمل (workbook protect API).  

## التحسينات في الإصدار 23.9

- أُضيف دعم فرز البيانات في وحدة التحكم بالنطاق (range controller).  
- أُضيف دعم إزالة البيانات المكرَّرة للكائنات القائمة (list objects).  
- أُضيف دعم إدخال عناصر التصفية (slicers) للكائنات القائمة.  
- تمت تحسين أداء الكائنات القائمة والمكونات ذات الصلة.  

## التحسينات في الإصدار 23.8

- أُضيف دعم واجهة برمجة التطبيقات للقفل (lock API).  
- تمت تحسين واجهة برمجة التطبيقات للحماية (protect API).  

## Aspose.Cells Cloud الإصدار 23.7

- أُضيف دعم إصلاح الملفات (file-repair support).  
- تمت تحسين وظائف التحويل.  

## Aspose.Cells Cloud الإصدار 23.6

- أُضيف قفل دفعي لعدة ملفات (batch lock for multiple files).  
- أُضيف فك قفل دفعي لعدة ملفات (batch unlock for multiple files).  
- أُضيف حماية دفعية لعدة ملفات (batch protect for multiple files).  
- أُضيف تقسيم دفعي لعدة ملفات (batch split for multiple files).
