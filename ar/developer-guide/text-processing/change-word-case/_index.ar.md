## **تغيير حالة الكلمات**

استخدم واجهة Aspose.Cells Cloud Web API لتحويل حالة النص في جدولك البياناتي فورًا — التبديل بين الأحرف الكبيرة، الأحرف الصغيرة، الحالة المناسبة (كبير أول حرف في كل كلمة)، أو الحالة المناسبة للجملة (كبير أول حرف في كل جملة) عبر النطاق المحدّد. تتأثر الخلايا النصية فقط؛ بينما تُهمَل القيم الرقمية، والقيم المنطقية، والأخطاء، والخلايا الفارغة. تظل الصيغ، والتنسيق، وتحقق البيانات دون تغيير.

- **UpperCase** – تحويل كل حرف إلى حرف كبير.
- **LowerCase** – تحويل كل حرف إلى حرف صغير.
- **ProperCase** – تحويل أول حرف في كل كلمة إلى حرف كبير، وبقية الحروف إلى أحرف صغيرة.
- **SentenceCase** – تحويل أول حرف في كل جملة إلى حرف كبير، وبقية الحروف إلى أحرف صغيرة.

### واجهة برمجة التطبيقات عبر الويب

```http
PUT https://api.aspose.cloud/v4.0/cells/content/wordcase
```


### **الأمان والمصادقة**

واجهات برمجة تطبيقات Aspose.Cells Cloud آمنة وتتطلب <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### الاستجابة

في حال النجاح، تُعيد الخدمة الرمز **200 OK** (أو **202 Accepted**) مع حمولة JSON تحتوي على تدفق ثنائي للمصنف المعالج.

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

### أكواد الخطأ

- **400 Bad Request** – عنوان URI لواجهة Aspose.Cells Cloud API غير صالح.
- **401 Unauthorized** – رمز الوصول غير صالح أو بيانات اعتماد العميل غير صحيحة.
- **404 Not Found** – ملف الجدول غير قابل للوصول.
- **500 Server Error** – حدث خلل داخلي أثناء معالجة الجدول.

## أين يجب استخدام واجهة برمجة التطبيقات لتغيير حالة الكلمات؟

### تنظيف البيانات وتوحيد التنسيق

- **إدارة بيانات العملاء** – توحيد تنسيق أسماء العملاء وعناوينهم (مثال: `john doe` → `John Doe`).
- **معالجة كتالوج المنتجات** – توحيد عناوين المنتجات ونصوص أوصافها (مثال: `IPHONE 15 PRO` → `iPhone 15 Pro`).
- **توليد التقارير المالية** – توحيد أسماء البنود وحقول الأوصاف في البيانات المالية.

### دمج البيانات من مصادر متعددة

- **ETL لمستودع البيانات** – توحيد تنسيق النص عند تحميل البيانات من أنظمة مختلفة.
- **استقبال البيانات من واجهات برمجة التطبيقات** – التعامل مع البيانات ذات التنسيق غير المتجانس الذي تُعيده واجهات برمجة التطبيقات الخارجية.
- **دمج البيانات بين الإدارات** – توحيد تنسيق النص في تقارير إكسل الصادرة من إدارات مختلفة.

### نظام إدارة المحتوى

- **الإفراج الصحفي التلقائي** – تنسيق عناوين الأخبار والمحتوى تلقائيًا (قواعد حالة الأحرف للعناوين).
- **توليد وثائق المنتجات** – ضمان الاتساق في تنسيق مصطلحات الوثائق التقنية.
- **صيانة قاعدة المعرفة** – توحيد تنسيق النص في الأسئلة الشائعة ووثائق المساعدة.

### دمج تطبيقات المؤسسة

- **دمج نظام إدارة علاقات العملاء (CRM)** – تنسيق الأسماء ومعلومات الشركات تلقائيًا أثناء استيراد/تصدير بيانات العملاء.
- **معالجة بيانات نظام تخطيط موارد المؤسسة (ERP)** – توحيد الحقول الأساسية مثل أوصاف المواد وأسماء الموردين.
- **نظام إدارة الموارد البشرية** – توحيد معلومات الموظفين والعناوين الوظيفية.

### معالجة المستندات بالجملة

- **إعداد المستندات القانونية** – معالجة جمل العقود والاتفاقيات بالجملة.
- **توليد المواد التسويقية** – توحيد تنسيق نصوص الإعلانات وقوالب البريد الإلكتروني.
- **تنسيق الأوراق الأكاديمية** – توحيد متطلبات التنسيق للمراجع والعناوين.

### معالجة البيانات في الوقت الفعلي

- **التحقق من إدخال المستخدم** – تنسيق بيانات النموذج المُدخلة من المستخدمين فورًا.
- **ردود روبوتات المحادثة** – توحيد تنسيق النص في الردود المولّدة آليًا.
- **توليد التقارير الفورية** – إنشاء تقارير أعمال موحدة التنسيق ديناميكيًا.

### التوطين والعالمية

- **معالجة البيانات متعددة اللغات** – التعامل مع اختلافات قواعد الأحرف في النصوص بلغات مختلفة.
- **تحضير المحتوى المحلي** – إعداد محتوى محلي مُنسّق حسب المناطق المختلفة.
- **إدارة مشاريع الترجمة** – ضمان الاتساق في تنسيق النص قبل وبعد الترجمة.

## لماذا يجب عليك استخدام واجهة برمجة التطبيقات لتغيير حالة الكلمات؟

- **سهلة للمطورين** – توفر Aspose.Cells Cloud مكتبات SDK بلغات برمجة متعددة، مما يتيح تطويرًا سريعًا وتوثيقًا شاملًا. وبالمقارنة بإنشاء حلول مخصصة، فإنها تقلّل بشكل كبير من جهد التطوير.
- **فعالة من حيث التكلفة** – يمكنك تغيير حالة الكلمات دون الحاجة أولاً إلى رفع المصنف، مما يوفر مساحة التخزين ويقلل التكاليف.
