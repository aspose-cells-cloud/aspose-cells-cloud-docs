احذف الأحرف من خلايا إكسل حسب الموقع: احذف أول/آخر N أحرف، أو احذف النص قبل/بعد علامات محددة. تنظيف نص دقيق باستخدام واجهة برمجة تطبيقات (Web API) لـ Aspose.Cells Cloud.


## **مقدمة**: حذف الأحرف غير المرغوب فيها حسب الموقع

**أوضاع الموقع**

- `theFirstNCharacters` – حذف N أحرف من البداية
- `theLastNCharacters` – حذف N أحرف من النهاية
- `allCharactersBeforeText` – حذف كل ما يسبق أول ظهور للنص المُدخل كسلسلة فرعية
- `allCharactersAfterText` – حذف كل ما يلي أول ظهور للنص المُدخل كسلسلة فرعية
- `BetweenValues` – إزالة السلسلة الفرعية (وباختياري حذف الفواصل نفسها) الواقعة بين قيمتين معرفتين من قِبل المستخدم

**الخيارات**

- `caseSensitive` – يُحدد ما إذا كانت عمليات البحث عن `BeforeText` و `AfterText` و `BetweenValues` حساسة لحالة الأحرف (أحرف كبيرة/صغيرة)

## **واجهة برمجة تطبيقات RemoveCharactersByPosition**

### واجهة برمجة تطبيقات الويب

```http
PUT https://api.aspose.cloud/v4.0/cells/content/remove/characters
```

### **الأمان والمصادقة**

تُعد واجهات برمجة تطبيقات Aspose.Cells Cloud آمنة وتتطلب <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### **أكواد الخطأ**

- **200 OK** – تم تنفيذ الطلب بنجاح وعُاد الملف المعالج.
- **400 Bad Request**: رابط واجهة برمجة تطبيقات Aspose.Cells Cloud غير صالح.
- **401 Unauthorized**: رمز الوصول غير صالح أو معرّف العميل/سره غير صحيح.
- **404 Not Found**: ملف جدول العمل غير قابل للوصول.
- **500 Server Error**: واجه جدول العمل مشكلة أثناء جلب بيانات الحساب.

## **أين يجب استخدام واجهة برمجة تطبيقات Remove Characters by Position؟**

- **توحيد البيانات**: تنظيف رموز المنتجات (حذف الأصفار البادئة أو لاحقاتها)، و تنظيف أرقام الهواتف (حذف أكواد الدول)
- **استخراج النصوص**: استخراج المعلومات الأساسية من ملفات السجلات (حذف الطوابع الزمنية أو اللاحقات البادئة)
- **معالجة الملفات**: تنظيم أسماء الملفات (حذف اللاحقات البادئة الموحدة أو لاحقات التواريخ)
- **تحليل البيانات**: معالجة النصوص المنظمة (استخراج المحتوى بين الأقواس أو العلامات المحددة)
- **إدارة قواعد البيانات**: تنظيف البيانات المستوردة (حذف أحرف الرأس/الذيل ذات التنسيق الثابت)

## **لماذا يجب استخدام واجهة برمجة تطبيقات Remove Characters by Position؟**

- **دقة وكفاءة عالية**: يُحقّق الحذف المباشر حسب الموقع تجنب الحاجة إلى تعبيرات نمطية معقدة (Regular Expressions).
- **إعدادات مرنة**: تغطي خمسة أوضاع موضعية بالإضافة إلى خيار التمييز بين الأحرف الكبيرة والصغيرة مختلف السيناريوهات.
- **معالجة دُفعات (Batch Processing)**: تنظيف أعمدة كاملة في استدعاء واحد، مما يرفع الكفاءة بنسبة تصل إلى 10 أضعاف.
- **تحليل ذكي**: التعامل بسهولة مع استخراج المحتوى المحصور بين فاصلين.
- **مُيسّرة للمطورين**: توفر Aspose.Cells Cloud مكتبات (SDKs) متعددة اللغات، مما يسرّع التطوير ويقدّم وثائق شاملة. ومقارنةً ببناء منطق معالجة نصوص مخصصة، فإن هذا يقلّل بشكل كبير من جهد التطوير.
- **فعّالة من حيث التكلفة**: يمكن حذف الأحرف دون رفع ملف جدول العمل أولًا، مما يوفّر مساحة التخزين ويقلّل التكاليف.
