أدرج نصًا في خلايا إكسل متعددة في عملية واحدة. أضف بادئات أو لاحقات أو تصنيفات أو أحرف مخصصة في البداية أو النهاية أو قبل/بعد نص محدد داخل الخلايا باستخدام واجهة برمجة تطبيقات Aspose.Cells.

## نظرة عامة

إدراج جماعي في استدعاء واحد للبادئات أو اللاحقات أو السلاسل المُرتبطة بموقع معين داخل كل خلية في النطاق المستهدف — بدون صيغ، بدون أعمدة مساعدة.

- أدرج نصًّا مخصصًا في **أي موضع** داخل كل خلية

| القيمة            | الوصف                                                           |
| ---------------- | --------------------------------------------------------------------- |
| `None`           | استبدال المحتوى الأصلي                                          |
| `AtTheBeginning` | الإدراج في البداية (بادئة)                                              |
| `AtTheEnd`       | الإدراج في النهاية (لاحقة)                                                |
| `BeforeText`     | الإدراج **قبل** أول ظهور لـ `selectText`؛ تخطي إذا لم يُعثر عليه |
| `AfterText`      | الإدراج **بعد** أول ظهور لـ `selectText`؛ تخطي إذا لم يُعثر عليه  |

- أربعة أوضاع لموقع الإدراج: بادئة، لاحقة، قبل/بعد نص فرعي.
- تخطي الخلايا الفارغة لتجنب الفوضى.
- تُعالِج الواجهة فقط القيم من نوع **النص**؛ تُحوَّل القيم الرقمية والقيمة المنطقية والصيغ أولًا إلى نص.
- **الخلايا الفارغة**
  - `skipEmptyCells = true` → تُتخطَّى الخلايا الفارغة.
  - `skipEmptyCells = false` → يُضاف النص إلى الخلايا الفارغة (تصبح الخلية من نوع نص).

- **عدم وجود عنصر الارتباط**: عندما يكون `position = BeforeText | AfterText` ولا يحتوي النص المُحدد `selectText` على **أي** وجود، يبقى قيمة الخلية دون تغيير.

### **واجهة برمجة التطبيقات عبر الويب**

```http
PUT https://api.aspose.cloud/v4.0/cells/content/add/text
```

### **الأمان والمصادقة**

تُعدّ واجهات برمجة تطبيقات Aspose.Cells Cloud آمنة وتتطلب <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة مبنية على رمز JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### معلمات الطلب لواجهة برمجة التطبيقات **AddText** هي:

| اسم المعلمة | النوع | المسار / سلسلة الاستعلام / جسم HTTP | الوصف                                                                                                                                              | الإلزام |
| :------------- | :------ | :------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------- | :------- |
| Spreadsheet | ملف | FormData | ملف جدول البيانات المراد معالجته. تشمل التنسيقات المدعومة XLSX وXLS وODS وCSV وما إلى ذلك. | نعم |
| text | نص | Query | محتوى النص المراد إضافته إلى الخلايا المحددة في جدول البيانات. | نعم |
| position | نص | Query | يحدد مكان إضافة النص بالنسبة لمحتوى الخلية الحالي. الخيارات: `AtTheBeginning` و`AtTheEnd` و`BeforeText` و`AfterText` و`None`. | نعم |
| selectText | نص | Query | _(اختياري)_ إذا وُجِّد، يُضاف النص فقط إلى الخلايا التي تحتوي على هذه السلسلة الفرعية المحددة تمامًا. يُستخدم بالاقتران مع المعلمة `position`. | لا |
| skipEmptyCells | منطقي | Query | إذا كانت القيمة `true`، تُتخطَّى الخلايا الفارغة؛ وإذا كانت `false`، يُضاف النص إلى الخلايا الفارغة. | لا |
| worksheet | نص | Query | _(اختياري)_ اسم ورقة العمل التي سيتم إضافة النص إليها. وإذا حُذِف، يُطبَّق الإجراء على ورقة العمل الأولى افتراضيًا. | لا |
| range | نص | Query | _(اختياري)_ نطاق الخلايا التي سيتم إضافة النص إليها (مثل `"A1:C10"`). وإذا حُذِف، يُطبَّق الإجراء على جميع الخلايا المستخدمة في ورقة العمل المحددة. | لا |
| outPath | نص | Query | _(اختياري)_ مسار مجلد تخزين السحابة حيث سيُحفَظ ملف الحساب المُعالَج. وإذا حُذِف، يُحفَظ الملف في المجلد الأصلي. | لا |
| outStorageName | نص | Query | اسم تخزين السحابة الذي ستُحفَظ فيه الملف الناتج. | لا |
| region | نص | Query | _(اختياري)_ يعيّن الإعدادات الإقليمية لتنسيق الأرقام والتاريخ والعملة في الملف الناتج (مثل `"en-US"` و`"zh-CN"` و`"de-DE"`). | لا |
| password | نص | Query | _(اختياري)_ إذا كان ملف جدول البيانات المرفوع مُحميًا بكلمة مرور، فزود بكلمة المرور لفتح الملف ومعالجته. | لا |

**مثال باستخدام cURL**

```bash
curl -X PUT "https://api.aspose.cloud/v4.0/cells/content/add/text?text=Report&position=AtTheBeginning&skipEmptyCells=true" \
  -H "Authorization: Bearer {access_token}" \
  -F "Spreadsheet=@/path/to/workbook.xlsx" \
  -F "outPath=output/workbook_modified.xlsx"
```

### أكواد الأخطاء

| الكود | الوصف |
| ---- | ----------- |
| **400** طلب غير صالح | رابط واجهة برمجة تطبيقات Aspose.Cells Cloud غير صحيح أو معلمات مطلوبة مفقودة. |
| **401** غير مُعتمد | رمز وصول غير صالح أو معرّف عميل وسر غير صحيحين. |
| **404** غير موجود | ملف جدول البيانات غير قابل للوصول. |
| **500** خطأ في الخادم | واجه جدول البيانات تباينًا أثناء جلب بيانات الحساب. |

## أين نستخدم واجهة برمجة التطبيقات لإضافة نص لجداول البيانات؟

- **وضع تسميات ديناميكية للتقارير**: أضف عناوين ديناميكية أو علامات تواريخ أو ملاحظات إلى بيانات مالية وتقارير مبيعات تم توليدها تلقائيًا.
- **تغميز الملفات دفعة واحدة**: أضف شعارات الشركة أو علامات مائية لسرية المعلومات أو معلومات الإصدار إلى دفعة من ملفات إكسل.
- **ملء قوالب البيانات**: ملء أسماء العملاء والمبالغ وغيرها من النصوص تلقائيًا في المواقع المخصصة داخل قوالب العقود أو الفواتير.
- **وضع علامات تصنيف البيانات**: أضف تلقائيًا علامات تصنيف أو تصنيفات حالة (مثل "قيد المراجعة"، "تمت الموافقة") إلى صفوف البيانات استنادًا إلى نتائج التحليل.
- **توضيح جودة البيانات**: أضف ملاحظات حول البيانات ذات المشكلات أثناء تنظيف البيانات.
- **تنسيق النص دفعة واحدة**: أضف بادئات أو لاحقات موحدة لأسماء المنتجات أو العملاء.

## لماذا يجب استخدام واجهة برمجة التطبيقات لإضافة نص لجداول البيانات؟

- **إضافة نص دفعي**: أضف نصًّا إلى مئات الخلايا أو الملفات دفعة واحدة، مما يوفر ما يصل إلى 95٪ من الوقت مقارنة بالعمل اليدوي.
- **التحكم الدقيق في الموقع**: تدعم إضافة النص بدقة في ستة مواضع، بما في ذلك البداية والنهاية أو قبل/بعد نص محدد داخل الخلية.
- **معالجة ذكية مشروطة**: قرر ما إذا كان سيتم إضافة النص بناءً على ما إذا كانت الخلية فارغة أو تحتوي على نص محدد.
- **دعم استراتيجية المواضع المتعددة**:
  - `AtTheBeginning`: أضف نفس النص قبل محتوى جميع الخلايا المحددة.
  - `AtTheEnd`: أضف النص بعد محتوى جميع الخلايا المحددة.
  - `BeforeText` / `AfterText`: أضف النص قبل أو بعد الخلايا التي تحتوي على نص محدد فقط.
  - `None`: استبدال المحتوى الأصلي.
- **التحكم الدقيق في النطاق**: يسمح بتحديد ورقات عمل أو نطاقات خلايا محددة للعمليات.
- **خيار التخطي الشرطي**: يدعم تخطي الخلايا الفارغة لتجنب إضافة نص غير ضروري.
- **مُيسّرة للمطورين**: تُقدّم Aspose.Cells Cloud مكتبات SDK بلغات برمجة متعددة، مما يمكّن من تطوير سريع، وتُرفق معها وثائق شاملة. وبالمقارنة مع بناء حلول مخصصة لرسم الرسوم البيانية، فإن ذلك يقلل بشكل كبير من حجم العمل التطويري.
- **فعالة من حيث التكلفة**: يمكنك إلحاق نص في خلية دون رفع ملف الحساب أولاً، مما يوفر مساحة تخزين ويقلل التكاليف.
