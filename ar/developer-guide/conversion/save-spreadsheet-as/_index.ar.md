احفظ جدول بيانات سحابي أو ملف Excel بصيغة مختلفة في مساحة التخزين السحابية.

## **واجهة برمجة تطبيقات حفظ جدول البيانات بصيغة أخرى**

### واجهة برمجة التطبيقات عبر الويب

```http
PUT https://api.aspose.cloud/v4.0/cells/{name}/saveas
```

### **الأمان والمصادقة**

واجهات برمجة تطبيقات Aspose.Cells Cloud آمنة وتتطلب <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

### **معلمات الطلب**

| اسم المعلمة     | النوع    | الموقع | الوصف                                                                                       |
| :-------------- | :----- | :------- | :---------------------------------------------------------------------------------------- |
| name            | سلسلة | المسار   | **مطلوبة.** اسم ملف المصنف المراد تحويله.                                                |
| format          | سلسلة | الاستعلام | **مطلوبة.** الصيغة المطلوبة للإخراج (مثل `Xlsx`، `PDF`، `CSV`).                            |
| saveOptionsData | فئة   | الجسم   | بيانات خيارات الحفظ اختيارية. إذا تُركت فارغة، تُفترض القيمة الافتراضية `null`.             |
| folder          | سلسلة | الاستعلام | مسار المجلد اختياري حيث يتم تخزين المصنف المصدر. إذا تُرك فارغًا، تُفترض القيمة الافتراضية `null`. |
| storageName     | سلسلة | الاستعلام | اسم مساحة تخزين مخصصة اختيارية. إذا تُرك فارغًا، تُستخدم مساحة التخزين الافتراضية.           |
| outPath         | سلسلة | الاستعلام | مسار الإخراج اختياري للملف المحول. إذا تُرك فارغًا، تُفترض القيمة الافتراضية `null`.         |
| outStorageName  | سلسلة | الاستعلام | اسم مساحة التخزين اختياري للملف الناتج.                                                    |
| fontsLocation   | سلسلة | الاستعلام | موقع خطوط مخصص اختياري.                                                                    |
| region          | سلسلة | الاستعلام | إعداد المنطقة لجدول البيانات اختياري.                                                      |
| password        | سلسلة | الاستعلام | كلمة مرور اختيارية لفتح ملف جدول البيانات.                                                 |

**الصيغ المدعومة للإخراج**

| الصيغة   | الامتداد                                        |
| :------- | :----------------------------------------------- |
| Xlsx     | .xlsx                                            |
| Pdf      | .pdf                                             |
| Csv      | .csv                                             |
| Html     | .html                                            |
| Ods      | .ods                                             |
| Xls      | .xls                                             |
| Txt      | .txt                                             |
| Mhtml    | .mhtml                                           |
| Tiff     | .tiff                                            |
| Pptx     | .pptx                                            |
| … (المزيد) | راجع مواصفات واجهة برمجة التطبيقات للحصول على القائمة الكاملة (أكثر من 20 صيغة) |

### **الاستجابة**

```json
{
  "Code": 200,
  "Status": "OK"
}
```

**مثال على استجابة خطأ (400 طلب غير صالح)**

```json
{
  "Code": 400,
  "Message": "معلمات الطلب غير صالحة."
}
```

**رموز حالة HTTP**

| الرمز | المعنى                  | الوصف                                                           |
| ---- | --------------------- | ----------------------------------------------------------------- |
| 200  | ناجح                    | تم تطبيق الفلتر بنجاح؛ تحتوي الاستجابة على تفاصيل العملية.       |
| 400  | طلب غير صالح           | معلمات مفقودة أو غير صالحة (مثل نوع ملف غير مدعوم).              |
| 401  | غير مصرّح به           | رمز JWT غير صالح أو مفقود.                                        |
| 413  | حجم الحمولة كبير جدًا   | ملف التحميل يتجاوز الحد الأقصى للحجم.                              |
| 500  | خطأ داخلي في الخادم     | خطأ غير متوقع في الخادم.                                          |

## أين يجب عليك استخدام واجهة برمجة التطبيقات لحفظ جدول البيانات بصيغة أخرى؟

### نظام إدارة الوثائق المؤسسي

- حفظ تقارير مالية تلقائيًا كأرشيفات PDF.
- النسخ الاحتياطي المنتظم لبيانات المبيعات بصيغة CSV.
- حفظ خطط المشاريع كملفات للقراءة فقط لمنع التعديلات العرضية.

### عمليات دمج البيانات وعمليات ETL

- تصدير بيانات نظام إدارة علاقات العملاء وحفظها كقالب Excel قياسي.
- تحويل بيانات نظام تخطيط موارد المؤسسة إلى CSV لاستيرادها في أنظمة أخرى.
- حفظ البيانات الخام بصيغة JSON لنقلها عبر واجهة برمجة تطبيقات.

### سيناريوهات التطوير والأتمتة

- المعالجة الخلفية لتطبيقات الويب.
- أنظمة إنشاء التقارير الآلية.
- منصات التعاون السحابية.
- دمج عمليات الموافقة.
- النسخ الاحتياطي والترحيل للبيانات.

## لماذا يجب عليك استخدام واجهة برمجة التطبيقات لحفظ جدول البيانات بصيغة أخرى؟

- **سهلة الاستخدام للمطورين** – توفر SDKs للغات برمجة متعددة مع وثائق مفصلة، مما يُبسّط عملية الدمج.
- **موفرة للجهد** – تُنفَّذ عملية التحويل على الخادم، مما يقلل الحاجة إلى كتابة أكواد تحويل مخصصة.
- **تسعير حسب الاستخدام** – يتم الفوترة فقط مقابل استدعاءات واجهة برمجة التطبيقات التي تُنفَّذ، دون رسوم ترخيص مقدمة.
- **بدون صيانة خادم** – الخدمة تعمل في السحابة، مما يلغي الحاجة لإدارة بنية تحتية لعملية التحويل.
- **دعم واسع للصيغ** – يدعم التحويل بين أكثر من 20 صيغة لجدول البيانات.
- **الحفاظ على دقة البيانات** – يحافظ على التخطيط والصيغ والتنسيق أثناء التحويل.

## كيف تستخدم واجهة برمجة التطبيقات لحفظ جدول البيانات بصيغة أخرى باستخدام SDKs؟

### مواصفات واجهة برمجة تطبيقات حفظ جدول البيانات بصيغة أخرى

تُعرّف [مواصفات واجهة برمجة تطبيقات حفظ جدول البيانات بصيغة أخرى](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Conversion/SaveSpreadsheetAs) واجهة برمجة تطبيقات عامة قابلة للوصول، مما يسمح لك بإجراء تفاعلات REST مباشرة من متصفح ويب.

**مثال مع جسم الطلب وcURL**

يمكنك استخدام أداة سطر الأوامر cURL للوصول بسهولة إلى خدمات الويب الخاصة بـ Aspose.Cells. يوضح المثال التالي كيفية إجراء مكالمات لواجهة برمجة التطبيقات السحابية باستخدام cURL.

     -H "Content-Type: application/json" \
