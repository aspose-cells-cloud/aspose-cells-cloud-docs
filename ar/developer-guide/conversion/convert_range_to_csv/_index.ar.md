## تحويل النطاق إلى CSV باستخدام خدمات Aspose.Cells Cloud الويبية

تقوم هذه العملية بقراءة ملف جدول بيانات من نظام الملفات المحلي، وتحويل النطاق المُحدّد إلى تنسيق CSV، ثم إعادة النتيجة المحولة مباشرةً. وتُنفَّذ العملية بالكامل على خادوم السحابة، لذا لا يتطلّب الأمر رفعاً وسيطاً إلى مساحة التخزين السحابية. وتدعم الواجهة بارامترات اختيارية مثل الخطوط المخصّصة، ضبط تلقائي لحجم الصفوف/الأعمدة، إعدادات الإقليم/اللغة، وجدولت العمل المحمية بكلمة مرور.

### نقطة نهاية واجهة برمجة التطبيقات الويبية

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/range/csv
```

### **الأمان والمصادقة**

واجهات برمجة تطبيقات Aspose.Cells Cloud آمنة وتحتاج إلى <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

### بارامترات الطلب

| اسم البارامتر | النوع | المسار/سلسلة الاستعلام/جسم الـ HTTP | الوصف |
|----------------|---------|-----------------------------|------------------------------------------------------------------------|
| Spreadsheet | ملف | FormData | رفع ملف جدول البيانات. |
| worksheet | نص | استعلام | اسم ورقة العمل في جدول البيانات. **إلزامي**. |
| range | نص | استعلام | منطقة الخلايا. مثال: `A1:C10`. **إلزامي**. |
| outPath | نص | استعلام | (اختياري) مسار المجلد الذي يُخزَّن فيه جدول العمل. القيمة الافتراضية هي null. |
| outStorageName | نص | استعلام | اسم مساحة التخزين للملف الناتج. |
| fontsLocation | نص | استعلام | استخدام خطوط مخصّصة. |
| AutoRowsFit | منطقي | استعلام | (اختياري) ضبط تلقائي لحجم جميع الصفوف في أوراق العمل. |
| AutoColumnsFit | منطقي | استعلام | (اختياري) ضبط تلقائي لحجم جميع الأعمدة في أوراق العمل. |
| region | نص | استعلام | إعدادات إقليم/لغة جدول البيانات (مثل `en-US`، `fr-FR`). تؤثّر على تنسيق الأرقام، وتفسير التواريخ، والسلوك المرتبط بالإقليم. |
| password | نص | استعلام | كلمة المرور لفتح ملف جدول البيانات. |

### بارامترات جسم الطلب

| اسم البارامتر | النوع | الوصف |
| -------------- | ---- | ----------- |
| None | N/A | لا توجد بارامترات في جسم الطلب. |

### **الاستجابة**

```json
{
  "ResponseFile": "تدفق ملف ثنائي (محتوى CSV)"
}
```

**رموز حالة الاستجابة**

| الرمز | المعنى | الوصف |
|------|---------|-------------|
| 200 | ناجح | تم تحويل النطاق بنجاح وتمت إعادة ملف CSV في جسم الاستجابة. |
| 400 | طلب غير صالح | عنوان URL غير صحيح أو نقص بارامترات إلزامية. |
| 401 | غير مصادق عليه | فشلت المصادقة أو لم تُوفَّر بيانات اعتماد. |
| 413 | حجم الحمولة كبير جداً | تجاوز حجم جسم الطلب الحد المسموح به. |
| 500 | خطأ داخلي في الخادوم | واجه جدول البيانات مشكلة أثناء جلب بيانات التحويل. |

## كيفية استخدام تحويل النطاق إلى CSV باستخدام مكتبات التطوير (SDKs)

### مواصفات تحويل النطاق إلى CSV

تُعرّف <a href="https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Conversion/ConvertRangeToCsv" rel="noopener noreferrer">مواصفات واجهة برمجة تطبيقات تحويل النطاق إلى CSV</a> واجهة برمجة قابلة للوصول من خارجياً، وتتيح لك إجراء تفاعلات REST مباشرة من متصفح ويب.

يمكنك استخدام أداة سطر الأوامر cURL للوصول إلى خدمات الويب الخاصة بـ Aspose.Cells بسهولة. يُظهر المثال التالي كيفية إجراء مكالمات لواجهة برمجة التطبيقات السحابية باستخدام cURL.

{{< tabs tabTotal="2" tabID="1" tabName1="الطلب" tabName2="الاستجابة" >}}

{{< tab tabNum="1" >}}

```bash
# استخدام HTTPS لتوصيل آمن
curl -v "https://api.aspose.cloud/v4.0/cells/convert/range/csv?worksheet=Sheet1&range=A1:C10&outPath=outputFolder&outStorageName=MyStorage&fontsLocation=/custom/fonts&AutoRowsFit=true&AutoColumnsFit=true&region=en-US&password=MyPassword" \
  -X PUT \
  -H "Content-Type: multipart/form-data" \
  -H "Accept: application/octet-stream" \
  -H "Authorization: Bearer <jwt token>" \
  -F 'Spreadsheet=@sample.xlsx'
```
