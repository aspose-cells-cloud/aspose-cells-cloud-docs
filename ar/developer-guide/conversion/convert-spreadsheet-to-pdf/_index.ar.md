ينهي_endpoint_ **ConvertSpreadsheetToPdf** قراءة ملف جدول البيانات المرفوع من محرك أقراص محلي، ومعالجته على خادم Aspose.Cells Cloud، ثم إرجاع مستند PDF الناتج كدفق ثنائي. يلغي هذا التحويل السحابي الحاجة إلى رفع ملف المصدر إلى التخزين، ويقلل من استهلاك الموارد، ويُبسّط سير العمل من خلال تسليم ملف PDF مباشرةً إلى العميل. تعتمد التنسيقات المدعومة على المكتبات الأساسية؛ وتتحقق الواجهة من وجود الملف وأذوناته وسلامة التحويل، وتُطلق أكواد HTTP مناسبة للأخطاء الناتجة عن المدخلات غير الصالحة أو فشل المعالجة.

## **واجهة API لتحويل جدول البيانات إلى PDF**

### واجهة الويب

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/spreadsheet/pdf
```

### **الأمن والمصادقة**

تُعدّ واجهات برمجة تطبيقات Aspose.Cells Cloud آمنة وتتطلب <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

### **معاملات الطلب:**

| اسم المعامل | النوع | الموقع | إلزامي/اختياري | الوصف                                                                                                                                                                                    |
| :---------- | :----- | :------- | :---------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| جدول البيانات | ملف | FormData | إلزامي | ملف جدول البيانات المصدر (XLS أو XLSX أو CSV، إلخ) المراد تحويله. يجب أن يكون ملفًا صالحًا وقابلًا للقراءة؛ وأقصى حجم مسموح به هو 100 ميغا بايت. مثال: `myWorkbook.xlsx`.                                        |
| outPath | نص | استعلام | اختياري | مسار مجلد الوجهة الذي سيتم حفظ ملف PDF المحول فيه على الخادم (إن أردت الحفظ). وفي حال إهماله، يُعاد الملف مباشرةً في الاستجابة. مثال: `/output/reports/`. |
| outStorageName | نص | استعلام | اختياري | اسم خدمة التخزين المستهدفة (مثل `MyCloudStorage`). مطلوب فقط عند استخدام `outPath` وعدم كون التخزين الافتراضي هو الوجهة.                                                          |
| fontsLocation | نص | استعلام | اختياري | مسار مجلد خطوط مخصصة على الخادم لضمان عرض النصوص بشكل صحيح في ملف PDF. مثال: `/fonts/custom/`.                                                                             |
| region | نص | استعلام | اختياري | إعدادات إقليم/لغة جدول البيانات (مثل `en-US` أو `fr-FR`). تؤثر على تنسيق الأرقام وتحليل التواريخ والسلوك المتعلق بالإعدادات المحلية.                                                        |
| password | نص | استعلام | اختياري | كلمة المرور المطلوبة لفتح جدول البيانات المحمي. تُتجاهل في حال لم يكن الملف مشفرًا.                                                                                                          |

### **الاستجابة**

استجابة ناجحة (200 OK)  
نوع المحتوى: application/pdf  
تصرّف المحتوى: attachment; filename="converted.pdf"  
طول المحتوى: `<الحجم بالبايت>`

الجسم: دفق ثنائي لملف PDF المُولّد

**أكواد حالة HTTP**

| الكود | المعنى | الوصف |
| ---- | --------------------- | ----------------------------------------------------------------- |
| 200 | OK (نجاح) | تم تطبيق الفلتر بنجاح؛ تحتوي الاستجابة على تفاصيل العملية. |
| 400 | طلب غير صالح | معاملات مفقودة أو غير صالحة (مثل نوع ملف غير مدعوم). |
| 401 | غير مُصادق عليه | رمز JWT غير صالح أو مفقود. |
| 413 | حملة كبيرة جدًا | حجم ملف المرفقات يتجاوز الحد المسموح. |
| 500 | خطأ داخلي في الخادم | خطأ غير متوقع في الخادم. |

## أين ينبغي استخدام واجهة API لتحويل جدول البيانات إلى PDF؟

- **أنابيب توليد التقارير الآلية** – تحويل تقارير Excel التي تُولّد يوميًا إلى PDF لأغراض الأرشفة أو التوزيع عبر البريد الإلكتروني دون الحاجة إلى خطوات يدوية.
- **أنظمة إدارة المستندات** – حفظ ملفات PDF مباشرة في نظام إدارة المستندات بعد التحويل، مع الاحتفاظ بجدول البيانات الأصلي على جانب العميل فقط.
- **تطبيقات الويب مع التصدير الفوري** – السماح للمستخدمين النهائيين بتنزيل نسخة PDF من جدول البيانات الذي يحررونه داخل المتصفح، مع الاستفادة من التحويل السحابي للحفاظ على التنسيق.
- **الامتثال للوائح التنظيمية** – إنشاء لقطات PDF ثابتة لجداول البيانات المالية لأغراض التدقيق، مع التأكد من أن ملف المصدر لا يغادر بيئة العميل أبدًا.
- **سير العمل للتحويل بين التنسيقات المختلفة** – الجمع بين نقاط نهاية تحويل أخرى مثل [واجهة API لتحويل جدول البيانات إلى CSV](/convert-spreadsheet-to-csv/) لإنشاء أرشيفات متعددة التنسيقات.

## لماذا ينبغي استخدام واجهة API لتحويل جدول البيانات إلى PDF؟

- **سير عمل لا يتطلب رفع الملف أولاً** – لا حاجة لرفع ملف المصدر إلى التخزين السحابي؛ يتم التحويل مباشرةً من الدفق المرفوع، مما يوفر النطاق الترددي وتكاليف التخزين.
- **عرض عالي الجودة والدقة** – تحافظ Aspose.Cells على الصيغ المعقدة والرسوم البيانية والتنسيق عند التحويل إلى PDF، بحيث يطابق إخراج Excel على سطح المكتب.
- **تنفيذ قابل للتوسّع على السحابة** – تستفيد من البنية التحتية السحابية لـ Aspose لتقديم تحويل سريع وموثوق بغض النظر عن عتاد العميل.
- **واجهة REST بسيطة** – طلب `PUT` واحد مع معاملات اختيارية في سلسلة الاستعلام؛ وتُعيد دفق PDF جاهزًا للتنزيل، مما يجعل التكامل سهلًا في أي لغة برمجة.

```bash
  -o converted.pdf
```
