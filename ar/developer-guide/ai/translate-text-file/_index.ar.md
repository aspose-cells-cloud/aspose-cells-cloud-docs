تستخدم نقطة النهاية **TranslateTextFile** خدمات الذكاء الاصطناعي الخاصة بـ Aspose.Cells Cloud لترجمة محتوى ملف نصي إلى لغة مستهدفة محددة. وتدعم هذه النقطة وضعَي التشغيل: (1) **وضع رفع الملف** – إرسال ملف نصي عبر multipart/form-data والحصول على ملف مُترجَم؛ (2) **وضع المحتوى المباشر** – نشر نص خام في جسم الطلب والحصول على النص المُترجَم مباشرةً. تحافظ الخدمة على فواصل الأسطر الأصلية والتنسيق، وتُلحِق تلقائيًا لاحقة "_translated" باسم الملف، وتعيد النتيجة كدفق قابل للتنزيل. مثالية لترجمة المستندات دفعة واحدة، أو دمجها في سير عمل متعدد اللغات، أو ترجمة المحتوى الذي يُنشئه المستخدمون في الوقت الفعلي.

## **واجهة ترجمة ملف نصي**

### واجهة الويب API

```http
PUT https://api.aspose.cloud/v4.0/cells/ai/translate/text-file
```

### **معلمات الطلب:**

| اسم المعلمة | النوع | الموقع | إلزامي/اختياري | الوصف                                                                                                                                                                                                                                                                                 |
| :----------- | :----- | :------- | :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet | ملف | مطلوبة | FormData | الملف النصي المصدر المراد ترجمته. يجب أن يكون ملف نصي عادي (.txt) أو تنسيق جدول بيانات مدعوم. مثال: رفع `document.txt` عبر حقل multipart/form-data يُسمّى "file".                                                                                                                  |
| targetLanguage | سلسلة نصية | مطلوبة | Query | رمز اللغة المستهدفة وفق معيار ISO-639-1 (مثل "es" للإسبانية، "fr" للفرنسية، "de" للألمانية). الرمز غير حساس لحالة الأحرف.                                                                                                                                                       |
| region | string | اختيارية | Query | معرّف منطقة جدول البيانات، الذي يؤثر في التنسيق المُعتمد على التهيئة الإقليمية مثل التواريخ والأرقام والعملات. القيم الشائعة: "US" و"EU" و"CN". وفي حال عدم تحديده، تُستخدم إعدادات المنطقة الأصلية لورقة العمل.                                                             |
| password | سلسلة نصية | اختيارية | Query | كلمة المرور المطلوبة لفتح ملفات جداول البيانات المشفرة. غير مطلوبة للملفات النصية العادية.                                                                                                                                                                                       |

### **الاستجابة**

استجابة ناجحة (200 OK)
الرؤوس:
Content-Type: application/octet-stream // دفق ثنائي يحتوي على الملف المُترجَم
Content-Disposition: attachment; filename="<original_name>\_translated.txt"
Content-Length: <الحجم بالبايت>

الجسم: دفق ثنائي يحتوي على النص المُترجَم مع الحفاظ على فواصل الأسطر الأصلية والتنسيق.

**رموز حالة HTTP**

| الرمز | المعنى              | الوصف                                                             |
| ---- | ------------------- | ----------------------------------------------------------------- |
| 200  | OK (نجاح)          | تطبيق المرشح بنجاح؛ الاستجابة تحتوي على تفاصيل العملية.          |
| 400  | Bad Request (طلب غير صالح) | معلمات ناقصة أو غير صحيحة (مثل نوع ملف غير مدعوم).              |
| 401  | Unauthorized (غير مصرّح)    | رمز JWT غير صحيح أو ناقص.                                         |
| 413  | Payload Too Large (حمولة كبيرة جدًا) | تجاوز حجم الملف المرفوع الحد المسموح به.                        |
| 500  | Internal Server Error (خطأ داخلي في الخادم) | خطأ غير متوقع في الخادم.                                        |

## أين يجب استخدام واجهة ترجمة ملف نصي؟

- **بوابات الوثائق متعددة اللغات** – ترجمة أدلة المستخدم أو ملفات المساعدة تلقائيًا عند رفعها كمستندات نصية، وتقديم إصدارات مُترجَمة حسب الطلب.
- **أنظمة إدارة المحتوى (CMS)** – دمجها في سير عمل CMS لترجمة منشورات المدونات أو المقالات قبل نشرها للجمهور الدولي.
- **خطوط أنابيب البيانات المؤسسية** – استخدامها في مهام الدفعات التي تعالج كميات كبيرة من تقارير CSV أو TXT، وتحويلها إلى لغة المكاتب الإقليمية مع الحفاظ على التنسيق الأصلي.
- **منصات دعم العملاء** – ترجمة التذاكر أو سجلات الدردشة النصية الواردة في الوقت الفعلي لمساعدة وكلاء الدعم العاملين بلغات مختلفة.

## لماذا يجب استخدام واجهة ترجمة ملف نصي؟

- **دقة مدفوعة بالذكاء الاصطناعي** – تستخدم نماذج ترجمة عصبية حديثة لتوليد مخرجات طبيعية وذات سياق دقيق.
- **مرونة في المدخلات المزدوجة** – تقبل كل من رفع الملفات ونُشر المحتوى النصي الخام، مما يبسّط التكامل مع تطبيقات العميل المتنوعة.
- **الحفاظ على التصميم الأصلي** – تحافظ على فواصل الأسطر والمسافات البادئة والأحرف الخاصة، ما يلغي الحاجة إلى تنظيف يدوي بعد الترجمة.
- **معالجة سلسة للملفات** – تعيد ملفًا جاهزًا للتنزيل مع لاحقة "_translated" تُولّد تلقائيًا، مما يقلل من تعقيد كود جانب العميل.
