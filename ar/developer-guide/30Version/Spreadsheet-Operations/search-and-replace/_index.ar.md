تعتبر عمليات التعامل مع النصوص في ملفات إكسل عمليات معقدة. وتُسهم عوامل عديدة في هذه التعقيدات، ويجب أخذها بعين الاعتبار أثناء المعالجة. توفر Aspose.Cells Cloud طريقة موثوقة للبحث عن النص واستبداله عبر تنسيقات جداول البيانات المختلفة.

غالبًا ما يتطلب التعامل مع النص في كتب عمل إكسل تحديد سلاسل نصية محددة وتحديثها عبر أوراق عمل متعددة. وتُبسّط واجهة برمجة تطبيقات Aspose.Cells Cloud هذه المهمة من خلال تقديم عملية **بحث واستبدال** موحدة تعمل مع أي تنسيق جداول بيانات مدعوم.

## نظرة عامة

تتيح ميزة البحث والاستبدال تحديد السلاسل النصية المحددة داخل كتاب عمل أو ورقة عمل معيّنة واستبدالها بقيم جديدة. وتعمل هذه العملية مع جميع التنسيقات المدعومة من Aspose.Cells Cloud، مثل **XLS وXLSX وXLSM وXLSB وODS وCSV** وغير ذلك. وباستخدام ميزة **البحث والاستبدال**، يمكنك تنظيف البيانات بسرعة، أو تصحيح الأخطاء الإملائية المتكررة، أو تطبيق اصطلاحات تسمية جماعية عبر كتاب عمل بأكمله.

## المتطلبات المسبقة

- حساب نشط على Aspose.Cloud مع **Client‑Id** و**Client‑Secret** سارين.
- رمز وصول تم الحصول عليه عبر عملية مصادقة OAuth 2.0.
- يجب تخزين كتاب العمل المستهدف في وحدة التخزين السحابية لـ Aspose أو جعله متاحًا عبر رابط عام.
- تثبيت حزمة SDK المطلوبة (مثل Aspose.Cells‑Cloud لـ .NET أو Java أو Python).

## مرجع واجهة برمجة التطبيقات

**الطريقة:** `POST`  
**النقطة الطرفية**

```
POST https://api.aspose.cloud/v3.0/cells/{fileName}/searchreplace
```

| المعلمة          | النوع   | الإلزام | الوصف                                                                              |
| ----------------- | ------- | ------- | ---------------------------------------------------------------------------------- |
| `fileName`        | string  | نعم     | اسم كتاب العمل (مع امتداد الملف).                                                  |
| `folder`          | string  | لا      | مسار المجلد في وحدة التخزين السحابية.                                              |
| `storage`         | string  | لا      | اسم وحدة التخزين في حال عدم استخدام الافتراضية.                                   |
| `sheetName`       | string  | لا      | اسم ورقة العمل المحددة؛ وفي حال حذفها، تُطبّق العملية على كتاب العمل كاملاً.      |
| `searchString`    | string  | نعم     | النص المراد البحث عنه.                                                              |
| `replaceString`   | string  | نعم     | النص المستبدل بالتطابقات التي يتم العثور عليها.                                   |
| `ignoreCase`      | boolean | لا      | ضبطها على `true` لإجراء بحث لا يُراعي حالة الأحرف.                                 |
| `matchWholeCell`  | boolean | لا      | ضبطها على `true` لاستبدال التطابقات الكاملة فقط داخل الخلية.                      |

**الرؤوس**

- `Authorization: Bearer {access_token}`
- `Content-Type: application/json`

**جسم الطلب (JSON)**

```json
{
  "searchString": "OldValue",
  "replaceString": "NewValue",
  "ignoreCase": false,
  "matchWholeCell": false,
  "sheetName": "Sheet1"
}
```

**الاستجابة الناجحة (JSON)**

```json
{
  "status": "OK",
  "replacedCount": 3,
  "updatedFileUrl": "https://api.aspose.cloud/v3.0/storage/file/updatedWorkbook.xlsx"
}
```

## أمثلة للكود

فيما يلي أمثلة مبسطة لثلاث حزم SDK شائعة. استبدل `{clientId}` و`{clientSecret}` وباقي العناصر النائبة بقيمك الفعلية. وتُظهر هذه الأمثلة كيفية تنفيذ عملية **بحث واستبدال** برمجيًا.

## معالجة الأخطاء والحالات الاستثنائية

| رمز HTTP | المعنى                                           | الإجراء الموصى به                                                       |
| -------- | ------------------------------------------------ | ----------------------------------------------------------------------- |
| 400      | طلب غير صالح – معلمات مفقودة أو غير صحيحة      | تحقق من الحقول الإلزامية وأنواع البيانات.                             |
| 401      | غير مصرّح – رمز وصول غير صالح أو منتهٍ          | قم بتحديث رمز الوصول.                                                  |
| 404      | غير موجود – كتاب العمل أو ورقة العمل غير موجود  | تحقق من اسم الملف ومسار المجلد و`sheetName`.                           |
| 415      | نوع وسائط غير مدعوم – تنسيق ملف غير صالح       | تأكد من أن الملف المرفوع بصيغة إكسل أو CSV مدعومة.                   |
| 202      | تم القبول – تم قبول الطلب للمعالجة              | راجع حالة العملية إذا تم استخدام المعالجة غير المتزامنة.             |
| 204      | لا محتوى – نجحت العملية دون إرجار محتوى        | تمت تطبيق الاستبدال؛ ولا تُعاد بيانات إضافية.                        |
| 500      | خطأ داخلي في الخادم – فشل غير متوقع             | أعد المحاولة بعد تأخير قصير؛ واتصل بدعم Aspose في استمرار المشكلة.   |

**ملاحظات:**  
- قد تتجاوز كتب العمل الكبيرة حدود حجم الطلب؛ لذا فضّل رفع الملف إلى وحدة التخزين السحابية أولًا.  
- عندما تُضبط `ignoreCase` على `true`، فكّر في أن تعيينات حالة الأحرف المُتعلقة باللغة المحلية قد تؤثر في النتائج.  
- استخدام `matchWholeCell` مع الصيغ لن يؤدي إلى استبدال التطابقات الجزئية داخل نص الصيغة.
