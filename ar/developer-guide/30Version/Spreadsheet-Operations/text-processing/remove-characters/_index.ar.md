## إزالة الأحرف من واجهة ويب Excel

مجموعة شاملة من الأدوات لتنظيف محتوى النص داخل الخلايا المحددة. تقوم واجهة برمجة التطبيقات بإزالة أحرف محددة أو مجموعات أحرف مُعرّفة مسبقًا أو سلاسل فرعية، مما يضمن أن نصوص أوراق العمل معيارية وخالية من الرموز غير المرغوب فيها.

**متطلبات مسبقة**

- حساب نشط على Aspose Cloud.  
- رمز وصول JWT صالح تم الحصول عليه كما هو موضح في دليل المصادقة.  
- يجب رفع ملف Excel إلى التخزين قبل استدعاء هذه النقطة النهائية (endpoint).  
- تنسيقات الملفات المدعومة تشمل `.xlsx`، `.xls`، `.xlsm`، وأنواع Excel الشائعة الأخرى.

```http
POST https://api.aspose.cloud/v3.0/cells/removecharacters
```

### **الأمان والمصادقة**

تستخدم واجهات برمجة تطبيقات Aspose.Cells Cloud آليات أمان وتتطلب <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

### وصف الوظيفة

- **إزالة أحرف مخصصة** – حدد أي أحرف ترغب في حذفها. أدخل كل حرف في حقل _إزالة الأحرف المخصصة_؛ وستقوم واجهة برمجة التطبيقات بحذف كل ظهور لتلك الأحرف في الخلايا المحددة.  
- **إزالة مجموعات الأحرف** – اختر من المجموعات المُعرّفة مسبقًا:  
  - **الأحرف غير القابلة للطباعة** – تحذف فواصل الأسطر وأول 32 حرفًا غير قابلة للطباعة من ASCII (0–31) بالإضافة إلى رموز إضافية (127، 129، 141، 143، 144، 157).  
  - **أحرف النص** – تحذف كل الحروف الأبجدية.  
  - **أحرف الأرقام** – تحذف كل الأرقام.  
  - **الرموز** – تحذف الرموز الرياضية والهندسية والتقنية ورموز العملات وأحرف مشابهة مثل “؟” و “1” و “™”.  
  - **علامات الترقيم** – تحذف كل علامات الترقيم.  
- **إزالة سلسلة فرعية** – تحذف أي سلسلة فرعية محددة (مثل كلمة) من الخلايا المحددة.

### معاملات الطلب

| اسم المعامل            | النوع  | الموقع | الوصف                                                                           |
| ----------------------- | ----- | ------ | ------------------------------------------------------------------------------- |
| removeCharactersOptions | فئة   | الجسم | خيارات تُعرّف الأحرف أو مجموعات الأحرف أو السلاسل الفرعية المراد إزالتها.      |

**مخطط `removeCharactersOptions`**

| الخاصية          | النوع    | الإجباري | الوصف                                                                                               |
| ----------------- | -------- | -------- | ---------------------------------------------------------------------------------------------------- |
| Range             | سلسلة   | نعم      | تدوينة A‑1 أو اسم النطاق الذي يُحدّد الخلايا المراد معالجتها (مثل `"A1:C10"`).                     |
| CustomCharacters  | سلسلة   | لا       | سلسلة تحتوي على كل حرف مخصص لحذفه (مثل `"@#$"`).                                                    |
| CharacterSet      | سلسلة   | لا       | قيمة تعداد تُحدّد مجموعة مُعرّفة مسبقًا (`"NonPrinting"`، `"Text"`، `"Numeric"`، `"Symbols"`، `"Punctuation"`). |
| Substring         | سلسلة   | لا       | السلسلة الفرعية الدقيقة المراد إزالتها (مثل `"USD"`).                                               |
| IgnoreCase        | منطقي   | لا       | عند القيمة `true`، تتم إزالة الأحرف دون مراعاة حالة الأحرف (case-insensitive).                      |

**مثال لجسم الطلب بصيغة JSON**

```json
{
  "Range": "A1:B20",
  "CustomCharacters": "@#$",
  "CharacterSet": "NonPrinting",
  "Substring": "USD",
  "IgnoreCase": true
}
```

**مثال على طلب cURL**

```bash
curl -X POST "https://api.aspose.cloud/v3.0/cells/removecharacters" \
     -H "Authorization: Bearer {access_token}" \
     -H "Content-Type: application/json" \
     -d '{
           "Range": "A1:B20",
           "CustomCharacters": "@#$",
           "CharacterSet": "NonPrinting",
           "Substring": "USD",
           "IgnoreCase": true
         }'
```

### **الاستجابة**

```json
{
    "Status" : "OK",
    "Code" : 200,
    "Filename" : "[اسم الملف المدمج]",
    "Filesize" : [حجم الملف],
    "FileContent" : "[Base64String]"
}
```

**رموز حالة HTTP**

| الرمز | المعنى                      | الوصف                                                                 |
|-------|-----------------------------|------------------------------------------------------------------------|
| 200   | ناجح (OK)                   | تم تطبيق الفلتر بنجاح؛ تحتوي الاستجابة على تفاصيل العملية.           |
| 400   | طلب غير صحيح (Bad Request)  | معاملات ناقصة أو غير صحيحة (مثل نوع ملف غير مدعوم).                 |
| 401   | غير مُصادَق (Unauthorized)   | رمز JWT غير صالح أو مفقود.                                           |
| 413   | حمل البيانات كبير جدًا (Payload Too Large) | ملف مُرفَع يتجاوز الحد الأقصى للحجم.                               |
| 500   | خطأ داخلي في الخادم (Internal Server Error) | خطأ غير متوقع في الخادم.                                           |
