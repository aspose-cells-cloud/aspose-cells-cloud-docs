تقدم واجهة برمجة تطبيقات Aspose.Cells Cloud نقاط نهاية دفعية تسمح لك بتنفيذ عمليات شائعة على ملفات إكسل متعددة في طلب واحد. فيما يلي نظرة سريعة على العمليات الدفعية المتاحة مع مواصفات موجزة لواجهة برمجة التطبيقات لكل منها.

- **["تحويل دفعات من ملفات إكسل"](https://docs.aspose.cloud/cells/batch/convert "تحويل دفعات من ملفات إكسل")**  
  *حوّل ملفات إكسل متعددة إلى تنسيق إخراج مختار في طلب واحد.*  

  **تفاصيل واجهة برمجة التطبيقات**  
  ```http
  POST /cells/batch/convert
  Content-Type: multipart/form-data
  Authorization: Bearer {access_token}
  ```  

  **المُعاملات**  

  | الاسم          | النوع     | الوصف                                    |
  |---------------|----------|--------------------------------------------|
  | files         | file[]   | ملف إكسل واحد أو أكثر ليتم تحويله.        |
  | outputFormat  | string   | تنسيق الإخراج المرغوب (مثل pdf، csv، html). |
  | storage       | string   | (اختياري) اسم وحدة التخزين السحابية.       |

  **الاستجابات**  

  | الرمز | الوصف                                   |
  |------|-------------------------------------------|
  | 200  | تمت عملية التحويل بنجاح؛ تُعيد الملفات.   |
  | 400  | معاملات غير صالحة تم تزويدها.             |
  | 401  | غير مصرّح به – ناقص أو غير صالح لرمز الوصول. |
  | 500  | خطأ داخلي في الخادم.                      |

- **["قفل دفعات من ملفات إكسل"](https://docs.aspose.cloud/cells/batch/lock "قفل دفعات من ملفات إكسل")**  
  *طبّق قفلًا بكلمة مرور على ملفات إكسل متعددة في وقت واحد.*  

  **تفاصيل واجهة برمجة التطبيقات**  
  ```http
  POST /cells/batch/lock
  Content-Type: application/json
  Authorization: Bearer {access_token}
  ```  

  **المُعاملات**  

  | الاسم     | النوع   | الوصف                              |
  |----------|---------|-------------------------------------|
  | files    | array   | قائمة بمُعرّفات الملفات أو عناوين URLs. |
  | password | string  | كلمة المرور لقفل كتب العمل بها.    |
  | storage  | string  | (اختياري) اسم وحدة التخزين السحابية. |

  **الاستجابات**  

  | الرمز | الوصف                                   |
  |------|-------------------------------------------|
  | 200  | تم قفل الملفات بنجاح.                    |
  | 400  | معاملات مفقودة أو غير صالحة.             |
  | 401  | وصول غير مصرّح به.                       |
  | 500  | خطأ في الخادم.                           |

- **["حماية دفعات من ملفات إكسل"](https://docs.aspose.cloud/cells/batch/protect "حماية دفعات من ملفات إكسل")**  
  *أضف إعدادات الحماية (مثل القراءة فقط، البنية) إلى كتب عمل متعددة.*  

  **تفاصيل واجهة برمجة التطبيقات**  
  ```http
  POST /cells/batch/protect
  Content-Type: application/json
  Authorization: Bearer {access_token}
  ```  

  **المُعاملات**  

  | الاسم          | النوع   | الوصف                                          |
  |---------------|---------|------------------------------------------------|
  | files         | array   | قائمة بمُعرّفات الملفات أو عناوين URLs.        |
  | protection    | object  | خيارات الحماية (مثل readOnly، structure).     |
  | storage       | string  | (اختياري) اسم وحدة التخزين السحابية.           |

  **الاستجابات**  

  | الرمز | الوصف                                   |
  |------|-------------------------------------------|
  | 200  | تمت تطبيق الحماية بنجاح.                  |
  | 400  | بيانات الطلب غير صالحة.                   |
  | 401  | فشل المصادقة.                             |
  | 500  | خطأ غير متوقع في الخادم.                  |

- **["تقسيم دفعات"](https://docs.aspose.cloud/cells/batch/split "تقسيم دفعات")**  
  *قسّم كتب عمل إكسل كبيرة إلى ملفات أصغر استنادًا إلى أوراق العمل أو نطاقات الصفوف.*  

  **تفاصيل واجهة برمجة التطبيقات**  
  ```http
  POST /cells/batch/split
  Content-Type: application/json
  Authorization: Bearer {access_token}
  ```  

  **المُعاملات**  

  | الاسم        | النوع   | الوصف                                      |
  |-------------|---------|---------------------------------------------|
  | files       | array   | الملفات المراد تقسيمها.                     |
  | splitBy     | string  | المعيار: "worksheet" أو "rowRange".          |
  | criteria    | object  | التفاصيل الخاصة بطريقة التقسيم المختارة.   |
  | storage     | string  | (اختياري) اسم وحدة التخزين السحابية.        |

  **الاستجابات**  

  | الرمز | الوصف                                   |
  |------|-------------------------------------------|
  | 200  | تمت عملية التقسيم بنجاح؛ تُعيد الأجزاء.    |
  | 400  | معاملات تقسيم غير صحيحة.                  |
  | 401  | طلب غير مصرّح به.                         |
  | 500  | خطأ أثناء المعالجة.                        |

- **["فك قفل دفعات"](https://docs.aspose.cloud/cells/batch/unlock "فك قفل دفعات")**  
  *أزل الحماية بكلمة المرور من ملفات إكسل متعددة في استدعاء واحد.*  

  **تفاصيل واجهة برمجة التطبيقات**  
  ```http
  POST /cells/batch/unlock
  Content-Type: application/json
  Authorization: Bearer {access_token}
  ```  

  **المُعاملات**  

  | الاسم     | النوع   | الوصف                              |
  |----------|---------|-------------------------------------|
  | files    | array   | قائمة بمُعرّفات الملفات المقفلة أو عناوين URLs. |
  | password | string  | كلمة المرور الحالية للملفات.        |
  | storage  | string  | (اختياري) اسم وحدة التخزين السحابية. |

  **الاستجابات**  

  | الرمز | الوصف                                   |
  |------|-------------------------------------------|
  | 200  | تم فك قفل الملفات بنجاح.                 |
  | 400  | كلمة مرور خاطئة أو ملفات مفقودة.         |
  | 401  | وصول غير مصرّح به.                       |
  | 500  | فشل في جانب الخادم.                       |
