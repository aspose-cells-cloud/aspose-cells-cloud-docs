## خصائص FileInfo


| الاسم             | النوع   | الوصف                                                 |
| ----------------- | ------- | ----------------------------------------------------- |
| **FileName**      | نص (string) | اسم الملف، بما في ذلك امتداده.                         |
| **FileSize**      | عدد صحيح طويل (long) | حجم الملف بالبايت.                                     |
| **FileContent**   | نص (string) | يحتوي على بيانات ملف إكسل الخام، مُشفّرة بـ Base64.    |

يُعاد الاستجابة بصيغة JSON مع نفس الخصائص الثلاث المذكورة في الجدول أعلاه، مثال:

```json
{
  "FileName": "MyWorkbook.xlsx",
  "FileSize": 254312,
  "FileContent": "UEsDBBQABgAIAAAAIQD..."
}
```

### الأخطاء

| كود HTTP | المعنى                     | متى يحدث؟                                |
|---------|----------------------------|-------------------------------------------|
| 200     | نجاح – تم تنفيذ الطلب بنجاح | استجابة طبيعية.                           |
| 401     | غير مصرّح بالوصول          | نقص أو عدم صلاحية رمز المصادقة.           |
| 404     | غير موجود                  | الملف المحدد غير موجود.                  |
| 500     | خطأ داخلي في الخادم         | فشل غير متوقع من جانب الخادم.             |

بالنسبة لكل خطأ، تأكد من صلاحية رمز المصادقة (401)، وتحقق من مسار الملف (404)، أو راجع الدليل العام لمعالجة الأخطاء للحصول على استراتيجيات إعادة المحاولة (500).
