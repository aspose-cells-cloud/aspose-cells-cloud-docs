# خصائص SaveOptions

تتيح لك خيارات الحفظ (SaveOptions) التحكم في كيفية حفظ كتاب العمل عند استخدام واجهة Aspose.Cells Cloud REST API. وبضبط هذه الخيارات، يمكنك تمكين ضغط HTTP وتحديد تنسيق الملف الناتج وإدارة التخزين المؤقت وإدارة سلوكيات إضافية مثل تحديث ذاكرة التخزين المؤقت للمخططات وإنشاء المجلدات تلقائيًا.

**المتطلبات الأساسية**  
- جلسة مُصادق عليها على Aspose.Cells Cloud (OAuth 2.0 أو JWT).  
- يجب تحميل كتاب العمل المستهدف أو إنشاؤه عبر الواجهة البرمجية قبل عملية الحفظ.

| الاسم                      | النوع       | الوصف                                                                                        | الملاحظات      |
| ------------------------- | ---------- | -------------------------------------------------------------------------------------------------- | ---------- |
| **EnableHTTPCompression** | **bool?**  | تمكين ضغط HTTP للاستجابة.                                                         | [اختياري] |
| **SaveFormat**            | **string** | يحدد تنسيق الملف المستهدف لحفظ كتاب العمل.                                          | [اختياري] |
| **ClearData**             | **bool?**  | يجعل كتاب العمل فارغًا بعد حفظ الملف.                                                    | [اختياري] |
| **CachedFileFolder**      | **string** | مجلد الملفات المخزنة مؤقتًا المستخدم لتخزين البيانات الكبيرة مؤقتًا.                                       | [اختياري] |
| **ValidateMergedAreas**   | **bool?**  | يشير إلى ما إذا كان سيتم التحقق من صحة المناطق المدمجة قبل حفظ الملف. القيمة الافتراضية هي false.     | [اختياري] |
| **RefreshChartCache**     | **bool?**  | تحديث بيانات ذاكرة التخزين المؤقت للمخططات قبل الحفظ.                                                          | [اختياري] |
| **CreateDirectory**       | **bool?**  | إذا كانت القيمة true ولم يكن المجلد موجودًا، فسيتم إنشاؤه تلقائيًا قبل حفظ الملف. | [اختياري] |
| **SortNames**             | **bool?**  | ترتيب النطاقات المسماة أبجديًا عند الحفظ.                                                     | [اختياري] |

**الطلب**  
- **الطريقة:** `POST` (أو `PUT` حسب العملية)  
- **نقطة النهاية:** `/cells/workbook/save`  
- **الرؤوس:**  
  - `Authorization: Bearer <access_token>`  
  - `Content-Type: application/json`  
- **الجسم:** التمثيل JSON لنموذج `SaveOptions` (الجدول أعلاه) بالاقتران مع بيانات كتاب العمل أو مرجعيه.

**مثال على الاستجابة**  
```json
{
  "status": "OK",
  "downloadUrl": "https://api.aspose.cloud/v3.0/cells/workbook/save/result.xlsx",
  "message": "تم حفظ كتاب العمل بنجاح."
}
```

**رموز حالات HTTP**

| الرمز | المعنى                     | الوصف                                      |
|------|-----------------------------|--------------------------------------------------|
| 200  | ناجح (OK)                          | تم تطبيق الفلتر بنجاح؛ تحتوي الاستجابة على تفاصيل العملية. |
| 400  | طلب غير صالح (Bad Request)                 | معاملات مفقودة أو غير صحيحة (مثل نوع ملف غير مدعوم). |
| 401  | غير مصادق عليه (Unauthorized)                | رمز JWT غير صالح أو مفقود. |
| 413  | حمل البيانات كبير جدًا (Payload Too Large)           | حجم الملف المرفوع يتجاوز الحد المسموح. |
| 500  | خطأ داخلي في الخادم (Internal Server Error)       | خطأ غير متوقع في الخادم. |

**ملاحظات / تعليقات**  
- عند تعيين **CreateDirectory** إلى `true`، سينشئ API المجلد الهدف تلقائيًا إذا لم يكن موجودًا بالفعل.  
- يمكن أن يؤدي تمكين **EnableHTTPCompression** إلى تقليل حجم حمل البيانات لكتب العمل الكبيرة، ولكن العميل يجب أن يدعم فك التشفير بـ gzip/deflate.  
- يجب استخدام **RefreshChartCache** عندما تعتمد المخططات على بيانات ديناميكية ربما تغيرت منذ إنشاء كتاب العمل.
