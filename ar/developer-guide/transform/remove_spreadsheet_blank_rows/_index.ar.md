## إزالة الصفوف الفارغة من جدول البيانات في خدمات Aspose.Cells Cloud عبر الويب

تحذف هذه الطريقة الصفوف من جدول البيانات التي تكون فارغة تمامًا، أي التي لا تحتوي على أي بيانات أو كائنات. وتقوم بمسح جميع الأوراق وتحديد الصفوف التي تكون خلاياها كلها فارغة. ويتم تنفيذ هذه العملية مباشرةً على جدول البيانات، مما يضمن حذف الصفوف التي لا تحتوي على محتوى فقط. ويساعد ذلك في تنظيف جدول البيانات وإزالة الصفوف الفارغة غير الضرورية، مما يجعل البيانات أكثر تنظيمًا وسهولة في الإدارة. وينبغي على المستخدمين التأكد من وجود نسخة احتياطية لجدول البيانات قبل تنفيذ هذه العملية، نظرًا لأن الصفوف المحذوفة لا يمكن استعادتها.

### نقطة نهاية واجهة برمجة التطبيقات عبر الويب

```http
PUT https://api.aspose.cloud/v4.0/cells/remove/blank-rows
```

### **الأمان والمصادقة**

تتطلب واجهات برمجة تطبيقات Aspose.Cells Cloud أمانًا وتتطلب <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

### معاملات الطلب

| اسم المعامل | النوع | المسار / سلسلة الاستعلام / جسم HTTP | الوصف |
|-------------|-------|-------------------------------------|--------|
| Spreadsheet | ملف | FormData | رفع ملف جدول البيانات. |
| outPath | نص | استعلام | (اختياري) مسار المجلد الذي يُخزَّن فيه ملف المصنف. القيمة الافتراضية هي null. |
| outStorageName | نص | استعلام | اسم وحدة التخزين لملف الإخراج. |
| region | نص | استعلام | إعدادات منطقة/لغة جدول البيانات (مثل `en-US`، `fr-FR`). وتؤثر هذه الإعدادات على تنسيق الأرقام، وتفسير التواريخ، وسلوك محدّد للغة المحلية. |
| password | نص | استعلام | كلمة المرور لفتح ملف جدول البيانات. |

### معامل جسم الطلب

| اسم المعامل | النوع | الوصف |
|------------|-------|--------|
| Spreadsheet | ملف | رفع ملف جدول البيانات. |

### **الاستجابة**

```json
{
  "ResponseFile": "دفق ملف ثنائي"
}
```

**كود حالات الاستجابة**

| الكود | المعنى | الوصف |
|-------|--------|--------|
| 200 | ناجح | يتم إرجاع ملف جدول البيانات بعد إزالة الصفوف الفارغة. |
| 400 | طلب غير صالح | عنوان URL غير صحيح أو معاملات طلب غير صالحة. |
| 401 | غير مصرّح | فشلت المصادقة أو لم تُوفَّر أي بيانات اعتماد. |
| 404 | غير موجود | الملف المصدر غير متاح. |
| 413 | حجم الحمولة كبير جدًا | تجاوز حجم حمولة الطلب الحد المسموح به. |
| 500 | خطأ داخلي في الخادم | واجه جدول البيانات مشكلة أثناء استرجاع البيانات. |

## كيفية استخدام إزالة الصفوف الفارغة من جدول البيانات باستخدام SDKs

### مواصفات إزالة الصفوف الفارغة من جدول البيانات

يُعرّف [مواصفات واجهة برمجة تطبيقات إزالة الصفوف الفارغة من جدول البيانات](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Transform/RemoveSpreadsheetBlankRows) واجهة برمجة تطبيقات عامة قابلة للوصول وتتيح لك إجراء تفاعلات REST مباشرةً من متصفح ويب.

يمكنك استخدام أداة سطر الأوامر cURL للوصول إلى خدمات ويب Aspose.Cells بسهولة. يُظهر المثال التالي كيفية إجراء مكالمات إلى واجهة برمجة التطبيقات السحابية باستخدام cURL.

{< tabs tabTotal="2" tabID="1" tabName1="Request" tabName2="Response" >}
{< tab tabNum="1" >}
```bash
# استخدام HTTPS لاتصال آمن
curl -v "https://api.aspose.cloud/v4.0/cells/remove/blank-rows?outPath=outputFolder&outStorageName=MyStorage&region=en-US&password=12345" \
  -X PUT \
  -H "Content-Type: multipart/form-data" \
  -H "Accept: application/octet-stream" \
  -H "Authorization: Bearer <jwt token>" \
  -F 'Spreadsheet=@sample.xlsx'
```
