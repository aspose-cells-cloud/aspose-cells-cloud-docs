قم تلقائيًا بتبادل البيانات بين أي عمودين أو صفين أو نطاقين أو خليتين في ملفات إكسل باستخدام واجهة برمجة تطبيقات Aspose.Cells Cloud. تتيح واجهة برمجة تطبيقات "استبدال النطاق" تبادل البيانات بدقة مع الحفاظ على جميع التنسيقات والصيغ والإشارات الخلوية. وتدعم هذه الواجهة إعادة تنظيم البيانات المعقدة، والمعالجة الدفعية، والتكامل السلس مع السحابة لسير عمل المؤسسات.

## **واجهة برمجة تطبيقات استبدال النطاق**

### واجهة برمجة التطبيقات عبر الويب

```http
PUT https://api.aspose.cloud/v4.0/cells/swap/range
```

### **الأمان والمصادقة**

تُعدّ واجهات برمجة تطبيقات Aspose.Cells Cloud آمنة وتتطلب <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### **مُعلَمات الطلب**

| اسم المُعلَمة        | النوع   | الموقع     | الوصف                                                                                                                                           |
| ------------------- | ------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Spreadsheet**     | ملف    | FormData   | **إجباري.** ملف مصنف إكسل المصدر (`.xlsx`, `.xls`).                                                                                             |
| **worksheet1**      | نص    | استعلام    | **إجباري.** اسم ورقة العمل التي تحتوي على المنطقة الأولى للبيانات.                                                                               |
| **range1**          | نص    | استعلام    | **إجباري.** النطاق الخلوي (مثل `A1:D10`) في `worksheet1` الذي سيتم استبداله.                                                                      |
| **worksheet2**      | نص    | استعلام    | **إجباري.** اسم ورقة العمل التي تحتوي على المنطقة الثانية للبيانات (يمكن أن تكون نفسها `worksheet1`).                                             |
| **range2**          | نص    | استعلام    | **إجباري.** النطاق الخلوي (مثل `F1:I10`) في `worksheet2` الذي سيتم استبداله. **مهم:** يجب أن يكون لـ `range1` و`range2` أبعاد متطابقة تمامًا. |
| **outPath**         | نص    | استعلام    | **اختياري.** مجلد خدمة التخزين السحابي الذي سيتم حفظ المصنف المعدّل فيه.                                                                         |
| **outStorageName**  | نص    | استعلام    | **إجباري.** اسم خدمة التخزين السحابي المُعدّة مسبقًا (مثل `MyCompanyStorage`).                                                                   |
| **region**          | نص    | استعلام    | **اختياري.** إعداد الإقليم (مثل `en-US`, `ja-JP`) الذي قد يؤثر على التنسيق.                                                                      |
| **password**        | نص    | استعلام    | **اختياري.** كلمة المرور لفك تشفير ملف جدول البيانات المحمي. اتركه فارغًا إذا لم يكن المشفر.                                                       |

**مثال على الطلب (cURL)**  

```bash
curl -X PUT "https://api.aspose.cloud/v4.0/cells/swap/range?worksheet1=Sheet1&range1=A1:D10&worksheet2=Sheet2&range2=F1:I10&outStorageName=MyCompanyStorage" \
     -H "Authorization: Bearer {access_token}" \
     -F "Spreadsheet=@/path/to/workbook.xlsx"
```

### **الاستجابة**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**ملاحظات:**  
- تُعيد الواجهة مصنف الإكسل المعدّل كتدفق ملف. إذا تم تحديد `outPath`، فسيتم حفظ الملف أيضًا في موقع خدمة التخزين السحابي المحددة.  
- سيؤدي عدم تطابق أبعاد النطاقين إلى ظهور خطأ **400 Bad Request**.

### رموز الأخطاء

| الرمز                | الوصف                                                             |
| --------------------- | ------------------------------------------------------------------ |
| **400 Bad Request**   | URI طلب غير صالح أو أبعاد غير متطابقة للنطاق.                     |
| **401 Unauthorized**  | رمز وصول غير صالح أو منتهٍ؛ معرّف العميل أو السر خاطئ.             |
| **404 Not Found**     | لا يمكن الوصول إلى ملف جدول البيانات المحدد.                        |
| **500 Server Error**  | حدث خطأ داخلي أثناء معالجة المصنف.                                 |

## أين يجب استخدام واجهة برمجة تطبيقات استبدال النطاق؟

- **إعادة هيكلة النماذج المالية** – إعادة تنظيم كتل البيانات (مثل نقل توقعات الربع الثالث إلى الربع الرابع) مع الحفاظ على الصيغ والتنسيق الشرطي.
- **عمليات خطوط أنابيب البيانات وETL** – استبدال نطاقات البيانات الخام بنطاقات بيانات منظّفة في ورقة عمل مؤقتة قبل إخراجها النهائي.
- **تصحيح الأخطاء واسترجاع البيانات** – تصحيح البيانات المُوضعَة بشكل خاطئ بسرعة دون الحاجة إلى النسخ واللصق اليدوي.

## لماذا استخدام واجهة برمجة تطبيقات استبدال النطاق؟

- **سهل الاستخدام للمطورين** – توفر واجهات برمجة تطبيقات متاحة بعدة لغات، مما يقلل جهود التطوير مقارنةً ببناء حلول مخصصة.
- **يقلل تكاليف العمالة** – يُلقّم تلقائيًا إعادة ترتيب البيانات، مما يقلل الحاجة إلى عمليات الدمج اليدوي.
- **الدفع حسب الاستخدام** – تدفع مقابل مكالمات الواجهة التي تُجريها فقط.
- **لا تتطلب صيانة** – لا حاجة لإدارة خوادم، ولا تحديثات برمجية، ولا مخاوف تتعلق بالتوافق.
