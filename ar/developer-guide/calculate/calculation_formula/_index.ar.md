## حساب الصيغة في خدمات الويب Aspose.Cells السحابية

يحسب الصيغة المحددة في ورقة عمل محددة من ملف جدول بيانات تم تحميله، ويعيد ملف جدول البيانات الناتج كتيار ملف. تدعم هذه العملية المعالجة حسب الإعدادات الإقليمية من خلال المعلمة **region**، ويمكنها فتح الملفات المحمية بكلمة مرور.

### نقطة نهاية واجهة برمجة تطبيقات الويب

```http
PUT https://api.aspose.cloud/v4.0/cells/calculate/formula
```

### **الأمان والمصادقة**

واجهات برمجة تطبيقات Aspose.Cells السحابية آمنة وتتطلب <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

### معلمات الطلب

| اسم المعلمة | النوع | المسار / سلسلة الاستعلام / جسم HTTP | الوصف |
|-------------|-------|------------------------------------|--------|
| Spreadsheet | ملف | FormData | رفع ملف جدول البيانات. |
| worksheet | نص | استعلام | اسم ورقة العمل التي تحتوي على الصيغة. |
| formula | نص | استعلام | الصيغة المراد حسابها (مثال: `=SUM(A1:B2)`). |
| region | نص | استعلام | إعداد المنطقة/اللغة لجدول البيانات (مثال: `en-US`، `fr-FR`). يؤثر على تنسيق الأرقام، وتفسير التواريخ، والسلوك الخاص بالمنطقة. |
| password | نص | استعلام | كلمة المرور لفتح ملف جدول البيانات. |


**رموز حالة الاستجابة**

| الرمز | المعنى | الوصف |
|------|---------|--------|
| 200 | ناجح | نجح الحساب؛ يتم إرجاع ملف جدول البيانات الناتج. |
| 400 | طلب غير صالح | معلمة أو أكثر من معلمات الطلب مفقودة أو غير صالحة. |
| 401 | غير مصادق عليه | فشلت المصادقة أو رمز JWT مفقود/غير صالح. |
| 413 | حمل البيانات كبير جدًا | حجم الملف المرفوع يتجاوز الحد المسموح به. |
| 500 | خطأ داخلي في الخادم | حدث خطأ غير متوقع في الخادم. |

## كيفية استخدام حساب الصيغة مع مكتبات SDK

### مواصفات حساب الصيغة

تُعرّف <a href="https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Calculate/CalculationFormula" rel="noopener noreferrer">مواصفات API لحساب الصيغة</a> واجهة برمجة تطبيقات قابلة للوصول العام، وتتيح لك إجراء تفاعلات REST مباشرة من متصفح الويب.

يمكنك استخدام أداة سطر الأوامر cURL للوصول إلى خدمات الويب Aspose Cells السحابية بسهولة. يوضح المثال التالي كيفية إجراء مكالمات لواجهة برمجة التطبيقات السحابية باستخدام cURL.

{< tabs tabTotal="2" tabID="1" tabName1="Request" tabName2="Response" >}

{< tab tabNum="1" >}

```bash
# استخدم HTTPS لاتصال آمن
curl -v "https://api.aspose.cloud/v4.0/cells/calculate/formula?worksheet=Sheet1&formula=%3DSUM(A1%3AB2)&region=en-US&password=MyPassword" \
  -X PUT \
  -H "Content-Type: multipart/form-data" \
  -H "Accept: application/octet-stream" \
  -H "Authorization: Bearer <jwt token>" \
  -F "Spreadsheet=@sample.xlsx"
```
