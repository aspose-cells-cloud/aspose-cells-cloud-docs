## **المقدمة**: الحساب السريع في جداول البيانات – صيغ الجمع، الضرب، الطرح، القسمة والنسبة المئوية في واجهة برمجة تطبيقات واحدة

_قم بإجراء حسابات جماعية عبر أعمدة أو صفوف أو جداول كاملة دون الحاجة إلى كتابة صيغ._

- **الحسابات الأساسية**: جمع أو طرح أو ضرب أو قسمة كل خلية في نطاق في رقم محدد
- **النسب المئوية**: زيادة/تقليل بنسبة مئوية، أو حساب نسبة مئوية من رقم (مثال: +15%، -8%، 20% من...)
- **معالجة دُفعات**: تطبيق العمليات على آلاف الخلايا فورًا — بدون ملء تلقائي، ولا صيغ مصفوفة، ولا VBA

| **عملية الحساب** | الوصف |
| :---------------------- | :---------- |
| **جمع**                 | +           |
| **طرح**                | -           |
| **ضرب**                | \*          |
| **قسمة**               | /           |
| **نسبة مئوية**         | %           |

## **واجهة برمجة تطبيقات الحسابات الرياضية**

```http
PUT https://api.aspose.cloud/v4.0/cells/calculate/math
```

### **الأمان والمصادقة**

واجهات برمجة تطبيقات Aspose.Cells Cloud آمنة وتتطلب <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

### **متغيرات الطلب:**

| اسم المتغير | النوع | المسار/سلسلة الاستعلام/جسم HTTP | الوصف |
| :------------- | :----- | :-------------------------- | :--------------------------------------------------------------------------------------- |
| Spreadsheet    | ملف   | FormData                    | رفع ملف جدول البيانات للمعالجة.                                              |
| operation      | نص   | استعلام                       | العملية الحسابية المطلوب تنفيذها (جمع، طرح، ضرب، قسمة، نسبة مئوية). |
| value          | نص   | استعلام                       | قيمة تُستخدم في الحساب إن وُجدت.                                        |
| worksheet      | نص   | استعلام                       | اسم ورقة العمل التي ستُنفَّذ عليها العملية.                                                 |
| range          | نص   | استعلام                       | نطاق الخلايا الذي سيُضمَّن في الحساب.                                        |
| region         | نص   | استعلام                       | إعداد منطقة جدول البيانات.                                                          |
| password       | نص   | استعلام                       | كلمة المرور لفتح ملف جدول البيانات إن كان محميًا.                             |

**رموز حالة HTTP**

| الرمز | المعنى               | الوصف                                                       |
| ---- | --------------------- | ----------------------------------------------------------------- |
| 200  | ناجح (OK)                    | تطبيق الفلتر بنجاح؛ تحتوي الاستجابة على تفاصيل العملية. |
| 400  | طلب غير صالح (Bad Request)           | نقص في المتغيرات أو عدم صحتها (مثال: نوع ملف غير مدعوم).      |
| 401  | غير مخوّل (Unauthorized)          | رمز JWT غير صالح أو مفقود.                                     |
| 413  | حجم الحمولة كبير جدًا (Payload Too Large) | تجاوز حجم الملف المرفوع الحد المسموح به.                                 |
| 500  | خطأ داخلي في الخادم (Internal Server Error) | خطأ غير متوقع في الخادم.                                          |

## أين يجب استخدام واجهة برمجة تطبيقات الحسابات الرياضية؟

- **المجال المالي**: أضف ضريبة القيمة المضافة بنسبة 13% إلى عمود كامل من أسعار المشتريات.
- **إدارة المخزون**: اضرب عمود الكيلوجرامات في 2.2046 لتحويلها دُفعات إلى أرطال.
- **رواتب الموظفين**: أضف مكافأة ثابتة قدرها 1,000 إلى عمود المكافآت لجميع الموظفين.
- **تحويل العملات الأجنبية**: اقسم عمود المبيعات على سعر الصرف الحالي للحصول على المبالغ بالدولار الأمريكي.
- **التقييم**: اطرح 5 نقاط من درجات كل طالب كعقوبة للغياب.
- **التجارة الإلكترونية**: طبّق خصمًا ترويجيًا بنسبة 15% بخفض أسعار المنتجات بنقرة واحدة.

## لماذا يجب استخدام واجهة برمجة تطبيقات الحسابات الرياضية؟

- **حسابات إكسل سريعة** – أكمل تقارير نهاية الشهر في ثوانٍ.
- **زيادة النسبة المئوية دُفعات في إكسل** – حدّث الأسعار، التوقعات، العمولات بنقرة واحدة.
- **إضافة نفس الرقم إلى عمود كامل** – المخزون، تحويل العملة، تحويل الوحدات.
- **إكسل دون صيغ** – يُحبذ المستخدمون غير التقنيين بساطة الاستخدام.
- يمكن إكمال التطوير بسرعة باستخدام SDKs الموجودة.

**ملاحظات**  
الحد الأقصى لحجم الملف المدعوم هو 200 ميغابايت. يجب أن يكون متغير `range` عنوان إكسل صالحًا (مثال: A1:B10). قد تتطلب ورقة العمل الكبيرة جدًا وقتًا إضافيًا للمعالجة.
