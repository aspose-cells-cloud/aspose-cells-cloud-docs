## استيراد بيانات CSV إلى جدول بيانات عبر خدمات Aspose.Cells Cloud الويبية

استيراد ملف بيانات CSV إلى جدول البيانات المحلي. تقوم هذه الطريقة بتحليل ملف CSV وربط البيانات ببنية خلايا جدول البيانات وحفظ الملف محليًا. تشمل تنسيقات جداول البيانات المدعومة: `.xlsx` و`.ods`.

### نقطة نهاية واجهة برمجة التطبيقات عبر الويب

```http
PUT https://api.aspose.cloud/v4.0/cells/import/data/csv
```

### **الأمان والمصادقة**

تُعد واجهات برمجة تطبيقات Aspose.Cells Cloud آمنة وتتطلب <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

### معلمات الطلب

| اسم المعلمة         | النوع   | المسار/سلسلة الاستعلام/جسم HTTP | الوصف                                                                                                                           |
|----------------------|---------|----------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
| datafile             | ملف     | FormData                         | رفع ملف البيانات.                                                                                                                |
| Spreadsheet          | ملف     | FormData                         | رفع ملف جدول البيانات.                                                                                                           |
| worksheet            | نص     | استعلام                          | ورقة العمل التي يجب استيراد بيانات CSV إليها. (مطلوبة)                                                                         |
| startcell            | نص     | استعلام                          | الموقع الابتدائي لاستيراد البيانات. (مطلوبة)                                                                                   |
| insert               | منطقي  | استعلام                          | يتحكم في سلوك الإدراج. `true`: إدراج البيانات؛ `false`: استبدال البيانات الموجودة. الافتراضي: `true` (اختياري)              |
| convertNumericData   | منطقي  | استعلام                          | ما إذا كان يجب تحويل النصوص في الملف إلى بيانات رقمية. الافتراضي: `true` (اختياري)                                            |
| splitter             | نص     | استعلام                          | الفاصل المستخدم لتقسيم حقول CSV. الافتراضي: `","` (اختياري)                                                                     |
| outPath              | نص     | استعلام                          | (اختياري) مسار المجلد الذي يُخزَّن فيه ملف العمل. الافتراضي: `null` (اختياري).                                                |
| outStorageName       | نص     | استعلام                          | اسم وحدة التخزين الخاصة بالملف الناتج. (اختياري)                                                                               |
| fontsLocation        | نص     | استعلام                          | استخدام خطوط مخصصة. (اختياري)                                                                                                  |
| region               | نص     | استعلام                          | إعدادات المنطقة/اللغة لجدول البيانات (مثل `en-US`، `fr-FR`). تؤثر على تنسيق الأرقام، وتفسير التواريخ، والسلوك الخاص بالمنطقة. (اختياري) |
| password             | نص     | استعلام                          | كلمة المرور لفتح ملف جدول البيانات. (اختياري)                                                                                 |

### **الاستجابة**

```json
{
  "file": "<دفق ثنائي لملف جدول البيانات الناتج>"
}
```

**رموز حالة الاستجابة**

| الرمز | المعنى | الوصف |
|-------|---------|--------|
| 200 | ناجح | تم استيراد بيانات CSV بنجاح، ويُعاد ملف جدول البيانات الناتج. |
| 400 | طلب غير صالح | معلمات الطلب غير صحيحة أو عنوان URL غير سليم الصياغة. |
| 401 | غير مصرح | فشلت المصادقة أو لم تُقدَّم أي بيانات اعتماد. |
| 404 | غير موجود | الملف المصدر غير قابل للوصول. |
| 413 | حجم الحمولة كبير جدًا | تجاوزت الملفات المرفوعة الحد الأقصى المسموح به لحجم الملف. |
| 500 | خطأ داخلي في الخادم | واجه جدول البيانات مشكلة أثناء استرداد البيانات. |

## كيفية استخدام خدمة استيراد بيانات CSV إلى جدول البيانات باستخدام مكتبات SDK

### مواصفات استيراد بيانات CSV إلى جدول البيانات

تُعرِّف <a href="https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/DataProcessing/ImportCSVDataIntoSpreadsheet" rel="noopener noreferrer">مواصفات واجهة برمجة تطبيقات استيراد بيانات CSV إلى جدول البيانات</a> واجهة برمجة تطبيقات عامة قابلة للوصول، وتتيح لك إجراء عمليات REST مباشرة من متصفح ويب.

يمكنك استخدام أداة سطر الأوامر cURL للوصول إلى خدمات Aspose.Cells عبر الويب بسهولة. يوضح المثال التالي كيفية إجراء مكالمات إلى واجهة برمجة التطبيقات السحابية باستخدام cURL.

{< tabs tabTotal="2" tabID="1" tabName1="Request" tabName2="Response" >}

{< tab tabNum="1" >}

```bash
# استخدام HTTPS لاتصال آمن
curl -v "https://api.aspose.cloud/v4.0/cells/import/data/csv?worksheet=Sheet1&startcell=A1&insert=true&convertNumericData=true&splitter=,&outPath=outputFolder&outStorageName=MyStorage&fontsLocation=/custom/fonts&region=en-US&password=MyPassword" \
  -X PUT \
  -H "Content-Type: multipart/form-data" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer <jwt token>" \
  -F "datafile=@sample.csv" \
  -F "Spreadsheet=@workbook.xlsx"
```
