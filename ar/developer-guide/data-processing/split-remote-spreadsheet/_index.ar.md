اقسم ملف Excel الكبير المحفوظ في السحابة إلى ملفات منفصلة حسب ورقة العمل وصدّر كل منها إلى أكثر من 30 صيغة مخرجة مثل PDF وCSV وJSON وODS وXPS باستخدام Aspose.Cells Cloud.

## **واجهة برمجة تطبيقات تقسيم جداول البيانات السحابية**

### واجهة برمجة تطبيقات الويب

```http
PUT https://api.aspose.cloud/v4.0/cells/{name}/split/spreadsheet
```

### **الأمان والمصادقة**

تُعدّ واجهات برمجة تطبيقات Aspose.Cells Cloud آمنة وتحتاج إلى <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

### **مُعطَلات الطلب:**

| اسم المُعطَل | النوع | المسار/سلسلة الاستعلام/جسم HTTP | الوصف |
| :----------- | :---- | :----------------------------- | :----------------------------------------------------------- |
| name | String | المسار | اسم ملف ملف العمل (مثل `data.xlsx`) المراد تقسيمه، والموجود في مجلد التخزين السحابي المحدّد. |
| folder | String | الاستعلام | مسار مجلد التخزين السحابي حيث يُخزّن ملف العمل المصدر. |
| from | Integer | الاستعلام | فهرس ورقة العمل الابتدائي (يبدأ من الصفر) لعملية التقسيم. مثلاً، `0` يشير إلى ورقة العمل الأولى. |
| to | Integer | الاستعلام | فهرس ورقة العمل النهائية (يبدأ من الصفر) لعملية التقسيم. مثلاً، `2` يُقسّم أوراق العمل 0 و1 و2. |
| outFormat | String | الاستعلام | صيغة ملف المخرجات للملفات المُقسّمة. تشمل الصيغ المدعومة: `XLSX` و`PDF` و`CSV` و`JSON` و`HTML` وأكثر من 30 صيغة أخرى. |
| storageName | String | الاستعلام | _(اختياري)_ اسم مجلد التخزين السحابي حيث يكمن ملف العمل المصدر. وإذا لم يُحدّد، يُستخدم التخزين السحابي الافتراضي. |
| outPath | String | الاستعلام | _(اختياري)_ مسار مجلد التخزين السحابي الهدف حيث تُحفظ الملفات المُقسّمة. وإذا لم يُحدّد، تُحفظ الملفات في نفس مجلد المصدر. |
| outStorageName | String | الاستعلام | اسم مجلد التخزين السحابي حيث تُخزّن ملفات التقسيم المخرجة. |
| fontsLocation | String | الاستعلام | _(اختياري)_ يُحدّد مسار مجلد مخصص في السحابة يحتوي على ملفات الخطوط لضمان عرض النصوص بشكل صحيح في مخرجات PDF أو الصور. |
| region | String | الاستعلام | _(اختياري)_ يعيّن المنطقة المحلية لتنسيق الأرقام والتواريخ والعملات في الملفات المخرجة (مثل `"en-US"` أو `"zh-CN"` أو `"de-DE"`). |
| password | String | الاستعلام | _(اختياري)_ إذا كان ملف العمل المصدر محميًا بكلمة مرور، فحدّد كلمة المرور لفتح الملف. |

## **الاستجابة**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream",
      "Name": "file"
    }
  }
]
```

يمكن تنزيل الملف مباشرةً أو حفظه في الموقع المحدّد بواسطة `outPath`.

**تفاصيل الاستجابة الناجحة**

| رمز الحالة | نوع المحتوى | الوصف |
| ----------- | -------------------------- | ------------------------------------------ |
| 200 OK | `application/octet-stream` | تدفق ثنائي لملف العمل المدمج. |

**رموز حالة HTTP**

| الرمز | المعنى | الوصف |
| ---- | --------------------- | ----------------------------------------------------------------- |
| 200 | OK | تمت تطبيق الفلتر بنجاح؛ تحتوي الاستجابة على تفاصيل العملية. |
| 400 | Bad Request | مُعطَلات مفقودة أو غير صالحة (مثل نوع ملف غير مدعوم). |
| 401 | Unauthorized | رمز JWT غير صالح أو مفقود. |
| 413 | Payload Too Large | حجم الملف المرفوع يتجاوز الحد المسموح به. |
| 500 | Internal Server Error | خطأ داخلي غير متوقع في الخادم. |

## أين نستخدم واجهة برمجة تطبيقات تقسيم جداول البيانات السحابية؟

- **توزيع بيانات الأقسام**: اقسم ملف العمل الموحّد الذي يحتوي على بيانات من أقسام متعددة إلى ملفات منفصلة لكل قسم.
- **توزيع التقارير الإقليمية**: اقسم بيانات المبيعات الوطنية إلى ملفات تقارير إقليمية منفصلة حسب المنطقة.
- **توزيع بيانات العملاء مع إخفاء المعلومات الحساسة**: اقسم ملف العمل الذي يحتوي على معلومات حساسة إلى ملف خاص بالعرض المخصص للعميل.
- **تقسيم التقارير الدورية**: اقسم التقارير الملخّصة تلقائيًا إلى تقارير أسبوعية أو يومية شهريًا.
- **التوزيع بصيغ متعددة**: اقسم ملف Excel واحد إلى نسخ متعددة بصيغ مختلفة مثل PDF وCSV وJSON، في وقت واحد.
- **التقسيم حسب القوالب**: اقسم ملفات البيانات إلى ملفات مخرجة معيارية بناءً على قوالب مُعدّة مسبقًا.
- **المعالجة المسبقة لمصادر البيانات**: اقسم ملف Excel إلى ملف CSV معياري قبل تحميل البيانات في قاعدة البيانات.
- **تجهيز البيانات للواجهات البرمجية**: اقسم مجموعات البيانات الكبيرة إلى أجزاء أصغر تناسب نقل البيانات عبر واجهات برمجة التطبيقات.
- **توزيع البيانات لخدمات الميكروسيرفيس (Microservices)**: اقسم ملف البيانات المركزي إلى ملفات بيانات منفصلة مطلوبة لكل خدمة ميكروسيرفيس.

## لماذا يجب استخدام واجهة برمجة تطبيقات تقسيم جداول البيانات السحابية؟

- **سهلة للمطورين**: توفر Aspose.Cells Cloud مكتبات SDK بلغات برمجة متعددة، ما يتيح تطويرًا سريعًا مع توفر وثائق شاملة. ومقارنةً ببناء حلول مخصصة لرسم الرسوم البيانية، فإنها تقلل بشكل كبير من جهد التطوير.
- **تقليل تكاليف العمالة**: تقلل الحاجة إلى وظائف مخصصة لدمج المستندات.
- **الدفع حسب الاستخدام**: لا تحتاج إلى استثمار مبدئي؛ تدفع فقط مقابل استدعاءات API الفعلية.
- **بدون تكاليف صيانة**: لا حاجة للصيانة الخوادم أو تحديث البرمجيات أو التعامل مع مشكلات التوافق.
- **تحفظ التنسيقات المعقدة لملفات Excel** في صيغة PDF القابلة للوصول عالميًا.
