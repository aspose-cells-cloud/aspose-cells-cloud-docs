## تقسيم الجدول في خدمات الويب Aspose.Cells Cloud

تقوم هذه الطريقة بتنفيذ عملية تقسيم للجدول المصدر عن طريق تجميع الصفوف وفقًا للقيم المميزة في العمود المحدد. ثم تُعالَج كل مجموعة بيانات (لكل قيمة تقسيم فريدة) كوحدة بيانات منفصلة. ويتم التحكم في وجهة التصدير من خلال معامَلين منطقيين رئيسيين:

- يُحدِّد هيكل مصنف العمل. إذا كانت القيمة `true`، تُحفظ كل وحدة مقسَّمة في ملف مصنف عمل منفصل. أما إذا كانت القيمة `false`، تصبح كل وحدة ورقة عمل جديدة داخل المصنف الحالي.
- يُحدِّد تغليف الإخراج. عند تعيينها إلى `true` ودمجها مع `toNewWorkbook = true`، تُنشئ الطريقة ملفات منفصلة متعددة وتُعيدها كأرشيف ZIP. أما عند تعيينها إلى `false`، تُدمَج جميع البيانات في ملف واحد (إما مصنف متعدد الأوراق أو ملف واحد حسب الإعدادات الأخرى).

### نقطة نهاية واجهة برمجة التطبيقات للويب

```http
PUT https://api.aspose.cloud/v4.0/cells/split/table
```

### **الأمان والمصادقة**

تُعدّ واجهات برمجة تطبيقات Aspose.Cells Cloud آمنة وتتطلب <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

| Spreadsheet          | ملف       | FormData                         | رفع ملف جدول بيانات.                                                                                                                |
| worksheet            | سلسلة نصية | استعلام                          | ورقة العمل التي تحتوي على الجدول.                                                                                                   |
| tableName            | سلسلة نصية | استعلام                          | جدول البيانات الذي يجب تقسيمه.                                                                                                     |
| splitColumnName      | سلسلة نصية | استعلام                          | اسم العمود الذي يجب التقسيم حسبه.                                                                                                  |
| saveSplitColumn      | منطقي     | استعلام                          | ما إذا كان سيتم الاحتفاظ بالبيانات في عمود التقسيم أم لا.                                                                           |
| splitRowNumber       | عدد صحيح   | استعلام                          | [قيد التوضيح]                                                                                                                       |
| toNewWorkbook        | منطقي     | استعلام                          | التحكم في وجهة التصدير: `true` - إنشاء ملفات مصنفات عمل جديدة تحتوي على البيانات المقسَّمة؛ `false` - إضافة ورقة عمل جديدة للمصنف الحالي. |
| toMultipleFiles      | منطقي     | استعلام                          | `true` - تصدير بيانات الجدول كـ **ملفات منفصلة متعددة** (تُعاد كأرشيف ZIP)؛ `false` - تخزين جميع البيانات في **ملف واحد** متعدد الأوراق. القيمة الافتراضية: `false`. |
| outPath              | سلسلة نصية | استعلام                          | (اختياري) مسار المجلد الذي يُخزَّن فيه مصنف العمل. القيمة الافتراضية: `null`.                                                       |
| outStorageName       | سلسلة نصية | استعلام                          | اسم وحدة التخزين للملف الخارجِي.                                                                                                   |
| fontsLocation        | سلسلة نصية | استعلام                          | استخدام خطوط مخصصة.                                                                                                                 |
| region               | سلسلة نصية | استعلام                          | إعداد منطقة/لغة جدول البيانات (مثل `en-US`، `fr-FR`). يؤثر على تنسيق الأرقام، وتحليل التواريخ، وسلوك المنطقة المحددة.               |
| password             | سلسلة نصية | استعلام                          | كلمة المرور لفتح ملف جدول البيانات.                                                                                                |

### معامِل جسم الطلب

| اسم المعامِل | النوع | الوصف               |
|-------------|-------|---------------------|
| Spreadsheet | ملف   | رفع ملف جدول البيانات. |

### **الاستجابة**

```json
{
  "file": "تدفق ثنائي (أرشيف ZIP أو مصنف عمل حسب المعامِلات)"
}
```

**رموز حالة الاستجابة**

| الرمز | المعنى | الوصف                                                                 |
|-------|--------|-----------------------------------------------------------------------|
| 200   | ناجح   | اكتملت عملية التقسيم بنجاح. تحتوي الاستجابة على الملف المُولَّد (أرشيف ZIP أو مصنف عمل). |
| 400   | طلب غير صالح | عنوان URL أو معامِلات الطلب غير صالحة.                               |
| 401   | غير مصرّح | فشلت المصادقة أو لم تُقدَّم بيانات اعتماد.                           |
| 404   | غير موجود | لم يكن الملف المصدر متاحًا.                                          |
| 413   | حجم الحمولة كبير جدًا | تجاوز حجم حمولة الطلب الحد المسموح به.                              |
| 500   | خطأ داخلي في الخادم | واجه جدول البيانات مشكلة في استرجاع البيانات.                        |

## كيفية استخدام تقسيم الجدول باستخدام SDKs

### مواصفات تقسيم الجدول

تُعرِّف [مواصفات واجهة برمجة تطبيقات تقسيم الجدول](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/DataProcessing/SplitTable) واجهة برمجة تطبيقات عامة قابلة للوصول، وتتيح لك إجراء عمليات REST مباشرة من متصفح الويب.

يمكنك استخدام أداة سطر الأوامر cURL للوصول بسهولة إلى خدمات الويب Aspose.Cells Cloud. يوضح المثال التالي كيفية إجراء المكالمات إلى واجهة برمجة التطبيقات السحابية باستخدام cURL.

{{< tabs tabTotal="2" tabID="1" tabName1="الطلب" tabName2="الاستجابة" >}}

{{< tab tabNum="1" >}}

```bash
# استخدام HTTPS لتوصيل آمن
curl -v "https://api.aspose.cloud/v4.0/cells/split/table?worksheet=Sheet1&tableName=MyTable&splitColumnName=Category&saveSplitColumn=true&splitRowNumber=1&toNewWorkbook=true&toMultipleFiles=true&outPath=output%2Ffolder&outStorageName=MyStorage&fontsLocation=%2Fcustom%2Ffonts&region=en-US&password=SecretPassword" \
  -X PUT \
  -H "Content-Type: multipart/form-data" \
  -H "Accept: application/octet-stream" \
  -H "Authorization: Bearer <jwt token>" \
  -F "Spreadsheet=@sample.xlsx"
```
