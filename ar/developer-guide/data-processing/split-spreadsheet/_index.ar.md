قسّم ملف عمل إكسل محليًا إلى ملفات منفصلة بالكامل — لا حاجة إلى تخزين سحابي. يدعم الإخراج أكثر من 30 صيغة مثل PDF وCSV وJSON وODS وXPS.

## **واجهة برمجة تطبيقات تقسيم جدول البيانات**

### واجهة برمجة التطبيقات عبر الويب

```http
PUT https://api.aspose.cloud/v4.0/cells/split/spreadsheet
```

### **الأمان والمصادقة**

واجهات برمجة تطبيقات Aspose.Cells Cloud آمنة وتتطلب <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

## **الاستجابة**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

يمكن تنزيل الملف مباشرةً أو حفظه في الموقع المحدد بواسطة `outPath`.

**تفاصيل استجابة ناجحة**

| رمز الحالة | نوع المحتوى              | الوصف                                          |
| ---------- | ------------------------ | ---------------------------------------------- |
| 200 OK     | `application/octet-stream` | تيار ثنائي لملف العمل المدمج.                 |

**رموز حالة HTTP**

| الرمز | المعنى                 | الوصف                                                        |
| ---- | ---------------------- | ------------------------------------------------------------ |
| 200  | ناجح (OK)              | تم تطبيق الفلتر بنجاح؛ وتحتوي الاستجابة على تفاصيل العملية. |
| 400  | طلب غير صالح (Bad Request) | معطيات مفقودة أو غير صحيحة (مثال: نوع ملف غير مدعوم).       |
| 401  | غير مُصادَق (Unauthorized) | رمز JWT غير صالح أو مفقود.                                  |
| 413  | حجم الحمولة كبير جدًا (Payload Too Large) | حجم الملف المرفوع يتجاوز الحد المسموح به.                  |
| 500  | خطأ داخلي في الخادم (Internal Server Error) | خطأ غير متوقع في الخادم.                                    |

## أين نستخدم واجهة برمجة تطبيقات تقسيم جدول البيانات؟

- **توزيع بيانات الأقسام**: تقسيم ملف عمل موحّد يحتوي على بيانات من أقسام متعددة إلى ملفات منفصلة لكل قسم.
- **توزيع التقارير الإقليمية**: تقسيم بيانات مبيعات وطنية إلى ملفات تقارير إقليمية منفصلة.
- **توزيع بيانات العملاء مع إخفاء المعلومات الحساسة**: تقسيم ملف عمل يحتوي على بيانات حساسة إلى ملف يعرض بيانات العملاء المُخفية.
- **تقسيم التقارير الدورية**: تقسيم تلقائي للتقارير الموجزة إلى تقارير أسبوعية أو يومية شهريًا.
- **التوزيع بصيغ متعددة**: تقسيم ملف إكسل واحد إلى نسخ متعددة بصيغ مختلفة مثل PDF وCSV وJSON وما إلى ذلك، في وقت واحد.
- **التقسيم القائم على القوالب**: تقسيم ملفات البيانات إلى ملفات إخراج معيارية بناءً على قوالب مُعدة مسبقًا.
- **المعالجة المسبقة لمصادر البيانات**: تقسيم ملف إكسل إلى ملف CSV معياري قبل تحميل البيانات في قاعدة البيانات.
- **تجهيز البيانات لواجهات برمجة التطبيقات**: تقسيم مجموعات البيانات الكبيرة إلى وحدات أصغر مناسبة لنقلها عبر واجهات برمجة التطبيقات.

## لماذا يجب استخدام واجهة برمجة تطبيقات تقسيم جدول البيانات؟

- **سهلة للمطورين**: توفر Aspose.Cells Cloud مكتبات SDK بلغات برمجة متعددة، مما يسهّل التطوير السريع ويوفّر وثائق شاملة. وبالمقارنة مع بناء حلول مخصصة لعرض الرسوم البيانية، فإن ذلك يقلل بشكل كبير من جهد التطوير.
- **تقليل تكاليف العمالة**: يقلل الحاجة إلى وظائف مخصصة لدمج المستندات.
- **الدفع حسب الاستخدام**: لا استثمار مبدئي؛ تدفع فقط مقابل مكالمات API الفعلية المستخدمة.
- **لا تكاليف صيانة**: لا حاجة لصيانة الخوادم أو تحديث البرمجيات أو التعامل مع مشاكل التوافق.
- **الحفاظ على تنسيقات إكسل المعقدة** بصيغة PDF عالمية القابلية للوصول.

### مواصفات واجهة برمجة تطبيقات تقسيم جدول البيانات

توفّر [مواصفات واجهة برمجة تطبيقات تقسيم جدول البيانات](https://reference.aspose.cloud/cells/#/DataProcessingController/SplitSpreadsheet) واجهة برمجة تطبيقات مفتوحة للوصول مباشرةً عبر المتصفح لتنفيذ تفاعلات REST.
يمكنك استخدام أداة سطر الأوامر cURL للوصول بسهولة إلى خدمات الويب Aspose.Cells. ويوضّح المثال التالي كيفية إجراء مكالمات إلى واجهة برمجة التطبيقات السحابية باستخدام cURL.
