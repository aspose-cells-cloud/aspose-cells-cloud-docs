## خدمة ويب Aspose.Cells Cloud: الحصول على أوراق العمل باستخدام ملف جدول بيانات محلي

يقوم هذا الطرف (Endpoint) بالوصول إلى تطبيق جدول البيانات المحلي (مثل Excel) عبر واجهة تفاعلية (interop) أو واجهة برمجة محلية، ويجمع اسم نوع كل ورقة عمل (مثل: ورقة عادية، مخطط، ماكرو)، ثم يُعيد المجموعة على شكل مصفوفة JSON منظمة. ويُستخدم عادةً لملء واجهة اختيار أوراق العمل (UI) أو لتدقيق محتويات جدول البيانات.

### طرف واجهة برمجة التطبيقات (Web API)

```http
PUT https://api.aspose.cloud/v4.0/cells/spreadsheet/worksheets
```

### **الأمان والمصادقة**

تُعدّ واجهات برمجة تطبيقات Aspose.Cells Cloud آمنة وتشترط <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">المصادقة باستخدام رمز JWT</a>.

### معاملات الطلب

| اسم المعامل | النوع | المسار / سلسلة الاستعلام / جسم HTTP | الوصف |
|-------------|--------|-------------------------------------|--------|
| Spreadsheet | ملف | FormData (جسم HTTP) | رفع ملف جدول البيانات. |
| region | نص | استعلام | إعداد المنطقة/اللغة لجدول البيانات (مثل: `en-US`, `fr-FR`). يؤثر على تنسيق الأرقام، وتفسير التواريخ، والسلوك الخاص باللغة المحلية. *(اختياري)* |
| password | نص | استعلام | كلمة المرور لفتح ملف جدول البيانات. *(اختياري)* |

### معامل جسم الطلب

| اسم المعامل | النوع | الوصف |
|-------------|--------|--------|
| Spreadsheet | ملف | رفع ملف جدول البيانات. |

### **الاستجابة**

```json
{
  "Worksheets": [
    {
      "Name": "Sheet1",
      "Id": 0,
      "Type": "Standard"
    },
    {
      "Name": "Chart1",
      "Id": 1,
      "Type": "Chart"
    }
    // ... أوراق عمل إضافية
  ]
}
```

**رموز حالة الاستجابة**

| الرمز | المعنى | الوصف |
|-------|---------|--------|
| 200 | ناجح | تم استرجاع قائمة أوراق العمل بنجاح. |
| 400 | طلب غير صالح | طلب غير صحيح (مثل: رابط URL معطّل أو بيانات مطلوبة مفقودة). |
| 401 | غير مُصادَق عليه | فشلت المصادقة أو لم تُقدّم بيانات اعتماد. |
| 404 | غير موجود | ملف المصدر غير قابل للوصول. |
| 413 | حجم الحُمّال كبير جدًا | تجاوز حجم الملف المرفوع الحد المسموح به. |
| 500 | خطأ داخلي في الخادم | واجه جدول البيانات حالة شاذة أثناء استرجاع البيانات. |

## كيفية استخدام "الحصول على أوراق العمل باستخدام ملف جدول بيانات محلي" باستخدام مكتبات التطوير (SDKs)

### مواصفات "الحصول على أوراق العمل باستخدام ملف جدول بيانات محلي"

تُعرّف <a href="https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Management/GetWorksheetsWithLocalSpreadsheet" rel="noopener noreferrer">مواصفات API "الحصول على أوراق العمل باستخدام ملف جدول بيانات محلي"</a> واجهة برمجة قابلة للوصول العام، وتتيح لك إجراء تفاعلات REST مباشرة من متصفح ويب.

يمكنك استخدام أداة سطر الأوامر cURL للوصول إلى خدمات ويب Aspose.Cells Cloud بسهولة. يوضح المثال التالي كيفية إجراء مكالمات إلى واجهة برمجة التطبيقات السحابية باستخدام cURL.

```bash
# استخدام HTTPS لتوصيل آمن
curl -v "https://api.aspose.cloud/v4.0/cells/spreadsheet/worksheets?region=en-US&password=yourPassword" \
  -X PUT \
  -H "Content-Type: multipart/form-data" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer <jwt token>" \
  -F 'Spreadsheet=@example.xlsx'
```
