أضف أوراق عمل إلى ملفات Excel برمجيًا مع تحكم كامل في نوع الورقة وموقعها. أدرج أوراق عمل قياسية أو أوراق مخططات أو أوراق ماكرو في أي موقع داخل المصنف. تتيح لك هذه العملية التي تعتمد على REST إدارة وتجميع أوراق عمل ملفات Excel آليًا.

**المتطلبات المسبقة**

- حساب نشط في Aspose.Cells Cloud مع رمز وصول JWT صالح.
- اسم تخزين سحابي مُعدّ (مثل `CompanyOneDrive`) يُحفظ فيه المصنف.
- يجب أن يكون المصنف الهدف متاحًا في التخزين المحدّد، وإذا كان مشفرًا بكلمة مرور، فيجب تقديم كلمة المرور الصحيحة.

| **نوع الورقة**         | الوصف                                              |
| :--------------------- | :-------------------------------------------------- |
| **VB**                 | وحدة Visual Basic                                   |
| **Worksheet**          | ورقة عمل عادية                                      |
| **Chart**              | ورقة مخطط                                           |
| **BIFF4Macro**         | ورقة ماكرو BIFF4                                    |
| **InternationalMacro** | ورقة ماكرو دولية                                    |
| **Other**              | نوع ورقة مخصّص أو أقل شيوعًا وغير مذكور أعلاه      |
| **Dialog**             | ورقة حوار (Dialog worksheet)                        |

## **واجهة برمجة تطبيقات إضافة ورقة عمل إلى جدول البيانات**

### واجهة برمجة التطبيقات عبر الويب

```http
PUT https://api.aspose.cloud/v4.0/cells/spreadsheet/add/worksheet
```

### **الأمان والمصادقة**

واجهات برمجة تطبيقات Aspose.Cells Cloud آمنة وتتطلب <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

### مُعطَلات الطلب

| اسم المُعطَل          | النوع     | الموقع       | الوصف                                                                                                                                                                                                 |
| :-------------------- | :-------- | :----------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Spreadsheet**       | ملف      | FormData     | **إلزامي.** ملف Excel (.xlsx أو .xls وما إلى ذلك) الذي ستُضاف إليه ورقة عمل جديدة.                                                                                                                   |
| **sheetType**         | نص (String) | استعلام (Query) | **اختياري.** نوع الورقة المراد إنشاؤها. القيم المقبولة هي `worksheet` (الافتراضي)، `chartsheet`، `macrosheet`، `vbmodule`، و`dialog`.                                                                    |
| **position**          | عدد صحيح (Integer) | استعلام (Query) | **اختياري.** المؤشر المُعدّ صفرًا لموقع إدراج الورقة الجديدة. القيمة `0` تُدرجها قبل الورقة الأولى؛ والقيمة `2` تضعها كورقة ثالثة. اتركه فارغًا لإلحاق الورقة في نهاية المصنف.                             |
| **sheetName**         | نص (String) | استعلام (Query) | **اختياري.** اسم الورقة الجديدة. يجب أن يكون فريدًا داخل المصنف. إذا حُذِر، يُولّد اسم افتراضي مثل "SheetX".                                                                                             |
| **outPath**           | نص (String) | استعلام (Query) | **اختياري.** المسار المستهدف داخل التخزين السحابي حيث سيُحفظ المصنف المعدّل. إذا كانت القيمة `null` أو حُذِر، سيُحفظ المصنف في نفس الموقع الذي وُجد فيه الملف الأصلي أو في مسار افتراضي.                 |
| **outStorageName**    | نص (String) | استعلام (Query) | **إلزامي.** المُعرّف الخاص باسم التخزين السحابي المُعدّ (مثل `CompanyOneDrive`) الذي سيُكتب فيه الملف الناتج.                                                                                           |
| **region**            | نص (String) | استعلام (Query) | **اختياري.** إعداد التخطيط المحلي (مثل `en‑CA`) الذي قد يؤثر على التنسيق والقواعد الإقليمية في الورقة الجديدة.                                                                                         |
| **password**          | نص (String) | استعلام (Query) | **اختياري.** كلمة المرور لفك تشفير المصنف المحمي بكلمة مرور وتعديله. اتركه فارغًا إذا لم يكن الملف مشفرًا.                                                                                               |

### الاستجابة

في حال النجاح، تُعيد واجهة برمجة التطبيقات رمز الحالة **HTTP 200 OK** (أو **201 Created** عند إنشاء ملف جديد) مع الملف المُعدّل.

```json
{
  "Name": "ResponseFile",
  "DataType": {
    "Identifier": "File",
    "Reference": "Stream"
  }
}
```

**رموز حالة HTTP**

| الرمز | المعنى                     | الوصف                                                                |
| ----- | -------------------------- | --------------------------------------------------------------------- |
| 200   | OK (تم بنجاح)              | تطبيق المرشّح بنجاح؛ تحتوي الاستجابة على تفاصيل العملية.             |
| 400   | Bad Request (طلب سيّئ)     | معطَلات مفقودة أو غير صالحة (مثل نوع ملف غير مدعوم).                |
| 401   | Unauthorized (غير مصرّح)   | رمز JWT غير صالح أو مفقود.                                           |
| 413   | Payload Too Large (حمولة كبيرة جدًا) | تجاوز حجم الملف المرفوع الحد المسموح به.                             |
| 500   | Internal Server Error (خطأ داخلي في الخادم) | خطأ غير متوقع في الخادم.                                             |

## أين نستخدم واجهة برمجة تطبيقات إضافة ورقة عمل إلى جدول البيانات؟

- **توليد التقارير آليًا** – إنشاء أوراق عمل شهرية ديناميكيًا (مثل `2024‑05`) أثناء توليد البيانات المالية.
- **تهيئة القوالب دفعة واحدة** – إضافة ورقة تحليل مخصّصة لكل عميل أو مشروع جديد عند توليد عروض الأسعار أو المقترحات بكمّ كبير.
- **توسيع لوحة التحكم ديناميكيًا** – إضافة أوراق مخططات جديدة في الوقت الفعلي عندما تصبح أبعاد البيانات الجديدة متاحة.
- **الامتثال والأرشفة للمراجعة** – إضافة أوراق جمع الأدلة تلقائيًا أثناء المراجعات السنوية، مع عزل نقطة التدقيق كلها في ورقة خاصة بها.

- لحذف ورقة، راجع عملية **[حذف ورقة العمل](/delete-worksheet/)**.
- لنقل ورقة عمل، راجع عملية **[نقل ورقة العمل](/move-worksheet/)**.

## لماذا يجب استخدام واجهة برمجة تطبيقات إضافة ورقة عمل إلى جدول البيانات؟

- **سهلة الاستخدام للمطورين** – توفر Aspose.Cells Cloud مكتبات SDK للغات برمجية متعددة، مما يقلل جهود التطوير ويوفّر وثائق شاملة.
- **خفض تكاليف العمالة** – يلغي الحاجة إلى إنشاء أوراق عمل يدويًا أو مهام النسخ واللصق المتكررة.
- **الدفع حسب الاستخدام** – تدفع فقط مقابل طلبات واجهة برمجة التطبيقات التي تُقدِّمها فعليًا.
- **لا صيانة مطلوبة** – لا خوادم لإدارتها، ولا تحديثات برمجية، ولا مخاوف تتعلق بالتوافق.

### مُواصفات واجهة برمجة تطبيقات إضافة ورقة عمل إلى جدول البيانات

تعرّف [مواصفات واجهة برمجة تطبيقات إضافة ورقة عمل إلى جدول البيانات](https://reference.aspose.cloud/cells/#/ManagementController/AddWorksheetToSpreadsheet) واجهة برمجة تطبيقات برمجية عامة قابلة للوصول، وتتيح لك إجراء تفاعلات REST مباشرة من متصفح ويب.

يمكنك استخدام أداة سطر الأوامر cURL للوصول إلى خدمات Aspose.Cells عبر الويب بسهولة. يُظهر المثال التالي كيفية إجراء استدعاءات إلى واجهة برمجة التطبيقات السحابية باستخدام cURL.

     -H "Accept: application/json" \
     -F "Spreadsheet=@/path/to/Book1.xlsx"
