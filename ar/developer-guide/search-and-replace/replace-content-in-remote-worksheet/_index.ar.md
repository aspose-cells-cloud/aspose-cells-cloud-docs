استبدال نص محدّد داخل ورقة عمل معيّنة من ملفات Excel البعيدة. حدّث محتوى أوراق العمل المستهدفة بكفاءة باستخدام واجهة برمجة تطبيقات (API) من Aspose.Cells للبحث والاستبدال، لتحقيق تعديلات دقيقة على ورقة العمل.

## **واجهة برمجة تطبيقات (API) لاستبدال محتوى ورقة العمل البعيدة**

### **واجهة برمجة التطبيقات عبر الويب**

```http
PUT https://api.aspose.cloud/v4.0/cells/{name}/worksheets/{worksheet}/replace/content
```

### **الأمان والمصادقة**

توفّر واجهات برمجة تطبيقات Aspose.Cells Cloud أماناً عالياً وتتطلب <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### **معامِلات الطلب**

| اسم المعامل | النوع | المسار/سلسلة الاستعلام/جسم الطلب HTTP | الوصف |
| :---------- | :----- | :------------------------------------- | :----------------------------------------------------------- |
| name | String | Path | اسم ملف المصنف المخزن في التخزين السحابي والذي سيتم تعديله (مثل `"sales_report.xlsx"`, `"budget_2024.xls"`). |
| worksheet | String | Path | اسم ورقة العمل المحددة التي سيتم تنفيذ عملية البحث والاستبدال فيها (مثل `"Q1_Sales"`, `"Sheet1"`). |
| searchText | String | Query | سلسلة النص التي سيتم البحث عنها داخل ورقة العمل المحددة. يُطبّق البحث على جميع الخلايا في ورقة العمل ما لم تُقيّد بشكل إضافي. |
| replaceText | String | Query | سلسلة النص التي ستستبدل جميع مرات ظهور `searchText` التي تم العثور عليها داخل ورقة العمل المحددة. |
| folder | String | Query | مسار المجلد في التخزين السحابي حيث يقع ملف المصنف المصدر (مثل `"/reports/monthly/"`, `"/finance/"`). |
| storageName | String | Query | _(اختياري)_ اسم التخزين السحابي المخصص (مثل `"CorporateS3"`, `"AzureArchive"`). وإذا لم يُحدّد، فسيُستخدم التخزين السحابي الافتراضي لحسابك. |
| region | String | Query | _(اختياري)_ يُعيّن الإعدادات المحلية لمعالجة النص، مما قد يؤثّر على ترميز الأحرف وسلوك البحث حسب اللغة داخل ورقة العمل (مثل `"en-GB"`, `"es-ES"`). |
| password | String | Query | _(اختياري)_ إذا كان المصنف محمياً بكلمة مرور، فقم بتزويدها لفتح الملف وتعديله. |

**مثال على الطلب (cURL)**  

```bash
curl -X PUT "https://api.aspose.cloud/v4.0/cells/sales_report.xlsx/worksheets/Sheet1/replace/content?searchText=OldValue&replaceText=NewValue&folder=/reports" \
     -H "Authorization: Bearer {access_token}"
```

### **الاستجابة**

```json
{
  "Code": 200,
  "Status": "OK"
}
```

### **رموز الأخطاء**

| الكود | الوصف | متى يحدث الخطأ؟ |
|------|------------------------------------------|------------------------------------------------------------------|
| 400 | Request غير صالح (Bad Request) | يكون URI للطلب معطّلاً أو تغيب معاملات مطلوبة. |
| 401 | غير مصرّح (Unauthorized) | يغيب رمز الوصول أو يكون غير صالح، أو تكون بيانات اعتماد العميل خاطئة. |
| 404 | غير موجود (Not Found) | لا يمكن العثور على المصنف أو ورقة العمل المحدّدين. |
| 500 | خطأ داخلي في الخادم (Internal Server Error) | حدث خطأ غير متوقّع أثناء معالجة الطلب. |

## أين يجب استخدام واجهة برمجة تطبيقات (API) لاستبدال محتوى ورقة العمل في جدول البيانات البعيد؟

- **تحديث دفعات الملفات السحابية**: تعديل محتويات ملفات Excel المتعددة المخزّنة في تخزين سحابي مثل AWS S3 وAzure Blob.
- **تعبئة قوالب سحابية ديناميكية**: تعبئة بيانات ديناميكية دفعات لقوالب التقارير المخزّنة في السحابة.
- **مزامنة الملفات عبر المناطق الجغرافية**: مزامنة اتساق محتوى ملفات Excel المخزّنة في السحابة عبر مناطق جغرافية مختلفة.

## لماذا يجب استخدام واجهة برمجة تطبيقات (API) لاستبدال محتوى ورقة العمل في جدول البيانات البعيد؟

- **سهل الاستخدام للمطورين**: توفر Aspose.Cells Cloud مكتبات SDK بلغات برمجة متعددة، مما يتيح تطويراً سريعاً ويدعمها توثيق شامل. وبالمقارنة مع بناء حلول مخصّصة لعرض الرسوم البيانية، فإنها تقلّل بشكل كبير من جهود التطوير.
- **تقليل تكاليف العمالة**: تقلّل الحاجة إلى الموظفين المخصّصين لدمج الوثائق.
- **الدفع حسب الاستخدام**: لا توجد استثمارات مبدئية؛ تدفع فقط مقابل مكالمات API التي تُستخدم فعلياً.
- **بدون تكاليف صيانة**: لا حاجة لصيانة الخوادم، أو تحديث البرمجيات، أو التعامل مع مشكلات التوافق.
