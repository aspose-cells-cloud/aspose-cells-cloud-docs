قم بإجراء استبدال دفعي للنصوص عبر ملفات إكسل البعيدة المخزّنة في السحابة. ابحث عن نصوص محددة وحدّثها بكفاءة باستخدام واجهة برمجة تطبيقات Aspose.Cells للبحث والاستبدال في جداول البيانات السحابية.


## **واجهة برمجة التطبيقات لاستبدال المحتوى في جدول بيانات بعيد**

### **واجهة برمجة التطبيقات عبر الويب**

```http
PUT https://api.aspose.cloud/v4.0/cells/{name}/replace/content
```

### **الأمان والمصادقة**

تتطلب واجهات برمجة تطبيقات Aspose.Cells Cloud أماناً عالياً وتستلزم <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### معاملات الطلب

| اسم المعامل      | النوع   | الموقع  | الوصف                                                                                                                                                     |
| ---------------- | ------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **name**         | سلسلة  | المسار   | اسم ملف كتاب العمل المخزّن في التخزين السحابي المراد تعديله (مثال: `"report.xlsx"`).                                                                     |
| **searchText**   | سلسلة  | الاستعلام | السلسلة التي سيتم البحث عنها في كامل كتاب العمل. يتم تنفيذ البحث بحساسية حالات الأحرف (كبير/صغير)، ويطبّق على جميع أوراق العمل ما لم يُقيّد بمعاملات أخرى. |
| **replaceText**  | سلسلة  | الاستعلام | السلسلة التي ستُستبدل بكلّ ظهور لـ `searchText`.                                                                                                          |
| **folder**       | سلسلة  | الاستعلام | مسار مجلد التخزين السحابي الذي يحتوي على كتاب العمل المصدر (مثال: `"/documents/quarterly/"`).                                                            |
| **storageName**  | سلسلة  | الاستعلام | _(اختياري)_ اسم تخزين سحابي مخصص (مثال: `"MyS3Bucket"`). إذا حُذف، يُستخدم التخزين الافتراضي المُعدّ للمستخدم.                                              |
| **region**       | سلسلة  | الاستعلام | _(اختياري)_ معرّف لغة/منطقة قد يؤثر على ترميز الأحرف وسلوك البحث الخاص باللغة (مثال: `"en-US"`).                                                         |
| **password**     | سلسلة  | الاستعلام | _(اختياري)_ كلمة المرور لفتح كتاب عمل محمي.                                                                                                              |

### الاستجابة

تُرجع الاستجابة الناجحة المعتادة حالة العملية وعدد عمليات الاستبدال المنفذة:

```json
{
  "Code": 200,
  "Status": "OK"
}
```

### رموز الأخطاء

- **400 طلب غير صالح** – رابط واجهة برمجة تطبيقات Aspose.Cells Cloud غير صالح.
- **401 غير مُصرّح به** – ناقص أو غير صحيح رمز الوصول OAuth 2.0.
- **404 غير موجود** – لم يُمكن الوصول إلى ملف جدول البيانات المحدّد.
- **500 خطأ في الخادم** – حدثت مشكلة غير متوقعة في جانب الخادم أثناء معالجة الطلب.

## متى يجب استخدام واجهة برمجة التطبيقات لاستبدال المحتوى في جدول بيانات بعيد؟

- **تحديث ملفات سحابية دفعياً** – عدّل محتويات ملفات إكسل متعددة مخزّنة في تخزين سحابي مثل AWS S3 أو Azure Blob.
- **ملء قوالب السحابة ديناميكياً** – املأ قوالب التقارير المخزّنة في السحابة ببيانات مُحدّثة.
- **مزامنة الملفات عبر مناطق جغرافية مختلفة** – اجعل ملفات إكسل متناسقة عبر مناطق تخزين جغرافية مختلفة.

## لماذا استخدام واجهة برمجة التطبيقات لاستبدال المحتوى في جدول بيانات بعيد؟

- **مُيسّرة للمطورين** – توفر Aspose.Cells Cloud مكتبات SDK لعدة لغات برمجة، ما يقلل جهود التطوير مقارنةً ببناء حل مخصّص.
- **خفض تكاليف العمالة** – يلغي الحاجة إلى موظفين مخصّصين لدمج المستندات يدوياً.
- **دفع مقابل الاستخدام فقط** – لا استثمار أولي؛ تدفع فقط مقابل طلبات واجهة برمجة التطبيقات التي تُنفّذها فعلياً.
- **بدون تكاليف صيانة** – لا خوادم لإدارتها، ولا تحديثات برمجية، ولا مشكلات توافق.
- **الحفاظ على تنسيق الخلايا والمعادلات والرسوم البيانية** – تحافظ العملية على تخطيط وحسابات كتاب العمل الأصلي بعد استبدال النصوص.
