## **البحث عن محتوى في ورقة عمل عن بُعد**

ابحث برمجيًا عن نصوص محددة داخل أي ورقة عمل في إكسل باستخدام واجهة برمجة تطبيقات Aspose.Cells Cloud API. يمكن للخدمة العثور على نصوص أو أرقام أو صيغ في الملفات المخزَّنة في التخزين السحابي، ما يمكّن من تنفيذ عمليات تلقائية لاكتشاف البيانات وتحليل المحتوى ومراجعة جداول البيانات.

### **واجهة برمجة التطبيقات عبر الويب (Web API)**

```curl
PUT https://api.aspose.cloud/v4.0/cells/{name}/worksheets/{worksheet}/search/content
```

### **الأمان والمصادقة**

واجهات برمجة تطبيقات Aspose.Cells Cloud آمنة وتتطلب <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">مصادقة تعتمد على رمز JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### **معامِلات الطلب**

| اسم المعامِل | النوع | المسار / سلسلة الاستعلام / جسم HTTP | الوصف |
| ------------ | ------- | --------------------------- | ------------------------------------------------------------------------------------------------- |
| name | نص (String) | المسار (Path) | **إلزامي.** اسم ملف جدول العمل المستهدف (مثل `annual_report.xlsx`). |
| worksheet | نص (String) | المسار (Path) | **إلزامي.** اسم ورقة العمل داخل جدول العمل الذي سيتم البحث فيه. |
| searchText | نص (String) | سلسلة الاستعلام (Query) | **إلزامي.** النص أو الرقم الدقيق الذي ترغب في العثور عليه. |
| ignoreCase | منطقي (Boolean) | سلسلة الاستعلام (Query) | **اختياري.** إذا كانت قيمته `true`، فلن تُؤخذ الحالة (كبيرة/صغيرة) بعين الاعتبار. القيمة الافتراضية هي `false`. |
| folder | نص (String) | سلسلة الاستعلام (Query) | **اختياري.** مسار المجلد الذي يحتوي على ملف جدول العمل. إذا تم تجاهله، سيُستخدم المجلد الجذري. |
| storageName | نص (String) | سلسلة الاستعلام (Query) | **اختياري.** اسم تخزين سحابي مُعد مسبقًا حسب التخصيص. إذا تم تجاهله، سيُستخدم التخزين الافتراضي. |
| region | نص (String) | سلسلة الاستعلام (Query) | **اختياري.** إعداد التهيئة الإقليمية (مثل `ja-JP`) التي قد تؤثر على مقارنة النصوص. |
| password | نص (String) | سلسلة الاستعلام (Query) | **اختياري.** كلمة المرور لجدول العمل المحمي. اتركه فارغًا إذا لم يكن الملف مشفرًا. |

### **الاستجابة**

```json
{
  "textItems": [
    {
      "cellName": "A1",
      "text": "الإجمالي",
      "occurrences": 1
    },
    {
      "cellName": "B5",
      "text": "الإجمالي",
      "occurrences": 2
    }
  ],
  "code": 200,
  "status": "OK"
}
```

- **textItems** – مصفوفة تحتوي على النتائج المطابقة. يحتوي كل عنصر على عنوان الخلية (`cellName`) والنص المطابق (`text`) وعدد مرات تكراره في تلك الخلية (`occurrences`).
- **code** – رمز حالة HTTP الذي تعيده الخدمة.
- **status** – وصف نصي لحالة النتيجة.

### **أكواد الخطأ**

- **400 Bad Request** – عنوان URI لواجهة برمجة التطبيقات غير صالح أو المعامِلات غير صحيحة.
- **401 Unauthorized** – رمز OAuth 2.0 مفقود أو غير صالح.
- **404 Not Found** – لا يمكن العثور على ملف جدول العمل أو ورقة العمل.
- **500 Server Error** – حدثت حالة غير متوقعة أثناء معالجة الطلب.

## أين يجب استخدام ميزة البحث عن المحتوى داخل ورقة عمل جدول البيانات من واجهة برمجة التطبيقات؟

- **مراجعة الامتثال لملف جدول العمل:** ابحث بسرعة عن مصطلحات حساسة (مثل "سري") عبر الملف بأكمله.
- **الارتباط بين البيانات عبر ورقات العمل:** ابحث عن رقم مشروع أو اسم عميل يظهر في عدة أوراق عمل.
- **التحقق من القوالب:** بعد إنشاء التقارير، تأكد من استبدال العناصر النائبة مثل `{{Date}}`.
- **تعدين البيانات التاريخية:** ابحث عن أكوال أحداث محددة في جداول البيانات القديمة لفهم المنطق التجاري السابق.

## لماذا يجب استخدام ميزة البحث عن المحتوى داخل ورقة عمل جدول البيانات من واجهة برمجة التطبيقات؟

- **سهولة الاستخدام للمطورين:** توفر مكتبات (SDKs) لعدة لغات برمجة تسريعًا كبيرًا في التطوير، وهي موثقة بالكامل.
- **تقليل تكاليف العمالة:** يقلل الحاجة إلى موظفين مخصصين لجمع البيانات يدويًا.
- **الدفع حسب الاستخدام:** تدفع فقط مقابل استدعاءات واجهة برمجة التطبيقات التي تُنفِّذها فعليًا.
- **لا صيانة مطلوبة:** لا توجد خوادم لإدارتها، ولا تحديثات برمجية، ولا قلق تجاه التوافق.
- **الحفاظ على تنسيقات إكسل المعقدة** عند تصدير النتائج إلى PDF أو تنسيقات أخرى.

## كيف تستخدم ميزة البحث عن الروابط التالفة داخل ورقة عمل جدول البيانات من واجهة برمجة التطبيقات باستخدام المكتبات (SDKs)

### **مواصفات OpenAPI**

تعرّف [مواصفات OpenAPI](https://reference.aspose.cloud/cells/#/SearchControllor/SearchContentInRemoteWorksheet) واجهة برمجة تطبيقات يمكن الوصول إليها علنًا، وتتيح التفاعل عبر REST مباشرة من متصفح ويب.

### **استخدام مكتبات Aspose.Cells Cloud SDKs**

استخدام المكتبة (SDK) هو أفضل طريقة لتسريع التطوير. فتتولى المكتبة جميع التفاصيل الأساسية، وتسمح لك بتنفيذ البحث عن المحتوى داخل ورقة العمل برمجيًا باستخدام كود محدود. يُرجى زيارة [مستودع GitHub](https://github.com/aspose-cells-cloud) للاطلاع على القائمة الكاملة لمكتبات Aspose.Cells Cloud SDKs.
