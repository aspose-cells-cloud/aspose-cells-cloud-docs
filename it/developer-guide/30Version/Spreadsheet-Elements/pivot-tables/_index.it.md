## Lavorare con PivotTable in un file Excel

Le PivotTable sono potenti strumenti di sintesi dei dati in Excel che consentono agli sviluppatori di aggregare, filtrare e analizzare dinamicamente grandi insiemi di dati. L'API REST di Aspose.Cells Cloud fornisce endpoint per creare, recuperare, modificare ed eliminare PivotTable in modo programmatico, consentendo un'integrazione fluida nelle proprie applicazioni.

**Prerequisiti** – È necessario disporre di un token di autenticazione valido per Aspose.Cells Cloud e di un SDK supportato (ad esempio .NET, Java, Python, Go, Node.js, PHP, Ruby, Swift) installato nel proprio progetto.

**Esempio di chiamata API** – Per recuperare tutte le PivotTable in un foglio di calcolo specifico, inviare una richiesta GET come la seguente:

```http
GET https://api.aspose.cloud/v3.0/cells/{fileName}/worksheets/{sheetName}/pivottables
```

**Note** – Queste operazioni richiedono la versione 3.0 o successiva di Aspose.Cells Cloud.
