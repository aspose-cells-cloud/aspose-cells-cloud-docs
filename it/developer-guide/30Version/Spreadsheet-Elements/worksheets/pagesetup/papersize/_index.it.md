**Prerequisiti**  
Prima di invocare l’endpoint, è necessario ottenere un token di accesso Aspose Cloud valido con le autorizzazioni appropriate e la versione dell’API (`v3.0`).

### Come impostare una dimensione della carta tramite l’API REST di Aspose.Cells Cloud

```bash
curl -X PUT "https://api.aspose.cloud/v3.0/cells/Workbook/worksheets/Sheet1/pageSetup" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{"PaperSize":"PaperA4"}'
```

**Dettagli della richiesta**  
- **Metodo:** `PUT`  
- **Endpoint:** `/cells/Workbook/worksheets/{sheetName}/pageSetup`  
- **Parametri di percorso:** `sheetName` – nome del foglio di lavoro (stringa, obbligatorio).  
- **Corpo della richiesta:** Oggetto JSON contenente la proprietà `PaperSize`. Il valore deve essere una delle costanti elencate nella tabella precedente, ad esempio `"PaperA4"`.

**Risposte**  
- `200 OK` – Impostazione pagina aggiornata correttamente.  
- `400 Bad Request` – Valore `PaperSize` non valido.  
- `401 Unauthorized` – Autenticazione non riuscita o token mancante.  
- `404 Not Found` – Il foglio di lavoro specificato non esiste.

**Esempio di SDK (C#)**  
```csharp
var api = new CellsApi("client_id", "client_secret");
var request = new PageSetup { PaperSize = PaperSizeEnum.PaperA4 };
api.PutWorksheetPageSetup("Book1.xlsx", "Sheet1", request);
```

Per una definizione OpenAPI completa, consulta la <a href="https://api.aspose.cloud/v3.0/swagger.json" target="_blank" rel="noopener">specifiche Swagger di Aspose.Cells Cloud</a>.

Consulta anche la [documentazione sull’impostazione della pagina](/page-setup/) per configurare margini, orientamento e altre opzioni di layout.
