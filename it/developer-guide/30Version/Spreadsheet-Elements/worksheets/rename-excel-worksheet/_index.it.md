Questa API REST rinomina un foglio di calcolo Excel.

## API REST

```bash
POST http://api.aspose.cloud/v3.0/cells/{name}/worksheets/{sheetName}/rename
```

### **Parametri della richiesta**

| Nome parametro | Tipo   | Posizione | Descrizione                                     |
| -------------- | ------ | --------- | ----------------------------------------------- |
| name           | string | path      | Nome del file Excel.                            |
| sheetName      | string | path      | Nome attuale del foglio di calcolo da rinominare. |
| newname        | string | query     | Nuovo nome per il foglio di calcolo.            |
| folder         | string | query     | Percorso della cartella nell’archivio (opzionale). |
| storageName    | string | query     | Nome dell’archivio (opzionale).                 |

La [specifica OpenAPI](https://apireference.aspose.cloud/cells/#/Worksheets/PostRenameWorksheet) definisce un'interfaccia di programmazione accessibile pubblicamente e consente di effettuare interazioni REST direttamente da un browser web.

Puoi utilizzare lo strumento a riga di comando cURL per accedere facilmente ai servizi web di Aspose.Cells. L'esempio seguente mostra come effettuare chiamate all'API Cloud con cURL.
