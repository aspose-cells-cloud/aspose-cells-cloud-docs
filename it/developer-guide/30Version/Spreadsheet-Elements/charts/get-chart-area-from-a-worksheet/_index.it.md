Questa REST API restituisce le informazioni sull’area del grafico.

**Prerequisiti:** Per chiamare questo endpoint è necessario disporre di un token di accesso JWT valido, il foglio di lavoro di destinazione deve essere caricato nell’archivio cloud di Aspose Cloud e il formato del file deve essere supportato da Aspose.Cells.

**Contesto:** L’area del grafico definisce il riquadro esterno più ampio di un grafico Excel, inclusi titoli, legende e area di tracciato. Recuperarne le proprietà consente di regolare in modo programmatico il layout e lo stile.

## API GetChartArea

```http
GET https://api.aspose.cloud/v3.0/cells/{name}/worksheets/{sheetName}/charts/{chartIndex}/chartArea
```

### **Sicurezza e autenticazione**

Le API di Aspose.Cells Cloud sono sicure e richiedono l’<a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">autenticazione basata su token JWT</a>.

### Parametri della richiesta

| Nome parametro | Tipo    | Posizione | Descrizione                                       |
| -------------- | ------- | --------- | ------------------------------------------------- |
| name           | string  | path      | Nome del file del foglio di lavoro.               |
| sheetName      | string  | path      | Nome del foglio di lavoro contenente il grafico.  |
| chartIndex     | integer | path      | Indice in base zero del grafico.                  |
| folder         | string  | query     | Cartella in cui è archiviato il foglio di lavoro. |
| storageName    | string  | query     | Nome del servizio di archiviazione.               |

**Richiesta HTTP generica (ad esempio, utilizzando fetch):**

```javascript
fetch('https://api.aspose.cloud/v3.0/cells/Sample_Test_Book.xls/worksheets/Sheet5/charts/0/chartArea', {
  method: 'GET',
  headers: {
    'Content-Type': 'application/json',
    'Accept': 'application/json',
    'Authorization': 'Bearer <jwt token>'
  }
})
  .then(response => response.json())
  .then(data => console.log(data));
```
