## Lavorare con le forme in un file Excel

Le forme rappresentano oggetti di disegno come linee, rettangoli, caselle di testo e immagini che possono essere posizionate su un foglio di calcolo Excel. Sono utili per visualizzare dati, aggiungere annotazioni o creare elementi interattivi all'interno di un foglio di calcolo. Questa pagina fornisce link rapidi alle operazioni più comuni relative alle forme, ognuna accompagnata da una breve descrizione.

**Prerequisiti:** Per utilizzare le operazioni sulle forme, è necessario disporre di una chiave API valida di Aspose.Cells Cloud e di un foglio di calcolo esistente caricato nel cloud.

- [Come ottenere tutte le forme su un foglio di calcolo Excel.](/it/cells/shapes/get-all/) – Recupera una raccolta completa delle forme presenti nel foglio di calcolo.
- [Come ottenere una forma per indice su un foglio di calcolo Excel.](/it/cells/shapes/get/) – Restituisce la forma situata all'indice specificato.
- [Come aggiungere una forma su un foglio di calcolo Excel.](/it/cells/shapes/add/) – Inserisce una nuova forma (ad esempio rettangolo, linea o immagine) nel foglio di calcolo.
- [Come eliminare tutte le forme su un foglio di calcolo Excel.](/it/cells/shapes/clear/) – Rimuove tutte le forme dal foglio di calcolo in un'unica operazione.
- [Come eliminare una forma per indice su un foglio di calcolo Excel.](/it/cells/shapes/delete/) – Elimina la forma all'indice specificato.
- [Come convertire una forma in un'immagine su un foglio di calcolo Excel.](/it/cells/shapes/conversion/) – Converte una forma selezionata in un file immagine (PNG, JPEG, ecc.) per un utilizzo esterno.
