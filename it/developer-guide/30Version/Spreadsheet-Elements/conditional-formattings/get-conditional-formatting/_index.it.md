Questa REST API recupera le regole di formattazione condizionale da un foglio di lavoro.

## REST API

```bash
GET http://api.aspose.cloud/v3.0/cells/{name}/worksheets/{sheetName}/conditionalFormattings/{index}
```

### Parametri della Richiesta

| Nome Parametro | Tipo    | Posizione | Descrizione                                             |
| -------------- | ------- | --------- | ------------------------------------------------------- |
| name           | string  | path      | Nome del file del foglio di calcolo.                   |
| sheetName      | string  | path      | Nome del foglio di lavoro che contiene la formattazione. |
| index          | integer | path      | Indice a base zero della regola di formattazione condizionale. |
| folder         | string  | query     | Percorso della cartella in cui è memorizzato il foglio di calcolo. |
| storageName    | string  | query     | Nome del servizio di archiviazione.                     |

### Risposte di Errore

| Codice HTTP | Motivo                                                         | Esempio Corpo Risposta                                              |
| ----------- | -------------------------------------------------------------- | ------------------------------------------------------------------- |
| **400**     | Richiesta Non Validata – parametri mancanti o non validi.     | `{ "Code":"400", "Message":"Valore del parametro non valido." }`   |
| **401**     | Non Autorizzato – token JWT mancante o non valido.            | `{ "Code":"401", "Message":"Token di accesso mancante o non valido." }` |
| **404**     | Non Trovato – il foglio di calcolo o il foglio di lavoro non esiste. | `{ "Code":"404", "Message":"File non trovato." }`                  |
| **500**     | Errore Interno del Server – errore imprevisto nel server.     | `{ "Code":"500", "Message":"Si è verificato un errore imprevisto." }` |

La [Specifiche OpenAPI](https://apireference.aspose.cloud/cells/#/ConditionalFormattings/GetWorksheetConditionalFormatting) definiscono un'interfaccia di programmazione pubblicamente accessibile e consentono di effettuare interazioni REST direttamente da un browser web.

Puoi utilizzare lo strumento a riga di comando cURL per accedere facilmente ai servizi web di Aspose.Cells. L'esempio seguente mostra come effettuare una chiamata all'API Cloud con cURL.
