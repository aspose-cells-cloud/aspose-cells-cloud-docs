## Lavorare con le attività

Aspose.Cells Cloud fornisce un'**API delle attività** che consente agli sviluppatori di eseguire una varietà di operazioni sui file Excel, come la conversione di formati, l'importazione di dati, l'esecuzione di modelli SmartMarker e il salvataggio dei risultati. Le attività vengono eseguite in modo asincrono: si crea un'attività, la si esegue e poi se ne recupera il risultato.

**Prerequisiti:** un account Aspose Cloud con una chiave API valida, formati Excel supportati e l'ultima versione dell'API Cells (v3.0 o successiva).

- [Richiesta di file di supporto nell'API delle attività](/it/cells/support-request-file-in-task-api/) – Consente di caricare un file nello storage cloud e di farvi riferimento nelle attività successive, garantendo che il file sia disponibile per l'elaborazione.
- [Lavorare con l'attività CellsObjectOperate](/it/cells/working-with-cellsobjectoperate-task/) – Esegue operazioni sugli oggetti celle (ad esempio righe, colonne) all'interno di un workbook, come l'aggiunta, l'eliminazione o l'aggiornamento dei valori delle celle.
- [Lavorare con l'attività di conversione](/it/cells/working-with-convert-task/) – Converte un workbook nei formati PDF, HTML, CSV o JSON, con opzioni per l'intervallo di pagine, la protezione tramite password e impostazioni di conversione personalizzate.
- [Lavorare con l'attività ImportData](/it/cells/working-with-importdata-task/) – Importa dati da file CSV, JSON o XML in un foglio di calcolo, mappando le colonne alle celle e, facoltativamente, specificando la riga e la colonna iniziali.
- [Lavorare con l'attività SaveResult](/it/cells/working-with-saveresult-task/) – Salva il risultato di un'attività precedentemente eseguita (ad esempio, un file convertito) nuovamente nello storage cloud oppure lo restituisce nella risposta.
- [Lavorare con l'attività SmartMarker](/it/cells/working-with-smartmarker-task/) – Elabora un workbook contenente tag SmartMarker (ad esempio `{{Customer.Name}}`) utilizzando una sorgente dati JSON per generare un report compilato.
- [Lavorare con le operazioni sui fogli di calcolo nell'API delle attività](/it/cells/working-with-worksheetoperates-in-task-api/) – Esegue operazioni a livello di foglio di calcolo, come l'aggiunta, l'eliminazione o la ridenominazione dei fogli di calcolo, come parte di un flusso di lavoro di attività.

Per specifiche complete dei metodi—including verbi HTTP, URL degli endpoint, schemi di richiesta/risposta, tabelle dei parametri e payload di esempio—fare riferimento alle singole pagine delle attività collegate sopra. Questo riferimento API dettagliato aiuta gli sviluppatori a integrare rapidamente e in modo affidabile l'API delle attività.
