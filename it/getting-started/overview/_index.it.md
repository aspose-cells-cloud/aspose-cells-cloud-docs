Aspose.Cells Cloud è un'API REST che abilita una vasta gamma di attività di elaborazione dei documenti, come la creazione, la manipolazione, la conversione e la resa di documenti Excel nel cloud. Puoi convertire facilmente i file Excel in vari formati, tra cui:

- PDF  
- HTML  
- ODS  
- XPS  
- CSV  
- e altri formati popolari  

**Prerequisiti:** Per utilizzare il servizio è necessario disporre di un account Aspose Cloud e di una chiave API valida. Queste credenziali sono richieste per tutte le richieste autenticate.

## **SDK**

L'utilizzo di un SDK (client API) accelera lo sviluppo gestendo i dettagli di basso livello relativi alla realizzazione delle richieste e alla gestione delle risposte, consentendo agli sviluppatori di concentrarsi sul codice specifico del progetto. Esplora il nostro <a href="https://github.com/aspose-cells-cloud" rel="noopener noreferrer">repository GitHub</a> per un elenco completo degli SDK di Aspose.Cells, completi di esempi funzionanti per accelerare lo sviluppo del tuo progetto. Consulta l'articolo "[SDK disponibili](/it/cells/available-sdks/)" per apprendere come integrare un SDK nel proprio progetto.

## **API Explorer**

L'<a href="https://apireference.aspose.cloud/cells/" rel="noopener noreferrer">Riferimento API di Aspose.Cells Cloud</a> offre un modo intuitivo per sperimentare direttamente le API dal proprio browser. Consente un'interazione fluida e il test di tutte le operazioni messe a disposizione dal servizio. Per iniziare rapidamente, puoi provare l'esempio "Converti cartella di lavoro", che illustra una semplice richiesta POST per convertire un file Excel in PDF.

### **Sicurezza e autenticazione**

Le API di Aspose.Cells Cloud sono sicure e richiedono <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">l'autenticazione basata su token JWT</a>.
