## Что такое контейнер Aspose.Cells Cloud Docker?

Контейнер Aspose.Cells Cloud Docker — это контейнеризованная служба, предоставляемая компанией Aspose на базе Docker, позволяющая развертывать функциональность API Aspose.Cells Cloud в локальных или частных облачных средах без использования публичных облачных сервисов Aspose.

## Почему использовать контейнер Aspose.Cells Cloud Docker?

Контейнер Aspose.Cells Cloud Docker — это мощная контейнеризованная служба для обработки электронных таблиц, поддерживающая:

### Основные функции

- Чтение и запись файлов Excel (XLS, XLSX, CSV, ODS и др.)
- Расчет формул, диаграммы, условное форматирование, сводные таблицы и др.
- Конвертация форматов (например, Excel в PDF, HTML, изображения и др.)
- Операции с ячейками, настройка стилей, управление листами и др.

Контейнер Aspose.Cells Cloud Docker инкапсулирует эти функции в виде RESTful API и упаковывает их в образ Docker, позволяя запускать его на собственной инфраструктуре.

### Основные преимущества

| Преимущества             | Описание                                                                 |
| ------------------------ | ------------------------------------------------------------------------ |
| Конфиденциальность и безопасность данных | Все операции по обработке файлов выполняются внутри вашей частной сети; загрузка в стороннее облачное хранилище не требуется. |
| Доступность в автономном режиме | Не зависит от публичного облака Aspose; подходит для внутренних сетей или изолированных сред. |
| Масштабируемость         | Легко масштабируется с помощью Docker/Kubernetes.                        |
| Единый API               | Полностью совместим с публичным API Aspose.Cells Cloud; изменения в коде не требуются. |
| Контроль лицензирования   | Поддерживает два типа авторизации; выберите подходящий вариант для вашей ситуации. |

## Как использовать контейнер Aspose.Cells Cloud Docker

См. руководство пользователя — [Как использовать контейнер Aspose.Cells Cloud Docker](https://docs.aspose.cloud/cells/docker-developer-guide/#run-asposecells-cloud-docker-container).

**Предварительные требования**

- Docker Engine версии 20.10 или выше, установленный на хост-машине.  
- Минимум 2 ГБ оперативной памяти и 2 ядра ЦП, выделенные контейнеру для типичных рабочих нагрузок.  
- Действующий файл лицензии Aspose.Cells Cloud (или токен доступа), размещённый в каталоге, который будет смонтирован в контейнер.

**Быстрый старт**

1. Загрузите образ Docker: `docker pull aspose/cells-cloud`.  
2. Запустите контейнер, смонтировав каталоги лицензии и данных, например:  
   ```bash
   docker run -d -p 8080:80 \
     -v /path/to/license:/app/license \
     -v /path/to/data:/app/data \
     aspose/cells-cloud
   ```  
3. Обратитесь к REST API по адресу `http://localhost:8080/v3.0/`. Подробное описание использования API приведено в [справочнике по API Aspose.Cells Cloud](https://docs.aspose.cloud/cells/api-reference/).
