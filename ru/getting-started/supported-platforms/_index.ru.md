Aspose.Cells Cloud предоставляет независимую от платформы, настоящую REST API для обработки документов. Она работает с любым языком программирования, способным отправлять HTTP-запросы, например Go, Java, .NET, Node.js, Perl, PHP, Python, Ruby и многими другими. Поскольку сервис доступен через стандартные REST-вызовы, ограничений по языку или платформе не существует. Вы можете вызывать API из веб-, настольных, мобильных или облачных сред. API также интегрируется с другими облачными сервисами, обеспечивая гибкость, необходимую для обработки документов Excel, PDF, CSV, JSON и других форматов во всех бизнес-сценариях.

Сервис поддерживает последние версии Windows, популярные дистрибутивы Linux (Ubuntu, CentOS, Debian) и macOS. SDK доступны для .NET, Java, Python, PHP, Ruby, Go и Node.js, каждый из которых поставляется с подробными примерами кода. Docker-образы предоставляются для упрощения развертывания в контейнеризированных средах, позволяя вам запускать API локально или в облаке с минимальной настройкой.
