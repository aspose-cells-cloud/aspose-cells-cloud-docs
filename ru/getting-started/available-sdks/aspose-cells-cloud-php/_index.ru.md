# **Как использовать Aspose.Cells Cloud SDK для PHP**

Aspose.Cells Cloud SDK для PHP — мощная библиотека, позволяющая разработчикам манипулировать и обрабатывать файлы Microsoft Excel с помощью **языка программирования PHP**. С помощью этого SDK вы можете создавать, редактировать и конвертировать документы Excel в облаке, не устанавливая дополнительное программное обеспечение или зависимости на вашем локальном компьютере.

В этой статье мы рассмотрим, как использовать Aspose.Cells Cloud SDK для PHP для выполнения некоторых типичных задач: создания новой рабочей книги Excel, вставки данных в ячейки и сохранения изменённой рабочей книги в облако.

## Начало работы

Прежде чем начать использовать Aspose.Cells Cloud SDK для **PHP**, необходимо настроить среду разработки и установить необходимые зависимости. Обратитесь к <a href="https://docs.aspose.cloud/cells/quickstart/" target="_blank" rel="noopener noreferrer">статье</a> на сайте Aspose, чтобы получить ваш идентификатор клиента и секретный ключ клиента.

**Предварительные требования**

- PHP 7.4 или более поздняя версия  
- Установленный Composer на вашей машине для разработки  
- Действующий идентификатор клиента и секретный ключ клиента Aspose Cloud  
- Доступ к хранилищу Aspose Cloud (по умолчанию или пользовательскому)  

## Как установить PHP-пакет для Aspose.Cells Cloud

Вы можете установить Aspose.Cells Cloud SDK для PHP. Ниже приведены шаги:

- Добавьте Aspose.Cells Cloud как зависимость в ваш файл `composer.json`:

   ```json
   {
       "require": {
           "aspose/cells-cloud": "^24.3"
       }
   }
   ```

- Выполните обновление Composer для установки SDK:

   ```bash
   composer install
   ```

- Подключите автозагрузчик Composer в ваш PHP-код:

   ```php
   require 'vendor/autoload.php';
   ```

## Как использовать PHP-пакет для конвертации Xlsx в другие форматы

- Импортируйте библиотеку Aspose.Cells Cloud  
  Начните с импорта необходимого пакета из Aspose.Cells Cloud PHP SDK в ваш проект.

- Настройте клиент API с учётными данными  
  Аутентифицируйте ваш клиент API с помощью уникального идентификатора клиента и секретного ключа клиента.

- Подготовьте параметры конвертации  
  Задайте параметры задачи конвертации, включая имя исходного файла, желаемый формат вывода и путь к папке хранилища.

- Выполните конвертацию рабочей книги  
  Вызовите процесс конвертации с помощью метода `PostConvertWorkbook` и обработайте ответ.

### Справочник по API для `PostConvertWorkbook`

| Параметр       | Описание                                              | Тип    | Обязательный |
|----------------|--------------------------------------------------------|--------|--------------|
| `file`         | Имя исходного файла Excel (например, `sample.xlsx`). | string | Да           |
| `format`       | Желаемый формат вывода (`pdf`, `csv`, `png` и др.).   | string | Да           |
| `storage`      | Имя хранилища или путь к папке, где находится исходный файл. | string | Нет          |
| `outPath`      | Необязательный путь для сохранения сконвертированного файла непосредственно в хранилище. | string | Нет          |

**HTTP-метод:** POST  
**Конечная точка:** `/cells/convert/{format}`  

**Пример ответа (JSON)**  

```json
{
  "status": "OK",
  "url": "https://api.aspose.cloud/v3.0/cells/convert/output.pdf"
}
```

**Коды состояния**

- `200` — конвертация успешно завершена.  
- `400` — неверный запрос (отсутствуют или недопустимы параметры).  
- `401` — ошибка аутентификации.  
- `500` — ошибка сервера.
