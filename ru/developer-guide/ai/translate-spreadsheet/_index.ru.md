Endpoint **TranslateSpreadsheet**, входящий в состав **API перевода электронных таблиц**, считывает каждый текстовый элемент в рабочей книге, отправляет содержимое в сервис перевода на основе ИИ и возвращает новый файл электронной таблицы, в котором все текстовые данные представлены на указанном языке — **targetLanguage**. Операция сохраняет исходную компоновку, стили ячеек, формулы и **структуру** с несколькими листами, что делает её идеальной для локализации отчётов, информационных панелей и документов, основанных на данных. Поддерживаемые форматы файлов: XLS, XLSX, XLSM, CSV и ODS. Ошибки возвращаются при недопустимых кодах языка, сбоях аутентификации или недоступности сервиса перевода.

## **API перевода электронных таблиц**

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/ai/translate/spreadsheet
```

### **Параметры запроса:**

| Имя параметра | Тип    | Расположение | Обязательный/Необязательный | Описание                                                                                                                                                                                                 |
| :------------ | :----- | :----------- | :------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet   | File   | Required     | FormData                   | Рабочая книга Excel, подлежащая переводу. Допустимые расширения: .xls, .xlsx, .xlsm, .csv, .ods. Максимальный размер файла: 50 МБ. Пример: `budget.xlsx`.                                                 |
| targetLanguage | string | Required     | Query                      | Код языка по стандарту ISO 639‑1 для целевого языка вывода (например, «es» — испанский, «fr» — французский, «de» — немецкий). Язык должен поддерживаться базовым сервисом ИИ.                               |
| region        | string | Optional     | Query                      | Идентификатор региона электронной таблицы, влияющий на форматирование, зависящее от региона: даты, числа, валюты. Типичные значения: «US», «EU», «CN». Если не указан, используется исходный регион книги. |
| password      | string | Optional     | Query                      | Пароль для открытия защищённой рабочей книги. Оставьте пустым, если файл не защищён паролем.                                                                                                              |

### **Ответ**

Успешный ответ (200 OK)  
Заголовки:  
Content‑Type: application/octet-stream // или text/csv, если запрошен вывод CSV  
Content‑Disposition: attachment; filename="translated.xlsx"  
Content‑Length: <размер в байтах>

Тело ответа:  
<двоичный поток, содержащий переведённый файл электронной таблицы>

Ответы об ошибках следуют стандартной модели ошибок Aspose.Cells Cloud (application/json), включая поля `code`, `message` и необязательное поле `details`.

**Коды HTTP-статуса**

| Код | Значение              | Описание                                                          |
| --- | --------------------- | ----------------------------------------------------------------- |
| 200 | OK                    | Фильтр применён успешно; ответ содержит детали операции.         |
| 400 | Bad Request           | Отсутствуют или некорректны параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized          | Некорректный или отсутствующий JWT-токен.                         |
| 413 | Payload Too Large     | Загруженный файл превышает лимит размера.                         |
| 500 | Internal Server Error | Непредвиденная ошибка сервера.                                    |

## Где следует использовать API перевода электронных таблиц?

- **Международная финансовая отчётность** — Перевод квартальных отчётов Excel на несколько языков для региональных офисов с сохранением формул и макетов диаграмм.
- **Многоязычные маркетинговые информационные панели** — Автоматическая генерация локализованных версий панелей отслеживания показателей продаж для глобальных команд.
- **Распространение образовательного контента** — Перевод оценочных таблиц, заданий и учебных таблиц для студентов в разных странах без ручного копирования и вставки.
- **Соблюдение регуляторных требований** — Генерация отчётов о соответствии, адаптированных к языку, с сохранением правил валидации и списков ограничений данных.

## Почему стоит использовать API перевода электронных таблиц?

- **Точность на основе ИИ** — Использует современные нейросетевые модели перевода для контекстно-зависимого и высококачественного языкового преобразования.
- **Нулевые искажения макета** — Сохраняет формулы ячеек, условное форматирование, диаграммы и порядок листов в точности как в исходном файле.
- **Обработка нескольких листов за один вызов** — Переводит каждый лист в одном запросе, исключая необходимость циклов по листам.
- **Бесшовная интеграция в облако** — Работает с аутентификацией Aspose.Cells Cloud, обеспечивая автоматизацию в CI/CD, serverless-функциях и корпоративных бэкендах.
