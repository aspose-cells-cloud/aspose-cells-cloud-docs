Конечная точка **DecomposeUserTask** предоставляет REST-интерфейс для преобразования описания задачи в свободной форме в детальный, последовательный план действий, соответствующий критериям SMART. Система автоматически рассчитывает оценки длительности в часах, формирует вывод в формате, совместимом с Redmine, и создаёт узлы этапов проекта. При предоставлении только исходного списка задач и, при необходимости, предварительных оценок времени, API возвращает готовый к использованию файл (CSV, XLSX и др.), который можно непосредственно импортировать в инструменты управления проектами, автоматизируя разбиение задач и сокращая ручной труд.

## **API декомпозиции пользовательской задачи**

### Веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/ai/task/decompose
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### **Параметры запроса:**

| Название параметра | Тип    | Расположение | Обязательный/необязательный | Описание                                                                                                                                                                                                                              |
| :----------------- | :----- | :---------- | :-------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| TaskDescription    | string | Body        | Обязательный                | Описание общей цели пользователя в виде обычного текста. Сервис анализирует описание и генерирует отдельные задачи. Пример: «Запустить маркетинговую кампанию на III квартал, включая создание контента, рассылку по электронной почте и рекламу в соцсетях». |

### **Ответ**

Успешный ответ (200 OK)  
Content-Type: `application/octet-stream` (поток двоичных данных)

Заголовки:

- `Content-Disposition: attachment; filename="DecomposedTaskPlan.xlsx"`
- `Content-Length: <размер в байтах>`

Для форматов XLSX/ODS структура аналогична, столбцы размещаются в первом листе.

**Коды HTTP-статусов**

| Код | Значение              | Описание                                                         |
| --- | --------------------- | ---------------------------------------------------------------- |
| 200 | OK                    | Фильтр применён успешно; в ответе содержатся данные об операции. |
| 400 | Bad Request           | Отсутствуют или некорректны параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized          | Неверный или отсутствующий JWT-токен.                            |
| 413 | Payload Too Large     | Размер загружаемого файла превышает допустимый лимит.            |
| 500 | Internal Server Error | Непредвиденная ошибка сервера.                                   |

**Пример ответа об ошибке (400 Bad Request)**

```json
{
  "code": "InvalidParameter",
  "message": "Поле 'TaskDescription' является обязательным и не может быть пустым."
}
```

**Пример тела запроса (JSON)**

```json
{
  "TaskDescription": "Разработать веб-API для функции разбиения задач в существующей системе."
}
```

**Пример ответа**  
API возвращает двоичный поток, содержащий сгенерированный файл. Чтобы просмотреть первые несколько строк CSV-ответа, декодируйте поток и отобразите строку заголовков, например:


## Где следует использовать API декомпозиции пользовательской задачи?

- **Запуск проекта**: Преобразуйте общий brief проекта в список задач, совместимый с Redmine, с оценками времени, чтобы сразу приступить к планированию спринта.
- **Автоматизация маркетинга**: Разбейте цели кампании на исполнимые этапы, экспортируйте как CSV и импортируйте в инструменты управления задачами для координации работы между командами.
- **Распределение ресурсов**: Сгенерируйте почасовые оценки для каждой подзадачи, чтобы менеджеры могли сбалансировать нагрузку между участниками команды до начала проекта.
- **Отслеживание вех**: Автоматически создавайте узлы вех, синхронизируемые с инструментами диаграмм Ганта, обеспечивая чёткие выходные данные для каждой фазы.

## Почему стоит использовать API декомпозиции пользовательской задачи?

- **Выходные данные, соответствующие критериям SMART**, гарантируют, что каждая сгенерированная задача будет конкретной, измеримой, достижимой, релевантной и ограниченной по времени.
- **Встроенная почасовая оценка времени** устраняет необходимость вручную рассчитывать длительность и повышает точность прогнозов.
- **Готовые к импорту форматы файлов** (CSV, XLSX и др.) упрощают интеграцию с Redmine, Jira, Azure DevOps и другими платформами управления проектами.
- **Автоматизация одним запросом** позволяет разбивать задачи за один вызов, ускоряя инициацию проекта и минимизируя ручной труд.
