Конечная точка **TranslateTextFile** использует облачные ИИ-сервисы Aspose.Cells для перевода содержимого текстового файла на указанный целевой язык. Она поддерживает два режима работы: (1) **Режим загрузки файла** — отправка текстового файла через multipart/form-data с получением переведённого файла в ответ; (2) **Режим прямой передачи контента** — отправка необработанного текста в теле запроса с получением переведённого текста напрямую. Сервис сохраняет исходные разрывы строк и форматирование, автоматически добавляет суффикс "\_translated" к имени файла и возвращает результат в виде потока для скачивания. Идеально подходит для пакетного перевода документов, интеграции в многоязыковые рабочие процессы или оперативного перевода пользовательского контента.

## **API перевода текстового файла**

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/ai/translate/text-file
```

### **Параметры запроса:**

| Название параметра | Тип   | Расположение | Обязательный/необязательный | Описание                                                                                                                                                                                                 |
| :----------------- | :---- | :---------- | :-------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet        | File  | Обязательный | FormData                    | Исходный текстовый файл для перевода. Должен быть простым текстовым файлом (.txt) или поддерживаемым форматом электронной таблицы. Пример: загрузка `document.txt` через поле "file" в multipart/form-data. |
| targetLanguage     | String| Обязательный | Query                       | Языковой код ISO‑639‑1 целевого языка (например, "es" — испанский, "fr" — французский, "de" — немецкий). Код нечувствителен к регистру.                                                                     |
| region             | string| Необязательный| Query                       | Идентификатор региона электронной таблицы, влияющий на форматирование, зависящее от локали (даты, числа, валюты). Типичные значения: "US", "EU", "CN". При отсутствии используется исходный регион книги.     |
| password           | String| Необязательный| Query                       | Пароль, необходимый для открытия зашифрованных файлов электронных таблиц. Для простых текстовых файлов не требуется.                                                                                     |

### **Ответ**

Успешный ответ (200 OK)
Заголовки:
Content-Type: application/octet-stream // бинарный поток переведённого файла
Content-Disposition: attachment; filename="<исходное_имя>\_translated.txt"
Content-Length: <размер в байтах>

Тело: бинарный поток, содержащий переведённый текст с сохранением исходных разрывов строк и форматирования.

**Коды HTTP-статуса**

| Код | Значение                | Описание                                                           |
| --- | ----------------------- | ------------------------------------------------------------------ |
| 200 | OK                      | Перевод успешно выполнен; ответ содержит детали операции.         |
| 400 | Bad Request             | Отсутствуют или недопустимы параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized            | Недействительный или отсутствующий JWT-токен.                     |
| 413 | Payload Too Large       | Размер загруженного файла превышает допустимый лимит.              |
| 500 | Internal Server Error   | Непредвиденная ошибка сервера.                                     |

## Где следует использовать API перевода текстового файла?

- **Многоязычные порталы документации** — автоматический перевод пользовательских руководств или справочных файлов, загружаемых как текстовые документы, с предоставлением локализованных версий по запросу.
- **Системы управления контентом (CMS)** — интеграция в рабочий процесс CMS для перевода блог-постов или статей перед публикацией в международных версиях.
- **Предприятные конвейерные процессы обработки данных** — использование в пакетных задачах обработки больших объёмов отчётов в форматах CSV или TXT с переводом их на язык региональных подразделений при сохранении исходного форматирования.
- **Платформы поддержки клиентов** — перевод входящих текстовых заявок или логов чатов в режиме реального времени для помощи агентам поддержки, работающим на разных языках.

## Почему стоит использовать API перевода текстового файла?

- **Точность на основе ИИ** — использует передовые нейросетевые модели перевода для получения естественного, контекстно-зависимого результата.
- **Гибкость входных данных** — поддерживает как загрузку файлов, так и передачу необработанного текста, упрощая интеграцию с разнообразными клиентскими приложениями.
- **Сохранение исходного макета** — сохраняет разрывы строк, отступы и специальные символы, исключая необходимость постобработки.
- **Удобная обработка файлов** — возвращает готовый к скачиванию файл с автоматически сгенерированным суффиксом "\_translated", снижая сложность клиентского кода.
