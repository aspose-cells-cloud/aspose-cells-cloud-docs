Aspose.Cells Cloud AI предоставляет три мощных сервиса на основе искусственного интеллекта, упрощающих работу с данными Excel и текста: **Декомпозиция пользовательской задачи**, **Перевод электронной таблицы** и **Перевод текстового файла**. Эти API позволяют разработчикам программно разбивать сложные пользовательские цели на последовательные действия, переводить целые рабочие книги или текстовые файлы, а также интегрировать полученные результаты в собственные приложения. Используйте приведённые ниже эндпоинты для быстрого старта, а также обратитесь к подробным спецификациям запросов и ответов, предоставленным для каждого сервиса.

- **[Декомпозиция пользовательской задачи](https://docs.aspose.cloud/cells/ru/decompose-user-task/)** – Преобразуйте пользовательские цели в последовательные планы действий с помощью Aspose.Cells Cloud AI.  
  - **Метод запроса:** `POST`  
  - **URL-адрес эндпоинта:** `https://api.aspose.cloud/v4.0/cells/ai/decompose-task`  
  - **Заголовки:** `Authorization: Bearer <access_token>`, `Content-Type: application/json`  
  - **Тело запроса (JSON):**  
    ```json
    {
      "task": "Создать отчёт о продажах за квартал с диаграммами и сводными таблицами"
    }
    ```  
  - **Ответ:** Возвращает файл электронной таблицы, содержащий список задач, в виде загружаемого файла.  
  - **Коды состояния:** `200 OK`, `400 Bad Request`, `401 Unauthorized`, `500 Internal Server Error`  
  - **Необходимые условия:** Действующий токен доступа со scope **CellsAI**.  
  - **Пример ответа (фрагмент JSON):**  
    ```json
    {
      "fileId": "12345abcde",
      "downloadUrl": "https://api.aspose.cloud/v4.0/cells/ai/files/12345abcde"
    }
    ```  
  - **Примечания:** Сгенерированная рабочая книга включает лист с названием **TaskList**, содержащий упорядоченные шаги. Ограничение скорости: 100 запросов в минуту.

- **[Перевод электронной таблицы](https://docs.aspose.cloud/cells/ru/translate-spreadsheet/)** – Переведите всю электронную таблицу с помощью Aspose.Cells Cloud AI.  
  - **Метод запроса:** `POST`  
  - **URL-адрес эндпоинта:** `https://api.aspose.cloud/v4.0/cells/ai/translate-spreadsheet`  
  - **Заголовки:** `Authorization: Bearer <access_token>`, `Content-Type: multipart/form-data`  
  - **Параметры запроса:**  
    - `file` – Файл Excel для перевода (бинарные данные).  
    - `targetLanguage` – Код языка по стандарту ISO (например, `fr`, `de`).  
  - **Ответ:** Возвращает переведённую рабочую книгу в виде загружаемого файла.  
  - **Коды состояния:** `200 OK`, `400 Bad Request`, `401 Unauthorized`, `415 Unsupported Media Type`, `500 Internal Server Error`  
  - **Необходимые условия:** Токен доступа со scope **CellsAI** и достаточный объём квоты хранилища.  
  - **Пример ответа (фрагмент JSON):**  
    ```json
    {
      "translatedFileId": "f9d8c7b6",
      "downloadUrl": "https://api.aspose.cloud/v4.0/cells/ai/files/f9d8c7b6"
    }
    ```  
  - **Примечания:** Переводятся все значения ячеек, комментарии и названия листов. Ограничение скорости: 100 запросов в минуту.

- **[Перевод текстового файла](https://docs.aspose.cloud/cells/ru/translate-text-file/)** – Переведите весь текстовый файл с помощью Aspose.Cells Cloud AI.  
  - **Метод запроса:** `POST`  
  - **URL-адрес эндпоинта:** `https://api.aspose.cloud/v4.0/cells/ai/translate-text`  
  - **Заголовки:** `Authorization: Bearer <access_token>`, `Content-Type: multipart/form-data`  
  - **Параметры запроса:**  
    - `file` – Текстовый файл для перевода (бинарные данные).  
    - `targetLanguage` – Код языка по стандарту ISO (например, `es`, `ja`).  
  - **Ответ:** Возвращает переведённый текстовый файл.  
  - **Коды состояния:** `200 OK`, `400 Bad Request`, `401 Unauthorized`, `415 Unsupported Media Type`, `500 Internal Server Error`  
  - **Необходимые условия:** Действующий токен доступа со scope **CellsAI**.  
  - **Пример ответа (фрагмент JSON):**  
    ```json
    {
      "translatedFileId": "a1b2c3d4",
      "downloadUrl": "https://api.aspose.cloud/v4.0/cells/ai/files/a1b2c3d4"
    }
    ```  
  - **Примечания:** Поддерживаются текстовые файлы в кодировке UTF‑8 объёмом до 5 МБ. Ограничение скорости: 100 запросов в минуту.
