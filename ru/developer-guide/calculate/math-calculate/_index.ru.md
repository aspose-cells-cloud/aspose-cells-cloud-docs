## **Введение**: Быстрые вычисления в электронных таблицах — сложение, умножение, вычитание, деление и процентные формулы в одном API-вызове

_Выполняйте массовые вычисления по всей колонке, строке или таблице без необходимости записывать формулы._

- **Базовая математика**: прибавляйте, вычитайте, умножайте или делите каждую ячейку в диапазоне на любое число.
- **Проценты**: увеличивайте/уменьшайте значения на %, либо находите % от числа (например, +15%, -8%, 20% от…).
- **Массово**: примените операции к тысячам ячеек мгновенно — без автозаполнения, матричных формул или VBA.

| **Операция вычисления** | Описание |
| :---------------------- | :------- |
| **Add** (Сложение)      | +        |
| **Subtract** (Вычитание)| -        |
| **Multiply** (Умножение)| \*       |
| **Divide** (Деление)    | /        |
| **Percentage** (Процент)| %        |

## **API математических вычислений**

```http
PUT https://api.aspose.cloud/v4.0/cells/calculate/math
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации по токену JWT</a>.

### **Параметры запроса:**

| Имя параметра | Тип   | Путь/Строка запроса/HTTP-тело | Описание                                                                 |
| :------------ | :---- | :--------------------------- | :----------------------------------------------------------------------- |
| Spreadsheet   | File  | FormData                     | Загрузите файл электронной таблицы для обработки.                        |
| operation     | String| Query                        | Математическая операция для выполнения (Add, Subtract, Multiply, Divide, Percentage). |
| value         | String| Query                        | Значение, используемое в вычислениях (если применимо).                   |
| worksheet     | String| Query                        | Имя листа, на котором будет выполнена операция.                          |
| range         | String| Query                        | Диапазон ячеек, включаемых в вычисления.                                  |
| region        | String| Query                        | Настройка региона электронной таблицы.                                    |
| password      | String| Query                        | Пароль для открытия защищённого файла электронной таблицы.               |

### **Ответ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream",
      "Name": "file"
    }
  }
]
```

**Коды HTTP-статуса**

| Код | Значение                   | Описание                                                         |
|-----|----------------------------|------------------------------------------------------------------|
| 200 | OK (ОК)                    | Фильтр успешно применён; ответ содержит данные об операции.      |
| 400 | Bad Request (Неверный запрос) | Отсутствуют или некорректны параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized (Неавторизовано) | Неверный или отсутствующий JWT-токен.                            |
| 413 | Payload Too Large (Слишком большой payload) | Размер загруженного файла превышает допустимый лимит.            |
| 500 | Internal Server Error (Внутренняя ошибка сервера) | Непредвиденная ошибка сервера.                                   |

## Где следует использовать API математических вычислений?

- **Финансы**: добавьте 13% НДС ко всей колонке цен закупки.
- **Инвентарь**: умножьте колонку килограммов на 2,2046 для массового перевода в фунты.
- **Зарплата**: прибавьте фиксированную премию 1000 ко всем строкам колонки премий для всех сотрудников.
- **Конвертация валют**: поделите колонку продаж на текущий обменный курс, чтобы получить суммы в USD.
- **Оценка**: отнимите 5 баллов от каждого ученического балла за неявку.
- **Электронная коммерция**: примените 15%-ную рекламную скидку, уменьшив цены товаров одним кликом.

## Почему стоит использовать API математических вычислений?

- **Быстрые вычисления в Excel** — завершайте отчёты за конец месяца за секунды.
- **Массовое увеличение на проценты в Excel** — обновляйте цены, прогнозы, комиссии одним кликом.
- **Прибавление одного числа ко всей колонке** — инвентарь, конвертация валют, перевод единиц измерения.
- **Excel без формул** — неподготовленные пользователи ценят простоту.
- Разработка может быть быстро завершена с использованием существующих SDK.

**Примечания**  
Максимальный поддерживаемый размер файла: 200 МБ. Параметр `range` должен быть корректным адресом Excel-диапазона (например, A1:B10). Очень большие листы могут требовать дополнительного времени на обработку.

## Как использовать API математических вычислений с SDK

### Спецификация API математических вычислений

[Спецификация API математических вычислений](https://reference.aspose.cloud/cells/#/CalculateController/MathCalculate) определяет публично доступное программное интерфейсное описание, позволяя разработчикам взаимодействовать с API непосредственно из веб-браузера.

Полный список SDK Aspose.Cells Cloud доступен на [GitHub](https://github.com/aspose-cells-cloud).
