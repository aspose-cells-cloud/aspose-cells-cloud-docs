## Вычисление формулы в веб-сервисах Aspose.Cells Cloud

Вычисляет указанную формулу в заданном листе загруженного файла электронной таблицы и возвращает результирующую электронную таблицу в виде потока данных. Эта операция поддерживает локализационную обработку через параметр **region** и может открывать файлы, защищённые паролем.

### Конечная точка веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/calculate/formula
```

### **Безопасность и аутентификация**

Веб-API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### Параметры запроса

| Имя параметра | Тип   | Путь/Строка запроса/HTTP-тело | Описание |
|----------------|--------|-----------------------------|-------------|
| Spreadsheet    | Файл   | FormData                    | Загрузка файла электронной таблицы. |
| worksheet      | Строка | Query                       | Имя листа, содержащего формулу. |
| formula        | Строка | Query                       | Формула для вычисления (например, `=SUM(A1:B2)`). |
| region         | Строка | Query                       | Настройка региона/языка электронной таблицы (например, `en-US`, `fr-FR`). Влияет на форматирование чисел, разбор дат и поведение, зависящее от локали. |
| password       | Строка | Query                       | Пароль для открытия файла электронной таблицы. |

### **Ответ**

```json
{
  "File": "<двоичный поток результирующей электронной таблицы>"
}
```

**Коды статуса ответа**

| Код | Значение | Описание |
|------|---------|-------------|
| 200 | OK | Вычисление выполнено успешно; возвращён результирующий файл электронной таблицы. |
| 400 | Bad Request | Один или несколько параметров запроса отсутствуют или недопустимы. |
| 401 | Unauthorized | Аутентификация не удалась или JWT-токен отсутствует/недействителен. |
| 413 | Payload Too Large | Размер загруженного файла превышает допустимый лимит. |
| 500 | Internal Server Error | На сервере произошла непредвиденная ошибка. |

## Как использовать функцию вычисления формулы с SDK

### Спецификация API вычисления формулы

Спецификация [API вычисления формулы](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Calculate/CalculationFormula) определяет публично доступный программный интерфейс и позволяет выполнять REST-взаимодействия непосредственно из веб-браузера.

Вы можете использовать утилиту командной строки cURL для удобного доступа к веб-сервисам Aspose.Cells Cloud. В следующем примере показано, как выполнить вызов в облачный API с помощью cURL.

{< tabs tabTotal="2" tabID="1" tabName1="Запрос" tabName2="Ответ" >}

{< tab tabNum="1" >}

```bash
# Используйте HTTPS для безопасного соединения
curl -v "https://api.aspose.cloud/v4.0/cells/calculate/formula?worksheet=Sheet1&formula=%3DSUM(A1%3AB2)&region=en-US&password=MyPassword" \
  -X PUT \
  -H "Content-Type: multipart/form-data" \
  -H "Accept: application/octet-stream" \
  -H "Authorization: Bearer <jwt token>" \
  -F "Spreadsheet=@sample.xlsx"
```
