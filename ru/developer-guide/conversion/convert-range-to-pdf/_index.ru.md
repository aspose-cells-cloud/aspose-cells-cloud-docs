Экспорт диапазона данных из локального файла Excel в [PDF](https://docs.fileformat.com/pdf/) с использованием облачного API.

**Необходимые условия**: перед использованием этого API вам необходима действующая учетная запись Aspose.Cells Cloud, JWT-токен доступа и, по желанию, SDK Aspose.Cells Cloud для вашего языка программирования. Убедитесь, что целевое хранилище (по умолчанию или пользовательское) настроено, если вы планируете использовать параметр `outStorageName`.

## **API преобразования диапазона в PDF**

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/range/pdf
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### **Параметры запроса:**

| Имя параметра | Тип   | Путь/Строка запроса/HTTP-тело | Описание                                                                |
| ------------- | ----- | ---------------------------- | ----------------------------------------------------------------------- |
| Spreadsheet   | Файл  | FormData                     | Загрузка файла электронной таблицы.                                     |
| worksheet     | Строка | Запрос                       | Имя рабочего листа в электронной таблице.                               |
| range         | Строка | Запрос                       | Диапазон ячеек для преобразования, например, A1:C10.                   |
| outPath       | Строка | Запрос                       | (Необязательно) Путь к папке, где сохранена рабочая книга. По умолчанию null. |
| outStorageName| Строка | Запрос                       | Имя хранилища для выходного файла.                                      |
| fontsLocation | Строка | Запрос                       | Местоположение для хранения пользовательских шрифтов для личного использования. |
| region        | Строка | Запрос                       | Настройка региона электронной таблицы.                                  |
| password      | Строка | Запрос                       | Пароль для открытия файла электронной таблицы.                          |

### **Ответ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

_Типичный ответ — двоичный PDF-поток, возвращаемый как загружаемый файл._

**Коды HTTP-статуса**

| Код | Значение                | Описание                                                           |
| --- | ----------------------- | ------------------------------------------------------------------ |
| 200 | OK (OK)                 | Фильтр применён успешно; ответ содержит данные об операции.        |
| 400 | Bad Request (Неверный запрос) | Отсутствуют или недопустимы параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized (Неавторизовано) | Недопустимый или отсутствующий JWT-токен.                         |
| 413 | Payload Too Large (Слишком большой полезный груз) | Загруженный файл превышает лимит размера.                         |
| 500 | Internal Server Error (Внутренняя ошибка сервера) | Непредвиденная ошибка сервера.                                    |

## **Где следует использовать API преобразования диапазона в PDF?**

- **Финансовая отчетность**: преобразование балансов, отчетов о прибылях и убытках (конкретные диапазоны) в PDF для подготовки к аудиту.
- **Отчеты о продажах**: преобразование панелей продаж или расчета комиссионных в распространяемые PDF-файлы.
- **Операционные показатели**: экспорт таблиц ключевых показателей эффективности (KPI) и метрик производительности в виде официальных PDF-отчетов.
- **Договорные данные**: экспорт ценовых таблиц и соглашений об уровне обслуживания из электронных таблиц в виде PDF-вложений.
- **Журналы аудита**: сохранение диапазонов финансовых данных в виде неизменяемых PDF-доказательств.
- **Сводки портфеля**: экспорт диапазонов доходности инвестиций в виде готовых к отправке клиентам PDF-выписок.
- **Отчеты по контролю качества**: экспорт диапазонов данных инспекции в PDF для ведения отчетов о соответствии требованиям.
- **Сводки по запасам**: преобразование таблиц уровней запасов в PDF для обзора руководством.

## **Зачем использовать API преобразования диапазона в PDF?**

- **Удобный для разработчиков**: Aspose.Cells Cloud предлагает библиотеки SDK на множестве языков программирования, что позволяет быстро разрабатывать решения и обеспечивает всестороннюю документацию. По сравнению с созданием собственных решений для визуализации диаграмм, это значительно сокращает объем работы по разработке.
- **Экономически эффективно**: вы можете преобразовывать данные диапазона без предварительной загрузки всей рабочей книги, экономя место в хранилище и снижая затраты.
- **Сохраняет сложное форматирование Excel** в универсально доступном формате PDF.

### Спецификация API преобразования диапазона в PDF

[Спецификация API преобразования диапазона в PDF](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Conversion/ConvertRangeToPDF) определяет публично доступное программное интерфейсное описание и позволяет выполнять REST-взаимодействия непосредственно из веб-браузера.
