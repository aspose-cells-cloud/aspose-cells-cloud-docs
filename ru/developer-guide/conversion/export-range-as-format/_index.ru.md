Экспортируйте диапазон облачной электронной таблицы/Excel в файл определённого формата. Файл формата можно сохранить в облаке или экспортировать на локальное хранилище.

## API экспорта диапазона как формата

### Веб-API

```http
GET https://api.aspose.cloud/v4.0/cells/{name}/worksheets/{worksheet}/ranges/{range}
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### Параметры запроса

| Имя параметра     | Тип    | Расположение | Описание                                                                                                                                             |
| :---------------- | :----- | :---------- | :--------------------------------------------------------------------------------------------------------------------------------------------------- |
| **name**          | String | Path        | (Обязательный) Имя файла рабочей книги, который необходимо получить.                                                                                |
| **worksheet**     | String | Path        | Имя листа электронной таблицы.                                                                                                                       |
| **range**         | String | Path        | Диапазон, подлежащий преобразованию (например, `A1:C12`).                                                                                           |
| **format**        | String | Query       | (Обязательный) Желаемый выходной формат (например, `pdf`, `png`, `svg`).                                                                            |
| **folder**        | String | Query       | (Необязательный) Путь к папке, где хранится рабочая книга.                                                                                          |
| **storageName**   | String | Query       | (Необязательный) Имя хранилища при использовании пользовательского облачного хранилища.                                                             |
| **outPath**       | String | Query       | (Необязательный) Путь к выходному файлу в облачном хранилище.                                                                                       |
| **outStorageName**| String | Query       | (Необязательный) Имя хранилища для выходного файла.                                                                                                 |
| **fontsLocation** | String | Query       | (Необязательный) Пользовательское расположение шрифтов.                                                                                             |
| **region**        | String | Query       | (Необязательный) Региональные/языковые настройки электронной таблицы (например, `en-US`, `fr-FR`). Влияет на форматирование чисел, разбор дат и поведение, зависящее от локали. |
| **password**      | String | Query       | (Необязательный) Пароль, необходимый для открытия файла электронной таблицы.                                                                        |

### Ответ

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**Коды HTTP-статуса**

| Код | Значение                     | Описание                                                               |
|-----|-----------------------------|------------------------------------------------------------------------|
| 200 | OK (ОК)                     | Фильтр применён успешно; ответ содержит данные об операции.            |
| 400 | Bad Request (Неверный запрос) | Отсутствуют или недопустимы параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized (Неавторизовано) | Недопустимый или отсутствующий JWT-токен.                             |
| 413 | Payload Too Large (Слишком большой полезный груз) | Загруженный файл превышает ограничение по размеру.               |
| 500 | Internal Server Error (Внутренняя ошибка сервера) | Непредвиденная ошибка сервера.                                      |

## Где следует использовать API экспорта диапазона в другой формат?

### Сценарии экспорта и миграции данных

- **Интеграция с базами данных** – экспорт конкретных диапазонов Excel непосредственно в системы управления базами данных.
- **Интеграция с приложениями** – передача выбранных данных электронной таблицы в SaaS-приложения.
- **Миграция систем** – передача конкретных диапазонов данных между устаревшими и современными системами.
- **Межплатформенный обмен** – обмен фокусированными подмножествами данных между различными платформами.

### Отчётность и аналитика

- **Целевая отчётность** – экспорт конкретных разделов отчётов в другие форматы для целевого анализа.
- **Потоки данных для информационных панелей** – предоставление конкретных диапазонов данных инструментам BI для информационных панелей.
- **Показатели эффективности** – извлечение диапазонов KPI для систем мониторинга эффективности.
- **Финансовая отчётность** – экспорт разделов финансовой отчётности для внешнего аудита.

### Разработка и тестирование

- **Управление тестовыми данными** – экспорт конкретных диапазонов данных для целей тестирования.
- **Среды разработки** – передача образцов диапазонов данных командам разработчиков.
- **Тестирование API** – генерация тестовых данных CSV из конкретных разделов электронной таблицы.
- **Разработка прототипов** – предоставление фокусированных наборов данных для прототипирования приложений.

### Бизнес-операции

- **Выборочный обмен данными** – обмен конкретными диапазонами данных с внешними партнёрами.
- **Частичное резервное копирование** – резервное копирование критически важных диапазонов данных в выбранном формате.
- **Межведомственная передача данных** – обмен конкретными данными между отделами.
- **Отчётность по соответствию требованиям** – экспорт диапазонов регуляторных данных для подачи отчётов о соответствии.

### Автоматизация рабочих процессов

- **Планируемый экспорт диапазонов** – автоматический экспорт конкретных диапазонов по расписанию.
- **Извлечение по триггеру** – экспорт диапазонов на основе бизнес-событий или триггеров.
- **Интеграция в рабочие процессы** – интеграция экспорта диапазонов в бизнес-процессные рабочие потоки.
- **Пакетная обработка диапазонов** – обработка нескольких конкретных диапазонов в пакетных операциях.

## Почему следует использовать API экспорта диапазона в другой формат?

- **Удобный для разработчика** – Aspose.Cells Cloud предоставляет SDK-библиотеки на множестве языков, что позволяет быстро разрабатывать решения при полной документации. По сравнению с созданием собственных решений для визуализации диаграмм это значительно снижает объём работы разработчика.
- **Снижение затрат на персонал** – снижение потребности в сотрудниках, занятых в объединении документов.
- **Платёж по факту использования** – отсутствие первоначальных инвестиций; вы платите только за фактически выполненные вызовы API.
- **Отсутствие обслуживания серверов** – не требуется обслуживать серверы, обновлять программное обеспечение и решать проблемы совместимости.
- **Сохранение сложного форматирования Excel** – выходные файлы сохраняют исходное форматирование электронной таблицы.
