Конечная точка **ConvertWorksheetToJson** считывает файл электронной таблицы из локальной файловой системы, извлекает указанный лист и возвращает его содержимое в виде JSON-файла. Преобразование выполняется полностью на серверах Aspose.Cells Cloud, поэтому промежуточная загрузка или хранение не требуются. Поддерживаются зашифрованные рабочие книги, пользовательские расположения шрифтов и региональные настройки, что обеспечивает быстрое облачное решение для экспорта данных листа в формат JSON для последующей обработки.

## **API преобразования листа в JSON**

### Веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/worksheet/json
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud безопасны и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### **Параметры запроса:**

| Имя параметра | Тип    | Местоположение | Обязательный/Необязательный | Описание                                                                                                                                                                                                   |
| :------------ | :----- | :------------ | :------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet   | файл   | FormData      | Обязательный               | Рабочая книга Excel для обработки. Должен поддерживаться формат (xls, xlsx, csv и т.д.). Отправляется как multipart/form-data. Пример: `Spreadsheet=@C:\Docs\Sample.xlsx`.                                  |
| worksheet     | строка | Query         | Обязательный               | Точное имя листа для преобразования (с учётом регистра). Если параметр опущен или лист не найден, API возвращает ошибку. Пример: `worksheet=Sheet1`.                                                       |
| outPath       | строка | Query         | Необязательный             | Путь к папке в настроенной облачной хранилище, куда будет сохранён созданный JSON-файл. Если не указан, JSON возвращается непосредственно в потоке ответа. Пример: `outPath=/converted/`.                   |
| outStorageName| строка | Query         | Необязательный             | Имя целевого хранилища (например, "MyStorage"), в котором находится `outPath`. При опущении используется хранилище по умолчанию.                                                                         |
| fontsLocation | строка | Query         | Необязательный             | Папка на сервере, содержащая пользовательские шрифты, необходимые для точного отображения текста в листе. Пример: `fontsLocation=/fonts/custom/`.                                                         |
| region        | строка | Query         | Необязательный             | Идентификатор языка/региона, влияющий на форматирование чисел, дат и валют в генерируемом JSON (например, `en-US`, `fr-FR`).                                                                             |
| password      | строка | Query         | Необязательный             | Пароль для открытия зашифрованной рабочей книги. Если книга не защищена паролем, этот параметр можно опустить.                                                                                           |

### **Ответ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**Коды HTTP-статуса**

| Код | Значение                | Описание                                                                 |
| --- | ----------------------- | ------------------------------------------------------------------------ |
| 200 | OK (ОК)                 | Фильтр успешно применён; ответ содержит детали операции.                |
| 400 | Bad Request (Неверный запрос) | Отсутствуют или некорректны параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized (Неавторизован) | Некорректный или отсутствующий JWT-токен.                               |
| 413 | Payload Too Large (Слишком большой полезный груз) | Загруженный файл превышает допустимый размер.                         |
| 500 | Internal Server Error (Внутренняя ошибка сервера) | Непредвиденная ошибка сервера.                                          |

## Где следует использовать API преобразования листа в JSON?

- **Веб-панели управления (dashboards)** – экспорт данных листа в формат JSON для клиентских библиотек визуализации (например, Chart.js, D3.js).
- **Миграция данных** – перенос устаревших данных Excel в NoSQL-базы данных или REST-сервисы, принимающие JSON.
- **Мобильные или автономные приложения** – преобразование содержимого листа на сервере в JSON, последующая синхронизация лёгкого полезного груза на мобильные устройства.
- **Конвейеры отчётов** – подача данных листа напрямую в аналитические движки, принимающие JSON без промежуточного CSV-этапа.

## Почему стоит использовать API преобразования листа в JSON?

- **Беззагрузочная рабочая схема** – обработка локальных файлов в облаке без предварительной загрузки в хранилище, экономя пропускную способность и стоимость хранения.
- **Полнофункциональное преобразование** – поддержка зашифрованных рабочих книг, пользовательских шрифтов и регионального форматирования для точного представления данных.
- **Быстрое и масштабируемое выполнение** – использование высокоэффективного движка Aspose.Cells на облачной инфраструктуре, эффективно обрабатывающего большие листы.
- **Упрощённая интеграция** – один PUT-вызов возвращает готовый к использованию JSON-файл или сохраняет его напрямую, снижая сложность кода клиентских приложений.

## Как использовать API преобразования листа в JSON с SDK

### Спецификация API преобразования листа в JSON

Спецификация <a href="https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Conversion/ConvertWorksheetToJson" rel="noopener noreferrer">API преобразования листа в JSON</a> предоставляет публично доступное программное интерфейсное описание для выполнения REST-взаимодействий непосредственно из веб-браузера.

Для удобного доступа к веб-сервисам Aspose.Cells Cloud можно использовать утилиту командной строки cURL. Приведённый ниже пример демонстрирует, как выполнять вызовы к облачному API с помощью cURL.

```bash
curl -X PUT "https://api.aspose.cloud/v4.0/cells/convert/worksheet/json?worksheet=Sheet1" \
  -H "Authorization: Bearer {access_token}" \
  -F "Spreadsheet=@myWorkbook.xlsx" \
  -o converted.json
```
