Конечная точка **ConvertSpreadsheetToJson** преобразует электронную таблицу, хранящуюся на локальном диске, в файл JSON полностью на сервере Aspose.Cells Cloud. При отправке электронной таблицы в формате `multipart/form-data` сервис возвращает поток JSON, готовый для загрузки или дальнейшей обработки. Это облачное преобразование устраняет необходимость предварительной загрузки файла в облачное хранилище, снижает затраты на хранение и упрощает рабочий процесс приложений, которым требуются данные электронной таблицы в формате JSON для аналитики, отчетности или обмена данными.

**Необходимые условия**: у вас должен быть аккаунт Aspose Cloud, действующий JWT-токен доступа, а также настроенный SDK или ключ API Aspose.Cells Cloud.

**Введение**: Преобразование электронных таблиц в JSON — распространённый шаг при интеграции данных Excel с веб-сервисами, NoSQL-базами данных или клиентскими JavaScript-приложениями. API преобразования электронных таблиц в JSON обеспечивает быстрое серверное преобразование без необходимости хранить исходный файл.

## API преобразования электронной таблицы в JSON

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/spreadsheet/json
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации по токену JWT</a>.

### Параметры запроса

| Имя параметра | Тип                        | Расположение | Обязательный/необязательный | Описание                                                                                                                                                     |
| :------------ | :------------------------- | :--------- | :-------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet   | Файл (multipart/form-data) | FormData   | Обязательный                | Исходный файл электронной таблицы (например, .xls, .xlsx, .xlsm). Пример: `curl -F "Spreadsheet=@myfile.xlsx"`                                              |
| outPath       | Строка                     | Query      | Необязательный              | Путь к целевой папке в облачном хранилище, куда будет сохранён преобразованный JSON-файл. Если не указан, JSON возвращается непосредственно в потоке ответа. Пример: `outPath=/output/`. |
| outStorageName| Строка                     | Query      | Необязательный              | Имя облачного хранилища (например, Amazon S3, Azure Blob), в которое будет записан выходной файл. Требуется только при использовании `outPath` с нестандартным хранилищем. |
| fontsLocation | Строка                     | Query      | Необязательный              | Путь к пользовательской папке со шрифтами на сервере. Используется, если электронная таблица ссылается на шрифты, отсутствующие в библиотеке по умолчанию.     |
| region        | Строка                     | Query      | Необязательный              | Языковой/региональный параметр электронной таблицы (например, `en-US`, `fr-FR`). Влияет на форматирование чисел, дат и валют при преобразовании.              |
| password      | Строка                     | Query      | Необязательный              | Пароль для открытия защищённого паролем файла. Пропустите для незащищённых файлов.                                                                           |

### Ответ

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**Коды HTTP-статуса**

| Код | Значение                | Описание                                                                |
| --- | ----------------------- | ----------------------------------------------------------------------- |
| 200 | OK (ОК)                 | Фильтр применён успешно; ответ содержит детали операции.               |
| 400 | Bad Request (Неверный запрос) | Отсутствуют или недопустимы параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized (Неавторизован) | Недействительный или отсутствующий JWT-токен.                          |
| 413 | Payload Too Large (Слишком большой полезный груз) | Загруженный файл превышает допустимый размер.                         |
| 500 | Internal Server Error (Внутренняя ошибка сервера) | Непредвиденная ошибка сервера.                                         |

## Где использовать API преобразования электронной таблицы в JSON?

- **Конвейеры миграции данных** — преобразование устаревших отчётов Excel в JSON для загрузки в современные NoSQL-базы данных или хранилища данных.
- **Мобильные или веб-приложения** — быстрое преобразование загруженных пользователем электронных таблиц в JSON для отображения на стороне клиента без хранения оригинального файла в облаке.
- **Автоматическая генерация отчётов** — создание полезных нагрузок JSON для последующих аналитических сервисов (например, Power BI, Tableau) непосредственно из входных данных электронной таблицы.
- **Бессерверные функции** — использование API в AWS Lambda или Azure Functions для выполнения преобразований «на лету» без управления промежуточным хранением.

## Почему стоит использовать API преобразования электронной таблицы в JSON?

- Преобразование «в облаке» устраняет необходимость загрузки больших файлов в хранилище перед обработкой, снижая задержку и затраты на хранение.
- Рабочий процесс за один запрос: загрузите электронную таблицу и получите JSON в одном HTTP-вызове, упрощая логику интеграции.
- Поддержка защищённых паролем и регионально-специфичных электронных таблиц, обеспечивающая точное представление данных в разных локалях.
- Масштабируемость на инфраструктуре Aspose: обрабатывает большие рабочие книги и сложные формулы без нагрузки на собственные ресурсы вашего сервера.
