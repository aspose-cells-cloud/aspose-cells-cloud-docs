Конечная точка **ConvertWorksheetToCsv** преобразует один рабочий лист из локального файла электронной таблицы в CSV-документ полностью на сервере Aspose.Cells Cloud. Для этого загружается исходный файл и указывается целевой рабочий лист; разработчики получают бинарный поток CSV без необходимости сохранять файл в облачном хранилище. Этот API идеально подходит для автоматизации извлечения данных, интеграции данных электронных таблиц в последующие системы и снижения затрат на хранение.

## API преобразования рабочего листа в CSV

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/worksheet/csv
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации по токену JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### Параметры запроса

| Имя параметра | Тип   | Расположение | Обязательный/Необязательный | Описание                                                                                                                                 |
| :------------ | :---- | :--------- | :------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet   | File  | FormData   | **Обязательный**           | Бинарный файл исходной электронной таблицы (например, `.xlsx`, `.xls`). Пример: `myWorkbook.xlsx`.                                        |
| worksheet     | String| Query      | **Обязательный**           | Имя рабочего листа, который нужно преобразовать (с учётом регистра). Если не указан, используется первый рабочий лист. Пример: `Sheet1`. |
| outPath       | String| Query      | Необязательный              | Путь к целевой папке в облачном хранилище, куда будет сохранён созданный CSV. Если не указан, CSV возвращается непосредственно в потоке ответа. |
| outStorageName| String| Query      | Необязательный              | Имя сервиса хранилища (например, Azure, AWS S3), куда должен быть помещён выходной файл. Требуется только при использовании `outPath`.    |
| fontsLocation | String| Query      | Необязательный              | Путь к пользовательской папке со шрифтами на сервере, позволяющий движку преобразования использовать нестандартные шрифты.                 |
| region        | String| Query      | Необязательный              | Идентификатор локали, влияющий на форматирование чисел и дат в CSV (например, `ru-RU`, `fr-FR`).                                          |
| password      | String| Query      | Необязательный              | Пароль для открытия защищённой электронной таблицы. Должен совпадать с паролем шифрования исходного файла.                               |

### Ответ

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**Коды HTTP-статуса**

| Код | Значение                 | Описание                                                       |
| --- | ------------------------ | -------------------------------------------------------------- |
| 200 | OK (ОК)                 | Фильтр применён успешно; ответ содержит детали операции.       |
| 400 | Bad Request (Неверный запрос) | Отсутствуют или неверны параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized (Неавторизован) | Неверный или отсутствующий токен JWT.                          |
| 413 | Payload Too Large (Слишком большой полезный груз) | Загруженный файл превышает лимит размера.                      |
| 500 | Internal Server Error (Внутренняя ошибка сервера) | Непредвиденная ошибка сервера.                                 |

## Когда использовать API преобразования рабочего листа в CSV?

- **Извлечение данных для конвейеров BI** — Извлеките конкретный рабочий лист из отчёта Excel и передайте полученный CSV напрямую в Power BI или Tableau без промежуточной обработки файлов.
- **Автоматическая обработка счётов** — Преобразуйте рабочий лист с данными счётов в CSV для быстрой загрузки в бухгалтерские системы.
- **Интеграция со старыми системами** — Экспортируйте данные рабочего листа в CSV для использования старыми приложениями, которые принимают только текстовые файлы с разделителями.
- **Генерация отчётов в реальном времени** — Создавайте снимки данных из живой электронной таблицы в виде CSV в веб-сервисе, мгновенно возвращая файл клиентскому браузеру.

## Почему использовать API преобразования рабочего листа в CSV?

- **Не требуется постоянное облачное хранилище** — Файл передаётся напрямую в движок преобразования и удаляется после завершения, что экономит трафик и затраты на хранение.
- **Высокая производительность в облаке** — Преобразование выполняется на оптимизированных серверах Aspose, как правило, завершаясь менее чем за 2 секунды для файлов размером до 100 МБ.
- **Тонкая настройка** — Выберите один рабочий лист, примените пользовательские шрифты, региональные настройки и защиту паролем в одном запросе.
- **Единообразный кроссплатформенный вывод** — Гарантирует идентичный вывод CSV на всех платформах (.NET, Java, Python и др.) при использовании одного и того же REST-эндпоинта.
