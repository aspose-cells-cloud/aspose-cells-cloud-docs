## Преобразование таблицы в CSV с помощью облачных сервисов Aspose.Cells

Этот метод считывает файл электронной таблицы из локальной файловой системы, преобразует указанную таблицу в CSV-файл и возвращает результат преобразования. Выполнение осуществляется полностью на облачном сервере, поэтому промежуточная загрузка в облачное хранилище не требуется. Путь к исходному файлу и целевой формат должны быть указаны корректно, а также необходимы соответствующие права доступа для чтения исходного файла. Возникновение таких ошибок, как отсутствие файла, недоступность пути или сбой при преобразовании, приведёт к соответствующим исключениям.

### Конечная точка веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/table/csv
```

### **Безопасность и аутентификация**

API облачной платформы Aspose.Cells защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### Параметры запроса

| Имя параметра   | Тип    | Путь / Строка запроса / Тело HTTP-запроса | Описание |
|------------------|--------|-------------------------------------------|----------|
| Spreadsheet      | Файл   | FormData                                  | Загружаемый файл электронной таблицы. |
| worksheet        | Строка | Параметр запроса                          | Имя рабочего листа электронной таблицы. |
| tableName        | Строка | Параметр запроса                          | Имя таблицы. |
| outPath          | Строка | Параметр запроса                          | (Необязательно) Путь к папке, где будет сохранена рабочая книга. По умолчанию — null. |
| outStorageName   | Строка | Параметр запроса                          | Имя хранилища для выходного файла. |
| fontsLocation    | Строка | Параметр запроса                          | Использование пользовательских шрифтов. |
| AutoRowsFit      | Boolean| Параметр запроса                          | (Необязательно) Автоподбор высоты всех строк на рабочих листах. |
| AutoColumnsFit   | Boolean| Параметр запроса                          | (Необязательно) Автоподбор ширины всех столбцов на рабочих листах. |
| region           | Строка | Параметр запроса                          | Параметры региона/языка электронной таблицы (например, `en-US`, `fr-FR`). Влияет на форматирование чисел, разбор дат и поведение, зависящее от языкового стандарта. |
| password         | Строка | Параметр запроса                          | Пароль для открытия файла электронной таблицы. |

### Параметр тела запроса

| Имя параметра | Тип | Описание |
| -------------- | ---- | ----------- |
| *Отсутствует* | *Отсутствует* | *Тело запроса не требуется; файл отправляется как multipart/form-data.* |

### **Ответ**

```json
{
  "file": "двоичный поток сгенерированного CSV-файла"
}
```

**Коды состояния ответа**

| Код | Значение | Описание |
|------|---------|----------|
| 200 | OK | Таблица успешно преобразована, CSV-файл возвращён. |
| 400 | Bad Request | Некорректные параметры запроса или неверно сформированный URL. |
| 401 | Unauthorized | Аутентификация не удалась или учетные данные не предоставлены. |
| 404 | Not Found | Исходный файл недоступен или не существует. |
| 413 | Payload Too Large | Загруженный файл превышает допустимый размер. |
| 500 | Internal Server Error | Во время преобразования электронной таблицы произошла ошибка. |

## Как использовать функцию преобразования таблицы в CSV с помощью SDK

### Спецификация API преобразования таблицы в CSV

[Спецификация API преобразования таблицы в CSV](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Conversion/ConvertTableToCsv) определяет публично доступное программное интерфейсное описание, позволяя выполнять взаимодействие по REST напрямую из веб-браузера.

Для взаимодействия с облачными сервисами Aspose.Cells вы можете использовать утилиту командной строки cURL. В следующем примере показано, как выполнить вызов облачного API с помощью cURL.

{< tabs tabTotal="2" tabID="1" tabName1="Запрос" tabName2="Ответ" >}

{< tab tabNum="1" >}

```bash
# Используйте HTTPS для защищенного соединения
curl -v "https://api.aspose.cloud/v4.0/cells/convert/table/csv?worksheet={worksheet}&tableName={tableName}&outPath={outPath}&outStorageName={outStorageName}&fontsLocation={fontsLocation}&AutoRowsFit={AutoRowsFit}&AutoColumnsFit={AutoColumnsFit}&region={region}&password={password}" \
  -X PUT \
  -H "Content-Type: multipart/form-data" \
  -H "Accept: application/octet-stream" \
  -H "Authorization: Bearer <jwt token>" \
  -F "Spreadsheet=@sample.xlsx"
```

{< /tab >}

```json
}
```
