Экспортируйте диаграммы из локального файла Excel в формат [PDF](https://docs.fileformat.com/pdf/) с использованием облачного API.

## **Преобразование диаграммы в PDF — облачный API**

### Веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/chart/pdf
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе токена JWT</a>.

### **Параметры запроса:**

| Имя параметра  | Тип    | Путь/Строка запроса/Тело HTTP | Описание                                                                 |
| -------------- | ------ | ---------------------------- | ------------------------------------------------------------------------ |
| Spreadsheet    | Файл   | FormData                     | Загрузка файла электронной таблицы.                                      |
| worksheet      | Строка | Запрос                       | Имя рабочего листа, содержащего диаграмму.                              |
| chartIndex     | Целое  | Запрос                       | Индекс диаграммы, подлежащей преобразованию.                             |
| outPath        | Строка | Запрос                       | (Необязательно) Путь к папке, где будет сохранён преобразованный файл. По умолчанию — null. |
| outStorageName | Строка | Запрос                       | Имя хранилища для выходного файла.                                       |
| fontsLocation  | Строка | Запрос                       | Использование пользовательских шрифтов, при необходимости.              |
| region         | Строка | Запрос                       | Параметр региона электронной таблицы.                                    |
| password       | Строка | Запрос                       | Пароль для открытия файла электронной таблицы.                           |

### **Ответ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**Коды HTTP-статуса**

| Код | Значение              | Описание                                                         |
| --- | --------------------- | ---------------------------------------------------------------- |
| 200 | OK (ОК)              | Фильтр успешно применён; ответ содержит сведения об операции.   |
| 400 | Bad Request (Неверный запрос) | Отсутствуют или недопустимы параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized (Неавторизован) | Недействительный или отсутствующий токен JWT.                   |
| 413 | Payload Too Large (Слишком большой объём полезной нагрузки) | Загруженный файл превышает предельный размер.                    |
| 500 | Internal Server Error (Внутренняя ошибка сервера) | Непредвиденная ошибка сервера.                                   |

## Где следует использовать API преобразования диаграммы в PDF?

### **1. Бизнес-отчётность и автоматизация**

- **Финансовые отделы**: Диаграммы ежемесячных финансовых отчётов → архивирование в PDF
- **Отделы продаж**: Диаграммы динамики показателей → PDF-отчёты для клиентов
- **Маркетинговые аналитики**: Диаграммы эффективности кампаний → PDF-резюме для руководства
- **Управление операциями**: Диаграммы мониторинга производства → PDF-документы для обеспечения соответствия требованиям

### **2. Разработка ПО и интеграция**

- **SaaS-приложения**: Генерируемые пользователем данные диаграмм → загружаемые PDF-отчёты
- **Корпоративные системы**: Диаграммы из ERP/CRM-систем → PDF-документы для аудита
- **Мобильные приложения**: Диаграммы встроенной аналитики → обмениваемые PDF-файлы
- **Веб-приложения**: Диаграммы панелей управления → функция экспорта в PDF

### **3. Рабочие процессы обработки документов**

- **Пакетная обработка**: Одновременное преобразование диаграмм из нескольких файлов Excel в PDF
- **Запланированные задачи**: Автоматическая ежедневная/еженедельная генерация отчётов на основе диаграмм
- **Вывод на основе шаблонов**: Стандартные форматы диаграмм → PDF-документы
- **Сборка документов**: Объединение диаграмм с другим содержимым в формате PDF

### **4. Отраслевые приложения**

- **Научные учреждения**: Диаграммы экспериментальных данных → иллюстрации для научных статей в PDF
- **Сфера образования**: Диаграммы учебных материалов → PDF-материалы для курсов
- **Консалтинговые фирмы**: Анализирующие диаграммы → PDF-материалы для клиентов
- **Производство**: Диаграммы контроля качества → PDF-отчёты по инспекциям
- **Здравоохранение**: Диаграммы данных пациентов → PDF-медические записи
- **Государственный сектор**: Статистические диаграммы → PDF-официальные публикации

### **5. Управление и распространение контента**

- **Управление цифровыми активами**: Архивирование диаграмм в стандартизированном PDF-формате
- **Базы знаний**: Техническая документация с встроенными PDF-файлами диаграмм
- **Клиентские порталы**: Безопасная доставка PDF-отчётов заинтересованным сторонам
- **Соответствие нормативным требованиям**: Генерация PDF-документации, готовой к аудиту

## Почему следует использовать API преобразования диаграммы в PDF?

- Можно преобразовывать диаграммы **без предварительной загрузки рабочей книги**, что экономит место в хранилище и снижает затраты.
- Разработка может быть быстро завершена с использованием существующих SDK Aspose.Cells Cloud.
- **Простая интеграция**: REST API с чёткой документацией.
- **Масштабируемая архитектура**: Обработка нагрузки — от небольших до корпоративных задач.
