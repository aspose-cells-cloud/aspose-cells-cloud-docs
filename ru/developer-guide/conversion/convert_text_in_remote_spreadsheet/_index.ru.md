## Преобразование текста в удалённой таблице в веб-сервисах Aspose.Cells Cloud

Означает преобразование чисел, хранящихся как текст, в корректный числовой формат, замену нежелательных символов и разрывов строк на требуемые символы, а также преобразование символов с диакритикой в эквивалентные символы без диакритики.

### Конечная точка веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/{name}/worksheets/{worksheet}/range/{range}/content/convert/text
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе токена JWT</a>.

### Параметры запроса

| Имя параметра    | Тип    | Путь/Строка запроса/HTTP-тело | Описание |
|------------------|--------|-------------------------------|----------|
| name             | string | Путь | (Обязательный) Имя файла рабочей книги, который необходимо получить. |
| worksheet        | string | Путь | Указывает лист электронной таблицы. |
| range            | string | Путь | Указывает диапазон листа электронной таблицы. |
| convertTextType  | string | Запрос | Указывает тип преобразуемого текста. (Обязательный) |
| sourceCharacters | string | Запрос | Указывает исходные символы. (Необязательный) |
| targetCharacters | string | Запрос | Указывает целевые символы. (Необязательный) |
| folder           | string | Запрос | (Необязательный) Путь к папке, где хранится рабочая книга. По умолчанию — null. |
| storageName      | string | Запрос | (Необязательный) Имя хранилища при использовании пользовательского облачного хранилища. При отсутствии параметра используется хранилище по умолчанию. |
| region           | string | Запрос | Региональные/языковые настройки электронной таблицы (например, `en-US`, `fr-FR`). Влияет на форматирование чисел, разбор дат и поведение, зависящее от региона. (Необязательный) |
| password         | string | Запрос | Пароль для открытия файла электронной таблицы. (Необязательный) |

### Параметр тела запроса

| Имя параметра | Тип | Описание |
| -------------- | --- | --------- |
| - | - | - |

### **Ответ**

```json
{
  "Code": 200,
  "Status": "OK",
  "Message": "Преобразование текста завершено успешно.",
  "Data": {
    // Здесь могут быть указаны подробности результата преобразования, например, количество обновлённых ячеек.
  }
}
```

**Коды статусов ответа**

| Код | Значение | Описание |
|-----|----------|----------|
| 200 | OK | Операция преобразования текста завершена успешно. |
| 400 | Bad Request | Запрос был некорректным или в нём отсутствовали обязательные параметры. |
| 401 | Unauthorized | Ошибка аутентификации или отсутствует/некорректен токен JWT. |
| 413 | Payload Too Large | Размер полезной нагрузки запроса превышает допустимый лимит. |
| 500 | Internal Server Error | На сервере произошла непредвиденная ошибка. |

## Как использовать преобразование текста в удалённой таблице с помощью SDK

### Спецификация преобразования текста в удалённой таблице

[Спецификация API преобразования текста в удалённой таблице](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/{TextProcessingController}/{ConvertTextInRemoteSpreadsheet}) определяет публично доступный программный интерфейс и позволяет выполнять взаимодействие по REST непосредственно из веб-браузера.

Для доступа к веб-сервисам Aspose.Cells Cloud можно легко использовать утилиту командной строки cURL. Пример ниже показывает, как выполнять вызовы облачного API с помощью cURL.

{< tabs tabTotal="2" tabID="1" tabName1="Запрос" tabName2="Ответ" >}

{< tab tabNum="1" >}

```bash
# Используйте HTTPS для защищённого соединения
curl -v "https://api.aspose.cloud/v4.0/cells/{name}/worksheets/{worksheet}/range/{range}/content/convert/text?convertTextType={convertTextType}&sourceCharacters={sourceCharacters}&targetCharacters={targetCharacters}&folder={folder}&storageName={storageName}&region={region}&password={password}" \
  -X PUT \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer <jwt token>"
```

{< /tab >}

```json
    "UpdatedCellsCount": 124,
    "Details": "Числа преобразованы, символы заменены, разрывы строк нормализованы."
  }
}
```
