Эндпоинт **ConvertSpreadsheetToPdf** считывает файл электронной таблицы, загруженный с локального диска, обрабатывает его на сервере Aspose.Cells Cloud и возвращает результирующий PDF-документ в виде двоичного потока. Такой облачный подход исключает необходимость загрузки исходного файла в облачное хранилище, снижает потребление ресурсов и упрощает рабочие процессы, доставляя PDF непосредственно клиенту. Поддерживаемые форматы зависят от используемых библиотек; API проверяет наличие файла, права доступа и целостность конвертации, возвращая соответствующие HTTP-ошибки при неверном входном файле или сбоях обработки.

## **API конвертации электронной таблицы в PDF**

### Веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/spreadsheet/pdf
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации по токену JWT</a>.

### **Параметры запроса:**

| Имя параметра | Тип   | Расположение | Обязательный/необязательный | Описание                                                                                                                                                               |
| :------------ | :---- | :---------- | :-------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet   | Файл  | FormData    | Обязательный                | Исходный файл электронной таблицы (XLS, XLSX, CSV и др.) для конвертации. Должен быть допустимым читаемым файлом; максимальный размер — 100 МБ. Пример: `myWorkbook.xlsx`. |
| outPath       | Строка | Query       | Необязательный              | Путь к целевой папке на сервере, куда будет сохранён сконвертированный PDF (если требуется сохранение). Если не указан, файл возвращается непосредственно в ответе. Пример: `/output/reports/`. |
| outStorageName| Строка | Query       | Необязательный              | Имя целевого облачного хранилища (например, `MyCloudStorage`). Требуется только при использовании `outPath`, если хранилище не является хранилищем по умолчанию.     |
| fontsLocation | Строка | Query       | Необязательный              | Путь к пользовательской папке со шрифтами на сервере для корректного отображения текста в PDF. Пример: `/fonts/custom/`.                                              |
| region        | Строка | Query       | Необязательный              | Параметры региона/языка электронной таблицы (например, `ru-RU`, `en-US`). Влияет на форматирование чисел, разбор дат и поведение, зависящее от локали.                |
| password      | Строка | Query       | Необязательный              | Пароль, необходимый для открытия защищённой электронной таблицы. Пропустите, если файл не зашифрован.                                                                  |

### **Ответ**

Успешный ответ (200 OK)  
Content-Type: application/pdf  
Content-Disposition: attachment; filename="converted.pdf"  
Content-Length: `<размер в байтах>`

Тело: двоичный потерг PDF-файла

**Коды HTTP-статусов**

| Код | Значение               | Описание                                                                 |
| --- | ---------------------- | ------------------------------------------------------------------------ |
| 200 | OK (ОК)               | Фильтр применён успешно; ответ содержит детали операции.                |
| 400 | Bad Request (Неверный запрос) | Отсутствуют или некорректны параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized (Неавторизовано) | Неверный или отсутствует токен JWT.                                     |
| 413 | Payload Too Large (Слишком большой полезный груз) | Загруженный файл превышает лимит размера.                           |
| 500 | Internal Server Error (Внутренняя ошибка сервера) | Непредвиденная ошибка сервера.                                         |

## Где следует использовать API конвертации электронной таблицы в PDF?

- **Автоматизированные конвейеры отчётов** – Конвертация ежедневно генерируемых отчётов Excel в PDF для архивирования или рассылки по электронной почте без ручного вмешательства.
- **Системы управления документами (DMS)** – Прямое сохранение PDF в DMS после конвертации, при этом исходная электронная таблица остаётся только на клиентской стороне.
- **Веб-приложения с экспортом «на лету»** – Предоставление конечным пользователям возможности загрузки PDF-версии электронной таблицы, редактируемой в браузере, с сохранением макета за счёт облачной конвертации.
- **Соблюдение нормативных требований** – Генерация неизменяемых PDF-снимков финансовых электронных таблиц для аудиторских проверок, при этом исходный файл никогда не покидает клиентскую среду.
- **Многоформатные рабочие процессы конвертации** – Комбинирование с другими эндпоинтами конвертации, например, [API конвертации электронной таблицы в CSV](/convert-spreadsheet-to-csv/), для создания архивов в нескольких форматах.

## Почему стоит использовать API конвертации электронной таблицы в PDF?

- **Беззагрузочная схема работы** – Не требуется загружать исходный файл в облачное хранилище; конвертация происходит напрямую из загружаемого потока, что экономит пропускную способность и стоимость хранения.
- **Высокоточное отображение** – Aspose.Cells сохраняет сложные формулы, диаграммы и форматирование при конвертации в PDF, обеспечивая сопоставимый с Excel настольным результат.
- **Масштабируемое облачное выполнение** – Использует облачную инфраструктуру Aspose для быстрой и надёжной конвертации независимо от аппаратных возможностей клиента.
- **Простой REST-интерфейс** – Один `PUT`-запрос с необязательными параметрами запроса; возвращает готовый к загрузке PDF-поток, что упрощает интеграцию на любом языке программирования.

### Спецификация API конвертации электронной таблицы в PDF

Для удобного доступа к веб-сервисам Aspose.Cells Cloud можно использовать утилиту командной строки cURL. В следующем примере показано, как отправлять запросы к облачному API с помощью cURL.

```bash
curl -X PUT "https://api.aspose.cloud/v4.0/cells/convert/spreadsheet/pdf" \
  -H "Authorization: Bearer {access_token}" \
  -F "Spreadsheet=@myWorkbook.xlsx" \
  -o converted.pdf
```
