Конечная точка **ConvertWorksheetToHtml** считывает рабочую тетрадь Excel из локальной файловой системы, извлекает указанный рабочий лист и возвращает содержимое в виде HTML-файла. Преобразование выполняется полностью на облачных серверах Aspose, поэтому промежуточная загрузка или хранение не требуются. API идеально подходит для создания веб-представлений табличных данных и поддерживает дополнительные параметры: путь к выходному файлу, пользовательские шрифты, региональные настройки и защищённые паролем тетради.

## Преобразование рабочего листа в HTML: API

### Веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/worksheet/html
```

### **Безопасность и аутентификация**

Облачные API Aspose.Cells защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### Параметры запроса

| Имя параметра | Тип    | Расположение | Обязательный/необязательный | Описание                                                                                                                                                                     |
| :------------ | :----- | :---------- | :------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet   | Файл   | Обязательный | FormData                   | Двоичный Excel-файл для обработки. Должен быть допустимым файлом формата .xlsx, .xls, .xlsb и т.д. Пример: `myWorkbook.xlsx`. Файл Excel считывается непосредственно из тела запроса; предварительная загрузка в облачное хранилище не требуется. |
| worksheet     | Строка | Обязательный | Query                      | Имя преобразуемого рабочего листа (с учётом регистра). Должен существовать в предоставленной тетради. Пример: `Sheet1`.                                                       |
| outPath       | Строка | Необязательный | Query                      | Путь к целевой папке (в облачном хранилище), куда будет сохранён полученный HTML-файл. Если параметр опущен, файл возвращается непосредственно в ответе. Пример: `/output/html/`. |
| outStorageName| Строка | Необязательный | Query                      | Имя используемой облачной службы хранения для параметра `outPath`. Требуется только в случае, если `outPath` указывает на нестандартное хранилище.                           |
| fontsLocation | Строка | Необязательный | Query                      | Абсолютный путь к папке, содержащей пользовательские шрифты TrueType/OpenType, которые должны использоваться при преобразовании. Позволяет корректно отображать нестандартные символы. |
| region        | Строка | Необязательный | Query                      | Идентификатор языкового стандарта, влияющий на форматирование чисел и дат (например, `ru-RU`, `en-US`, `fr-FR`). По умолчанию используется внутренний региональный параметр тетради. |
| password      | Строка | Необязательный | Query                      | Пароль, необходимый для открытия защищённой тетради. Пропустите для незащищённых файлов.                                                                                      |

### Ответ

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**Коды HTTP-статуса**

| Код | Значение              | Описание                                                                      |
|-----|-----------------------|-------------------------------------------------------------------------------|
| 200 | OK (ОК)              | Фильтр успешно применён; ответ содержит данные об операции.                  |
| 400 | Bad Request (Неверный запрос) | Отсутствуют или некорректны параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized (Неавторизован) | Некорректный или отсутствующий JWT-токен.                                    |
| 413 | Payload Too Large (Слишком большой объём данных) | Загруженный файл превышает допустимый размер.                             |
| 500 | Internal Server Error (Внутренняя ошибка сервера) | Непредвиденная ошибка сервера.                                              |

## Где следует использовать API преобразования рабочего листа в HTML?

- Встраивание живых табличных данных в веб-портал — преобразование рабочего листа финансового отчёта в HTML для прямого просмотра в браузере без установки плагинов Excel.
- Генерация печатных HTML-счётов из шаблона Excel — автоматизация создания веб-готовых страниц счётов из предопределённого рабочего листа.
- Создание фрагментов документации — преобразование спецификаций проектирования в HTML-фрагменты, встраиваемые в технические руководства или вики.
- Разработка BI-панелей с низким уровнем кода — извлечение данных рабочего листа, преобразование их в HTML и отображение в пользовательских виджетах панелей.

## Почему стоит использовать API преобразования рабочего листа в HTML?

- **Рабочий процесс без загрузки файлов** — преобразование локальных файлов непосредственно в облаке, без необходимости сначала передавать большие тетради в хранилище.
- **Высокопроизводительная визуализация** — преобразование на стороне сервера использует оптимизированный движок Aspose, обеспечивая быстрое и точное HTML-выведение.
- **Полный контроль над выводом** — дополнительные параметры (пользовательские шрифты, регион, пароль) позволяют адаптировать HTML под требования локализации и брендинга.
- **Лёгкая интеграция** — простой PUT-запрос с multipart/form‑data естественным образом вписывается в CI/CD-конвейеры, микросервисы или функции serverless.

## Как использовать API преобразования рабочего листа в HTML с помощью SDK

### Спецификация API преобразования рабочего листа в HTML

Спецификация <a href="https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Conversion/ConvertWorksheetToHtml" target="_blank" rel="noopener noreferrer">API преобразования рабочего листа в HTML</a> предоставляет доступный публично программный интерфейс для выполнения REST-взаимодействий непосредственно из веб-браузера.

Вы можете использовать утилиту командной строки cURL для простого доступа к веб-сервисам Aspose.Cells. Пример ниже демонстрирует, как отправлять запросы к облачному API с помощью cURL.

```bash
curl -X PUT "https://api.aspose.cloud/v4.0/cells/convert/worksheet/html?worksheet=Sheet1" \
  -H "Authorization: Bearer {access_token}" \
  -F "Spreadsheet=@myWorkbook.xlsx" \
  -o converted.html
```
