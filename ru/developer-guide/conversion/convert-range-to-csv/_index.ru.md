Экспортируйте конкретный диапазон из локального файла Excel в CSV с использованием API Aspose.Cells Cloud.

## **Преобразование диапазона в CSV: API**

**Необходимые условия**  
Для вызова этого конечного узла вам необходимы действующие **Client ID** и **Client Secret** Aspose Cloud, **JWT-токен доступа**, а также исходная электронная таблица должна быть в формате **XLSX** или **XLS**.

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/range/csv
```

**Пример cURL**

```bash
curl -X PUT "https://api.aspose.cloud/v4.0/cells/convert/range/csv?worksheet=Sheet1&range=A1:C10" \
     -H "Authorization: Bearer {access_token}" \
     -F "Spreadsheet=@sample.xlsx"
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### **Параметры запроса:**

| Имя параметра | Тип   | Путь/Строка запроса/HTTPBody | Описание                                                                 |
| :------------ | :---- | :-------------------------- | :----------------------------------------------------------------------- |
| Spreadsheet   | File  | FormData                    | Загрузите файл электронной таблицы.                                      |
| worksheet     | String| Query                       | Имя листа электронной таблицы.                                           |
| range         | String| Query                       | Укажите диапазон ячеек (например, A1:C10).                               |
| outPath       | String| Query                       | Путь к папке, где будет сохранена рабочая книга (необязательно). По умолчанию null. |
| outStorageName| String| Query                       | Имя выходного хранилища.                                                 |
| fontsLocation | String| Query                       | Укажите пользовательские шрифты при необходимости.                       |
| region        | String| Query                       | Определяет настройку региона электронной таблицы.                        |
| password      | String| Query                       | Пароль, необходимый для открытия файла электронной таблицы.             |

### **Ответ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

_Пример возвращаемого CSV-содержимого (первые несколько строк):_

```csv
Name,Date,Amount
John Doe,2023-01-15,1250.00
Jane Smith,2023-01-16,980.50
```

**Коды HTTP-статуса**

| Код | Значение                 | Описание                                                               |
| --- | ------------------------ | ---------------------------------------------------------------------- |
| 200 | OK (ОК)                  | Фильтр применён успешно; ответ содержит детали операции.              |
| 400 | Bad Request (Неверный запрос) | Отсутствуют или некорректны параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized (Неавторизован) | Неверный или отсутствует JWT-токен.                                    |
| 413 | Payload Too Large (Слишком большой полезный размер) | Загруженный файл превышает лимит размера.                             |
| 500 | Internal Server Error (Внутренняя ошибка сервера) | Непредвиденная ошибка сервера.                                         |

## Где следует использовать API преобразования диапазона в CSV?

### **1. Сценарии экспорта и миграции данных**

- **Интеграция с базами данных**: Экспортируйте конкретные диапазоны Excel непосредственно в системы баз данных.
- **Интеграция с приложениями**: Передавайте выбранные данные электронных таблиц в SaaS-приложения.
- **Миграция систем**: Переносите конкретные диапазоны данных между устаревшими и современными системами.
- **Межплатформенный обмен**: Делитесь фокусированными подмножествами данных между различными платформами.

### **2. Отчёты и аналитика**

- **Целевая отчётность**: Экспортируйте конкретные разделы отчётов в CSV для целевого анализа.
- **Потоки данных для дашбордов**: Предоставляйте определённые диапазоны данных инструментам BI-дашбордов.
- **Метрики производительности**: Извлекайте диапазоны KPI для систем отслеживания производительности.
- **Финансовая отчётность**: Экспортируйте разделы финансовых отчётов для внешней аудиторской проверки.

### **3. Разработка и тестирование**

- **Управление тестовыми данными**: Экспортируйте конкретные диапазоны данных для тестирования.
- **Среды разработки**: Делитесь примерами диапазонов данных с командами разработчиков.
- **Тестирование API**: Генерируйте CSV-тестовые данные из конкретных разделов электронных таблиц.
- **Разработка прототипов**: Предоставляйте фокусированные наборы данных для прототипов приложений.

### **4. Бизнес-операции**

- **Выборочный обмен данными**: Делитесь конкретными диапазонами данных с внешними партнёрами.
- **Частичное резервное копирование**: Резервируйте критически важные диапазоны данных в формате CSV.
- **Межведомственная передача данных**: Передавайте конкретные данные между отделами.
- **Отчёты по соответствию**: Экспортируйте диапазоны данных регулирования для сдачи отчётов.

### **5. Автоматизация рабочих процессов**

- **Плановый экспорт диапазонов**: Автоматически экспортируйте конкретные диапазоны по расписанию.
- **Извлечение по триггеру**: Экспортируйте диапазоны на основе бизнес-событий или триггеров.
- **Интеграция в рабочие процессы**: Встраивайте экспорт диапазонов в бизнес-процессные рабочие потоки.
- **Пакетная обработка диапазонов**: Обрабатывайте несколько конкретных диапазонов в пакетных операциях.

## Почему следует использовать API преобразования диапазона в CSV?

- Можно преобразовать диапазон электронной таблицы без предварительной загрузки рабочей книги, что экономит место в хранилище и снижает затраты.
- Разработка может быть завершена быстро с использованием существующих SDK Aspose.Cells Cloud.
- **Простая интеграция**: REST API с чёткой документацией.
- **Масштабируемая архитектура**: Обрабатывает всё — от небольших до корпоративных операций.
