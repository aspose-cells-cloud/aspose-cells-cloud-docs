## Преобразование диаграммы в PDF с помощью облачных веб-сервисов Aspose.Cells

Этот метод считывает диаграмму из файла электронной таблицы, загружаемого через локальную отправку файла, преобразует её в формат PDF и возвращает результат преобразования. Работа выполняется полностью на облачном сервере, поэтому промежуточное хранение не требуется. Путь к исходному файлу и целевой формат должны быть корректными, а также необходимы соответствующие права доступа для чтения исходного файла. Ошибки, такие как отсутствие файла, проблемы с доступом или сбои преобразования, приведут к соответствующим HTTP-ошибкам.

### Конечная точка веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/chart/pdf
```

### **Безопасность и аутентификация**

API облачных сервисов Aspose.Cells защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификацию на основе токена JWT</a>.

### Параметры запроса

| Имя параметра   | Тип   | Путь/Строка запроса/HTTP-тело | Описание |
|------------------|--------|-----------------------------|-------------|
| Spreadsheet      | Файл   | FormData                    | Загрузить файл электронной таблицы. |
| worksheet        | Строка | Query                       | Имя рабочего листа электронной таблицы. |
| chartIndex       | Целое число | Query                       | Индекс диаграммы на рабочем листе. |
| outPath          | Строка | Query                       | (Необязательно) Путь к папке, где сохраняется рабочая книга. По умолчанию — null. |
| outStorageName   | Строка | Query                       | Имя хранилища для выходного файла. |
| fontsLocation    | Строка | Query                       | Использовать пользовательские шрифты. |
| region           | Строка | Query                       | Настройки региона/языка электронной таблицы (например, `en-US`, `fr-FR`). Влияет на форматирование чисел, разбор дат и поведение, зависящее от локали. |
| password         | Строка | Query                       | Пароль для открытия файла электронной таблицы. |

### Параметр тела запроса

| Имя параметра | Тип | Описание |
| -------------- | ---- | ----------- |
| Spreadsheet    | Файл | Загрузить файл электронной таблицы. |

### **Ответ**

```json
{
  "ResponseFile": "двоичный поток PDF-файла"
}
```

**Коды состояния ответа**

| Код | Значение | Описание |
|------|---------|-------------|
| 200 | OK | Диаграмма успешно преобразована в PDF; возвращён двоичный PDF-файл. |
| 400 | Bad Request | Некорректные параметры запроса или неправильно сформированный URL. |
| 401 | Unauthorized | Аутентификация не удалась или учётные данные не были предоставлены. |
| 404 | Not Found | Исходный файл недоступен. |
| 413 | Payload Too Large | Размер загружаемого файла превышает допустимый лимит. |
| 500 | Internal Server Error | При обработке преобразования произошла ошибка. |

## Как использовать преобразование диаграммы в PDF с помощью SDK

### Спецификация API преобразования диаграммы в PDF

[Спецификация API преобразования диаграммы в PDF](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Conversion/ConvertChartToPdf) определяет публично доступное программное интерфейсное описание и позволяет выполнять взаимодействие REST напрямую из веб-браузера.

Вы можете использовать утилиту командной строки cURL для простого доступа к веб-сервисам Aspose.Cells. Пример ниже показывает, как выполнять вызовы к облачному API с помощью cURL.

{< tabs tabTotal="2" tabID="1" tabName1="Запрос" tabName2="Ответ" >}
{< tab tabNum="1" >}
```bash
# Используйте HTTPS для защищённого соединения
curl -v "https://api.aspose.cloud/v4.0/cells/convert/chart/pdf?worksheet={worksheet}&chartIndex={chartIndex}&outPath={outPath}&outStorageName={outStorageName}&fontsLocation={fontsLocation}&region={region}&password={password}" \
  -X PUT \
  -H "Content-Type: multipart/form-data" \
  -H "Accept: application/pdf" \
  -H "Authorization: Bearer <jwt token>" \
  -F "Spreadsheet=@sample.xlsx"
```
{< /tab >}
{< tab tabNum="2" >}
```json
{
  "ResponseFile": "двоичный поток PDF-файла"
}
```
