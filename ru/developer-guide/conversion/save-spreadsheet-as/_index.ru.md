Сохраните облачную электронную таблицу или файл Excel в другом формате в облачном хранилище.

## **API для сохранения электронной таблицы в другом формате**

### Веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/{name}/saveas
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### **Параметры запроса**

| Имя параметра   | Тип    | Расположение | Описание                                                                                     |
| :-------------- | :----- | :--------- | :------------------------------------------------------------------------------------------ |
| name            | String | Path       | **Обязательный.** Имя файла рабочей книги, подлежащего преобразованию.                      |
| format          | String | Query      | **Обязательный.** Желаемый выходной формат (например, `Xlsx`, `PDF`, `CSV`).               |
| saveOptionsData | Class  | Body       | Необязательные данные параметров сохранения. Если не указаны, значение по умолчанию — `null`|
| folder          | String | Query      | Необязательный путь к папке, где хранится исходная рабочая книга. Если не указан, значение по умолчанию — `null` |
| storageName     | String | Query      | Необязательное имя пользовательского хранилища. Если не указано, используется хранилище по умолчанию |
| outPath         | String | Query      | Необязательный путь выходного файла. Если не указан, значение по умолчанию — `null`.        |
| outStorageName  | String | Query      | Необязательное имя хранилища для выходного файла.                                           |
| fontsLocation   | String | Query      | Необязательный путь к пользовательским шрифтам.                                             |
| region          | String | Query      | Необязательная настройка региона электронной таблицы.                                       |
| password        | String | Query      | Необязательный пароль для открытия файла электронной таблицы.                               |

**Поддерживаемые выходные форматы**

| Формат   | Расширение                                      |
| :------- | :---------------------------------------------- |
| Xlsx     | .xlsx                                           |
| Pdf      | .pdf                                            |
| Csv      | .csv                                            |
| Html     | .html                                           |
| Ods      | .ods                                            |
| Xls      | .xls                                            |
| Txt      | .txt                                            |
| Mhtml    | .mhtml                                          |
| Tiff     | .tiff                                           |
| Pptx     | .pptx                                           |
| … (другие) | См. спецификацию API для полного списка (более 20 форматов) |

### **Ответ**

```json
{
  "Code": 200,
  "Status": "OK"
}
```

**Пример ошибочного ответа (400 Bad Request)**

```json
{
  "Code": 400,
  "Message": "Недопустимые параметры запроса."
}
```

**HTTP-коды статусов**

| Код | Значение                | Описание                                                               |
| --- | ----------------------- | ---------------------------------------------------------------------- |
| 200 | OK                      | Фильтр применён успешно; ответ содержит детали операции.              |
| 400 | Bad Request             | Отсутствуют или недопустимы параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized            | Недействительный или отсутствующий JWT-токен.                         |
| 413 | Payload Too Large       | Загруженный файл превышает предельный размер.                          |
| 500 | Internal Server Error   | Непредвиденная ошибка сервера.                                         |

## Где следует использовать API для сохранения электронной таблицы в другом формате?

### Корпоративная система управления документами

- Автоматическое сохранение финансовых отчетов в виде PDF-архивов.
- Регулярное резервное копирование данных продаж в формате CSV.
- Сохранение проектных планов в виде файлов только для чтения для предотвращения случайных изменений.

### Интеграция данных и процессы ETL

- Экспорт данных из CRM-системы и сохранение их в виде стандартного шаблона Excel.
- Преобразование данных ERP в CSV для импорта в другие системы.
- Сохранение исходных данных в формате JSON для передачи через API.

### Сценарии разработки и автоматизации

- Обработка на стороне сервера для веб-приложений.
- Автоматизированные системы генерации отчётов.
- Платформы облачного совместного использования.
- Интеграция процессов утверждения.
- Резервное копирование и миграция данных.

## Почему стоит использовать API для сохранения электронной таблицы в другом формате?

- **Удобный для разработчиков** – предоставляет SDK для множества языков с подробной документацией, упрощая интеграцию.
- **Экономия труда** – обработка конвертации выполняется на сервере, что снижает необходимость в написании собственного кода конвертации.
- **Ценообразование по использованию** – взимается плата только за выполненные вызовы API, без авансовых лицензионных платежей.
- **Отсутствие необходимости обслуживания сервера** – сервис работает в облаке, исключая необходимость управления инфраструктурой конвертации.
- **Широкая поддержка форматов** – поддерживает конвертацию между более чем 20 форматами электронных таблиц.
- **Сохранение целостности данных** – сохраняет макет, формулы и стили при конвертации.
