Конечная точка **ConvertSpreadsheetToCsv** считывает файл электронной таблицы, загруженный с локального диска, полностью обрабатывает преобразование на серверах Aspose.Cells Cloud и возвращает результирующий CSV-файл в виде двоичного потока. Это облачная операция, которая исключает необходимость загрузки исходного файла в облачное хранилище, снижает затраты на хранение и упрощает рабочий процесс для разработчиков, которым требуется быстрое преобразование электронных таблиц в CSV. Поддерживаемые форматы зависят от используемых библиотек, а для чтения исходного файла требуются соответствующие разрешения. Ошибки, такие как отсутствие файла, недопустимые запросы или сбои при преобразовании, возвращаются со стандартными HTTP-кодами состояния.

## **API преобразования электронной таблицы в CSV**

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/spreadsheet/csv
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### **Параметры запроса:**

| Имя параметра   | Тип    | Расположение | Обязательность | Описание                                                                                                                                                     |
| :-------------- | :----- | :---------- | :------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Spreadsheet     | Файл   | FormData    | Обязательный   | Файл электронной таблицы для преобразования. Поддерживает распространённые форматы, такие как .xls, .xlsx, .xlsm. Должен быть передан как multipart/form‑data. Пример: `myWorkbook.xlsx`. |
| outPath         | Строка | Query       | Необязательный | Путь к папке назначения, куда должен быть сохранён преобразованный CSV. Если параметр опущен, CSV возвращается непосредственно в теле ответа. Пример: `/output/reports/`. |
| outStorageName  | Строка | Query       | Необязательный | Имя облачного сервиса хранилища, куда будет сохранён выходной файл. Если параметр не указан, используется хранилище по умолчанию, настроенное для учётной записи Aspose.Cells. |
| fontsLocation   | Строка | Query       | Необязательный | Путь к папке, содержащей пользовательские шрифты, необходимые для электронной таблицы. Обеспечивает корректное отображение ячеек, использующих нестандартные шрифты. |
| region          | Строка | Query       | Необязательный | Региональные/языковые настройки электронной таблицы (например, `en-US`, `fr-FR`). Влияют на форматирование чисел, разбор дат и поведение, зависящее от региона. |
| password        | Строка | Query       | Необязательный | Пароль для открытия защищённых паролем электронных таблиц. Если файл зашифрован, а пароль отсутствует или указан неверно, возвращается ошибка 400/401. |

### **Ответ**

При успешном выполнении API возвращает **HTTP 200** (или **202** для асинхронной обработки) с заголовком `Content-Type: application/octet-stream`. Тело ответа содержит сгенерированный CSV-файл в виде двоичного потока.

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**HTTP-коды состояния**

| Код | Значение              | Описание                                                           |
| ---- | --------------------- | ------------------------------------------------------------------ |
| 200  | OK (OK)               | Фильтр применён успешно; ответ содержит подробности операции.     |
| 400  | Bad Request (Неверный запрос) | Отсутствуют или недопустимы параметры (например, неподдерживаемый тип файла). |
| 401  | Unauthorized (Неавторизован) | Недействительный или отсутствующий JWT-токен.                     |
| 413  | Payload Too Large (Слишком большой payload) | Загруженный файл превышает лимит размера.                  |
| 500  | Internal Server Error (Внутренняя ошибка сервера) | Непредвиденная ошибка сервера.                               |

## Где следует использовать API преобразования электронной таблицы в CSV?

- **Экспорт данных для отчётных систем** – Генерация CSV-выгрузок из отчётов на основе Excel для последующей подачи в BI-инструменты или хранилища данных без ручной обработки файлов.
- **Автоматизированная пакетная обработка** – Преобразование большого количества локально хранящихся электронных таблиц в CSV в серверной задаче, с последующей передачей результатов напрямую в нижестоящие сервисы.
- **Веб-приложения с загрузкой файлов** – Позволяет конечным пользователям загружать файл Excel и мгновенно получать его CSV-версию для дальнейшего анализа или импорта в другие платформы.
- **Интеграция со старыми системами** – Преобразование устаревших форматов электронных таблиц в CSV для систем, которые принимают только простые текстовые файлы с разделителями.

## Почему использовать API преобразования электронной таблицы в CSV?

- **Архитектура без предварительной загрузки в хранилище** – Не требуется сохранять исходный файл в облачном хранилище; преобразование происходит напрямую из загружаемого потока, экономя время и стоимость хранения.
- **Высокая производительность облачной обработки** – Использует оптимизированный движок преобразования Aspose.Cells на масштабируемых облачных серверах, обеспечивая быструю генерацию CSV даже для больших книг.
- **Простота интеграции** – Один PUT-запрос с необязательными параметрами запроса; возвращает CSV как готовый к загрузке двоичный поток, исключая необходимость в последующей обработке.
- **Полная поддержка функций** – Обрабатывает файлы, защищённые паролем, пользовательские шрифты и региональные настройки, обеспечивая точное преобразование сложных электронных таблиц.
