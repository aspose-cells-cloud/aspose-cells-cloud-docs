Экспортируйте данные диапазона из локального файла Excel в JSON-файл с использованием облачного API.

## **API преобразования диапазона в JSON**

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/range/json
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### **Параметры запроса:**

| Имя параметра | Тип   | Путь/Строка запроса/HTTP-тело | Описание                                                         |
| -------------- | ------ | --------------------------- | ---------------------------------------------------------------- |
| Spreadsheet    | Файл   | FormData                    | Загрузка файла электронной таблицы.                              |
| worksheet      | Строка | Query                       | Имя рабочего листа в электронной таблице.                        |
| range          | Строка | Query                       | Диапазон ячеек для преобразования, например, A1:C10.            |
| outPath        | Строка | Query                       | (Необязательно) Путь к папке, где хранится рабочая книга; по умолчанию — null. |
| outStorageName | Строка | Query                       | Имя хранилища выходного файла.                                   |
| fontsLocation  | Строка | Query                       | Местоположение для хранения пользовательских шрифтов для личного использования. |
| region         | Строка | Query                       | Настройка региона электронной таблицы.                           |
| password       | Строка | Query                       | Пароль для открытия файла электронной таблицы.                   |

### **Ответ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**Коды HTTP-статуса**

| Код | Значение                | Описание                                                             |
| ---- | --------------------- | ------------------------------------------------------------------ |
| 200  | OK (ОК)               | Фильтр применён успешно; ответ содержит данные о выполнении операции. |
| 400  | Bad Request (Неверный запрос) | Отсутствуют или недопустимы параметры (например, неподдерживаемый тип файла). |
| 401  | Unauthorized (Неавторизованный доступ) | Недействительный или отсутствующий JWT-токен.                 |
| 413  | Payload Too Large (Слишком большой заголовок запроса) | Загруженный файл превышает допустимый размер.          |
| 500  | Internal Server Error (Внутренняя ошибка сервера) | Непредвиденная ошибка сервера.                                  |

## **Где следует использовать API преобразования диапазона в JSON?**

- Интерактивные панели мониторинга в реальном времени: преобразуйте актуальные данные Excel в JSON для использования с библиотеками визуализации, такими как Chart.js или D3.js.
- Электронные таблицы как сервис (Spreadsheet-as-a-Service): предоставляйте диапазоны Excel в виде JSON-эндпоинтов для других сервисов.
- Полезные нагрузки веб-хуков: преобразуйте данные электронных таблиц в JSON для уведомлений через веб-хуки.
- Быстрое прототипирование данных: быстро преобразуйте очищенные данные Excel в JSON для анализа в Python или R.
- Конвейеры машинного обучения: предварительная обработка обучающих данных из электронных таблиц, поддерживаемых бизнес-пользователями.
- Операции в электронной коммерции: синхронизация каталогов товаров или прайс-листов с веб-сайтами через JSON.
- Автоматизация отчётов: генерация JSON-потоков данных из финансовых моделей для автоматической генерации отчётов.
- Конфигурация приложений: управление флагами функций, настройками или параметрами A/B-тестов в Excel → JSON.
- Поддержка нескольких языков: преобразование локализованных электронных таблиц в JSON для библиотек интернационализации (i18n).
- Динамические меню/навигация: хранение структур навигации веб-сайта в Excel и развертывание их в виде JSON.

_Дополнительные варианты преобразования см. в руководстве [Преобразование диапазона в CSV](/convert-range-to-csv/)._

## Почему стоит использовать API преобразования диапазона в JSON?

- **Поддержка SDK**: Aspose.Cells Cloud предоставляет библиотеки для множества языков программирования, что снижает объём необходимого пользовательского кода.
- **Снижение затрат на хранение**: диапазон можно преобразовать без предварительной загрузки всей рабочей книги, экономя место в хранилище.
- **Совместимость с веб- и мобильными приложениями**: JSON является нативным форматом данных для современных JavaScript-фреймворков, таких как React, Vue и Angular.
- **Широкая поддержка языков**: фактически любой язык программирования и база данных могут работать с JSON.
- **Сохранение структуры данных**
  - **Интеллектуальное определение структуры**: автоматически преобразует табличные данные в корректные массивы или объекты JSON.
  - **Сопоставление заголовков**: использует первую строку в качестве ключей JSON для получения чистых объектных структур.
  - **Сохранение типов данных**: сохраняет числа, даты и логические значения, а не просто текстовые строки.
