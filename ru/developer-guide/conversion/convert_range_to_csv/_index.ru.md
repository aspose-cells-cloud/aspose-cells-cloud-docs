## Преобразование диапазона в CSV с помощью веб-сервисов Aspose.Cells Cloud

Этот метод считывает файл электронной таблицы из локальной файловой системы, преобразует указанный диапазон в формат CSV и возвращает результат напрямую. Вся обработка происходит на облачном сервере, поэтому промежуточная загрузка в облачное хранилище не требуется. API поддерживает дополнительные параметры, такие как пользовательские шрифты, автоматическая подгонка строк/столбцов, настройки локали и защищённые паролем рабочие книги.

### Конечная точка веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/range/csv
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API являются защищёнными и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### Параметры запроса

| Имя параметра   | Тип    | Путь/Строка запроса/HTTP-тело | Описание                                                                                                                            |
|------------------|---------|-----------------------------|----------------------------------------------------------------------------------------------------------------------------------------|
| Spreadsheet      | Файл    | FormData                    | Загружаемый файл электронной таблицы.                                                                                                               |
| worksheet        | Строка  | Запрос                      | Имя рабочего листа электронной таблицы. **Обязательный параметр**.                                                                                           |
| range            | Строка  | Запрос                      | Диапазон ячеек, например `A1:C10`. **Обязательный параметр**.                                                                                                 |
| outPath          | Строка  | Запрос                      | (Необязательный) Путь к папке, в которой хранится рабочая книга. По умолчанию — null.                                                          |
| outStorageName   | Строка  | Запрос                      | Имя хранилища для выходного файла.                                                                                                              |
| fontsLocation    | Строка  | Запрос                      | Использование пользовательских шрифтов.                                                                                                                      |
| AutoRowsFit      | Логический тип | Запрос                      | (Необязательный) Автоматическая подгонка всех строк на рабочих листах.                                                                                            |
| AutoColumnsFit   | Логический тип | Запрос                      | (Необязательный) Автоматическая подгонка всех столбцов на рабочих листах.                                                                                         |
| region           | Строка  | Запрос                      | Региональные/языковые настройки электронной таблицы (например, `en-US`, `fr-FR`). Влияет на форматирование чисел, разбор дат и поведение, зависящее от локали. |
| password         | Строка  | Запрос                      | Пароль для открытия файла электронной таблицы.                                                                                             |

### Параметр тела запроса

| Имя параметра | Тип | Описание |
| -------------- | ---- | ----------- |
| Нет | N/A | Параметры тела запроса отсутствуют. |

### **Ответ**

```json
{
  "ResponseFile": "поток бинарных данных (содержимое CSV)"
}
```

**Коды статуса ответа**

| Код | Значение | Описание |
|------|---------|-------------|
| 200 | OK | Диапазон успешно преобразован, и файл CSV возвращён в теле ответа. |
| 400 | Bad Request | Неверный URL или отсутствуют обязательные параметры. |
| 401 | Unauthorized | Аутентификация не удалась или учётные данные не предоставлены. |
| 413 | Payload Too Large | Размер полезной нагрузки запроса превышает допустимый предел. |
| 500 | Internal Server Error | При получении данных для преобразования возникла ошибка в электронной таблице. |

## Как использовать функцию преобразования диапазона в CSV с помощью SDK

### Спецификация API преобразования диапазона в CSV

[Спецификация API преобразования диапазона в CSV](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Conversion/ConvertRangeToCsv) определяет общедоступное программное интерфейсное взаимодействие и позволяет выполнять REST-взаимодействия непосредственно из веб-браузера.

Вы можете использовать инструмент командной строки cURL для простого доступа к веб-сервисам Aspose.Cells. В следующем примере показано, как выполнять вызовы облачного API с помощью cURL.

{{< tabs tabTotal="2" tabID="1" tabName1="Запрос" tabName2="Ответ" >}}

{{< tab tabNum="1" >}}

```bash
# Используйте HTTPS для защищённого соединения
curl -v "https://api.aspose.cloud/v4.0/cells/convert/range/csv?worksheet=Sheet1&range=A1:C10&outPath=outputFolder&outStorageName=MyStorage&fontsLocation=/custom/fonts&AutoRowsFit=true&AutoColumnsFit=true&region=en-US&password=MyPassword" \
  -X PUT \
  -H "Content-Type: multipart/form-data" \
  -H "Accept: application/octet-stream" \
  -H "Authorization: Bearer <jwt token>" \
  -F 'Spreadsheet=@sample.xlsx'
```
