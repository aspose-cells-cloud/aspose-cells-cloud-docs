Aspose.Cells Cloud предоставляет комплексный набор вспомогательных функций для работы с файлами, хранящимися в облачном хранилище Aspose.Cells Cloud или любом стороннем облачном хранилище по вашему выбору. Для получения помощи по настройке стороннего хранилища обратитесь к разделу [Тем справки Aspose Cloud UI](https://docs.aspose.cloud/display/totalcloud/Aspose+Cloud+UI+Help+Topics).

**Aspose.Cells Cloud предоставляет широкий спектр API для работы с файлами, папками и хранилищами.**

> **Примечание:** Все вызовы API должны использовать **HTTPS**. Подробности о получении токена JWT см. в [Руководстве по аутентификации](/cells/ru/authentication/).

**Необходимые условия:** Для использования этих API необходима действующая учетная запись Aspose Cloud, полученный токен доступа JWT и настроенное место хранения (либо облачное хранилище Aspose Cloud, либо подключенное стороннее хранилище).

**Последнее обновление:** 2024‑12‑01

## **Как загрузить файл**

### Информация об API загрузки файла

```bash
PUT https://api.aspose.cloud/v3.0/cells/storage/file/{path}
```

Параметры запроса перечислены ниже:

| Имя параметра | Тип    | Местоположение | Описание |
|---------------|--------|----------------|----------|
| path          | string | path           | Путь загружаемого файла, включая имя файла и расширение (например, `/folder1/Report.xlsx`). |
| file          | file   | formData       | Загружаемый файл. |
| storageName   | string | query          | Имя используемого хранилища. |

**HTTP-ответы**

| Код  | Описание                                |
|------|-----------------------------------------|
| 200  | Файл успешно загружен.                  |
| 400  | Неверный запрос — отсутствуют или недопустимы параметры. |
| 401  | Неавторизованный доступ — недействительный или отсутствующий JWT-токен. |
| 404  | Хранилище не найдено.                   |
| 500  | Внутренняя ошибка сервера.              |

[Спецификация OpenAPI](https://apireference.aspose.cloud/cells/#/File/UploadFile) определяет общедоступный программный интерфейс, позволяющий выполнять REST-взаимодействия непосредственно из веб-браузера.

### Пример загрузки файла

Вы можете использовать утилиту командной строки cURL для простого доступа к веб-сервисам Aspose.Cells. В следующем примере показано, как загрузить файл с помощью cURL.

{{< tabs tabTotal="2" tabID="11" tabName11="Запрос" tabName12="Ответ" >}}
{{< tab tabNum="11" >}}

```bash
curl -v "https://api.aspose.cloud/v3.0/cells/storage/file/MyFolder/Report.xlsx" \
  -X PUT \
  -H "accept: application/json" \
  -H "Authorization: Bearer <jwt token>" \
  -F "File=@Report.xlsx"
```

{{< /tab >}}
{{< tab tabNum="12" >}}

```json
{
  "Uploaded": [
    "MyFolder/Report.xlsx"
  ],
  "Errors": []
}
```

{{< /tab >}}
{{< /tabs >}}

*Примечание: Максимальный размер файла для загрузки — 100 МБ. Могут действовать ограничения частоты запросов.*

## **Как скачать файл**

### Информация об API скачивания файла

```bash
GET https://api.aspose.cloud/v3.0/cells/storage/file/{path}
```

Параметры запроса перечислены ниже:

| Имя параметра | Тип    | Местоположение | Описание |
|---------------|--------|----------------|----------|
| path          | string | path           | Путь к файлу (например, `/folder/Report.xlsx`). |
| storageName   | string | query          | Имя используемого хранилища. |
| versionId     | string | query          | Идентификатор версии файла для скачивания (необязательно). |

**HTTP-ответы**

| Код  | Описание                                |
|------|-----------------------------------------|
| 200  | Файл скачан; возвращается бинарный поток. |
| 400  | Неверный запрос — недопустимые параметры. |
| 401  | Неавторизованный доступ — отсутствует или недействителен JWT. |
| 404  | Файл не найден.                         |
| 500  | Внутренняя ошибка сервера.              |

[Спецификация OpenAPI](https://apireference.aspose.cloud/cells/#/File/DownloadFile) определяет общедоступный программный интерфейс, позволяющий выполнять REST-взаимодействия непосредственно из веб-браузера.

### Пример скачивания файла

```bash
curl -v "https://api.aspose.cloud/v3.0/cells/storage/file/MyFolder/Report.xlsx" \
  -X GET \
  -H "accept: application/json" \
  -H "Authorization: Bearer <jwt token>"
```
