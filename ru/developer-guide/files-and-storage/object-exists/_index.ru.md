**Object Exists API** позволяет разработчикам определить, присутствует ли конкретный файл или папка в облачном хранилище Aspose.Cells Cloud. Возвращается простое логическое значение, указывающее на наличие и то, указывает ли путь на папку.

## **Excel API: Object Exists**

### Web API

```http
GET https://api.aspose.cloud/v5.0/cells/storage/exist/{path}
```

_`{path}`_ — полный путь к файлу или папке в хранилище.

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### Параметры запроса

| Имя параметра | Тип   | Расположение | Обязательный | Описание                                                                 |
| ------------- | ----- | ------------ | ------------ | ------------------------------------------------------------------------ |
| `path`        | string | Путь         | Да           | Полный путь к файлу или папке.                                           |
| `storageName` | string | Параметр запроса | Нет          | Имя хранилища; по умолчанию используется основное хранилище, если не указано. |
| `versionId`   | string | Параметр запроса | Нет          | Идентификатор конкретной версии файла (если включено версионирование).   |

**Коды HTTP-статуса**

| Код HTTP | HTTP-статус           | Описание                                                              |
| -------- | --------------------- | --------------------------------------------------------------------- |
| 200      | OK (ОК)               | Web API успешно вызван; ответ содержит подробности операции.         |
| 400      | Bad Request (Неверный запрос) | Отсутствуют или некорректны параметры (например, неподдерживаемый тип файла). |
| 401      | Unauthorized (Неавторизован) | Некорректный или отсутствующий JWT-токен.                            |
| 413      | Payload Too Large (Слишком большой полезный груз) | Загружаемый файл превышает предельный размер.                         |
| 500      | Internal Server Error (Внутренняя ошибка сервера) | Непредвиденная ошибка сервера.                                        |

### **Ответ**

Успешный вызов возвращает JSON-объект со следующими двумя свойствами:

```json
{
  "Exists": true,
  "IsFolder": false
}
```

- **Exists** — `true`, если файл или папка существует; иначе `false`.
- **IsFolder** — `true`, если путь указывает на папку; `false` — если на файл.
