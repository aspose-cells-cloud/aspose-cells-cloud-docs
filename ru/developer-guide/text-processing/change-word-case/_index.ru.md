## **Изменение регистра слов**

С помощью Aspose.Cells Cloud Web API мгновенно преобразуйте регистр текста в вашей электронной таблице: переключайтесь между верхним, нижним, заглавными по словам (каждое слово начинается с заглавной буквы) или заглавной по предложениям (первая буква каждого предложения заглавная) в выбранном диапазоне. Изменяются только ячейки со строками; числа, логические значения, ошибки и пустые ячейки игнорируются. Формулы, форматирование и проверка данных остаются без изменений.

- **UpperCase** – все символы приводятся к верхнему регистру.
- **LowerCase** – все символы приводятся к нижнему регистру.
- **ProperCase** – первая буква каждого слова приводится к верхнему регистру, остальные — к нижнему.
- **SentenceCase** – первая буква каждого предложения приводится к верхнему регистру, остальные — к нижнему.

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/content/wordcase
```


### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации по токену JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```
### Параметры запроса для API **UpdateWordCase**

| Имя параметра | Тип   | Местоположение | Описание                                                                                                                                                  |
| :------------- | :----- | :------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------- |
| spreadsheet    | File   | FormData | Файл электронной таблицы для обработки. Поддерживаемые форматы: XLSX, XLS, ODS, CSV и др.                                                                  |
| wordCaseType   | String | Query    | Указывает тип преобразования регистра текста: `UpperCase`, `LowerCase`, `ProperCase` или `SentenceCase`.                                                  |
| worksheet      | String | Query    | _(Необязательно)_ Название листа, к которому будет применено преобразование регистра. Если не указано, операция применяется к первому листу книги.       |
| range          | String | Query    | _(Необязательно)_ Диапазон ячеек, к которому будет применено преобразование регистра (например, `"A1:C10"`). Если не указано, операция применяется ко всем используемым ячейкам указанного листа. |
| outPath        | String | Query    | _(Необязательно)_ Путь к папке облачного хранилища, где будет сохранена обработанная книга. Если не указано, файл сохраняется в исходной папке.             |
| outStorageName | String | Query    | Имя облачного хранилища, в котором будет сохранён выходной файл.                                                                                          |
| region         | String | Query    | _(Необязательно)_ Задаёт локаль для правил преобразования регистра, особенно актуально для языково-специфических правил заглавных букв (например, `"en-US"`, `"tr-TR"`). |
| password       | String | Query    | _(Необязательно)_ Если загруженная электронная таблица защищена паролем, укажите его для открытия и обработки файла.                                       |

### Ответ

При успешном выполнении сервис возвращает **200 OK** (или **202 Accepted**) с JSON-данными, содержащими бинарный поток обработанной книги.

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

### Коды ошибок

- **400 Bad Request** – некорректный URI API Aspose.Cells Cloud.
- **401 Unauthorized** – недействительный токен доступа или неверные учётные данные клиента.
- **404 Not Found** – файл электронной таблицы недоступен.
- **500 Server Error** – внутренняя ошибка обработки электронной таблицы.

## Где следует использовать API изменения регистра слов?

### Очистка и стандартизация данных

- **Управление данными клиентов** – стандартизация регистра имён клиентов и адресной информации (например, `иванов иван` → `Иванов Иван`).
- **Обработка каталога товаров** – стандартизация заголовков и описаний товаров (например, `IPHONE 15 PRO` → `iPhone 15 Pro`).
- **Генерация финансовой отчётности** – нормализация названий статей и описаний в финансовых документах.

### Интеграция данных из разных источников

- **ETL в хранилище данных** – стандартизация формата текста при загрузке данных из различных систем.
- **Приём данных через API** – обработка данных с несогласованным регистром, возвращаемых внешними API.
- **Объединение данных из разных отделов** – стандартизация формата текста в отчётах Excel от разных подразделений.

### Системы управления контентом

- **Автоматическая публикация новостей** – автоматическое форматирование заголовков и текста новостей (правила заглавных в заголовках).
- **Генерация технической документации** – обеспечение единообразия форматирования терминов в документации.
- **Поддержка базы знаний** – стандартизация формата текста в FAQ и справочных материалах.

### Интеграция корпоративных приложений

- **Интеграция с CRM** – автоматическое форматирование имён и названий компаний при импорте/экспорте данных клиентов.
- **Обработка данных ERP** – стандартизация ключевых полей, таких как описания материалов и названия поставщиков.
- **Системы управления персоналом** – стандартизация данных сотрудников и названий должностей.

### Пакетная обработка документов

- **Подготовка юридических документов** – пакетная обработка форматов пунктов в договорах и соглашениях.
- **Генерация маркетинговых материалов** – стандартизация формата рекламного текста и шаблонов писем.
- **Форматирование академических статей** – стандартизация требований к оформлению ссылок и заголовков.

### Обработка данных в реальном времени

- **Валидация пользовательского ввода** – форматирование данных форм в реальном времени при отправке пользователями.
- **Ответы чат-ботов** – стандартизация формата текста в автоматически генерируемых ответах.
- **Генерация отчётов в реальном времени** – динамическое создание отчётов с единым форматированием.

### Интернационализация и локализация

- **Обработка многоязычных данных** – учёт различий в правилах заглавных букв для текстов на разных языках.
- **Подготовка локализованного контента** – создание отформатированного контента для разных регионов.
- **Управление переводческими проектами** – обеспечение единообразия формата текста до и после перевода.

## Почему стоит использовать API изменения регистра слов?

- **Удобен для разработчиков** – Aspose.Cells Cloud предоставляет SDK на множестве языков программирования, что ускоряет разработку и обеспечивает подробную документацию. По сравнению с созданием собственных решений это значительно снижает объём работы.
- **Экономически эффективно** – вы можете изменять регистр слов без предварительной загрузки книги, что экономит место в хранилище и снижает затраты.
