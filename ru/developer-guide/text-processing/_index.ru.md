## API для манипуляций с текстом в Excel

Aspose.Cells Cloud предоставляет набор REST-эндпоинтов, позволяющих выполнять манипуляции с текстом внутри листов Excel. Эти операции охватывают повседневные задачи, такие как обрезка пробельных символов, разделение строк, преобразование регистра, извлечение подстрок и удаление нежелательных символов.

**Требования:** все запросы должны быть аутентифицированы с помощью действительного токена доступа, передаваемого в заголовке `Authorization`. Подробности об получении и использовании токенов см. в руководстве по аутентификации.
