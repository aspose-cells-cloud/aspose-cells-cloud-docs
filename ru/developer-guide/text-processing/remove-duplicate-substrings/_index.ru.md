Удаление дублирующихся подстрок из ячеек Excel с интеллектуальным обнаружением. Сохраняйте исходное форматирование, устраняя избыточный текст с помощью API дедупликации Aspose.Cells.

## **Введение**: Точное удаление нежелательных символов

API очистки повторяющихся подстрок удаляет дублирующиеся подстроки внутри отдельных ячеек диапазона Excel, сохраняя форматирование ячеек, правила проверки данных и другие структуры рабочей книги. Он обрабатывает каждую ячейку независимо, оставляя только первое вхождение каждой дублирующейся подстроки.

### **Параметры источника данных**

| Поле       | Тип    | Обязательное | Описание                                                |
| ---------- | ------ | ------------ | ------------------------------------------------------- |
| `workbook` | файл   | Да           | Файл рабочей книги Excel (.xlsx, .xlsm)                |
| `range`    | строка | Да           | Целевой диапазон для обработки (например, "A1:D100", "Sheet1!A:D") |

### **Параметры разделителей**

| Поле                               | Тип     | По умолчанию | Описание                                                                                                                                                  |
| ---------------------------------- | ------- | ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `delimiters`                       | строка  | `"preset"`   | Варианты: `preset`, `custom`, `comma`, `semicolon`, `space`, `tab`, `line-break`, либо пользовательская строка-разделитель (несколько символов рассматриваются как составной разделитель) |
| `treatConsecutiveDelimitersAsOne` | логическое значение | `false`      | Объединять смежные разделители в один разделитель                                                                                                        |
| `caseSensitive`                    | логическое значение | `false`      | Определяет, учитывается ли регистр при сравнении. При значении `false` регистр игнорируется при обнаружении дубликатов.                                   |

## **API RemoveDuplicateSubstrings**

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/content/remove/duplicate-substrings
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации по токену JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### Параметры запроса API **RemoveDuplicateSubstrings**

| Имя параметра                  | Тип     | Путь/Строка запроса/HTTP-тело | Описание                                                                                                                                                                       |
| :----------------------------- | :------ | :--------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet                    | Файл    | FormData                     | Файл электронной таблицы для обработки. Поддерживаемые форматы: XLSX, XLS, ODS, CSV и др.                                                                                       |
| delimiters                     | Строка  | Query                        | Указывает один или несколько символов-разделителей, используемых для разбиения содержимого ячейки на подстроки для обнаружения и удаления дубликатов. Можно указать несколько разделителей (например, `",;"`). |
| treatConsecutiveDelimitersAsOne | Логическое значение | Query                        | Если установлено значение `true`, последовательные символы-разделители рассматриваются как один разделитель. Если `false`, каждый разделитель обрабатывается отдельно.           |
| caseSensitive                   | Логическое значение | Query                        | Если `true`, обнаружение дубликатов учитывает регистр (например, "Текст" ≠ "текст"). Если `false`, регистр игнорируется при сравнении дубликатов.                              |
| worksheet                       | Строка  | Query                        | _(Необязательный)_ Имя рабочего листа, к которому будет применено удаление дублирующихся подстрок. Если опущено, операция применяется к первому рабочему листу.                 |
| range                           | Строка  | Query                        | _(Необязательный)_ Диапазон ячеек, к которому будет применено удаление дублирующихся подстрок (например, `"A1:C10"`). Если опущено, операция применяется ко всем используемым ячейкам указанного рабочего листа. |
| outPath                         | Строка  | Query                        | _(Необязательный)_ Путь к папке облачного хранилища, куда будет сохранена обработанная рабочая книга. Если опущено, файл сохраняется в исходной папке.                          |
| outStorageName                  | Строка  | Query                        | Имя облачного хранилища, в котором будет сохранен выходной файл.                                                                                                               |
| region                          | Строка  | Query                        | _(Необязательный)_ Устанавливает локаль для обработки текста, что может повлиять на интерпретацию разделителей и правила учета регистра для некоторых языков (например, `"en-US"`, `"tr-TR"`). |
| password                        | Строка  | Query                        | _(Необязательный)_ Если загруженная электронная таблица защищена паролем, укажите пароль для открытия и обработки файла.                                                        |

**Пример запроса (cURL)**

```bash
curl -X PUT "https://api.aspose.cloud/v4.0/cells/content/remove/duplicate-substrings?delimiters=comma&caseSensitive=false" \
     -H "Authorization: Bearer {access_token}" \
     -F "Spreadsheet=@Sample.xlsx" \
     -F "range=A1:D100"
```

### **Ответ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

### **Коды состояния**

| Код | Значение                                | Описание                                                                                     |
|-----|-----------------------------------------|----------------------------------------------------------------------------------------------|
| 200 | OK (Успешно)                            | Запрос выполнен успешно, возвращается обработанная рабочая книга.                           |
| 202 | Accepted (Принято)                      | Запрос принят для асинхронной обработки.                                                     |
| 400 | Bad Request (Неверный запрос)           | Запрос сформирован некорректно или содержит недопустимые параметры.                         |
| 401 | Unauthorized (Неавторизован)            | Ошибка аутентификации или отсутствует/недействителен токен.                                 |
| 404 | Not Found (Не найдено)                  | Указанная рабочая книга или ресурс не найдены.                                              |
| 500 | Internal Server Error (Внутренняя ошибка сервера) | Произошла непредвиденная ошибка на стороне сервера.                                         |

## Где следует использовать API Remove Duplicate Substrings?

- **Очистка и стандартизация данных**: Очистка тегов вроде `"VIP,Premium,VIP,Gold"` → `"VIP,Premium,Gold"`.
- **Технические и операционные данные**: Очистка записей журналов с повторяющимися кодами ошибок, удаление дублирующихся идентификаторов ячеек/стеллажей и т.д.
- **Управление контентом и мультимедиа**: Устранение дубликатов меток навыков, удаление повторяющихся записей сертификатов.

## Почему следует использовать API Remove Duplicate Substrings?

- **Автоматизация рутинных задач**: Устранение утомительного ручного редактирования и снижение вероятности ошибок человека.
- **Сохранение целостности данных**: Цвета ячеек, шрифты, границы и условное форматирование остаются неизменными; выпадающие списки и правила проверки сохраняются.
- **Гибкая обработка**: Независимость от типа разделителя, возможность выборочного учета регистра и защита заголовков.
- **Удобно для разработчиков**: Aspose.Cells Cloud предоставляет SDK на нескольких языках программирования, что позволяет быстро разрабатывать решения при помощи подробной документации.
- **Экономически эффективно**: Операция выполняется в облаке, исключая необходимость хранения промежуточных файлов локально.
