Добавляйте текст в несколько ячеек Excel за одну операцию. Добавляйте префиксы, суффиксы, метки или пользовательские символы в начало, конец или до/после указанного текста внутри ячеек с помощью API Aspose.Cells.

## Обзор

Однократное пакетное добавление префиксов, суффиксов или привязанных строк во все ячейки целевого диапазона — без формул и вспомогательных столбцов.

- Добавление пользовательского текста в **любую позицию** внутри каждой ячейки

| Значение         | Описание                                                                              |
| ---------------- | ------------------------------------------------------------------------------------- |
| `None`           | Заменить исходное содержимое                                                          |
| `AtTheBeginning` | Вставить в начало (префикс)                                                           |
| `AtTheEnd`       | Вставить в конец (суффикс)                                                            |
| `BeforeText`     | Вставить **до** первого вхождения `selectText`; пропустить, если не найдено          |
| `AfterText`      | Вставить **после** первого вхождения `selectText`; пропустить, если не найдено       |

- Четыре режима позиционирования: префикс, суффикс, до/после подстроки.
- Пропуск пустых ячеек для избежания засорения.
- API затрагивает только значения **строкового типа**; числа, логические значения и формулы сначала преобразуются в текст.
- **Пустые ячейки**
  - `skipEmptyCells = true` → пустые ячейки пропускаются.
  - `skipEmptyCells = false` → в пустые ячейки добавляется текст (ячейка становится строкового типа).

- **Якорь не найден**: если `position = BeforeText | AfterText`, а `selectText` **отсутствует**, значение ячейки остаётся без изменений.

### **Веб-API**

```http
PUT https://api.aspose.cloud/v4.0/cells/content/add/text
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе токена JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### Параметры запроса API **AddText**:

| Имя параметра | Тип     | Путь/строка запроса/HTTP-тело | Описание                                                                                                                                                 | Обязательный |
| :------------ | :------ | :--------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------- |
| Spreadsheet   | Файл    | FormData                     | Файл электронной таблицы для обработки. Поддерживаемые форматы: XLSX, XLS, ODS, CSV и др.                                                                | Да           |
| text          | Строка  | Query                        | Текстовое содержимое, которое будет добавлено в указанные ячейки электронной таблицы.                                                                    | Да           |
| position      | Строка  | Query                        | Указывает, куда добавлять текст относительно существующего содержимого ячейки. Возможные значения: `AtTheBeginning`, `AtTheEnd`, `BeforeText`, `AfterText`, `None`. | Да           |
| selectText    | Строка  | Query                        | _(Опционально)_ Если указано, текст будет добавлен только в ячейки, содержащие эту подстроку. Используется совместно с параметром `position`.           | Нет          |
| skipEmptyCells| Булево  | Query                        | Если `true`, пустые ячейки пропускаются; если `false`, текст добавляется в пустые ячейки.                                                                 | Нет          |
| worksheet     | Строка  | Query                        | _(Опционально)_ Имя листа, в который будет добавлен текст. Если не указано, операция применяется к первому листу по умолчанию.                          | Нет          |
| range         | Строка  | Query                        | _(Опционально)_ Диапазон ячеек, в который будет добавлен текст (например, `"A1:C10"`). Если не указано, операция применяется ко всем используемым ячейкам указанного листа. | Нет          |
| outPath       | Строка  | Query                        | _(Опционально)_ Путь к папке облачного хранилища, куда будет сохранён обработанный файл. Если не указано, файл сохраняется в исходной папке.             | Нет          |
| outStorageName| Строка  | Query                        | Имя облачного хранилища, в котором будет сохранён выходной файл.                                                                                         | Нет          |
| region        | Строка  | Query                        | _(Опционально)_ Устанавливает локаль для форматирования чисел, дат и валют в выходном файле (например, `"en-US"`, `"zh-CN"`, `"de-DE"`).                   | Нет          |
| password      | Строка  | Query                        | _(Опционально)_ Если загруженная электронная таблица защищена паролем, укажите пароль для открытия и обработки файла.                                    | Нет          |

**Пример cURL**

```bash
curl -X PUT "https://api.aspose.cloud/v4.0/cells/content/add/text?text=Report&position=AtTheBeginning&skipEmptyCells=true" \
  -H "Authorization: Bearer {access_token}" \
  -F "Spreadsheet=@/path/to/workbook.xlsx" \
  -F "outPath=output/workbook_modified.xlsx"
```

### **Ответ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

### Коды ошибок

| Код | Описание |
| --- | -------- |
| **400** Bad Request | Неверный URI API Aspose.Cells Cloud или отсутствуют обязательные параметры. |
| **401** Unauthorized | Неверный токен доступа или неверные идентификаторы клиента и секретный ключ. |
| **404** Not Found | Файл электронной таблицы недоступен. |
| **500** Server Error | При получении данных для расчётов возникла ошибка в электронной таблице. |

## Где использовать API Add Text для электронных таблиц?

- **Динамическая маркировка отчётов**: добавляйте динамические заголовки, метки даты или примечания к автоматически генерируемым финансовым отчётам и отчётам о продажах.
- **Массовая вставка водяных знаков**: добавляйте логотипы компании, водяные знаки конфиденциальности или информацию о версии к пакету файлов Excel.
- **Заполнение шаблонов данными**: автоматически заполняйте имена клиентов, суммы и другой текст в заданных позициях шаблонов договоров или счёт-фактур.
- **Метки классификации данных**: автоматически добавляйте метки классификации или статусы (например, «Ожидает проверки», «Утверждено») к строкам данных на основе результатов анализа.
- **Аннотации качества данных**: добавляйте примечания к проблемным данным при очистке данных.
- **Массовое форматирование текста**: единообразно добавляйте префиксы или суффиксы к названиям товаров или клиентов.

## Почему стоит использовать API Add Text для электронных таблиц?

- **Пакетное добавление текста**: добавляйте текст в сотни ячеек или файлов одновременно, сэкономив до 95 % времени по сравнению с ручной работой.
- **Точное управление позицией**: поддерживает вставку текста в шести позициях — в начало, в конец, до или после указанного текста внутри ячейки.
- **Умная условная обработка**: решайте, добавлять текст или нет, в зависимости от того, пуста ли ячейка или содержит ли она определённый текст.
- **Поддержка стратегии нескольких позиций**:
  - `AtTheBeginning`: добавляет один и тот же текст перед содержимым всех выбранных ячеек.
  - `AtTheEnd`: добавляет текст после содержимого всех выбранных ячеек.
  - `BeforeText` / `AfterText`: добавляет текст только до или после ячеек, содержащих указанный текст.
  - `None`: заменяет исходное содержимое.
- **Точное управление диапазоном**: позволяет указывать конкретные листы или диапазоны ячеек для операций.
- **Опция пропуска условий**: поддерживает пропуск пустых ячеек, чтобы избежать ненужного добавления текста.
- **Удобно для разработчиков**: Aspose.Cells Cloud предоставляет SDK на множестве языков, что обеспечивает быструю разработку, и сопровождается подробной документацией. По сравнению с созданием собственных решений для визуализации графиков, это значительно сокращает объём работы.
- **Экономически эффективно**: можно добавлять текст в ячейку без предварительной загрузки файла книги, что экономит место в хранилище и снижает затраты.
