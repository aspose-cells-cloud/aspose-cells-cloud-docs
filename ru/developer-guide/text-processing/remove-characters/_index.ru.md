Очистите данные Excel, удалив пользовательские символы, наборы символов или подстроки из выбранного диапазона ячеек. Удаляйте текст в определённых позициях с помощью Aspose.Cells API для точного форматирования данных.

## Введение

Легко очищайте и стандартизируйте данные Excel, удаляя ненужные символы. Наш надстройка предоставляет множество целевых способов очистки ячеек:

- **Удаление пользовательских символов**  
  Удалите любые заданные вами символы. Просто введите каждый символ в поле, и надстройка мгновенно удалит все его вхождения из выбранных ячеек. Отлично подходит для устранения уникальных разделителей, опечаток или специальных знаков.

- **Удаление наборов символов (массовая очистка)**  
  - **Непечатаемые символы** – очистите данные от невидимых символов, нарушающих анализ и форматирование (разрывы строк, возвраты каретки, табуляции и другие управляющие символы, такие как ASCII 0‑31, 127, 129, 141, 143, 144, 157).  
  - **Символы текста (все буквы)** – выделите цифры и символы, удалив все буквы (A‑Z, a‑z) из выбранного диапазона.  
  - **Цифровые символы (все цифры)** – извлеките чистый текст, удалив все цифры (0‑9), что идеально подходит для очистки названий товаров или текстовых описаний.  
  - **Символы** – удалите широкий спектр символьного «мусора», включая математические (например, ±, √), геометрические (например, ∆, °), технические, валютные (например, £, ¢) и буквоподобные символы (например, ™, ®, ©).  
  - **Знаки препинания** – получите чистый текст без знаков препинания, удалив все знаки препинания, такие как точки, запятые, кавычки и дефисы.

- **Удаление конкретной подстроки**  
  Выходите за рамки одиночных символов и удаляйте целые слова или конкретные последовательности символов. Легко удаляйте распространённые префиксы, суффиксы или любые избыточные текстовые фразы из ваших наборов данных.

## API RemoveCharacters

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/content/remove/characters
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации по токену JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### Параметры запроса

| Имя параметра   | Тип    | Расположение         | Описание                                                                                                                                                                                                                      |
| ----------------- | ------ | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet       | File   | FormData           | Файл электронной таблицы для обработки. Поддерживаемые форматы: XLSX, XLS, ODS, CSV и др.                                                                                                                                        |
| removeTextMethod  | String | Query              | Указывает метод удаления текста. Возможные значения: `None`, `RemoveCustomCharacter`, `RemoveCharacterSets`, `RemoveSubString`. По умолчанию `None`.                                                                                        |
| characterSets     | String | Query              | Предопределённые наборы символов для удаления при выборе `RemoveCharacterSets`. Возможные значения: `NonPrintingCharacters`, `TextCharacters`, `NumericCharacters`, `Symbols`, `PunctuationMarks`. Несколько наборов можно объединить запятыми. |
| removeCustomValue | String | Query              | Пользовательские символы или подстроки для удаления при использовании `RemoveCustomCharacter` или `RemoveSubString`.                                                                                                                           |
| worksheet         | String | Query _(опционально)_ | Имя рабочего листа, к которому будет применено удаление текста. **Если параметр опущен, API обрабатывает первый рабочий лист книги.**                                                                                           |
| range             | String | Query _(опционально)_ | Диапазон ячеек, к которому будет применено удаление текста (например, `"A1:C10"`). **Если параметр опущен, операция применяется ко всем используемым ячейкам указанного рабочего листа.**                                                                      |
| outPath           | String | Query _(опционально)_ | Путь к папке облачного хранилища, куда будет сохранена обработанная книга. Если опущен, файл сохраняется в исходной папке.                                                                                                        |
| outStorageName    | String | Query _(опционально)_ | Имя облачного хранилища, куда будет сохранён выходной файл.                                                                                                                                                              |
| region            | String | Query _(опционально)_ | Задаёт локаль для определений наборов символов (например, `"en-US"`, `"ja-JP"`).                                                                                                                                                      |
| password          | String | Query _(опционально)_ | Пароль защищённой книги, если требуется.                                                                                                                                                                                  |

### Ответ

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

### Коды ошибок

- **400 Bad Request** – недопустимый URI API Aspose.Cells Cloud.
- **401 Unauthorized** – недействительный токен доступа или неверные идентификатор клиента и секрет.
- **404 Not Found** – файл электронной таблицы недоступен.
- **500 Server Error** – при получении данных для расчётов электронная таблица столкнулась с ошибкой.

## Где использовать API удаления символов?

- **Импорт/экспорт данных** – очищайте импортированные CSV/данные, удаляя невидимые символы и ошибки форматирования.
- **Управление базами данных** – стандартизируйте коды товаров, идентификаторы и названия, удаляя нежелательные символы и знаки препинания.
- **Финансовый анализ** – извлекайте чистые числа, удаляя валютные символы и текстовые символы.
- **Обработка текста** – удаляйте разрывы строк и табуляции для чистого анализа и отчётности.
- **Управление инвентарем** – очищайте названия товаров, удаляя избыточные префиксы и суффиксы.

## Почему использовать API удаления символов?

- **Экономия времени** – мгновенно удаляйте несколько типов символов пакетно, вместо ручной очистки.
- **Обеспечение точности** – устраняйте скрытые символы, вызывающие ошибки анализа и проблемы форматирования.
- **Стандартизация данных** – достигайте единообразного форматирования наборов данных и систем.
- **Улучшение анализа** – получайте чистые, готовые к анализу данные, выделяя при необходимости числа или текст.
- **Устранение ошибок импорта** – удаляйте проблемные символы, нарушающие работу баз данных и формул.
- **Удобно для разработчиков** – Aspose.Cells Cloud предоставляет SDK на множестве языков, что позволяет быстро разрабатывать решения с подробной документацией. По сравнению с созданием собственных решений это значительно сокращает объём работы.
- **Экономичность** – удаляйте символы без предварительной загрузки книги, экономя место в хранилище и снижая затраты.
