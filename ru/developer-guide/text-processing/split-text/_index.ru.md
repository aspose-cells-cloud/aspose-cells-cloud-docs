Разбивайте текст в ячейках Excel на несколько столбцов, используя настраиваемые правила сегментации. Разделяйте содержимое по разделителям и выводите результат в указанные диапазоны с помощью облачного веб-API Aspose.Cells Cloud для разделения текста.

## **Введение**: Разделение текста

API сегментации текста разделяет содержимое ячеек на несколько ячеек на основе заданных разделителей, шаблонов или разрывов строк и выводит результаты в целевой диапазон. Поддерживает гибкие методы разделения, направление вывода (столбцы или строки) и возможность сохранения разделителей — идеально подходит для разбора конкатенированных данных, содержимого в формате CSV или многострочного текста в структурированные форматы.

- **Разделение ячейки по конкретному символу** — разбейте содержимое ячейки на несколько ячеек, выбрав любой символ в качестве разделителя (запятая, пробел, точка с запятой и т.д.).
- **Разделение ячеек по строке** — разделяйте ячейки по любой комбинации символов, которую вы укажете.
- **Разделение текста по маске** — используйте подстановочные знаки для разделения текста на основе определённого шаблона, что обеспечивает ещё более гибкий и мощный способ разделения текста.
- **Разделение содержимого ячейки по разрыву строки** — создайте более упорядоченное представление, разделяя текст по разрывам строк.
- **Разделение ячеек на столбцы или строки** — выберите, будут ли результаты разделения записаны в последовательные столбцы или строки.
- **Удаление или сохранение разделителей** — решите, будут ли разделители удалены или сохранены в начале или в конце результирующих ячеек.

## **API SplitText**

**Предварительные требования**: Для использования этого API вам необходим действующий токен доступа Aspose Cloud, а книга, подлежащая обработке, должна быть загружена в облачное хранилище Aspose Cloud или предоставлена непосредственно в запросе. API поддерживает распространённые форматы электронных таблиц, такие как XLSX, XLS, ODS и CSV.

### Web API

```http
POST https://api.aspose.cloud/v4.0/cells/content/split/text
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### **Ответ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

### Коды ошибок

- **400 Bad Request** — Неверный URI API Aspose.Cells Cloud или некорректные параметры запроса.
- **401 Unauthorized** — Отсутствующий или недействительный токен доступа (или client-id/secret).
- **404 Not Found** — Указанный файл электронной таблицы не может быть найден.
- **500 Server Error** — Внутренняя ошибка обработки электронной таблицы.

## Где следует использовать API для разделения текста?

### **Очистка при импорте CSV и текстовых файлов**

При импорте данных из внешних систем поля часто конкатенируются в одну ячейку:

- **Импорт данных ERP/CRM** — разделите `"Иванов Иван;ivanov@example.com;+7-999-123-45-67"` на отдельные столбцы: имя, email и телефон.
- **Экспорт из базы данных** — разберите объединённые ключи, например `"ЗАК-2024-001|Премиум|Экспресс"`, на идентификатор заказа, тариф и способ доставки.
- **Анализ журналов** — разбейте полуструктурированные логи, например `"2024-01-15 10:30:00|ОШИБКА|ConnectionTimeout"`, для последующей фильтрации.

### **Миграция устаревших систем**

- Старые системы сохраняют поля с несколькими значениями в одной ячейке; разделите их, чтобы соответствовать новым схемам баз данных.
- Преобразуйте экспорты в виде плоских файлов в нормализованные таблицы Excel, готовые для использования в Power BI или Tableau.

### **Очистка и стандартизация данных**

- **Нормализация разделителей** — преобразуйте смешанные разделители (например, `"A,B;C|D"`) в единый формат с помощью разделения по нескольким разделителям.
- **Очистка пробелов** — разбейте по пробелам, чтобы выявить и удалить лишние пробелы между словами.
- **Финансовые данные** — разделите объединённые коды транзакций, например `"ВЗ-ЧЕК-3847"`, на тип транзакции, источник и ссылку.
- **Медицинские записи** — разберите данные пациентов, например `"Смит,Джейн_Ж_1985"`, на фамилию, имя, пол и год рождения.

## Почему стоит использовать API для разделения текста?

- **Конкретные символы** — разделяйте по любому одному символу (запятая, точка с запятой, tab, пробел).
- **Комбинации строк** — используйте многосимвольные разделители, такие как `||`, `->` или пользовательские разделители.
- **Разрывы строк** — мгновенно разбивайте многострочные ячейки на отдельные строки (адреса, комментарии, описания).
- **Пользовательские разделители** — определите любую комбинацию символов в качестве разделителя для проприетарных форматов данных.
- **Удобство для разработчиков** — Aspose.Cells Cloud предоставляет SDK на множестве языков программирования, что позволяет быстро разрабатывать приложения, и поставляется с исчерпывающей документацией. По сравнению с созданием собственных решений это значительно снижает объём разработки.
- **Экономичность** — вы можете удалять дублирующиеся символы без предварительной загрузки книги, что экономит место в хранилище и снижает затраты.
