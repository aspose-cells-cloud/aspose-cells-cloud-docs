Очищайте данные Excel, преобразуя числа в текстовом формате в числовые значения, заменяя нежелательные символы и разрывы строк, а также нормализуя акцентированные символы до стандартных букв с помощью API Aspose.Cells.

## Обзор

**Преобразуйте числа в текстовом формате, очистите данные от мусора, замените акцентированные символы — одно обращение, без формул.**

- **Преобразование чисел, сохранённых как текст, в числа**: Преобразуйте числовые данные, хранящиеся в текстовом формате, в настоящие числа, обеспечивая точность вычислений и корректное представление данных.
- **Замена определённых символов**: Замените все вхождения указанных символов в выбранных ячейках одновременно для стандартизации данных.
- **Преобразование разрывов строк в пробел, запятую или точку с запятой**: Улучшите читаемость, заменяя разрывы строк на пробелы, запятые или точки с запятыми, что делает представление данных более организованным и визуально привлекательным.
- **Замена акцентированных символов**: Если ваши данные содержат текст на разных языках, вы можете заменить акцентированные символы (например, «é» или «ü») на их неакцентированные аналоги, что повышает согласованность и читаемость.

## API **ConvertText**

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/content/convert/text
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе токена JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### Параметры запроса API **convertText**

| Имя параметра  | Тип   | Путь/Строка запроса/HTTPBody | Описание                                                                                                                                                             |
|----------------|-------|----------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Spreadsheet    | File  | FormData                   | Файл электронной таблицы для обработки. Поддерживаемые форматы: XLSX, XLS, ODS, CSV и др.                                                                           |
| convertTextType| String| Query                      | Указывает тип преобразования текста, например: преобразование чисел, представленных в текстовом формате, в числовые значения, или замена акцентированных символов на обычные. |
| sourceCharacters| String| Query                     | Указывает символы, строки или шаблоны, которые нужно заменить или удалить из текста (например, `"é,è,ê"`, `"#N/A"`, `"\\n"` для разрывов строк).                     |
| targetCharacters| String| Query                     | Указывает символы или строки-заменители, которые будут использоваться вместо исходных символов (например, `"e"` для акцентированных букв, `""` для удаления, `" "` для разрывов строк). |
| worksheet      | String| Query                      | *(Необязательно)* Имя листа, к которому будет применено преобразование текста. Если не указано, операция применяется к первому листу.                              |
| range          | String| Query                      | *(Необязательно)* Диапазон ячеек, к которому будет применено преобразование текста (например, `"A1:C10"`). Если не указано, операция применяется ко всем используемым ячейкам указанного листа. |
| outPath        | String| Query                      | *(Необязательно)* Путь к папке в облачном хранилище, куда будет сохранён обработанный рабочий файл. Если не указано, файл сохраняется в исходной папке.               |
| outStorageName | String| Query                      | Имя облачного хранилища, в котором будет сохранён выходной файл.                                                                                                    |
| region         | String| Query                      | *(Необязательно)* Устанавливает региональные настройки для правил преобразования текста, особенно важные для языковой обработки символов (например, `"en-US"`, `"fr-FR"`). |
| password       | String| Query                      | *(Необязательно)* Если загруженный файл электронной таблицы защищён паролем, укажите пароль для открытия и обработки файла.                                          |

### **Ответ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

### Коды ошибок

- **400 Bad Request**: Неверный URI API Aspose.Cells Cloud.
- **401 Unauthorized**: Неверный токен доступа, или неверные client ID и secret.
- **404 Not Found**: Файл электронной таблицы недоступен.
- **500 Server Error**: При получении данных для расчёта в электронной таблице возникла аномалия.

## Где следует использовать API Convert Text?

- **Исправление формата чисел**: Преобразуйте числа, сохранённые как текст (например, «123.45»), в числовой формат, пригодный для вычислений.
- **Очистка специальных символов**: Удалите ненужные специальные символы, лишние пробелы или невидимые символы из данных.
- **Обработка разрывов строк**: Замените разрывы строк в ячейках на пробелы или другие разделители.
- **Нормализация акцентированных символов**: Преобразуйте акцентированные буквы (например, «é», «ñ») в обычные буквы («e», «n»).
- **Предварительная обработка файлов CSV**: Стандартизируйте текстовый формат перед импортом CSV-файлов в Excel.

## Почему стоит использовать API Convert Text?

- **Автоматическое преобразование формата**: Преобразуйте числа в текстовом формате в вычисляемые значения пакетно за одно обращение.
- **Стандартизация символов**: Единообразно обрабатывайте специальные символы, диакритические знаки и проблемы с кодировкой.
- **Единообразие данных**: Обеспечьте полное единообразие текстового формата по всему набору данных.
- **Удобство для разработчиков**: Aspose.Cells Cloud предоставляет SDK на множестве языков программирования, что позволяет быстро разрабатывать решения и обеспечивает исчерпывающую документацию. По сравнению с созданием собственных решений для обработки текста, это значительно снижает объём рабочей нагрузки.
- **Экономичность**: Вы можете преобразовывать текст без предварительной загрузки рабочей книги, что экономит место в хранилище и снижает затраты.
