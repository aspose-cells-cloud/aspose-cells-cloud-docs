Удаляйте символы из ячеек Excel по позиции: удалите первые/последние N символов или текст до/после заданных меток. Точная очистка текста с помощью Aspose.Cells Cloud Web API.


## **Введение**: Удаление нежелательных символов по позиции

**Режимы позиционирования**

- `theFirstNCharacters` — удалить N символов с начала
- `theLastNCharacters` — удалить N символов с конца
- `allCharactersBeforeText` — удалить всё до первого вхождения указанной подстроки
- `allCharactersAfterText` — удалить всё после первого вхождения
- `BetweenValues` — удалить подстроку (и, при необходимости, сами разделители) между двумя заданными значениями

**Параметры**

- `caseSensitive` — определяет, будут ли поиски для `BeforeText`, `AfterText` и `BetweenValues` учитывать регистр

## **API RemoveCharactersByPosition**

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/content/remove/characters
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации по токену JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

### Коды ошибок

- **200 OK** — Запрос выполнен успешно, обработанный файл возвращён.
- **400 Bad Request**: Неверный URI Aspose.Cells Cloud API.
- **401 Unauthorized**: Неверный токен доступа или неверные client ID и client secret.
- **404 Not Found**: Файл электронной таблицы недоступен.
- **500 Server Error**: При получении данных для расчётов в электронной таблице возникла ошибка.

## Где следует использовать API Remove Characters by Position?

- **Стандартизация данных**: Очистка кодов товаров (удаление ведущих нулей или суффиксов), телефонных номеров (удаление кодов стран)
- **Извлечение текста**: Извлечение ключевой информации из лог-файлов (удаление временных меток или префиксов)
- **Обработка файлов**: Организация имён файлов (удаление одинаковых префиксов или суффиксов с датами)
- **Парсинг данных**: Обработка структурированного текста (извлечение содержимого между скобками или конкретными маркерами)
- **Управление базами данных**: Очистка импортируемых данных (удаление фиксированных заголовочных/завершающих символов)

## Почему стоит использовать API Remove Characters by Position?

- **Точность и эффективность**: Прямое позиционное удаление устраняет необходимость в сложных регулярных выражениях.
- **Гибкая настройка**: Пять режимов позиционирования и параметр чувствительности к регистру покрывают разнообразные сценарии.
- **Пакетная обработка**: Очистка целых столбцов одним вызовом, повышая производительность до 10 раз.
- **Умный парсинг**: Легко обрабатывайте извлечение содержимого между двумя разделителями.
- **Удобно для разработчиков**: Aspose.Cells Cloud предоставляет SDK для множества языков, ускоряя разработку и обеспечивая подробную документацию. По сравнению с написанием собственной логики обработки текста, это значительно снижает объём работы.
- **Экономия**: Символы можно удалять без предварительной загрузки книги, экономя место в хранилище и снижая затраты.
