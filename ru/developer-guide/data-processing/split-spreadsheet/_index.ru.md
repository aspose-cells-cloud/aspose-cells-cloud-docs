Разделите локальную рабочую книгу Excel на отдельные файлы полностью — облачное хранилище не требуется. Поддерживаемые выходные форматы: PDF, CSV, JSON, ODS, XPS и ещё более 30.

## **API разделения электронной таблицы**

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/split/spreadsheet
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации по токену JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### **Параметры запроса:**

| Имя параметра | Тип    | Путь/Строка запроса/HTTPBody | Описание                                                                                                                                                                                                 |
| :------------ | :------ | :--------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet   | File    | FormData                     | Локальный файл электронной таблицы, подлежащий разделению. Поддерживаемые форматы включают XLSX, XLS, ODS, CSV и др. Обработка файла происходит полностью на сервере без использования облачного хранилища. |
| from          | Integer | Query                        | Начальный индекс (с нуля) диапазона листов для разделения (например, `0` для первого листа).                                                                                                               |
| to            | Integer | Query                        | Конечный индекс (с нуля) диапазона листов для разделения (например, `2` разделит листы с индексами 0, 1 и 2).                                                                                               |
| outFormat     | String  | Query                        | Выходной формат создаваемых файлов. Поддерживает более 30 форматов: `PDF`, `CSV`, `JSON`, `XLSX`, `HTML` и др.                                                                                             |
| outPath       | String  | Query                        | _(Опционально)_ Путь к локальной папке, в которую будут сохранены выходные файлы. Если не указан, файлы сохраняются во временную папку по умолчанию.                                                      |
| outStorageName| String  | Query                        | Идентификатор хранилища для организации выходных файлов. В режиме локальной обработки обычно обозначает сессионное или пользовательское хранилище.                                                        |
| fontsLocation | String  | Query                        | _(Опционально)_ Указывает локальную или пользовательскую папку шрифтов для корректного отображения текста при экспорте в PDF или графические форматы.                                                      |
| region        | String  | Query                        | _(Опционально)_ Устанавливает региональные настройки для форматирования чисел, дат и валют в выходных файлах (например, `"ru-RU"`, `"de-DE"`).                                                               |
| password      | String  | Query                        | _(Опционально)_ Пароль, если загружаемая электронная таблица защищена. Необходим для открытия и обработки файла.                                                                                          |

## **Ответ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

Файл можно загрузить напрямую или сохранить в путь, указанный в параметре `outPath`.

**Детали успешного ответа**

| Код статуса | Content‑Type               | Описание                                          |
| ----------- | -------------------------- | ------------------------------------------------- |
| 200 OK      | `application/octet-stream` | Бинарный поток объединённой рабочей книги Excel. |

**HTTP-коды статуса**

| Код | Значение                 | Описание                                                             |
| --- | ------------------------ | -------------------------------------------------------------------- |
| 200 | OK (OK)                  | Фильтр применён успешно; ответ содержит детали операции.            |
| 400 | Bad Request (Неверный запрос) | Отсутствуют или неверны параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized (Неавторизован) | Неверный или отсутствует токен JWT.                                 |
| 413 | Payload Too Large (Слишком большой payload) | Загруженный файл превышает допустимый размер.                       |
| 500 | Internal Server Error (Внутренняя ошибка сервера) | Непредвиденная ошибка сервера.                                      |

## Где следует использовать API разделения электронной таблицы?

- **Распределение данных по отделам**: Разделить единую рабочую книгу с данными из нескольких отделов на отдельные файлы по каждому отделу.
- **Региональное распространение отчётов**: Разделить национальные отчёты по продажам на отдельные региональные отчёты.
- **Распределение данных с маскировкой**: Разделить рабочую книгу с конфиденциальной информацией на файлы с ограниченным набором данных.
- **Периодическое разделение отчётов**: Автоматически разделять сводные отчёты на еженедельные или ежедневные отчёты ежемесячно.
- **Мультиформатное распространение**: Разделить один файл Excel на несколько версий в различных форматах (PDF, CSV, JSON и др.) одновременно.
- **Разделение по шаблонам**: Разделить файлы данных на стандартные выходные файлы на основе предопределённых шаблонов.
- **Предобработка источника данных**: Разделить файл Excel на стандартный CSV-файл перед загрузкой данных в базу данных.
- **Подготовка данных для API**: Разделить большие наборы данных на более мелкие части, удобные для передачи через API.

## Почему стоит использовать API разделения электронной таблицы?

- **Удобен для разработчиков**: Aspose.Cells Cloud предоставляет SDK для множества языков программирования, что позволяет быстро разрабатывать приложения и предоставляет исчерпывающую документацию. По сравнению с созданием собственных решений для визуализации диаграмм, это значительно снижает объём разработки.
- **Снижение затрат на персонал**: Уменьшает потребность в специалистах, ответственных за объединение документов.
- **Оплата по факту использования**: Нет необходимости в начальных инвестициях; вы платите только за реально выполненные вызовы API.
- **Нулевые затраты на обслуживание**: Не требуется обслуживать серверы, обновлять ПО или решать проблемы совместимости.
- **Сохраняет сложное форматирование Excel** в универсально доступном формате PDF.
