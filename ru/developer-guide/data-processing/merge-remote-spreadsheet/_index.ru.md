Быстро объединяйте Excel-файлы, хранящиеся в облаке, с другими электронными таблицами с помощью Aspose.Cells Cloud API, а также задавайте формат выходных данных и место их хранения.

## API объединения удалённой электронной таблицы

Перед вызовом этой операции убедитесь, что у вас есть:

- Действительный **JWT-токен доступа** (см. руководство по аутентификации).
- Исходная рабочая книга и все файлы для объединения загружены в ваше облачное хранилище.
- Необходимые разрешения на чтение из исходной папки и запись в целевую папку.

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/{name}/merge/spreadsheet
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### Параметры запроса:

| Имя параметра     | Тип     | Путь/Строка запроса/Тело HTTP-запроса | Описание                                                                                                                               |
| :---------------- | :------ | :------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------- |
| name              | String  | Path                                   | Имя исходного файла рабочей книги, подлежащей объединению.                                                                             |
| mergedSpreadsheet | String  | Query                                  | Список имен файлов электронных таблиц для объединения в исходную рабочую книгу, разделённый запятыми.                                  |
| folder            | String  | Query                                  | Путь к папке в облачном хранилище, содержащей исходную рабочую книгу.                                                                  |
| outFormat         | String  | Query                                  | Желаемый формат выходного объединённого файла (например, `XLSX`, `PDF`, `CSV`).                                                       |
| mergeInOneSheet   | Boolean | Query                                  | Установите значение `true`, чтобы объединить все исходные данные в один рабочий лист; значение `false` создаёт отдельные рабочие листы для каждого файла. |
| storageName       | String  | Query                                  | _(Опционально)_ Имя облачного хранилища, в котором находится исходная рабочая книга. Если не указано, используется хранилище по умолчанию. |
| outPath           | String  | Query                                  | _(Опционально)_ Путь к целевой папке в облачном хранилище для сохранения объединённого файла. Если не указано, файл сохраняется в исходной папке. |
| outStorageName    | String  | Query                                  | Имя облачного хранилища для сохранения выходного файла.                                                                               |
| fontsLocation     | String  | Query                                  | _(Опционально)_ Пользовательский путь к папке с файлами шрифтов, используемыми при преобразовании в форматы изображений/PDF.            |
| region            | String  | Query                                  | _(Опционально)_ Локаль/регион для форматирования дат, чисел и валют в выходном файле (например, `en-US`, `de-DE`).                     |
| password          | String  | Query                                  | _(Опционально)_ Пароль, необходимый для открытия защищённой исходной рабочей книги.                                                    |

### Ответ

**Статус:** `200 OK`

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

Файл можно загрузить непосредственно из указанного места или сохранить по пути, заданному в параметре `outPath`.

**Детали успешного ответа**

| Код статуса | Content‑Type               | Описание                                           |
| ----------- | -------------------------- | -------------------------------------------------- |
| 200 OK      | `application/octet-stream` | Двоичный поток объединённого файла рабочей книги. |

**Коды HTTP-статусов**

| Код | Значение                | Описание                                                           |
| --- | ----------------------- | ------------------------------------------------------------------ |
| 200 | OK                      | Фильтр применён успешно; ответ содержит детали операции.          |
| 400 | Bad Request             | Отсутствуют или недопустимы параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized            | Недействительный или отсутствующий JWT-токен.                     |
| 413 | Payload Too Large       | Загруженный файл превышает лимит размера.                          |
| 500 | Internal Server Error   | Непредвиденная ошибка сервера.                                     |

## Где следует использовать API объединения удалённой электронной таблицы?

### Интеграция данных корпоративного уровня

- **Агрегация отчётов нескольких отделов** — объединение отдельных отчётов Excel, представленных отделами продаж, маркетинга, финансов и другими.
- **Сводная сводка данных по филиалам** — обобщение показателей эффективности каждого филиала по всему миру.
- **Консолидация данных партнёров** — объединение данных, предоставленных несколькими партнёрами, в одну рабочую книгу.

### Облачный рабочий процесс обработки документов

- **Обработка файлов в облачном хранилище** — прямое объединение Excel-файлов, хранящихся в AWS S3, Azure Blob или Google Cloud Storage.
- **Консолидация данных из нескольких источников** — объединение файлов из различных облачных местоположений в одну рабочую книгу.
- **Автоматизация конвейеров данных** — интеграция API в ETL-процессы для автоматического объединения файлов.

### Автоматизация управления документами

- **Консолидация по версиям** — объединение различных версий плана проекта или бюджетной книги.
- **Заполнение данных в шаблонах** — вставка файлов данных в стандартизированные шаблоны отчётов.
- **Регулярная генерация отчётов** — автоматизация еженедельных, ежемесячных и ежеквартальных сводных отчётов.

### Кроссплатформенное сотрудничество

- **Сотрудничество удалённых команд** — консолидация работы, представленной разрозненными членами команды.
- **Организация данных клиентов** — объединение заказов или отзывов от нескольких клиентов.
- **Сводка информации от поставщиков** — объединение коммерческих предложений или информационных данных от нескольких поставщиков.

## Почему стоит использовать API объединения удалённой электронной таблицы?

- **Удобный для разработчиков** — Aspose.Cells Cloud предоставляет SDK для множества языков программирования, сокращая время разработки и предлагая подробную документацию. По сравнению с созданием собственного решения это значительно снижает объём работ.
- **Снижение затрат на персонал** — уменьшает потребность в сотрудниках, занятых ручной консолидацией документов.
- **Платежи по факту использования** — отсутствие предварительных инвестиций; вы платите только за фактически выполненные вызовы API.
- **Отсутствие затрат на обслуживание** — отсутствие необходимости в обслуживании серверов, обновлении программного обеспечения и решениях проблем совместимости.
