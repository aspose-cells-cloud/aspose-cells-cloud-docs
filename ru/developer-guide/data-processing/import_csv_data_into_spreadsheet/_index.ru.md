## Импорт данных CSV в электронную таблицу в веб-сервисах Aspose.Cells Cloud

Импорт файла данных CSV в локальную электронную таблицу. Метод парсит CSV-файл, сопоставляет данные со структурой ячеек электронной таблицы и сохраняет файл локально. Поддерживаемые форматы электронных таблиц включают .xlsx и .ods.

### Конечная точка веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/import/data/csv
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификацию на основе JWT-токена</a>.

### Параметры запроса

| Имя параметра        | Тип    | Путь/Строка запроса/HTTP-тело | Описание                                                                                                                          |
|----------------------|--------|-------------------------------|-----------------------------------------------------------------------------------------------------------------------------------|
| datafile             | Файл   | FormData                      | Загрузка файла данных.                                                                                                            |
| Spreadsheet          | Файл   | FormData                      | Загрузка файла электронной таблицы.                                                                                               |
| worksheet            | Строка | Query                         | Лист, в который необходимо импортировать данные CSV. (обязательный)                                                               |
| startcell            | Строка | Query                         | Начальная позиция для импорта данных. (обязательный)                                                                              |
| insert               | Логический | Query                     | Управляет поведением вставки. true: вставить данные; false: перезаписать существующие данные. По умолчанию: true (необязательный) |
| convertNumericData   | Логический | Query                     | Преобразуется ли строка в текстовом файле в числовые данные. По умолчанию: true (необязательный)                                   |
| splitter             | Строка | Query                         | Разделитель, используемый для разделения полей CSV. По умолчанию: "," (необязательный)                                            |
| outPath              | Строка | Query                         | (Необязательный) Путь к папке, где хранится рабочая книга. По умолчанию — null.                                                  |
| outStorageName       | Строка | Query                         | Имя хранилища для выходного файла. (необязательный)                                                                               |
| fontsLocation        | Строка | Query                         | Использование пользовательских шрифтов. (необязательный)                                                                          |
| region               | Строка | Query                         | Настройка региона/языка электронной таблицы (например, `en-US`, `fr-FR`). Влияет на форматирование чисел, разбор дат и поведение, зависящее от региона. (необязательный) |
| password             | Строка | Query                         | Пароль для открытия файла электронной таблицы. (необязательный)                                                                   |

### **Ответ**

```json
{
  "file": "<двоичный поток результирующей электронной таблицы>"
}
```

**Коды состояния ответа**

| Код | Значение | Описание |
|-----|----------|----------|
| 200 | OK | Данные CSV успешно импортированы, возвращён результирующий файл электронной таблицы. |
| 400 | Bad Request | Неверные параметры запроса или некорректный URL. |
| 401 | Unauthorized | Аутентификация не удалась или учётные данные не были предоставлены. |
| 404 | Not Found | Исходный файл недоступен. |
| 413 | Payload Too Large | Загруженные файлы превышают допустимый размер. |
| 500 | Internal Server Error | В процессе получения данных произошла ошибка в электронной таблице. |

## Как использовать импорт данных CSV в электронную таблицу с помощью SDK

### Спецификация импорта данных CSV в электронную таблицу

[Спецификация API импорта данных CSV в электронную таблицу](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/DataProcessing/ImportCSVDataIntoSpreadsheet) определяет публично доступный программный интерфейс и позволяет выполнять взаимодействие по REST непосредственно из веб-браузера.

Вы можете использовать утилиту командной строки cURL для простого доступа к веб-сервисам Aspose.Cells. Следующий пример демонстрирует, как выполнить вызов облачного API с помощью cURL.

{< tabs tabTotal="2" tabID="1" tabName1="Запрос" tabName2="Ответ" >}

{< tab tabNum="1" >}

```bash
# Используйте HTTPS для безопасного соединения
curl -v "https://api.aspose.cloud/v4.0/cells/import/data/csv?worksheet=Sheet1&startcell=A1&insert=true&convertNumericData=true&splitter=,&outPath=outputFolder&outStorageName=MyStorage&fontsLocation=/custom/fonts&region=en-US&password=MyPassword" \
  -X PUT \
  -H "Content-Type: multipart/form-data" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer <jwt token>" \
  -F "datafile=@sample.csv" \
  -F "Spreadsheet=@workbook.xlsx"
```
