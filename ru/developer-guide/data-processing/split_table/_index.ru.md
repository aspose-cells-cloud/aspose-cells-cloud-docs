## Метод SplitTable веб-сервисов Aspose.Cells Cloud

Этот метод выполняет операцию разделения исходной таблицы путем группировки строк по уникальным значениям указанного столбца. Каждая группа данных (для каждого уникального значения разделения) обрабатывается как отдельная единица данных. Место экспорта определяется двумя ключевыми булевыми параметрами:
- Определяет структуру рабочей книги. Если `true`, каждая единица данных сохраняется в отдельный файл рабочей книги. Если `false`, каждая единица становится новым листом в текущей рабочей книге.
- Определяет упаковку вывода. При значении `true` и совместно с параметром `toNewWorkbook` = `true` метод создает несколько отдельных файлов и возвращает их в виде ZIP-архива. При значении `false` все данные объединяются в один файл (либо рабочая книга с несколькими листами, либо один файл в соответствии с другими настройками).

### Конечная точка веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/split/table
```

### **Безопасность и аутентификация**

Веб-API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### Параметры запроса

| Имя параметра   | Тип    | Путь/Строка запроса/Тело HTTP-запроса | Описание                                                                                                                                                                   |
|------------------|---------|-----------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Spreadsheet      | File    | FormData                    | Загрузка файла электронной таблицы.                                                                                                                                                      |
| worksheet        | String  | Query                       | Лист, содержащий таблицу.                                                                                                                                               |
| tableName        | String  | Query                       | Таблица данных, которую необходимо разделить.                                                                                                                                           |
| splitColumnName  | String  | Query                       | Имя столбца, по которому выполняется разделение.                                                                                                                                                      |
| saveSplitColumn  | Boolean | Query                       | Следует ли сохранять данные в столбце разделения.                                                                                                                                 |
| splitRowNumber   | Integer | Query                       | [TBD]                                                                                                                                                                          |
| toNewWorkbook    | Boolean | Query                       | Управление местом экспорта: true — создает новые файлы рабочих книг, содержащие разделённые данные; false — добавляет новый лист в текущую рабочую книгу.                              |
| toMultipleFiles  | Boolean | Query                       | true — экспортирует данные таблицы как **несколько отдельных файлов** (возвращается в виде ZIP-архива); false — сохраняет все данные в **одном файле** с несколькими листами. По умолчанию: false. |
| outPath          | String  | Query                       | (Необязательно) Путь к папке, где будет сохранена рабочая книга. По умолчанию: null.                                                                                                 |
| outStorageName   | String  | Query                       | Имя хранилища для выходного файла.                                                                                                                                                     |
| fontsLocation    | String  | Query                       | Использование пользовательских шрифтов.                                                                                                                                                              |
| region           | String  | Query                       | Региональные/языковые настройки электронной таблицы (например, `en-US`, `fr-FR`). Влияют на форматирование чисел, разбор дат и поведение, зависящее от локали.                                      |
| password         | String  | Query                       | Пароль для открытия файла электронной таблицы.                                                                                                                                   |

### Параметр тела запроса

| Имя параметра | Тип | Описание |
| -------------- | ---- | ----------- |
| Spreadsheet    | File | Загрузка файла электронной таблицы. |

### **Ответ**

```json
{
  "file": "двоичный поток (ZIP-архив или рабочая книга в зависимости от параметров)"
}
```

**Коды состояния ответа**

| Код | Значение | Описание |
|------|---------|-------------|
| 200  | OK      | Операция разделения завершена успешно. Ответ содержит сгенерированный файл (ZIP-архив или рабочую книгу). |
| 400  | Bad Request | Неверный URL или параметры запроса. |
| 401  | Unauthorized | Аутентификация не удалась, или учётные данные не были предоставлены. |
| 404  | Not Found | Исходный файл недоступен. |
| 413  | Payload Too Large | Размер полезной нагрузки запроса превышает допустимый предел. |
| 500  | Internal Server Error | В электронной таблице возникла ошибка при получении данных. |
