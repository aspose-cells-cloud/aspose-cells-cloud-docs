## Поиск недействующих ссылок в удалённом листе веб-сервисов Aspose.Cells Cloud

Этот метод выполняет поиск недействующих ссылок в листе файла электронной таблицы, хранящегося в облачном хранилище. Он сканирует все листы и ячейки для выявления гиперссылок, которые больше не указывают на корректные адреса, например, недоступные URL-адреса или отсутствующие внешние ссылки. Операция выполняется удалённо в облачной среде, без необходимости загрузки файла на локальную машину.

### Конечная точка веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/{name}/worksheets/{worksheet}/search/broken-links
```

### **Безопасность и аутентификация**

Веб-API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### Параметры запроса

| Имя параметра | Тип | Путь/Строка запроса/Тело HTTP-запроса | Описание |
|----------------|------|---------------------------------------|----------|
| name | string | Path | Имя файла рабочей книги, в котором следует выполнить поиск. |
| worksheet | string | Path | Указать лист для поиска. |
| folder | string | Query | Путь к папке, где хранится рабочая книга. (необязательно) |
| storageName | string | Query | (Необязательно) Имя хранилища при использовании пользовательского облачного хранилища. Если не указано, используется хранилище по умолчанию. |
| region | string | Query | Региональные/языковые настройки электронной таблицы (например, `en-US`, `fr-FR`). Влияют на форматирование чисел, разбор дат и поведение, зависящее от локали. |
| password | string | Query | Пароль для открытия файла электронной таблицы. |

### Параметр тела запроса

| Имя параметра | Тип | Описание |
| -------------- | ---- | ----------- |
| — | — | Для этой операции тело запроса не требуется. |

### **Ответ**

```json
{
  "Links": [
    {
      "SheetName": "Sheet1",
      "CellName": "A1",
      "Url": "http://invalid.example.com"
    }
  ],
  "Count": 1
}
```

**Коды состояния ответа**

| Код | Значение | Описание |
|------|---------|----------|
| 200 | OK | Список недействующих ссылок успешно получен. |
| 400 | Bad Request | Некорректные параметры запроса или неправильный формат URL. |
| 401 | Unauthorized | Аутентификация не удалась, или учётные данные не предоставлены. |
| 404 | Not Found | Исходный файл недоступен. |
| 413 | Payload Too Large | Размер сущности запроса превышает допустимый предел. |
| 500 | Internal Server Error | При получении данных электронной таблицы возникла ошибка. |
