## **Поиск битых ссылок в удалённом диапазоне — API**

Автоматически обнаруживайте битые ссылки в данных диапазона файлов Excel, хранящихся в облачном хранилище. Наш API сканирует указанные диапазоны на наличие битых внешних ссылок, некорректных формул и отсутствующих источников данных. Поддерживает удалённую аудиторскую проверку электронных таблиц, автоматизированные проверки качества и интеграцию с поставщиками облачных хранилищ. RESTful API для автоматизации корпоративных рабочих процессов.


### **Веб-API**

```http
PUT https://api.aspose.cloud/v4.0/cells/{name}/worksheets/{worksheet}/ranges/{cellArea}/search/broken-links
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации по токену JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### Параметры запроса

| Имя параметра | Тип   | Расположение | Описание                                                                                                                                                          |
|---------------|-------|-------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| name          | String| Path        | **Обязательный.** Имя файла рабочей книги Excel (например, `financial_report.xlsx`), хранящегося в облачном хранилище и подлежащего сканированию на наличие битых ссылок. |
| worksheet     | String| Path        | **Обязательный.** Имя конкретного листа (например, `Sheet1`, `Q4_Data`) внутри рабочей книги, в котором следует выполнить поиск битых ссылок.                      |
| cellArea      | String| Path        | **Обязательный.** Адрес целевого диапазона ячеек (например, `A1:F100`) в указанном листе, подлежащего сканированию на наличие битых внешних ссылок, формул или ссылок.|
| folder        | String| Query       | **Необязательный.** Путь к каталогу в вашем облачном хранилище, где расположен целевой файл рабочей книги. Если не указан, подразумевается корневой каталог.         |
| storageName   | String| Query       | **Необязательный.** Имя настроенного облачного сервиса хранения (например, `DropboxBusiness`, `S3Bucket`). Если не указан, используется хранилище по умолчанию.   |
| region        | String| Query       | **Необязательный.** Параметры локали (например, `en-GB`, `de-DE`) для интерпретации регионально-специфичных данных при сканировании.                              |
| password      | String| Query       | **Необязательный.** Пароль расшифровки, необходимый для доступа к защищённому паролем файлу рабочей книги. Оставьте пустым, если файл не зашифрован.               |

**Пример тела запроса**

```json
{
  "name": "financial_report.xlsx",
  "worksheet": "Sheet1",
  "cellArea": "A1:F100",
  "folder": "reports/2024",
  "storageName": "MyDropbox",
  "region": "en-US",
  "password": ""
}
```

### Ответ

```json
{
  "Name": "BrokenLinksResponse",
  "Type": "Class",
  "ParentName": "CellsCloudResponse",
  "Properties": [
    {
      "Name": "BrokenLinks",
      "DataType": {
        "Identifier": "Container",
        "Reference": "BrokenLink",
        "ElementDataType": {
          "Identifier": "Class",
          "Reference": "BrokenLink"
        }
      }
    },
    {
      "Name": "Code",
      "DataType": {
        "Identifier": "Integer"
      }
    },
    {
      "Name": "Status",
      "DataType": {
        "Identifier": "String"
      }
    }
  ]
}
```

Коллекция `BrokenLinks` содержит объекты типа **BrokenLink**. Каждый объект предоставляет следующие свойства:

- **CellName** — Адрес ячейки, содержащей битую ссылку (например, `B12`).
- **LinkType** — Тип сломанной ссылки (например, `ExternalReference`, `Formula`).
- **ErrorMessage** — Описание причины, по которой ссылка считается битой.

**Примечание**: API подлежит ограничениям по частоте запросов. Подробности см. на странице [Тарифы и ограничения скорости](https://www.aspose.cloud/pricing).

### Коды ошибок

- **400 Bad Request** — Некорректный URI API Aspose.Cells Cloud.
- **401 Unauthorized** — Неверный токен доступа, client ID или client secret.
- **404 Not Found** — Файл электронной таблицы недоступен.
- **500 Server Error** — При получении данных для расчётов возникла аномалия в электронной таблице.

## Где следует использовать поиск битых ссылок в диапазоне электронной таблицы?

- **Регулярная проверка крупных финансовых моделей** — Перед выпуском ежемесячных или ежеквартальных отчётов автоматически сканируйте ключевые расчётные области (например, `Dashboard!B5:K50`), содержащие множество внешних ссылок на данные, чтобы убедиться, что все ссылки указывают на действительные исходные файлы.
- **Интеграция данных при слияниях и поглощениях** — После объединения нескольких файлов электронных таблиц, представляющих бизнес-подразделения, просканируйте лист «Обзор» для выявления ссылок, ставших недействительными из-за изменения путей к файлам или проблем с правами доступа.
- **Подготовка пакетов данных для инвесторов** — Перед финализацией презентационных материалов, содержащих диаграммы и таблицы, связанные с внешними базами данных или источниками рыночных данных, проверьте действительность всех ссылок.

## Почему следует использовать поиск битых ссылок в диапазоне электронной таблицы?

- **Удобен для разработчиков** — Aspose.Cells Cloud предлагает SDK-библиотеки на множестве языков программирования, что обеспечивает быструю разработку при полной документации. По сравнению с созданием собственного решения, это значительно снижает трудозатраты.
- **Снижение трудозатрат** — Исключает необходимость выделения персонала для ручной консолидации документов.
- **Платёж по факту использования** — Никаких предварительных инвестиций; вы платите только за фактически выполненные вызовы API.
- **Отсутствие затрат на обслуживание** — Нет серверов для обслуживания, обновлений ПО и проблем совместимости.
- **Сохранение сложного форматирования Excel** — Результаты можно экспортировать в универсальный формат PDF без потери стилей.
