## Поиск всех текстовых элементов в электронной таблице с помощью облачных веб-сервисов Aspose.Cells

Этот метод выполняет поиск всех текстовых элементов в локальном файле электронной таблицы. Он поддерживает поиск по всем листам и ячейкам книги, выявляя вхождения искомого текста. Операция выполняется на стороне облака, при этом не требуется облачное хранилище. Убедитесь, что у вас есть необходимые права на чтение исходного файла. Если исходный файл недоступен либо во время поиска возникнет ошибка (например, неподдерживаемый формат файла), будет сгенерировано соответствующее исключение. В зависимости от деталей реализации метод может возвращать местоположения найденных совпадений (например, имя листа, координаты ячейки).

### Конечная точка веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/search/content/all-textitems
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### Параметры запроса

| Имя параметра | Тип | Путь/Строка запроса/HTTP-тело | Описание |
|----------------|------|-----------------------------|-------------|
| Spreadsheet | File | FormData | Загрузка файла электронной таблицы. |
| region | String | Query | Регион/языковые настройки электронной таблицы (например, `en-US`, `fr-FR`). Влияет на форматирование чисел, разбор дат и поведение, зависящее от локали. |
| password | String | Query | Пароль для открытия файла электронной таблицы. |

### **Ответ**

```json
{
  "SearchResults": [
    {
      "SheetName": "Sheet1",
      "CellName": "A1",
      "Text": "Sample text"
    }
    // ... дополнительные элементы
  ],
  "TotalCount": 42
}
```

**Коды состояния ответа**

| Код | Значение | Описание |
|------|---------|-------------|
| 200 | OK | Запрос успешно выполнен; ответ содержит все найденные текстовые элементы. |
| 400 | Bad Request | Неверный URL или некорректные параметры запроса. |
| 401 | Unauthorized | Аутентификация не удалась или учётные данные не предоставлены. |
| 404 | Not Found | Исходный файл недоступен. |
| 413 | Payload Too Large | Загруженный файл превышает допустимый размер. |
| 500 | Internal Server Error | При получении данных из электронной таблицы возникла ошибка. |

### Спецификация API поиска всех текстовых элементов в электронной таблице

Спецификация [API поиска всех текстовых элементов в электронной таблице](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/{SearchController}/{SearchSpreadsheetAllTextItems}) определяет публично доступное программное интерфейсное описание и позволяет выполнять взаимодействие по REST непосредственно из веб-браузера.

Для простого доступа к облачным сервисам Aspose.Cells вы можете использовать утилиту командной строки cURL. В следующем примере показано, как выполнить вызов облачного API с помощью cURL.

```bash
# Используйте HTTPS для защищённого соединения
curl -v "https://api.aspose.cloud/v4.0/cells/search/content/all-textitems?region=en-US&password=myPassword" \
  -X PUT \
  -H "Content-Type: multipart/form-data" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer <jwt token>" \
  -F "Spreadsheet=@sample.xlsx"
```
