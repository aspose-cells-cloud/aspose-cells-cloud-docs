### **API поиска содержимого в удаленном табличном файле**

Программно ищите конкретный текст в любом табличном файле Excel с помощью API Aspose.Cells Cloud. Находите текст, числа или формулы в файлах, хранящихся в облачном хранилище. Этот REST-интерфейс позволяет автоматизировать обнаружение данных, анализ содержимого и выполнение процедур аудита табличных файлов.

### **Веб-API**

```bash
PUT https://api.aspose.cloud/v4.0/cells/{name}/search/content
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### **Параметры запроса:**

| Имя параметра | Тип    | Путь / Строка запроса / HTTP-тело | Описание                                                                                                                                                      |
| :------------ | :------ | :------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| name          | String  | Путь                       | **Обязательный**. Имя файла рабочей книги Excel (с расширением), в которой будет выполняться поиск текста, например `sales_data.xlsx`.                         |
| searchText    | String  | Строка запроса             | **Обязательный**. Точная строка, число или фрагмент содержимого для поиска по всей рабочей книге или листам.                                                 |
| ignoringCase  | Boolean | Строка запроса             | **Необязательный**. Определяет чувствительность к регистру. Установите значение `true` для регистронезависимого поиска (например, «Отчет» соответствует «ОТЧЕТ»); по умолчанию `false`. |
| folder        | String  | Строка запроса             | **Необязательный**. Путь к каталогу в вашем облачном хранилище, где находится целевая рабочая книга. Если не указано, используется корневая папка.            |
| storageName   | String  | Строка запроса             | **Необязательный**. Идентификатор настраиваемой конфигурации облачного хранилища. Если не указан, используется хранилище по умолчанию, связанное с учетной записью. |
| region        | String  | Строка запроса             | **Необязательный**. Языковой стандарт (например, `es-ES`), применяемый во время поиска, может влиять на нормализацию текста или правила сортировки.              |
| password      | String  | Строка запроса             | **Необязательный**. Пароль расшифровки, необходимый для доступа к защищенному паролем файлу Excel. Пропустите этот параметр, если файл не зашифрован.                      |

**Глоссарий**

- **searchText** – Точная строка для поиска; может быть частичным совпадением.
- **ignoringCase** – `true` делает поиск регистронезависимым; `false` включает учет регистра.
- **folder** – Путь к каталогу, содержащему рабочую книгу.
- **storageName** – Идентификатор настраиваемой конфигурации хранилища.
- **region** – Код языкового стандарта, влияющий на правила сравнения текста.
- **password** – Пароль расшифровки для защищенных рабочих книг.

### **Ответ**

```json
{
  "Code": 200,
  "Status": "OK",
  "TextItems": [
    {
      "Filename": "string",
      "Worksheet": "string",
      "Position": "string",
      "Content": "string"
    }
  ]
}
```

Ответ содержит список ячеек (`CellName`), в которых найден искомый текст, а также имя листа и совпадающий текст. Если совпадений не найдено, массив `TextItems` пуст, но запрос всё равно возвращает HTTP 200 OK.

### Коды ошибок

- **400 Bad Request** – Неверный URI API Aspose.Cells Cloud.  
  ```json
  {"code":400,"message":"Invalid request URI"}
  ```
- **401 Unauthorized** – Неверный токен доступа, идентификатор клиента или секрет клиента.  
  ```json
  {"code":401,"message":"Invalid access token"}
  ```
- **404 Not Found** – Файл табличного файла недоступен.  
  ```json
  {"code":404,"message":"File not found"}
  ```
- **500 Server Error** – Непредвиденное состояние, препятствующее завершению запроса API.  
  ```json
  {"code":500,"message":"Internal server error"}
  ```

## Где следует использовать API поиска содержимого в табличных файлах?

- **Полная проверка соответствия рабочей книги** – Быстрое сканирование всего файла Excel для выявления всех конфиденциальных терминов (например, «Конфиденциальное положение», «Внутренние данные») при проверках информационной безопасности и соответствия корпоративным требованиям.
- **Запрос взаимосвязи данных между листами** – Когда информация о проекте разбросана по нескольким листам, выполните поиск конкретного номера проекта или имени клиента и мгновенно найдите всю связанную информацию.
- **Пакетная проверка содержимого шаблонов** – После автоматической генерации отчетов выполните пакетное сканирование нескольких файлов Excel для подтверждения того, что все заранее заданные заполнители (например, `{{Date}}`) заменены корректно, обеспечивая полноту и точность отчетов.
- **Архивирование и майнинг исторических данных** – Анализ устаревших файлов, поиск специфических кодов событий или бизнес-терминов, быстрое понимание исторической бизнес-логики для «археологии» данных.

## Почему стоит использовать API поиска содержимого в табличных файлах?

- **Удобен для разработчиков** – Aspose.Cells Cloud предлагает библиотеки SDK на множестве языков, что позволяет быстро разрабатывать решения при наличии подробной документации. По сравнению с созданием собственных решений это значительно сокращает усилия по разработке.
- **Снижение трудозатрат** – Автоматизирует повторяющиеся задачи поиска, освобождая разработчиков от ручной выгрузки данных.
- **Оплата по факту использования** – Никаких предварительных инвестиций; вы платите только за фактически выполненные вызовы API.
- **Не требует обслуживания** – Aspose управляет серверами, обновлениями и совместимостью, позволяя вам сосредоточиться на логике приложения.
- **Сохраняет сложное форматирование Excel** – Результаты можно экспортировать в универсальный формат PDF с сохранением исходного оформления.
