Замените указанный текст в конкретном рабочем листе удалённых файлов Excel. Эффективно обновляйте содержимое целевых листов электронных таблиц с помощью API Aspose.Cells для поиска и замены — для точной редактировки рабочих листов.

## **API замены содержимого удалённого рабочего листа**

### **Веб-API**

```http
PUT https://api.aspose.cloud/v4.0/cells/{name}/worksheets/{worksheet}/replace/content
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе токена JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### **Параметры запроса**

| Имя параметра | Тип    | Путь / Строка запроса / HTTPBody | Описание                                                                                                                                                       |
| :------------ | :----- | :----------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| name          | String | Path                           | Имя файла книги, хранящегося в облачном хранилище и подлежащего изменению (например, `"sales_report.xlsx"`, `"budget_2024.xls"`).                              |
| worksheet     | String | Path                           | Имя конкретного рабочего листа, в котором будет выполнен поиск и замена (например, `"Q1_Sales"`, `"Sheet1"`).                                                  |
| searchText    | String | Query                          | Искомая текстовая строка в указанном рабочем листе. Поиск применяется ко всем ячейкам рабочего листа, если не заданы дополнительные ограничения.                |
| replaceText   | String | Query                          | Текстовая строка, которая заменит все вхождения `searchText`, найденные в указанном рабочем листе.                                                             |
| folder        | String | Query                          | Путь к папке в облачном хранилище, где расположен исходный файл книги (например, `"/reports/monthly/"`, `"/finance/"`).                                        |
| storageName   | String | Query                          | _(Опционально)_ Имя пользовательского облачного хранилища (например, `"CorporateS3"`, `"AzureArchive"`). При отсутствии используется хранилище по умолчанию.  |
| region        | String | Query                          | _(Опционально)_ Устанавливает локаль для обработки текста, что может повлиять на кодировку символов и поведение поиска по языку в рабочем листе (например, `"en-GB"`, `"es-ES"`). |
| password      | String | Query                          | _(Опционально)_ Если книга защищена паролем, укажите пароль для открытия и редактирования файла.                                                               |

**Пример запроса (cURL)**  

```bash
curl -X PUT "https://api.aspose.cloud/v4.0/cells/sales_report.xlsx/worksheets/Sheet1/replace/content?searchText=OldValue&replaceText=NewValue&folder=/reports" \
     -H "Authorization: Bearer {access_token}"
```

### **Ответ**

```json
{
  "Code": 200,
  "Status": "OK"
}
```

### **Коды ошибок**

| Код | Описание                                 | Когда возникает                                                  |
|-----|------------------------------------------|------------------------------------------------------------------|
| 400 | Bad Request (Неверный запрос)            | Неверный URI запроса или отсутствуют обязательные параметры.    |
| 401 | Unauthorized (Неавторизовано)            | Отсутствует, недействителен токен доступа или неверны учётные данные клиента. |
| 404 | Not Found (Не найдено)                   | Указанная книга или рабочий лист не найдены.                     |
| 500 | Internal Server Error (Внутренняя ошибка сервера) | Во время обработки запроса произошла непредвиденная ошибка.     |

## Где следует использовать API замены содержимого рабочего листа в облачной электронной таблице?

- **Пакетное обновление файлов в облаке**: Изменение содержимого множества файлов Excel, хранящихся в облачных хранилищах, таких как AWS S3 и Azure Blob.
- **Динамическое заполнение облачных шаблонов**: Пакетное заполнение шаблонов отчётов, хранящихся в облаке, динамическими данными.
- **Синхронизация файлов между регионами**: Обеспечение единообразия содержимого файлов Excel в облачных хранилищах в различных географических регионах.

## Почему стоит использовать API замены содержимого рабочего листа в облачной электронной таблице?

- **Удобный для разработчиков**: Aspose.Cells Cloud предоставляет SDK на множестве языков программирования, что ускоряет разработку, и сопровождается подробной документацией. По сравнению с созданием собственных решений для рендеринга диаграмм, это значительно снижает объём рабочей нагрузки.
- **Снижение затрат на персонал**: Сокращает потребность в сотрудниках, занимающихся консолидацией документов.
- **Оплата по факту использования**: Не требует начальных вложений; вы платите только за фактически выполненные вызовы API.
- **Отсутствие затрат на обслуживание**: Не требуется поддерживать серверы, обновлять программное обеспечение или решать проблемы совместимости.
