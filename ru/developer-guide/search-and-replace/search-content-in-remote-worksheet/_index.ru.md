## **Поиск содержимого в удалённом листе**

Программно ищите конкретный текст в любом листе Excel с помощью Aspose.Cells Cloud API. Сервис может находить текст, числа или формулы в файлах, хранящихся в облачном хранилище, что позволяет автоматизировать процессы обнаружения данных, анализа контента и аудита электронных таблиц.

### **Web API**

```curl
PUT https://api.aspose.cloud/v4.0/cells/{name}/worksheets/{worksheet}/search/content
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API безопасны и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### **Параметры запроса**

| Имя параметра | Тип    | Путь/Строка запроса/HTTP-тело | Описание                                                                                       |
|---------------|--------|------------------------------|-------------------------------------------------------------------------------------------------|
| name          | String | Путь                         | **Обязательный.** Имя целевой рабочей книги (например, `annual_report.xlsx`).                  |
| worksheet     | String | Путь                         | **Обязательный.** Имя листа в рабочей книге, в котором выполняется поиск.                      |
| searchText    | String | Строка запроса               | **Обязательный.** Точная строка или число для поиска.                                          |
| ignoreCase    | Boolean| Строка запроса               | **Необязательный.** Если `true`, поиск выполняется без учёта регистра. По умолчанию — `false`. |
| folder        | String | Строка запроса               | **Необязательный.** Путь к папке, содержащей рабочую книгу. Если не указан, используется корневая папка. |
| storageName   | String | Строка запроса               | **Необязательный.** Имя настраиваемого облачного хранилища. Если не указано, используется хранилище по умолчанию. |
| region        | String | Строка запроса               | **Необязательный.** Параметр локали (например, `ja-JP`), который может повлиять на сравнение текста. |
| password      | String | Строка запроса               | **Необязательный.** Пароль для защищённой рабочей книги. Пропустите, если файл не зашифрован.   |

### **Ответ**

```json
{
  "textItems": [
    {
      "cellName": "A1",
      "text": "Итого",
      "occurrences": 1
    },
    {
      "cellName": "B5",
      "text": "Итого",
      "occurrences": 2
    }
  ],
  "code": 200,
  "status": "OK"
}
```

- **textItems** — Массив найденных совпадений. Каждый элемент содержит адрес ячейки (`cellName`), найденную строку (`text`) и количество её вхождений в данной ячейке (`occurrences`).
- **code** — HTTP-код статуса, возвращаемый сервисом.
- **status** — Текстовое описание результата.

### **Коды ошибок**

- **400 Bad Request** — Неверный URI API или некорректные параметры.
- **401 Unauthorized** — Отсутствует или недействителен OAuth 2.0-токен.
- **404 Not Found** — Рабочую книгу или лист невозможно найти.
- **500 Server Error** — Во время обработки запроса возникло непредвиденное состояние.

## Где следует использовать поиск содержимого в листе электронной таблицы?

- **Аудит соответствия требованиям к рабочей книге:** Быстро находите конфиденциальные термины (например, «Конфиденциально») по всему файлу.
- **Связывание данных между листами:** Найдите номер проекта или имя клиента, встречающееся на нескольких листах.
- **Проверка шаблонов:** После генерации отчётов убедитесь, что заполнители, например `{{Date}}`, были заменены.
- **Майнинг исторических данных:** Ищите конкретные коды событий в устаревших электронных таблицах, чтобы понять прошлую бизнес-логику.

## Почему следует использовать поиск содержимого в листе электронной таблицы?

- **Удобно для разработчиков:** SDK для множества языков ускоряют разработку и полностью задокументированы.
- **Снижение трудозатрат:** Уменьшает потребность в персонале, занятом ручной сводке данных.
- **Платёж по факту использования:** Оплачиваете только те вызовы API, которые реально выполняете.
- **Отсутствие необходимости в обслуживании:** Нет серверов для управления, обновлений ПО и проблем совместимости.
- **Сохранение сложного форматирования Excel** при экспорте результатов в PDF или другие форматы.
