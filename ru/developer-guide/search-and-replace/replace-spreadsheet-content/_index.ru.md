Замените указанный текст в локальных файлах электронных таблиц Excel без загрузки в облако. Эффективно обновляйте содержимое рабочих книг с помощью API поиска и замены Aspose.Cells Cloud для работы в автономном режиме.

## **API замены содержимого электронной таблицы**

### **Веб-API**

```http
PUT https://api.aspose.cloud/v4.0/cells/replace/content
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе токена JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### **Параметры запроса:**

| Имя параметра | Тип   | Путь/Строка запроса/HTTPBody | Описание                                                                                                                                                                                           |
| :------------- | :----- | :------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet    | File   | FormData                   | Локальный файл электронной таблицы для обработки. Поддерживаемые форматы: XLSX, XLS, ODS, CSV и др.                                                                                                       |
| searchText     | String | Query                      | Строка текста, которую необходимо найти в указанном листе и диапазоне ячеек.                                                                                                                           |
| replaceText    | String | Query                      | Строка текста, которая заменит все вхождения `searchText` в указанном диапазоне.                                                                                                         |
| worksheet      | String | Query                      | _(Опционально)_ Имя листа, в котором будет выполнена операция поиска и замены. Если опущено, операция применяется к первому листу.                                              |
| cellArea       | String | Query                      | _(Опционально)_ Конкретный диапазон ячеек (например, `"A1:D20"`, `"B5:F15"`), в котором будет происходить поиск и замена текста. Если опущено, операция применяется ко всем используемым ячейкам указанного листа. |
| region         | String | Query                      | _(Опционально)_ Задает локаль для обработки текста, что может повлиять на чувствительность к регистру и кодировку символов при поиске (например, `"en-US"`, `"fr-FR"`).                                           |
| password       | String | Query                      | _(Опционально)_ Если загруженная электронная таблица защищена паролем, укажите пароль для открытия и обработки файла.                                                                                    |

### **Ответ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream",
      "Name": "file"
    }
  }
]
```

Ответ представляет собой бинарный поток, содержащий обновленную рабочую книгу. Сохраните его с соответствующим расширением файла (например, `.xlsx`).

### **Коды ошибок**

- **400 Bad Request** – Неверный URI API Aspose.Cells Cloud или некорректные параметры запроса.
- **401 Unauthorized** – Неверный или отсутствующий токен доступа; получите новый токен.
- **404 Not Found** – Файл электронной таблицы недоступен или указанный лист не существует.
- **500 Server Error** – При обработке электронной таблицы возникла внутренняя ошибка; обратитесь в службу поддержки, если проблема сохраняется.

## Где следует использовать API замены содержимого электронной таблицы?

- **Пакетная обработка локальных файлов Excel** – Автоматизируйте поиск и замену во множестве рабочих книг, хранящихся локально.
- **Локальные конвейеры обработки данных** – Интегрируйте API в запланированные задачи для изменения отчётов перед их архивированием или распространением.
- **Локальная генерация отчётов** – Динамически вставляйте значения в шаблонные рабочие книги без их загрузки в облако.

## Почему стоит использовать API замены содержимого электронной таблицы?

- **Дружествен для разработчиков** – Aspose.Cells Cloud предоставляет SDK на множестве языков программирования, что позволяет быстро разрабатывать решения и обеспечивает подробную документацию. По сравнению с созданием собственных решений, это значительно снижает усилия по разработке.
- **Снижение трудозатрат** – Уменьшает потребность в персонале, занятом ручной обработке и консолидации документов.
- **Оплата по факту использования** – Не требуется начальных инвестиций; вы платите только за фактически выполненные вызовы API.
- **Нулевые расходы на обслуживание** – Не требуется поддерживать серверы, обновлять программное обеспечение или заботиться о совместимости.
- **Сохранение сложного форматирования Excel** – Исходное форматирование, формулы и диаграммы рабочей книги сохраняются после замены.
