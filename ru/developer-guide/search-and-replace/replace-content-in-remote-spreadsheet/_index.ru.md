Выполните пакетную замену текста в удаленных файлах Excel, хранящихся в облаке. Найдите и обновите конкретные текстовые строки эффективно с помощью API поиска и замены Aspose.Cells Cloud для облачных электронных таблиц.


## **Замена содержимого в удаленной электронной таблице через API**

### **Web API**

```http
PUT https://api.aspose.cloud/v4.0/cells/{name}/replace/content
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### Параметры запроса

| Имя параметра   | Тип    | Расположение | Описание                                                                                                                                                   |
|-----------------|--------|-------------|------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **name**        | String | Path        | Имя файла рабочей книги, хранящегося в облачном хранилище и подлежащего изменению (например, `"report.xlsx"`).                                             |
| **searchText**  | String | Query       | Строка для поиска во всей рабочей книге. Поиск регистрозависимый и применяется ко всем рабочим листам, если не ограничен другими параметрами.               |
| **replaceText** | String | Query       | Строка, которая заменит каждое вхождение `searchText`.                                                                                                     |
| **folder**      | String | Query       | Путь к папке облачного хранилища, содержащей исходную рабочую книгу (например, `"/documents/quarterly/"`).                                                |
| **storageName** | String | Query       | _(Опционально)_ Имя пользовательского облачного хранилища (например, `"MyS3Bucket"`). Если не указано, используется хранилище по умолчанию, настроенное для аккаунта. |
| **region**      | String | Query       | _(Опционально)_ Идентификатор региона, который может влиять на кодировку символов и поведение поиска с учетом языка (например, `"en-US"`).                  |
| **password**    | String | Query       | _(Опционально)_ Пароль для открытия защищенной рабочей книги.                                                                                             |

### Ответ

Типичный успешный ответ возвращает состояние операции и количество выполненных замен:

```json
{
  "Code": 200,
  "Status": "OK"
}
```

### Коды ошибок

- **400 Bad Request** — Неверный URI API Aspose.Cells Cloud.
- **401 Unauthorized** — Отсутствует или недействителен OAuth 2.0-токен доступа.
- **404 Not Found** — Указанный файл электронной таблицы не может быть найден.
- **500 Server Error** — При обработке запроса возникла непредвиденная проблема на стороне сервера.

## Когда следует использовать API замены содержимого в удаленной электронной таблице?

- **Пакетное обновление файлов в облаке** — Изменение содержимого нескольких файлов Excel, хранящихся в облачных хранилищах, таких как AWS S3 или Azure Blob.
- **Динамическое заполнение облачных шаблонов** — Заполнение шаблонов отчетов, хранящихся в облаке, актуальными данными.
- **Синхронизация файлов между регионами** — Обеспечение согласованности файлов Excel между различными географическими регионами хранения.

## Почему использовать API замены содержимого в удаленной электронной таблице?

- **Удобно для разработчиков** — Aspose.Cells Cloud предоставляет SDK-библиотеки для множества языков программирования, что сокращает усилия по разработке по сравнению с созданием собственного решения.
- **Снижение трудозатрат** — Исключает необходимость в штатных сотрудниках для ручной сводки документов.
- **Оплата по факту использования** — Нет необходимости в предварительных инвестициях; вы платите только за API-вызовы, которые фактически совершаете.
- **Нулевые затраты на обслуживание** — Нет серверов для управления, обновлений программного обеспечения и проблем совместимости.
- **Сохранение всех форматов ячеек, формул и диаграмм** — Операция сохраняет исходное оформление и расчеты рабочей книги после замены текста.
