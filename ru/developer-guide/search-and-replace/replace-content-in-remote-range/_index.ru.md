Выполняйте массовую замену текста в облачных файлах Excel, хранящихся в облаке. Эффективно находите и обновляйте конкретные текстовые строки в выбранных диапазонах с помощью API поиска и замены Aspose.Cells Cloud.

## **Замена содержимого в удаленном диапазоне через API**

### Web API

```
PUT https://api.aspose.cloud/v4.0/cells/{name}/worksheets/{worksheet}/ranges/{cellArea}/replace/content
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### **Параметры запроса**

| Имя параметра | Тип   | Путь/Строка запроса/HTTP-тело | Описание                                                                                                                                               |
| :------------ | :---- | :--------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------- |
| name          | String | Путь                         | Имя файла рабочей книги, хранящегося в облачном хранилище и подлежащего изменению (например, `"report.xlsx"`).                                         |
| searchText    | String | Строка запроса               | Искомая текстовая строка в указанном листе и диапазоне ячеек. Поддерживает точное совпадение текста.                                                   |
| replaceText   | String | Строка запроса               | Текстовая строка, которая заменит все вхождения `searchText` в заданном диапазоне.                                                                    |
| worksheet     | String | Путь                         | Имя листа, в котором будет выполнена операция поиска и замены.                                                                                        |
| cellArea      | String | Путь                         | Конкретный диапазон ячеек (например, `"A1:D20"`), в котором будет выполняться поиск и замена текста.                                                  |
| folder        | String | Строка запроса               | Путь к папке облачного хранилища, где расположен исходный файл рабочей книги.                                                                          |
| storageName   | String | Строка запроса               | _(Необязательно)_ Имя облачного хранилища, где находится рабочая книга. Если не указано, используется хранилище по умолчанию.                         |
| region        | String | Строка запроса               | _(Необязательно)_ Задает локаль для обработки текста, что может повлиять на регистрозависимость и кодировку символов при поиске (например, `"en-US"`, `"tr-TR"`). |
| password      | String | Строка запроса               | _(Необязательно)_ Если файл рабочей книги защищен паролем, укажите его для открытия и редактирования файла.                                           |

### **Ответ**

```json
{
  "Name": "CellsCloudResponse",
  "Type": "Class",
  "Properties": [
    {
      "Name": "Code",
      "DataType": {
        "Identifier": "Integer"
      }
    },
    {
      "Name": "Status",
      "DataType": {

      }
    }
  ]

```

При успешном вызове возвращается следующий конкретный JSON-ответ:

```json
{
  "Code": 200,
  "Status": "OK"
}
```


### Коды ошибок

| Код | Сообщение       | Когда возникает                                          |
| --- | --------------- | -------------------------------------------------------- |
| 400 | Bad Request     | Неверный URI запроса или параметры.                      |
| 401 | Unauthorized    | Отсутствует или недействителен токен аутентификации.    |
| 404 | Not Found       | Указанный файл рабочей книги не найден или недоступен.  |
| 500 | Server Error    | Внутренняя ошибка сервера при обработке рабочей книги.  |

## Где следует использовать API замены содержимого диапазона в удаленной электронной таблице?

- **Пакетное обновление файлов в облаке**: Изменение содержимого нескольких файлов Excel, хранящихся в облачных хранилищах, таких как AWS S3 и Azure Blob.
- **Динамическое заполнение облачных шаблонов**: Пакетное заполнение динамическими данными шаблонов отчетов, хранящихся в облаке.
- **Синхронизация файлов между регионами**: Обеспечение согласованности содержимого файлов Excel в облачных хранилищах в различных географических регионах.

## Почему следует использовать API замены содержимого диапазона в удаленной электронной таблице?

- **Удобно для разработчиков**: Aspose.Cells Cloud предоставляет SDK на множестве языков программирования, что обеспечивает быструю разработку и подробную документацию. По сравнению с созданием собственных решений это значительно снижает трудозатраты.
- **Снижение затрат на персонал**: Уменьшает потребность в специалистах, отвечающих за консолидацию документов.
- **Оплата по факту использования**: Нет необходимости в начальных инвестициях; вы платите только за фактически выполненные вызовы API.
- **Отсутствие затрат на обслуживание**: Не требуется поддерживать серверы, обновлять ПО или решать проблемы совместимости.
- **Сохранение сложного форматирования Excel** в универсально доступном формате PDF.
