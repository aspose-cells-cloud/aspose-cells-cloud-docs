Автоматизируйте защиту Excel паролем в масштабе с помощью нашего API для разработчиков — программно применяйте пароли открытия и изменения. Идеально подходит для корпоративных рабочих процессов и совместим с форматами .xlsx и устаревшими форматами. Ознакомьтесь с документацией и начните бесплатную интеграцию уже сегодня.

## **API защиты электронной таблицы**

### **Web API**

```http
PUT https://api.aspose.cloud/v4.0/cells/protection/spreadsheet
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### **Параметры запроса:**

| Имя параметра | Тип   | Путь/Строка запроса/Тело HTTP-запроса | Описание                                                                                                                                              |
| :------------ | :---- | :------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet   | File  | FormData                               | Файл электронной таблицы Excel для загрузки и защиты шифрованием пароля.                                                                              |
| openPassword  | String | Query                                 | Пароль, необходимый для открытия (расшифровки) защищенной электронной таблицы.                                                                        |
| modifyPassword| String | Query                                 | Пароль, необходимый для включения редактирования или изменения содержимого электронной таблицы.                                                       |
| outPath       | String | Query                                 | (Необязательно) Указывает путь к выходной папке, куда будет сохранена защищенная книга. Если не указано, файл возвращается в ответе.                 |
| outStorageName| String | Query                                 | Имя облачного хранилища, используемого для хранения защищенного выходного файла.                                                                     |
| region        | String | Query                                 | Указывает региональные/культурные настройки (например, формат даты, форматирование чисел), применяемые к электронной таблице во время обработки.      |

**Аутентификация**  
Все вызовы API защиты электронной таблицы требуют действительного токена доступа OAuth 2.0. Включите токен в заголовке `Authorization`:

```http
Authorization: Bearer {access_token}
```

Токен должен быть получен из точки аутентификации Aspose Cloud и должен включать область доступа **Cells**.

## **Ответ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**Коды HTTP-статуса**

| Код | Значение                | Описание                                                                |
|-----|-------------------------|-------------------------------------------------------------------------|
| 200 | OK (ОК)                 | Фильтр успешно применен; ответ содержит подробности операции.          |
| 400 | Bad Request (Неверный запрос) | Отсутствуют или недопустимы параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized (Неавторизован) | Недействительный или отсутствующий JWT-токен.                          |
| 413 | Payload Too Large (Слишком большой полезный груз) | Загруженный файл превышает лимит размера.                         |
| 500 | Internal Server Error (Внутренняя ошибка сервера) | Непредвиденная ошибка сервера.                                        |

## Где следует использовать API защиты электронной таблицы?

- **Защита конфиденциальных финансовых данных** – Защищайте файлы Excel, содержащие бюджеты, счета или данные по заработной плате, с помощью паролей открытия и изменения, чтобы предотвратить несанкционированный доступ или изменения.
- **Безопасное распространение конфиденциальных отчетов** – Убедитесь, что только авторизованные получатели могут просматривать или изменять бизнес-, аудиторские или отчеты по соответствию при внутреннем или внешнем распространении.
- **Автоматизация безопасности документов в рабочих процессах** – Интегрируйте API в корпоративные системы (например, ERP, CRM) для автоматической защиты паролем создаваемых электронных таблиц перед их сохранением или отправкой по электронной почте.
- **Принудительное предоставление доступа только для чтения** – Разрешите пользователям открывать отчеты для просмотра, ограничивая при этом изменения с помощью отдельного пароля изменения — идеально подходит для шаблонов или завершенных наборов данных.
- **Соответствие нормативным требованиям** – Помогите соблюдать требования GDPR, HIPAA или SOX, шифруя конфиденциальные данные электронных таблиц при хранении и передаче с помощью автоматизированной защиты.

## Почему следует использовать API защиты электронной таблицы?

- **Удобный для разработчиков** – Aspose.Cells Cloud предоставляет SDK-библиотеки на множестве языков программирования, что обеспечивает быструю разработку, и сопровождается подробной документацией. По сравнению с созданием собственных решений это значительно снижает трудозатраты на разработку.
- **Снижение потребности в персонале** – Автоматизирует консолидацию и безопасность документов, снижая потребность в выделенных сотрудниках.
- **Платежи по факту использования** – Никаких предварительных инвестиций; вы платите только за те вызовы API, которые фактически используете.
- **Отсутствие затрат на обслуживание** – Нет серверов для обслуживания, обновлений программного обеспечения и проблем совместимости.
- **Сохранение всех исходных форматов Excel** при применении защиты паролем, что гарантирует, что защищенная книга выглядит точно так же, как исходный файл.

## Как использовать API защиты электронной таблицы с помощью SDK

### Спецификация OpenAPI

Спецификация [API защиты электронной таблицы](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Protection/ProtectSpreadsheet) предоставляет общедоступный программный интерфейс, позволяющий выполнять прямые REST-взаимодействия из веб-браузера.
