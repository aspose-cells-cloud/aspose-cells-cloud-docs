Проверка данных в Microsoft Excel — это функция, позволяющая контролировать, какие данные пользователь может вводить в ячейку рабочего листа. С её помощью можно ограничить ввод определённым диапазоном дат, только целыми числами или даже создать раскрывающийся список, экономящий место и отображающий значения в одной ячейке. Также можно задать собственное сообщение, которое появляется, когда пользователь вводит некорректное значение или неверный формат.

Например, пользователь может указать, что встреча запланирована с 9:00 до 18:00.

Проверка данных может использоваться для обеспечения того, чтобы значение было положительным числом, датой между 15-м и 30-м числом месяца, датой, наступающей в ближайшие 30 дней, или текстовой записью, содержащей менее 25 символов, и так далее.

### Краткое описание API

| Операция | HTTP-метод | Конечная точка | Описание |
|---------|------------|---------------|----------|
| Добавить | POST | `/cells/{file}/worksheets/{sheet}/validations` | Создать правило проверки |
| Получить | GET | `/cells/{file}/worksheets/{sheet}/validations/{index}` | Получить конкретное правило |
| Получить все | GET | `/cells/{file}/worksheets/{sheet}/validations` | Получить список всех правил |
| Обновить | PUT | `/cells/{file}/worksheets/{sheet}/validations/{index}` | Изменить правило |
| Удалить | DELETE | `/cells/{file}/worksheets/{sheet}/validations/{index}` | Удалить правило |
| Очистить | POST | `/cells/{file}/worksheets/{sheet}/validations/clear` | Удалить все правила |
