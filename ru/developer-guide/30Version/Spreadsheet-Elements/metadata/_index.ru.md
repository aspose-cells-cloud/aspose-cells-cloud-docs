Файлы Excel могут хранить различные метаданные, которые помогают идентифицировать, организовывать и управлять документами. Aspose.Cells Cloud предоставляет простой REST API для чтения, добавления, обновления и удаления таких метаданных, позволяя разработчикам интегрировать управление свойствами документов в свои приложения. В этом руководстве рассматриваются две основные категории свойств — стандартные и пользовательские, объясняется, как с ними работать, и предоставляются прямые ссылки на соответствующие конечные точки API. Также приведена краткая таблица справочника API с деталями запросов для ускорения реализации.

**Последнее обновление:** 8 июля 2026 г.

**Типы свойств документов**

Прежде чем перейти к использованию API Aspose.Cells Cloud для просмотра, изменения и удаления свойств (метаданных) документов Excel, разберёмся, какие типы свойств могут быть у документа Excel.

- **Стандартные свойства** являются общими для Excel. Они содержат базовую информацию, такую как Заголовок, Тема, Автор, Категория и т.д. Вы можете задавать пользовательские текстовые значения для этих свойств, чтобы облегчить поиск файла.

- **Пользовательские свойства** определяются пользователем. Они позволяют добавлять дополнительные метаданные в документ Excel.

**Справочник API (без хранилища)**  

| Метод | Конечная точка | Описание |
|-------|----------------|----------|
| **GET** | `GET https://api.aspose.cloud/v3.0/cells/metadata` | Возвращает все свойства документа рабочей книги, хранящейся в облаке. |
| **GET** | `GET https://api.aspose.cloud/v3.0/cells/metadata/{propertyName}` | Возвращает значение конкретного свойства (стандартного или пользовательского), идентифицируемого по `propertyName`. |
| **PUT** | `PUT https://api.aspose.cloud/v3.0/cells/metadata/{propertyName}` | Обновляет значение существующего свойства. Тело запроса содержит новое значение в формате JSON. |
| **DELETE** | `DELETE https://api.aspose.cloud/v3.0/cells/metadata/{propertyName}` | Удаляет конкретное свойство из рабочей книги. |
| **DELETE** | `DELETE https://api.aspose.cloud/v3.0/cells/metadata` | Очищает все пользовательские и стандартные свойства из рабочей книги. |

*Все запросы требуют токена доступа OAuth 2.0 и могут включать необязательные параметры запроса, такие как `storage` и `folder`, если используется определённое хранилище.*
