**Необходимые условия**  
Перед вызовом конечной точки необходимо получить активный токен доступа Aspose Cloud с соответствующими правами и версию API (`v3.0`).

### Как задать размер бумаги с помощью REST API Aspose.Cells Cloud

```bash
curl -X PUT "https://api.aspose.cloud/v3.0/cells/Workbook/worksheets/Sheet1/pageSetup" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{"PaperSize":"PaperA4"}'
```

**Сведения о запросе**  
- **Метод:** `PUT`  
- **Конечная точка:** `/cells/Workbook/worksheets/{sheetName}/pageSetup`  
- **Параметры пути:** `sheetName` — имя рабочего листа (строка, обязательный параметр).  
- **Тело запроса:** JSON-объект, содержащий свойство `PaperSize`. Значение должно быть одной из констант, перечисленных в таблице выше, например `"PaperA4"`.

**Ответы**  
- `200 OK` — Настройки страницы успешно обновлены.  
- `400 Bad Request` — Недопустимое значение `PaperSize`.  
- `401 Unauthorized` — Ошибка аутентификации или отсутствует токен.  
- `404 Not Found` — Указанный рабочий лист не существует.

**Пример SDK (C#)**  
```csharp
var api = new CellsApi("client_id", "client_secret");
var request = new PageSetup { PaperSize = PaperSizeEnum.PaperA4 };
api.PutWorksheetPageSetup("Book1.xlsx", "Sheet1", request);
```

Полное определение OpenAPI см. в <a href="https://api.aspose.cloud/v3.0/swagger.json" target="_blank" rel="noopener">спецификации Aspose.Cells Cloud Swagger</a>.

Также ознакомьтесь с [документацией по настройке страницы](/page-setup/) для настройки полей, ориентации и других параметров макета.
