## Работа с фигурами в файле Excel

Фигуры представляют собой графические объекты, такие как линии, прямоугольники, текстовые поля и изображения, которые можно размещать на рабочем листе Excel. Они полезны для визуализации данных, добавления аннотаций или создания интерактивных элементов в электронной таблице. На этой странице приведены быстрые ссылки на наиболее распространённые операции с фигурами, каждая из которых сопровождается кратким описанием.

**Требования:** Для использования операций с фигурами необходимо иметь действующий ключ API Aspose.Cells Cloud и загруженную в облако рабочую книгу.

- [Как получить все фигуры на рабочем листе Excel.](/ru/cells/shapes/get-all/) – Получает полную коллекцию фигур, присутствующих на рабочем листе.
- [Как получить фигуру по индексу на рабочем листе Excel.](/ru/cells/shapes/get/) – Возвращает фигуру, расположенную по указанному индексу.
- [Как добавить фигуру на рабочий лист Excel.](/ru/cells/shapes/add/) – Вставляет новую фигуру (например, прямоугольник, линию или изображение) на рабочий лист.
- [Как удалить все фигуры на рабочем листе Excel.](/ru/cells/shapes/clear/) – Удаляет все фигуры с рабочего листа за одну операцию.
- [Как удалить фигуру по индексу на рабочем листе Excel.](/ru/cells/shapes/delete/) – Удаляет фигуру по заданному индексу.
- [Как преобразовать фигуру в изображение на рабочем листе Excel.](/ru/cells/shapes/conversion/) – Преобразует выбранную фигуру в файл изображения (PNG, JPEG и др.) для использования вне Excel.
