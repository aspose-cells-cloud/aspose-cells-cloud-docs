Операции с текстом в файлах Excel представляют собой сложные процессы. Множество факторов способствуют этой сложности и должны учитываться при обработке. Aspose.Cells Cloud предоставляет надёжный способ поиска и замены текста в различных форматах электронных таблиц.

Работа с текстом в файлах Excel часто требует поиска определённых строк и их обновления в нескольких листах. API Aspose.Cells Cloud упрощает эту задачу, предоставляя унифицированную операцию **поиска и замены**, которая работает с любыми поддерживаемыми форматами электронных таблиц.

## Обзор

Операция поиска и замены позволяет находить определённые строки в рабочей тетради или конкретном листе и заменять их новыми значениями. Эта операция работает со всеми форматами, поддерживаемыми Aspose.Cells Cloud, такими как **XLS, XLSX, XLSM, XLSB, ODS, CSV** и другими. С помощью функции **поиска и замены** вы можете быстро очистить данные, исправить повторяющиеся опечатки или применить единые соглашения об именовании ко всей рабочей тетради.

## Предварительные требования

- Активная учётная запись Aspose.Cloud с действительными **Client‑Id** и **Client‑Secret**.
- Токен доступа, полученный в рамках потока аутентификации OAuth 2.0.
- Целевая рабочая тетрадь должна храниться в облачном хранилище Aspose Cloud или быть доступной по общедоступному URL.
- Установленный необходимый SDK (например, Aspose.Cells‑Cloud для .NET, Java или Python).

## Ссылка на API

**Метод:** `POST`  
**Конечная точка**

```
POST https://api.aspose.cloud/v3.0/cells/{fileName}/searchreplace
```

| Параметр         | Тип     | Обязательный | Описание                                                                                |
| ---------------- | ------- | ------------ | --------------------------------------------------------------------------------------- |
| `fileName`       | string  | Да           | Имя рабочей тетради (включая расширение).                                               |
| `folder`         | string  | Нет          | Путь к папке облачного хранилища.                                                       |
| `storage`        | string  | Нет          | Имя хранилища, если оно не является хранилищем по умолчанию.                            |
| `sheetName`      | string  | Нет          | Имя конкретного листа; если опущено, операция применяется ко всей рабочей тетради.      |
| `searchString`   | string  | Да           | Текст для поиска.                                                                       |
| `replaceString`  | string  | Да           | Текст, на который будут заменены найденные вхождения.                                  |
| `ignoreCase`     | boolean | Нет          | Установите значение `true`, чтобы выполнить поиск без учёта регистра.                  |
| `matchWholeCell` | boolean | Нет          | Установите значение `true`, чтобы заменять только совпадения по всей ячейке.           |

**Заголовки**

- `Authorization: Bearer {access_token}`
- `Content-Type: application/json`

**Тело запроса (JSON)**

```json
{
  "searchString": "OldValue",
  "replaceString": "NewValue",
  "ignoreCase": false,
  "matchWholeCell": false,
  "sheetName": "Sheet1"
}
```

**Успешный ответ (JSON)**

```json
{
  "status": "OK",
  "replacedCount": 3,
  "updatedFileUrl": "https://api.aspose.cloud/v3.0/storage/file/updatedWorkbook.xlsx"
}
```

## Обработка ошибок и граничные случаи

| Код HTTP | Значение                                      | Рекомендуемое действие                                                  |
| -------- | --------------------------------------------- | ----------------------------------------------------------------------- |
| 400      | Неверный запрос — отсутствующие или недопустимые параметры | Проверьте обязательные поля и типы данных.                             |
| 401      | Неавторизован — недействительный или просроченный токен | Обновите токен доступа.                                                |
| 404      | Не найдено — рабочая тетрадь или лист не существуют | Проверьте имя файла, путь к папке и `sheetName`.                       |
| 415      | Неподдерживаемый тип носителя — недопустимый формат файла | Убедитесь, что загруженный файл имеет поддерживаемый формат Excel или CSV. |
| 202      | Принято — запрос принят на обработку          | Периодически проверяйте статус операции, если используется асинхронная обработка. |
| 204      | Нет содержимого — операция завершена успешно, без тела ответа | Замена применена; дополнительные данные не возвращаются.               |
| 500      | Внутренняя ошибка сервера — непредвиденный сбой | Повторите попытку через короткое время; обратитесь в службу поддержки Aspose, если проблема сохраняется. |

**Примечания:**  
- Крупные рабочие тетради могут превысить ограничения по размеру запроса; в таких случаях рекомендуется сначала загрузить файл в облачное хранилище.  
- При установке параметра `ignoreCase` в значение `true` следует учитывать, что регистронезависимые сопоставления могут зависеть от региональных настроек и влиять на результаты.  
- Использование `matchWholeCell` с формулами не приведёт к замене частичных совпадений внутри текста формулы.
