Сжатие книги Excel снижает её размер за счёт удаления неиспользуемых стилей, изображений и общих строк, а восстановление восстанавливает целостность повреждённых книг. Облачный API Aspose.Cells предоставляет специализированные конечные точки для обеих операций.

- **[Сжатие данных в файле Excel](https://docs.aspose.cloud/cells/compress-excel-files/).**
- **[Восстановление файлов Excel](https://docs.aspose.cloud/cells/repair-excel-files/).**

**API сжатия книги**  
Операция **Compress** (сжатие) использует простой POST-запрос. Ниже приведено полное описание запроса и ответа:

| Метод | Конечная точка | Обязательные параметры | Тело запроса | Пример ответа | Типичные коды состояния |
|-------|---------------|------------------------|--------------|----------------|-------------------------|
| POST  | `/cells/compress` | `file` (двоичные данные) — книга для сжатия; необязательный параметр `outPath` (строка) — путь назначения | *Нет* (файл отправляется как multipart/form‑data) | `{ "compressedSize": 12456, "originalSize": 45678 }` | `200 OK`, `400 Bad Request`, `401 Unauthorized` |

**API восстановления книги**  
Операция **Repair** (восстановление) также использует POST-запрос. Её описание:

| Метод | Конечная точка | Обязательные параметры | Тело запроса | Пример ответа | Типичные коды состояния |
|-------|---------------|------------------------|--------------|----------------|-------------------------|
| POST  | `/cells/repair` | `file` (двоичные данные) — повреждённая книга; необязательный параметр `outPath` (строка) — путь сохранения восстановленного файла | *Нет* (файл отправляется как multipart/form‑data) | `{ "isRepaired": true, "message": "Workbook repaired successfully." }` | `200 OK`, `400 Bad Request`, `415 Unsupported Media Type` |

Эти таблицы предоставляют разработчикам основную информацию, необходимую для прямого вызова API без необходимости переключаться на другие источники.
