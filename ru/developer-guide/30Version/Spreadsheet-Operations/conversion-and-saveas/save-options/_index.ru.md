# Свойства SaveOptions

Параметры SaveOptions позволяют управлять процессом сохранения рабочей книги при использовании REST API Aspose.Cells Cloud. Настройка этих параметров позволяет включить HTTP-сжатие, указать целевой формат файла, управлять временным хранилищем, а также контролировать дополнительные поведения, такие как обновление кэша диаграмм и автоматическое создание каталогов.

**Необходимые условия**  
- Аутентифицированный сеанс Aspose.Cells Cloud (OAuth 2.0 или JWT).  
- Целевая рабочая книга должна быть загружена или создана через API до её сохранения.

| Название                  | Тип        | Описание                                                                                                   | Примечания |
| ------------------------- | ---------- | ---------------------------------------------------------------------------------------------------------- | ---------- |
| **EnableHTTPCompression** | **bool?**  | Включает HTTP-сжатие для ответа.                                                                          | [опционально] |
| **SaveFormat**            | **string** | Указывает целевой формат файла для сохранения рабочей книги.                                              | [опционально] |
| **ClearData**             | **bool?**  | Очищает содержимое рабочей книги после сохранения файла.                                                  | [опционально] |
| **CachedFileFolder**      | **string** | Каталог для временного хранения больших данных.                                                            | [опционально] |
| **ValidateMergedAreas**   | **bool?**  | Определяет, следует ли проверять объединённые области перед сохранением файла. Значение по умолчанию — false. | [опционально] |
| **RefreshChartCache**     | **bool?**  | Обновляет данные кэша диаграмм перед сохранением.                                                         | [опционально] |
| **CreateDirectory**       | **bool?**  | Если true и каталог не существует, он будет автоматически создан перед сохранением файла.                | [опционально] |
| **SortNames**             | **bool?**  | Сортирует именованные диапазоны по алфавиту при сохранении.                                                | [опционально] |

**Запрос**  
- **Метод:** `POST` (или `PUT` в зависимости от операции)  
- **Конечная точка:** `/cells/workbook/save`  
- **Заголовки:**  
  - `Authorization: Bearer <access_token>`  
  - `Content-Type: application/json`  
- **Тело:** JSON-представление модели `SaveOptions` (таблица выше), объединённое с данными рабочей книги или ссылкой на неё.

**Пример ответа**  
```json
{
  "status": "OK",
  "downloadUrl": "https://api.aspose.cloud/v3.0/cells/workbook/save/result.xlsx",
  "message": "Рабочая книга успешно сохранена."
}
```

**Коды HTTP-статуса**

| Код | Значение                    | Описание                                               |
|-----|-----------------------------|--------------------------------------------------------|
| 200 | OK                          | Фильтр успешно применён; ответ содержит детали операции. |
| 400 | Bad Request                 | Отсутствуют или некорректны параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized                | Неверный или отсутствующий JWT-токен.                 |
| 413 | Payload Too Large           | Размер загружаемого файла превышает допустимый лимит. |
| 500 | Internal Server Error       | Непредвиденная ошибка сервера.                        |

**Примечания / Замечания**  
- Если **CreateDirectory** установлено в значение `true`, API автоматически создаст целевую папку, если она ещё не существует.  
- Включение **EnableHTTPCompression** может уменьшить объём полезной нагрузки для больших рабочих книг, однако клиент должен поддерживать декодирование gzip/deflate.  
- **RefreshChartCache** следует использовать, если диаграммы зависят от динамических данных, которые могли измениться после создания рабочей книги.
