Aspose.Cells Cloud API предоставляет пакетные конечные точки, позволяющие выполнять типовые операции над несколькими файлами Excel в одном запросе. Ниже приведено краткое описание доступных пакетных операций вместе с краткими спецификациями API для каждой из них.

- **["Пакетное преобразование файлов Excel"](https://docs.aspose.cloud/cells/batch/convert "Пакетное преобразование файлов Excel")**  
  *Преобразуйте несколько файлов Excel в выбранный выходной формат за один запрос.*  

  **Сведения об API**  
  ```http
  POST /cells/batch/convert
  Content-Type: multipart/form-data
  Authorization: Bearer {access_token}
  ```  

  **Параметры**  

  | Имя            | Тип      | Описание                                      |
  |----------------|----------|-----------------------------------------------|
  | files          | file[]   | Один или несколько файлов Excel для преобразования. |
  | outputFormat   | string   | Желаемый выходной формат (например, pdf, csv, html). |
  | storage        | string   | (Необязательно) Имя облачного хранилища.      |

  **Ответы**  

  | Код  | Описание                                     |
  |------|----------------------------------------------|
  | 200  | Преобразование успешно выполнено; возвращает файлы. |
  | 400  | Неверные параметры запроса.                  |
  | 401  | Несанкционированный доступ — отсутствует или недействителен токен. |
  | 500  | Внутренняя ошибка сервера.                   |

- **["Пакетная блокировка файлов Excel"](https://docs.aspose.cloud/cells/batch/lock "Пакетная блокировка файлов Excel")**  
  *Установите парольную блокировку сразу для нескольких файлов Excel.*  

  **Сведения об API**  
  ```http
  POST /cells/batch/lock
  Content-Type: application/json
  Authorization: Bearer {access_token}
  ```  

  **Параметры**  

  | Имя      | Тип    | Описание                                   |
  |----------|--------|--------------------------------------------|
  | files    | array  | Список идентификаторов файлов или URL-адресов. |
  | password | string | Пароль для блокировки рабочих книг.        |
  | storage  | string | (Необязательно) Имя облачного хранилища.   |

  **Ответы**  

  | Код  | Описание                                     |
  |------|----------------------------------------------|
  | 200  | Файлы успешно заблокированы.                 |
  | 400  | Отсутствуют или недопустимы параметры.      |
  | 401  | Несанкционированный доступ.                  |
  | 500  | Ошибка сервера.                              |

- **["Пакетная защита файлов Excel"](https://docs.aspose.cloud/cells/batch/protect "Пакетная защита файлов Excel")**  
  *Примените параметры защиты (например, только для чтения, структура) к нескольким рабочим книгам.*  

  **Сведения об API**  
  ```http
  POST /cells/batch/protect
  Content-Type: application/json
  Authorization: Bearer {access_token}
  ```  

  **Параметры**  

  | Имя           | Тип    | Описание                                         |
  |---------------|--------|--------------------------------------------------|
  | files         | array  | Список идентификаторов файлов или URL-адресов.   |
  | protection    | object | Параметры защиты (например, readOnly, structure). |
  | storage       | string | (Необязательно) Имя облачного хранилища.        |

  **Ответы**  

  | Код  | Описание                                     |
  |------|----------------------------------------------|
  | 200  | Защита успешно применена.                     |
  | 400  | Неверные данные запроса.                      |
  | 401  | Ошибка аутентификации.                        |
  | 500  | Непредвиденная ошибка сервера.                |

- **["Пакетное разделение"](https://docs.aspose.cloud/cells/batch/split "Пакетное разделение")**  
  *Разделите большие рабочие книги Excel на более мелкие файлы на основе листов или диапазонов строк.*  

  **Сведения об API**  
  ```http
  POST /cells/batch/split
  Content-Type: application/json
  Authorization: Bearer {access_token}
  ```  

  **Параметры**  

  | Имя         | Тип    | Описание                                       |
  |-------------|--------|------------------------------------------------|
  | files       | array  | Файлы, подлежащие разделению.                  |
  | splitBy     | string | Критерий: "worksheet" или "rowRange".          |
  | criteria    | object | Детали выбранного метода разделения.           |
  | storage     | string | (Необязательно) Имя облачного хранилища.       |

  **Ответы**  

  | Код  | Описание                                     |
  |------|----------------------------------------------|
  | 200  | Операция разделения завершена; возвращает части. |
  | 400  | Неверные параметры разделения.                |
  | 401  | Несанкционированный запрос.                   |
  | 500  | Ошибка обработки.                             |

- **["Пакетное снятие блокировки"](https://docs.aspose.cloud/cells/batch/unlock "Пакетное снятие блокировки")**  
  *Удалите парольную защиту сразу из нескольких файлов Excel за один вызов.*  

  **Сведения об API**  
  ```http
  POST /cells/batch/unlock
  Content-Type: application/json
  Authorization: Bearer {access_token}
  ```  

  **Параметры**  

  | Имя      | Тип    | Описание                                     |
  |----------|--------|----------------------------------------------|
  | files    | array  | Список идентификаторов заблокированных файлов или URL-адресов. |
  | password | string | Текущий пароль файлов.                       |
  | storage  | string | (Необязательно) Имя облачного хранилища.    |

  **Ответы**  

  | Код  | Описание                                     |
  |------|----------------------------------------------|
  | 200  | Файлы успешно разблокированы.                 |
  | 400  | Неверный пароль или отсутствуют файлы.        |
  | 401  | Несанкционированный доступ.                   |
  | 500  | Сбой на стороне сервера.                      |
