## Свойства FileInfo


| Имя             | Тип    | Описание                                                  |
| --------------- | ------ | --------------------------------------------------------- |
| **FileName**    | string | Имя файла, включая его расширение.                        |
| **FileSize**    | long   | Размер файла в байтах.                                    |
| **FileContent** | string | Содержит необработанные данные файла Excel, закодированные в Base64. |

Ответ возвращается в формате JSON и содержит те же три свойства, что указаны в таблице выше, например:

```json
{
  "FileName": "MyWorkbook.xlsx",
  "FileSize": 254312,
  "FileContent": "UEsDBBQABgAIAAAAIQD..."
}
```

### Ошибки

| Код HTTP | Значение                 | Условия возникновения                |
| -------- | ------------------------ | ------------------------------------ |
| 200      | OK — запрос выполнен успешно. | Нормальный ответ.                    |
| 401      | Unauthorized             | Отсутствует или недействителен токен аутентификации. |
| 404      | Not Found                | Указанный файл не существует.        |
| 500      | Internal Server Error    | Непредвиденная ошибка на стороне сервера. |

Для каждой ошибки убедитесь, что токен аутентификации действителен (401), проверьте путь к файлу (404) или обратитесь к общему руководству по обработке ошибок для получения рекомендаций по повторным попыткам (500).
