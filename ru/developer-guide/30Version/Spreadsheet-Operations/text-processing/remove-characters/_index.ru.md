## Удаление символов из Excel через веб-API

Набор инструментов для очистки текстового содержимого в выбранных ячейках. API удаляет указанные символы, предопределённые наборы символов или подстроки, обеспечивая стандартизацию и очистку текста на листе от нежелательных символов.

**Необходимые условия**

- Активная учётная запись Aspose Cloud.  
- Действующий JWT-токен доступа, полученный в соответствии с инструкцией по аутентификации.  
- Файл Excel должен быть загружен в хранилище перед вызовом этого endpoint.  
- Поддерживаемые форматы файлов: `.xlsx`, `.xls`, `.xlsm` и другие распространённые типы Excel.

```http
POST https://api.aspose.cloud/v3.0/cells/removecharacters
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации по токену JWT</a>.

### Описание функции

- **Удаление пользовательских символов** – Укажите любые символы, которые необходимо удалить. Введите каждый символ в поле _Удалить пользовательские символы_; API удалит все вхождения указанных символов в выбранных ячейках.  
- **Удаление наборов символов** – Выберите один из предопределённых наборов:  
  - **Непечатаемые символы** – Удаляет разрывы строк и первые 32 непечатаемых ASCII-символа (коды 0–31), а также дополнительные коды (127, 129, 141, 143, 144, 157).  
  - **Буквенные символы** – Удаляет все буквы.  
  - **Цифровые символы** – Удаляет все цифры.  
  - **Символы** – Удаляет математические, геометрические, технические, валютные символы и символы, похожие на буквы (например, «?», «1», «™»).  
  - **Знаки препинания** – Удаляет все знаки препинания.  
- **Удаление подстроки** – Удаляет указанную подстроку (например, слово) из выбранных ячеек.

### Параметры запроса

| Имя параметра           | Тип   | Местоположение | Описание                                                                      |
| ----------------------- | ----- | -------------- | ----------------------------------------------------------------------------- |
| removeCharactersOptions | Класс | Body           | Параметры, определяющие, какие символы, наборы символов или подстроки удалить. |

**Схема `removeCharactersOptions`**

| Свойство         | Тип     | Обязательное | Описание                                                                                                   |
| ---------------- | ------- | ------------- | ---------------------------------------------------------------------------------------------------------- |
| Range            | string  | Да            | Нотация A‑1 или именованный диапазон, определяющий обрабатываемые ячейки (например, `"A1:C10"`).          |
| CustomCharacters | string  | Нет           | Строка, содержащая каждый пользовательский символ для удаления (например, `"@#$"`).                       |
| CharacterSet     | string  | Нет           | Значение перечисления, задающее предопределённый набор (`"NonPrinting"`, `"Text"`, `"Numeric"`, `"Symbols"`, `"Punctuation"`). |
| Substring        | string  | Нет           | Точная подстрока для удаления (например, `"USD"`).                                                        |
| IgnoreCase       | boolean | Нет           | Если `true`, удаление символов выполняется без учёта регистра.                                             |

**Пример JSON-тела запроса**

```json
{
  "Range": "A1:B20",
  "CustomCharacters": "@#$",
  "CharacterSet": "NonPrinting",
  "Substring": "USD",
  "IgnoreCase": true
}
```

**Пример cURL-запроса**

```bash
curl -X POST "https://api.aspose.cloud/v3.0/cells/removecharacters" \
     -H "Authorization: Bearer {access_token}" \
     -H "Content-Type: application/json" \
     -d '{
           "Range": "A1:B20",
           "CustomCharacters": "@#$",
           "CharacterSet": "NonPrinting",
           "Substring": "USD",
           "IgnoreCase": true
         }'
```

### **Ответ**

```json
{
    "Status" : "OK",
    "Code" : 200,
    "Filename" : "[имя объединённого файла]",
    "Filesize" : [размер файла],
    "FileContent" : "[Base64String]"
}
```

**Коды HTTP-статуса**

| Код | Значение                    | Описание                                                   |
|-----|-----------------------------|------------------------------------------------------------|
| 200 | OK                          | Фильтр успешно применён; в ответе содержатся детали операции. |
| 400 | Bad Request                 | Отсутствуют или недопустимы параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized                | Недействительный или отсутствующий JWT-токен.             |
| 413 | Payload Too Large           | Загруженный файл превышает допустимый размер.              |
| 500 | Internal Server Error       | Непредвиденная ошибка сервера.                             |
