## Работа с задачами

Aspose.Cells Cloud предоставляет **API задач**, который позволяет разработчикам выполнять различные операции над рабочими книгами Excel, такие как преобразование форматов, импорт данных, выполнение шаблонов SmartMarker и сохранение результатов. Задачи выполняются асинхронно: вы создаёте задачу, запускаете её и затем получаете результат.

**Требования:** учётная запись Aspose Cloud с действующим API-ключом, поддерживаемые форматы файлов Excel и последняя версия API Cells (v3.0+).

- [Запрос файла поддержки в Task API](/cells/support-request-file-in-task-api/ru/support-request-file-in-task-api/) – Позволяет загрузить файл в облачное хранилище и ссылаться на него в последующих задачах, обеспечивая его доступность для обработки.
- [Работа с задачей CellsObjectOperate](/cells/working-with-cellsobjectoperate-task/ru/working-with-cellsobjectoperate-task/) – Выполняет операции над объектами ячеек (например, строками, столбцами) внутри рабочей книги, такие как добавление, удаление или обновление значений ячеек.
- [Работа с задачей Convert](/cells/working-with-convert-task/ru/working-with-convert-task/) – Преобразует рабочую книгу в форматы PDF, HTML, CSV или JSON, с возможностью указать диапазон страниц, защиту паролем и настраиваемые параметры преобразования.
- [Работа с задачей ImportData](/cells/working-with-importdata-task/ru/working-with-importdata-task/) – Импортирует данные из файлов CSV, JSON или XML в рабочий лист, сопоставляя столбцы с ячейками и при необходимости указывая начальную строку и столбец.
- [Работа с задачей SaveResult](/cells/working-with-saveresult-task/ru/working-with-saveresult-task/) – Сохраняет результат ранее выполненной задачи (например, преобразованный файл) обратно в облачное хранилище или возвращает его в ответе.
- [Работа с задачей SmartMarker](/cells/working-with-smartmarker-task/ru/working-with-smartmarker-task/) – Обрабатывает рабочую книгу, содержащую теги SmartMarker (например, `{{Customer.Name}}`), используя источник данных в формате JSON для генерации заполненного отчёта.
- [Работа с операциями над листами (WorksheetOperates) в Task API](/cells/working-with-worksheetoperates-in-task-api/ru/working-with-worksheetoperates-in-task-api/) – Выполняет операции на уровне рабочего листа, такие как добавление, удаление или переименование рабочих листов в рамках рабочего процесса задачи.

Для получения полных спецификаций методов — включая HTTP-глаголы, URL-адреса конечных точек, схемы запросов и ответов, таблицы параметров и примеры полезных нагрузок — обращайтесь к отдельным страницам задач, ссылки на которые указаны выше. Подробная справка по API помогает разработчикам быстро и надёжно интегрировать API задач.
