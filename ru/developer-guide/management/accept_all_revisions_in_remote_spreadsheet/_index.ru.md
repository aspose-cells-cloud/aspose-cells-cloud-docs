## Принятие всех изменений в удалённой таблице в веб-сервисах Aspose.Cells Cloud

Принимает все отслеживаемые изменения (ревизии) в указанной рабочей книге, хранящейся в удалённом хранилище. Операция может опционально сохранить результирующую рабочую книгу в другом месте или хранилище и возвращает обновлённый файл в виде двоичного потока.

### Конечная точка веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/{name}/accept-all-revisions
```

### **Безопасность и аутентификация**

Веб-API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе токена JWT</a>.

### Параметры запроса

| Имя параметра | Тип | Путь/Строка запроса/Тело HTTP-запроса | Описание |
|---------------|-----|---------------------------------------|----------|
| name | string | Путь | Имя файла рабочей книги, хранящегося в удалённом хранилище. |
| folder | string | Запрос | (Опционально) Папка в хранилище, где расположена рабочая книга. |
| storageName | string | Запрос | (Опционально) Имя хранилища при использовании пользовательского облачного хранилища. Если не указано, используется хранилище по умолчанию. |
| outPath | string | Запрос | (Опционально) Путь к папке, куда следует сохранить обновлённую рабочую книгу. По умолчанию — null. |
| outStorageName | string | Запрос | (Опционально) Имя хранилища для выходного файла. |
| fontsLocation | string | Запрос | (Опционально) Путь к пользовательскому расположению шрифтов. |
| region | string | Запрос | (Опционально) Региональные/языковые настройки таблицы (например, `en-US`, `fr-FR`). Влияет на форматирование чисел, разбор дат и поведение, зависящее от региона. |
| password | string | Запрос | (Опционально) Пароль для открытия файла таблицы. |

### Параметр тела запроса

| Имя параметра | Тип | Описание |
| ------------- | --- | -------- |
| *Нет* | *Нет* | Эта операция не требует тела запроса. |

### **Ответ**

```json
{
  "File": "Двоичный поток обновлённой рабочей книги (например, .xlsx), возвращаемый в теле ответа."
}
```

**Коды состояния ответа**

| Код | Значение | Описание |
|-----|----------|----------|
| 200 | OK | Рабочая книга со всеми принятыми изменениями возвращается в виде двоичного потока. |
| 400 | Bad Request | Отсутствуют обязательные параметры или неверный формат запроса. |
| 401 | Unauthorized | Неверный или отсутствующий JWT-токен. |
| 413 | Payload Too Large | Размер запроса превышает допустимые ограничения. |
| 500 | Internal Server Error | На сервере произошла непредвиденная ошибка. |
