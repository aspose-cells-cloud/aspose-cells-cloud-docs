Программно добавляйте листы в файлы Excel с полным контролем типа и местоположения листа. Вставляйте стандартные рабочие листы, листы диаграмм или макрос-листы в любую позицию книги. Эта REST-операция позволяет автоматизировать управление и организацию книг Excel.

**Необходимые условия**

- Активная учетная запись Aspose.Cells Cloud с действительным JWT-токеном доступа.
- Настроенное имя облачного хранилища (например, `CompanyOneDrive`), в котором будет сохранена книга.
- Целевая книга должна быть доступна в указанном хранилище; при необходимости следует указать правильный пароль для защищенных файлов.

| **Тип листа**          | Описание                                          |
| :--------------------- | :------------------------------------------------ |
| **VB**                 | Модуль Visual Basic                               |
| **Worksheet**          | Обычный рабочий лист                              |
| **Chart**              | Лист диаграммы                                    |
| **BIFF4Macro**         | Макрос-лист формата BIFF4                         |
| **InternationalMacro** | Международный макрос-лист                        |
| **Other**              | Пользовательский или менее распространенный тип листа, не указанный выше |
| **Dialog**             | Диалоговый рабочий лист                           |

## **API добавления листа в электронную таблицу**

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/spreadsheet/add/worksheet
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации по токену JWT</a>.

### Параметры запроса

| Имя параметра      | Тип     | Местоположение | Описание                                                                                                                                                                                          |
| :----------------- | :------ | :------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Spreadsheet**    | Файл    | FormData       | **Обязательный.** Книга Excel (.xlsx, .xls и др.), в которую будет добавлен новый лист.                                                                                                          |
| **sheetType**      | Строка  | Query          | **Необязательный.** Тип создаваемого листа. Допустимые значения: `worksheet` (по умолчанию), `chartsheet`, `macrosheet`, `vbmodule`, `dialog`.                                                    |
| **position**       | Целое   | Query          | **Необязательный.** Индекс позиции вставки нового листа (начиная с 0). `0` — вставить перед первым листом; `2` — вставить третьим по порядку. Пропустите, чтобы добавить лист в конец.             |
| **sheetName**      | Строка  | Query          | **Необязательный.** Имя нового рабочего листа. Должно быть уникальным в пределах книги. При отсутствии генерируется имя по умолчанию (например, «SheetX»).                                       |
| **outPath**        | Строка  | Query          | **Необязательный.** Целевой каталог в облачном хранилище, куда будет сохранена измененная книга. Если `null` или не указано, книга сохраняется в том же месте, что и исходный файл, либо в путь по умолчанию. |
| **outStorageName** | Строка  | Query          | **Обязательный.** Идентификатор настроенного облачного хранилища (например, `CompanyOneDrive`), куда будет записан выходной файл.                                                                 |
| **region**         | Строка  | Query          | **Необязательный.** Языковой стандарт (например, `ru-RU`), который может влиять на форматирование и региональные правила в новом листе.                                                         |
| **password**       | Строка  | Query          | **Необязательный.** Пароль для расшифровки и редактирования защищенной паролем книги. Пропустите, если файл не зашифрован.                                                                        |

### Ответ

При успешном выполнении API возвращает **HTTP 200 OK** (или **201 Created**, если создан новый файл) с обновленной книгой Excel.

```json
{
  "Name": "ResponseFile",
  "DataType": {
    "Identifier": "File",
    "Reference": "Stream"
  }
}
```

**Коды HTTP-статуса**

| Код | Значение              | Описание                                                           |
|-----|-----------------------|--------------------------------------------------------------------|
| 200 | OK (OK)               | Фильтр применен успешно; ответ содержит детали операции.          |
| 400 | Bad Request           | Отсутствуют или недопустимы параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized          | Недействительный или отсутствующий JWT-токен.                     |
| 413 | Payload Too Large     | Загруженный файл превышает лимит размера.                          |
| 500 | Internal Server Error | Непредвиденная ошибка сервера.                                     |

## Где использовать API добавления листа в электронную таблицу?

- **Автоматическая генерация отчетов** — динамическое создание и вставка ежемесячных листов (например, `2024-05`) при формировании финансовой отчетности.
- **Пакетная инициализация шаблонов** — добавление выделенного аналитического листа для каждого нового клиента или проекта при массовой генерации коммерческих предложений или заявок.
- **Динамическое расширение дашбордов** — вставка новых листов диаграмм в реальном времени при появлении новых измерений данных.
- **Соблюдение нормативных требований и архивирование аудитов** — автоматическое добавление листов для сбора доказательств во время ежегодных аудитов с изоляцией каждой проверочной точки.

- Для удаления листа см. операцию **[Удалить лист](/delete-worksheet/)**.
- Для перемещения листа см. операцию **[Переместить лист](/move-worksheet/)**.

## Почему стоит использовать API добавления листа в электронную таблицу?

- **Удобный для разработчика** — Aspose.Cells Cloud предоставляет SDK для множества языков программирования, снижая трудозатраты и обеспечивая обширную документацию.
- **Снижение затрат на труд** — исключает необходимость ручного создания листов и повторяющихся операций копирования/вставки.
- **Оплата по факту использования** — вы платите только за фактически выполненные вызовы API.
- **Отсутствие необходимости в обслуживании** — не требуется управлять серверами, обновлять ПО или заботиться о совместимости.
