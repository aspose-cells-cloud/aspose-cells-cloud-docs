Программно перемещайте листы внутри рабочих книг Excel с помощью API Aspose.Cells Cloud. Изменяйте положение листов, переупорядочивайте вкладки и оптимизируйте структуру рабочей книги с помощью вызовов RESTful API. Идеально подходит для автоматизации организации электронных таблиц и создания стандартных макетов рабочих книг.

## **Перемещение листа в API электронной таблицы**

### Web API

```http
PUT http://api.aspose.cloud/v4.0/cells/spreadsheet/move/worksheet?sheetName={sheetName}&position={position}&outPath={outPath}&outStorageName={outStorageName}&region={region}&password={password}
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации по токену JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### **Параметры запроса:**

| Имя параметра | Тип    | Путь/Строка запроса/HTTPBody | Описание                                                                                                                                                           |
| :------------ | :------ | :------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet   | Файл    | FormData                   | **Обязательный параметр**. Исходный файл рабочей книги Excel (.xlsx, .xls и др.), содержащий лист, который необходимо переместить.                                   |
| worksheet     | Строка  | Запрос                     | **Обязательный параметр**. Точное имя перемещаемого листа (например, `Summary`, `RawData_2024`).                                                                    |
| position      | Целое число | Запрос                  | **Обязательный параметр**. Новая позиция (индекс, начиная с нуля) для листа. Например, `0` перемещает его на первую позицию, `2` — на третью.                        |
| outPath       | Строка  | Запрос                     | **Необязательный параметр**. Путь к целевой папке в облачном хранилище, куда будет сохранена переупорядоченная рабочая книга. Если параметр `null` или опущен, используется путь исходного файла. |
| outStorageName| Строка  | Запрос                     | **Обязательный параметр**. Идентификатор имени настроенного облачного хранилища (например, `TeamDrive`), куда будет сохранён выходной файл.                         |
| region        | Строка  | Запрос                     | **Необязательный параметр**. Языковой стандарт (например, `es-MX`), который может повлиять на некоторые правила форматирования при сохранении.                    |
| password      | Строка  | Запрос                     | **Необязательный параметр**. Пароль расшифровки, необходимый для открытия и изменения защищённой паролем рабочей книги. Опустите, если файл не зашифрован.          |

### **Ответ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**Коды HTTP-статусов**

| Код | Значение               | Описание                                                          |
| --- | ---------------------- | ----------------------------------------------------------------- |
| 200 | OK (Успех)            | Фильтр успешно применён; в ответе содержатся детали операции.     |
| 400 | Bad Request (Неверный запрос) | Отсутствуют или некорректны параметры (например, неподдерживаемый тип файла). |
| 401 | Unauthorized (Неавторизованный доступ) | Неверный или отсутствующий токен JWT.                             |
| 413 | Payload Too Large (Слишком большой объём полезной нагрузки) | Загруженный файл превышает допустимый размер.                     |
| 500 | Internal Server Error (Внутренняя ошибка сервера) | Непредвиденная ошибка сервера.                                    |

## Где следует использовать API перемещения листа в электронной таблице?

- **Стандартизированная генерация отчётов**: После автоматической генерации ежемесячных или ежеквартальных отчётов лист `Summary` или `Executive Overview` перемещается в начало рабочей книги, чтобы основные выводы отображались при её открытии.
- **Конвейер обработки данных**: После обработки исходных листов из разных источников в ETL-процессе лист `Processed_Data`, содержащий очищенные и преобразованные данные, перемещается в логически обоснованное положение в книге (например, в середину), обеспечивая чёткую структуру процесса с исходными данными и результатами анализа.
- **Индивидуальная поставка файлов пользователю**: После выбора предпочитаемой компоновки через интерфейс настройки (например, размещения страницы диаграмм на первом месте) система автоматически переупорядочивает листы в книге в соответствии с выбором и поставляет персонализированный файл.

## Почему следует использовать API перемещения листа в электронной таблице?

- **Удобный для разработчика**: Aspose.Cells Cloud предоставляет SDK-библиотеки на множестве языков программирования, что обеспечивает быструю разработку и сопровождается подробной документацией. По сравнению с созданием собственных решений это значительно снижает объём работы разработчиков.
- **Снижение затрат на персонал**: Сокращает потребность в сотрудниках, занимающихся объединением документов.
- **Оплата по факту использования**: Нет необходимости в начальных вложениях; вы платите только за фактически выполненные вызовы API.
- **Отсутствие затрат на обслуживание**: Не требуется обслуживать серверы, обновлять ПО или решать проблемы совместимости.
