Программно создавайте новые таблицы Excel с помощью API Aspose.Cells Cloud. Генерируйте пустые рабочие книги или создавайте файлы на основе пользовательских шаблонов. RESTful API позволяет автоматически создавать файлы Excel, что идеально подходит для генерации отчётов, автоматизации документов и обработки данных.

## **API для создания таблицы Excel**

### Веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/spreadsheet/create
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации с помощью токена JWT</a>.

### Параметры запроса

| Имя параметра      | Тип    | Расположение | Описание                                                                                                                                          |
| ------------------ | ------ | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **format**         | String | Query        | **Обязательный**. Формат файла для новой таблицы (например, `XLSX`, `XLS`, `ODS`, `CSV`).                                                        |
| **template**       | String | Query        | **Необязательный**. Имя шаблона файла, хранящегося в вашем облачном хранилище (например, `invoice_template.xlsx`). Если не указан, создаётся пустая книга. |
| **outPath**        | String | Query        | **Необязательный**. Путь к целевой папке в облачном хранилище для сохранения сгенерированного файла. Если `null` или не указан, файл сохраняется в папку по умолчанию. |
| **outStorageName** | String | Query        | **Обязательный**. Идентификатор настроенного облачного хранилища (например, `MyDrive`).                                                          |
| **region**         | String | Query        | **Необязательный**. Параметр локали (например, `fr-FR`), определяющий форматы дат, чисел и валют по умолчанию.                                   |
| **password**       | String | Query        | **Необязательный**. Пароль для зашифрованного шаблона. Оставьте пустым, если шаблон не защищён.                                                   |

### Ответ

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**Коды HTTP-статусов**

| Код  | Значение                | Описание                                                            |
| ---- | ----------------------- | ------------------------------------------------------------------- |
| 200  | OK (Успешно)            | Фильтр применён успешно; ответ содержит детали операции.           |
| 400  | Bad Request (Ошибка)    | Отсутствуют или некорректны параметры (например, неподдерживаемый тип файла). |
| 401  | Unauthorized (Неавторизован) | Неверный или отсутствующий токен JWT.                            |
| 413  | Payload Too Large (Слишком большой запрос) | Загруженный файл превышает допустимый размер.              |
| 500  | Internal Server Error (Внутренняя ошибка сервера) | Непредвиденная ошибка сервера.                                |

## Где использовать API для создания таблицы Excel?

- **Инициализация автоматизированной системы отчётности** — Создавайте новую пустую книгу или генерируйте файл отчёта на основе стандартного шаблона в начале каждого цикла ежедневной/еженедельной автоматизации.
- **Портал для самостоятельной работы пользователей** — Позвольте клиентам выбрать шаблон (коммерческое предложение, график проекта и т.д.) и мгновенно загрузить настроенный файл Excel.
- **Пакетный экспорт и распространение данных** — Создавайте отдельные книги с единым форматом для каждого экспортируемого набора данных, упрощая последующее распространение и обработку.

Для последующих операций, таких как добавление рабочих листов или заполнение ячеек, см. **API добавления рабочего листа**, **API обновления ячейки** и **API экспорта книги**.

## Почему стоит использовать API для создания таблицы Excel?

- **Удобен для разработчиков** — Предоставляет SDK для множества языков программирования и подробную документацию, упрощая интеграцию по сравнению с созданием собственных решений.
- **Повышение производительности** — Позволяет автоматизировать объединение документов, снижая объём ручного труда.
- **Тарификация по факту использования** — Оплата производится только за фактическое использование API, без предварительных лицензионных сборов.
- **Управляемая услуга** — API полностью размещена на стороне провайдера, что исключает необходимость обслуживания собственных серверов или обновления ПО.
