## Получение листов с локальной электронной таблицей с помощью веб-сервисов Aspose.Cells Cloud

Этот endpoint обращается к локальному приложению электронной таблицы (например, Excel) через interop или локальный API, собирает имя и тип (например, стандартный, диаграмма, макрос) каждого листа и возвращает коллекцию в виде структурированного JSON-массива. Как правило, он используется для заполнения пользовательского интерфейса выбора листа или для аудита содержимого электронной таблицы.

### Конечная точка веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/spreadsheet/worksheets
```

### **Безопасность и аутентификация**

Веб-API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе токена JWT</a>.

### Параметры запроса

| Имя параметра | Тип   | Путь/Строка запроса/Тело HTTP-запроса | Описание |
|---------------|--------|----------------------------------------|----------|
| Spreadsheet   | File   | FormData (Тело HTTP-запроса)           | Загружаемый файл электронной таблицы. |
| region        | String | Query                                  | Региональные/языковые настройки электронной таблицы (например, `en-US`, `fr-FR`). Влияет на форматирование чисел, разбор дат и поведение, зависящее от локали. *(необязательно)* |
| password      | String | Query                                  | Пароль для открытия файла электронной таблицы. *(необязательно)* |

### Параметр тела запроса

| Имя параметра | Тип | Описание |
|---------------|-----|----------|
| Spreadsheet   | File | Загружаемый файл электронной таблицы. |

### **Ответ**

```json
{
  "Worksheets": [
    {
      "Name": "Лист1",
      "Id": 0,
      "Type": "Standard"
    },
    {
      "Name": "Диаграмма1",
      "Id": 1,
      "Type": "Chart"
    }
    // ... дополнительные листы
  ]
}
```

**Коды статуса ответа**

| Код | Значение | Описание |
|-----|----------|----------|
| 200 | OK | Список листов успешно получен. |
| 400 | Bad Request | Неверный запрос (например, некорректный URL или отсутствуют обязательные данные). |
| 401 | Unauthorized | Аутентификация не удалась, или учётные данные не предоставлены. |
| 404 | Not Found | Исходный файл недоступен. |
| 413 | Payload Too Large | Загруженный файл превышает допустимый размер. |
| 500 | Internal Server Error | При получении данных в электронной таблице возникла ошибка. |

### Спецификация API получения листов с локальной электронной таблицей

[Спецификация API получения листов с локальной электронной таблицей](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Management/GetWorksheetsWithLocalSpreadsheet) определяет общедоступное программное интерфейсное описание и позволяет выполнять REST-взаимодействия непосредственно из веб-браузера.
