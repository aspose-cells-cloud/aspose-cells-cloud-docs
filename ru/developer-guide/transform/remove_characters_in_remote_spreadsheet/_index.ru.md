## Удаление символов из удалённой электронной таблицы с помощью веб-сервисов Aspose.Cells Cloud

Удаляет заданные пользователем символы, предопределённые наборы символов или любую подстроку из каждой ячейки выбранного диапазона, сохраняя при этом формулы, форматирование и проверку данных для удалённой электронной таблицы.

### Конечная точка веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/{name}/worksheets/{worksheet}/range/{range}/content/remove/characters
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### Параметры запроса

| Имя параметра      | Тип    | Путь / строка запроса / тело HTTP-запроса | Описание                                                                                                                                                                       |
|---------------------|---------|---------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| name                | string  | Путь                                        | (Обязательный параметр) Имя файла рабочей книги, который необходимо получить.                                                                                                         |
| worksheet           | string  | Путь                                        | Указать лист электронной таблицы.                                                                                                                                              |
| range               | string  | Путь                                        | Указать диапазон листа электронной таблицы.                                                                                                                                       |
| removeTextMethod    | string  | Строка запроса                              | Указать тип метода удаления текста.                                                                                                                                          |
| characterSets       | string  | Строка запроса                              | Указать наборы символов.                                                                                                                                                       |
| removeCustomValue   | string  | Строка запроса                              | Указать пользовательское значение для удаления.                                                                                                                                                  |
| caseSensitive       | boolean | Строка запроса                              | Влияет на режим `Substring` и `CustomChars`, если включено.                                                                                                                          |
| folder              | string  | Строка запроса                              | (Необязательный параметр) Путь к папке, где хранится рабочая книга. По умолчанию — null.                                                                                                    |
| storageName         | string  | Строка запроса                              | (Необязательный параметр) Имя хранилища при использовании пользовательского облачного хранилища. Если не указано, используется хранилище по умолчанию.                                                                               |
| region              | string  | Строка запроса                              | Параметр региона/языка электронной таблицы (например, `en-US`, `fr-FR`). Влияет на форматирование чисел, разбор дат и поведение, зависящее от локали.                                         |
| password            | string  | Строка запроса                              | Пароль для открытия файла электронной таблицы.                                                                                                                                         |

### Параметр тела запроса

| Имя параметра | Тип | Описание |
| -------------- | ---- | ----------- |
| *Нет* | *Нет* | Эта операция не требует тела запроса. |

### **Ответ**

```json
{
  "Code": 200,
  "Status": "OK",
  "Message": "Символы успешно удалены.",
  "Data": {
    "RequestId": "строка",
    "Workbook": {
      "Name": "строка",
      "Path": "строка"
    }
  }
}
```

**Коды состояния ответа**

| Код | Значение | Описание |
|------|---------|-------------|
| 200 | OK | Символы успешно удалены, рабочая книга обновлена. |
| 400 | Bad Request | Отсутствует или недопустим один или несколько параметров. |
| 401 | Unauthorized | Аутентификация не удалась — отсутствует или недопустим JWT-токен. |
| 413 | Payload Too Large | Размер запроса превышает допустимый лимит. |
| 500 | Internal Server Error | Произошла непредвиденная ошибка на стороне сервера. |

## Как использовать удаление символов из удалённой электронной таблицы с помощью SDK

### Спецификация удаления символов из удалённой электронной таблицы

[Спецификация API удаления символов из удалённой электронной таблицы](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/{TextProcessingController}/RemoveCharactersInRemoteSpreadsheet) определяет общедоступное программное интерфейсное описание и позволяет выполнять взаимодействие REST непосредственно из веб-браузера.

Вы можете использовать инструмент командной строки cURL для лёгкого доступа к веб-сервисам Aspose.Cells. В следующем примере показано, как сделать вызовы в облачный API с помощью cURL.

{< tabs tabTotal="2" tabID="1" tabName1="Запрос" tabName2="Ответ" >}

{< tab tabNum="1" >}

```bash
# Использовать HTTPS для безопасного соединения
curl -v "https://api.aspose.cloud/v4.0/cells/{name}/worksheets/{worksheet}/range/{range}/content/remove/characters?removeTextMethod={removeTextMethod}&characterSets={characterSets}&removeCustomValue={removeCustomValue}&caseSensitive={caseSensitive}&folder={folder}&storageName={storageName}&region={region}&password={password}" \
  -X PUT \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer <jwt token>"
```
