Автоматически удаляйте все пустые листы из книг Excel с помощью Aspose.Cells Cloud API. Наш интеллектуальный API обнаруживает и удаляет листы, не содержащие данных, формул, диаграмм, комментариев или объектов, при этом сохраняя все заполненные листы. Поддерживает пакетную обработку, облачную автоматизацию и бесшовную интеграцию для корпоративных рабочих процессов очистки книг.

## **DeleteSpreadsheetBlankWorksheets API**

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/delete/blank-worksheets
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе токена JWT</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### **Параметры запроса:**

| Имя параметра | Тип   | Путь / Строка запроса / HTTP-тело | Описание                                                                                                                                                                                                 |
| :------------ | :---- | :------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet   | File  | FormData                        | **Обязательный параметр**. Файл книги Excel, подлежащий очистке. Поддерживаемые форматы: `.xlsx`, `.xls`, `.xlsm`, `.xlsb`, `.ods`.                                                                      |
| outPath       | String| Query                           | **Необязательный параметр**. Путь к целевой папке в облачном хранилище, куда будет сохранен выходной файл. Если оставить пустым или задать значение `null`, обработанный файл будет сохранен в папке по умолчанию или в той же директории, что и исходный файл. |
| outStorageName| String| Query                           | **Обязательный параметр**. Имя настроенного облачного сервиса хранения, куда следует сохранить выходной файл (например, `MyFirstStorage`). Этот параметр определяет, в каком хранилище будут записаны результаты. |
| region        | String| Query                           | **Необязательный параметр**. Региональные/локальные настройки, применяемые при обработке книги, например `en-US` или `zh-CN`. Может повлиять на обработку форматов дат, чисел и текста.                      |
| password      | String| Query                           | **Необязательный параметр**. Пароль, необходимый для открытия защищенной паролем книги Excel. Этот параметр можно опустить, если загруженный файл не зашифрован.                                           |

## **Ответ**

API возвращает обработанную книгу в виде потока данных.

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

- **Код успешного ответа:** `200 OK` — книга была обработана, очищенный файл возвращён в теле ответа.  
- **Content-Type:** `application/octet-stream`

### Коды ошибок

- **400 Bad Request**: Неверный URI API Aspose.Cells Cloud.  
- **401 Unauthorized**: Неверный токен доступа, либо неверные client ID и secret.  
- **404 Not Found**: Файл таблицы недоступен.  
- **500 Server Error**: В книге произошла ошибка при получении данных для расчётов.

## Где следует использовать API удаления пустых листов из таблицы?

- **Очистка после объединения данных**: После объединения данных из нескольких исходных файлов в одну книгу автоматически удаляйте оставшиеся или заглушки листы, созданные в процессе, но не содержащие данных.  
- **Генерация отчётов на основе шаблонов**: В рабочих процессах, использующих шаблоны Excel с несколькими предопределёнными листами, удаляйте все неиспользуемые листы шаблона после заполнения только нужных данными.  
- **Автоматизированные конвейеры обработки данных (ETL)**: Как этап предварительной обработки для очистки книг Excel, полученных из различных систем или загруженных пользователями, перед дальнейшим анализом, хранением или интеграцией, чтобы обрабатывались только листы с реальным содержимым.  
- **Оптимизация и миграция устаревших книг**: При модернизации или объединении старых, разросшихся файлов Excel, которые со временем нередко накапливают множество пустых или устаревших листов.  
- **Порталы пользовательского контента**: Очищайте и стандартизируйте книги, загружаемые пользователями через веб-приложения или формы, удаляя случайно созданные пустые листы для поддержания профессионального и согласованного качества файлов.
