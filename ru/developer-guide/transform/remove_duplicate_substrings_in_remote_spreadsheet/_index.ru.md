## Удаление дублирующихся подстрок в удалённой электронной таблице с помощью веб-сервисов Aspose.Cells Cloud

Находит и удаляет повторяющиеся подстроки внутри каждой ячейки выбранного диапазона, используя пользовательские или предустановленные разделители, сохраняя при этом формулы, форматирование и проверку данных.

**Как обнаруживаются дубликаты**  
1. Значение каждой ячейки разбивается на подстроки с помощью выбранных разделителей.  
2. Инструмент сравнивает подстроки **в пределах одной и той же ячейки** и сохраняет только **первое вхождение** каждой дублирующейся подстроки.  
3. Очищенные подстроки объединяются обратно с теми же разделителями и записываются обратно в ячейку.  

**Варианты разделителей**  
- Предустановленный список: запятая, точка с запятой, пробел, табуляция, разрыв строки  
- `Custom` (пользовательский) — введите любой(е) символ(ы); несколько символов рассматриваются как один составной разделитель  
- `TreatConsecutiveDelimitersAsOne` — объединять смежные разделители в один разделитель  

Обрабатываются только ячейки строкового типа; числа, логические значения и формулы преобразуются в строку перед разбиением (формулы отбрасываются). Возвращает количество очищенных ячеек и обновлённый поток рабочей книги.

### Конечная точка веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/{name}/worksheets/{worksheet}/range/{range}/content/remove/duplicate-substrings
```

### **Безопасность и аутентификация**

Aspose.Cells Cloud API защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

### Параметры запроса

| Имя параметра | Тип | Путь/Строка запроса/HTTP-тело | Описание |
|---------------|------|-------------------------------|----------|
| name | string | Path | (Обязательный) Имя файла рабочей книги, который необходимо получить. |
| worksheet | string | Path | Указать лист электронной таблицы. |
| range | string | Path | Указать диапазон листа электронной таблицы. |
| delimiters | string | Query | Разделители, используемые для разбиения значений ячеек (например, запятая, точка с запятой, пробел, табуляция, разрыв строки). Обязательный параметр. |
| treatConsecutiveDelimitersAsOne | boolean | Query | Объединять смежные разделители в один разделитель. По умолчанию: true. Необязательный. |
| caseSensitive | boolean | Query | Выполнять сравнение с учётом регистра при обнаружении дубликатов. Необязательный. |
| folder | string | Query | (Необязательный) Путь к папке, где хранится рабочая книга. По умолчанию: null. |
| storageName | string | Query | (Необязательный) Имя хранилища при использовании пользовательского облачного хранилища. |
| region | string | Query | Региональные/языковые настройки электронной таблицы (например, `en-US`, `fr-FR`). Необязательный. |
| password | string | Query | Пароль для открытия файла электронной таблицы. Необязательный. |

### Параметр тела запроса

| Имя параметра | Тип | Описание |
| -------------- | ---- | ----------- |
| - | - | Для этой операции тело запроса не требуется. |

### **Ответ**

```json
{
  "code": 200,
  "status": "OK",
  "cellsCount": 123,
  "file": "base64-encoded workbook stream"
}
```

**Коды статусов ответа**

| Код | Значение | Описание |
|-----|----------|----------|
| 200 | OK | Операция выполнена успешно; возвращает количество очищенных ячеек и обновлённый поток рабочей книги. |
| 400 | Bad Request | Один или несколько параметров запроса отсутствуют или недействительны. |
| 401 | Unauthorized | Не удалось пройти аутентификацию или JWT-токен отсутствует/недействителен. |
| 413 | Payload Too Large | Размер запроса превышает допустимые ограничения. |
| 500 | Internal Server Error | На сервере произошла непредвиденная ошибка. |
