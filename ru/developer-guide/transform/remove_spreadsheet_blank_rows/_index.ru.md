## Удаление пустых строк из электронной таблицы в веб-сервисах Aspose.Cells Cloud

Этот метод удаляет из электронной таблицы строки, полностью пустые, то есть не содержащие данных или объектов. Процесс сканирует все листы и определяет строки, в которых все ячейки пусты. Операция выполняется непосредственно над электронной таблицей, гарантируя, что будут удалены только строки без содержимого. Это помогает очистить электронную таблицу и убрать ненужные пустые строки, делая данные более структурированными и удобными для управления. Перед выполнением этой операции пользователи должны убедиться, что у них есть резервная копия электронной таблицы, поскольку удалённые строки восстановлению не подлежат.

### Конечная точка веб-API

```http
PUT https://api.aspose.cloud/v4.0/cells/remove/blank-rows
```

### **Безопасность и аутентификация**

Веб-API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе токена JWT</a>.

### Параметры запроса

| Имя параметра | Тип   | Путь/Строка запроса/Тело HTTP-запроса | Описание |
|---------------|-------|----------------------------------------|----------|
| Spreadsheet   | File  | FormData                               | Загрузка файла электронной таблицы. |
| outPath       | String | Query                                | (Необязательно) Путь к папке, где хранится рабочая книга. По умолчанию — null. |
| outStorageName| String | Query                                | Имя хранилища для выходного файла. |
| region        | String | Query                                | Языковой/региональный параметр электронной таблицы (например, `en-US`, `fr-FR`). Влияет на форматирование чисел, разбор дат и поведение, зависящее от локали. |
| password      | String | Query                                | Пароль для открытия файла электронной таблицы. |

### Параметр тела запроса

| Имя параметра | Тип | Описание |
| ------------- | ---- | ----------- |
| Spreadsheet   | File | Загрузка файла электронной таблицы. |

### **Ответ**

```json
{
  "ResponseFile": "поток двоичных данных"
}
```

**Коды статуса ответа**

| Код | Значение | Описание |
|-----|----------|----------|
| 200 | OK | Возвращается обработанный файл электронной таблицы с удалёнными пустыми строками. |
| 400 | Bad Request | Некорректный URL или параметры запроса. |
| 401 | Unauthorized | Аутентификация не удалась или учётные данные не предоставлены. |
| 404 | Not Found | Исходный файл недоступен. |
| 413 | Payload Too Large | Размер полезной нагрузки запроса превышает допустимый предел. |
| 500 | Internal Server Error | При получении данных возникла ошибка в электронной таблице. |

### Спецификация удаления пустых строк из электронной таблицы

[Спецификация API удаления пустых строк из электронной таблицы](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Transform/RemoveSpreadsheetBlankRows) определяет публично доступное программное интерфейсное описание и позволяет выполнять REST-взаимодействия непосредственно из веб-браузера.

Вы можете использовать утилиту командной строки cURL для простого доступа к веб-сервисам Aspose.Cells Cloud. Пример ниже показывает, как выполнять вызовы в облачный API с помощью cURL.
