Автоматический обмен данными между любыми двумя столбцами, строками, диапазонами или ячейками в файлах Excel с использованием API Aspose.Cells Cloud. API обмена диапазонами позволяет точно обменивать данные, сохраняя всё форматирование, формулы и ссылки на ячейки. Он поддерживает сложную реорганизацию данных, пакетную обработку и бесшовную интеграцию с облаком для корпоративных рабочих процессов.

## **API обмена диапазонами**

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/swap/range
```

### **Безопасность и аутентификация**

API Aspose.Cells Cloud защищены и требуют <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">аутентификации на основе JWT-токена</a>.

```bash
-H "Authorization: Bearer {access_token}"
```

### **Параметры запроса**

| Имя параметра      | Тип    | Расположение | Описание                                                                                                                                        |
| ------------------ | ------ | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Spreadsheet**    | File   | FormData     | **Обязательный.** Исходный файл рабочей книги Excel (`.xlsx`, `.xls`).                                                                          |
| **worksheet1**     | String | Query        | **Обязательный.** Имя листа, содержащего первую область данных.                                                                                 |
| **range1**         | String | Query        | **Обязательный.** Диапазон ячеек (например, `A1:D10`) в `worksheet1`, который нужно обменять.                                                    |
| **worksheet2**     | String | Query        | **Обязательный.** Имя листа, содержащего вторую область данных (может совпадать с `worksheet1`).                                                 |
| **range2**         | String | Query        | **Обязательный.** Диапазон ячеек (например, `F1:I10`) в `worksheet2`, который нужно обменять. **Важно:** `range1` и `range2` должны иметь одинаковые размеры. |
| **outPath**        | String | Query        | **Необязательный.** Папка облачного хранилища, в которую будет сохранена изменённая рабочая книга.                                              |
| **outStorageName** | String | Query        | **Обязательный.** Имя настроенного облачного сервиса хранения (например, `MyCompanyStorage`).                                                   |
| **region**         | String | Query        | **Необязательный.** Языковой стандарт (например, `en-US`, `ja-JP`), который может влиять на форматирование.                                     |
| **password**       | String | Query        | **Необязательный.** Пароль для расшифровки защищённой таблицы. Пропустите, если файл не зашифрован.                                              |

**Пример запроса (cURL)**  

```bash
curl -X PUT "https://api.aspose.cloud/v4.0/cells/swap/range?worksheet1=Sheet1&range1=A1:D10&worksheet2=Sheet2&range2=F1:I10&outStorageName=MyCompanyStorage" \
     -H "Authorization: Bearer {access_token}" \
     -F "Spreadsheet=@/path/to/workbook.xlsx"
```

### **Ответ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**Примечания:**  
- API возвращает изменённую рабочую книгу в виде потока данных. Если указан `outPath`, файл также сохраняется в указанной папке облачного хранилища.  
- Несоответствие размеров диапазонов приведёт к ошибке **400 Bad Request**.

### Коды ошибок

| Код                  | Описание                                                                 |
| -------------------- | ------------------------------------------------------------------------ |
| **400 Bad Request**  | Неверный URI запроса или несоответствие размеров диапазонов.             |
| **401 Unauthorized** | Неверный или просроченный токен доступа; неверные client-id или secret.  |
| **404 Not Found**    | Указанный файл таблицы не может быть доступен.                          |
| **500 Server Error** | Внутренняя ошибка при обработке рабочей книги.                          |

## Где следует использовать API обмена диапазонами?

- **Перестройка финансовых моделей** – реорганизация блоков данных (например, перемещение прогноза Q3 в Q4) с сохранением формул и условного форматирования.
- **Конвейеры данных и ETL-процессы** – обмен диапазонами исходных данных с очищенными диапазонами во промежуточном листе перед финальным выводом.
- **Исправление ошибок и восстановление данных** – быстрое исправление неправильно размещённых данных без ручного копирования и вставки.

## Почему использовать API обмена диапазонами?

- **Удобно для разработчиков** – SDK доступны для множества языков программирования, что снижает усилия по разработке по сравнению с созданием собственных решений.
- **Снижает трудозатраты** – автоматизирует перестановку данных, уменьшая потребность в ручной сводке.
- **Оплата по факту использования** – вы платите только за фактически выполненные вызовы API.
- **Отсутствие затрат на обслуживание** – нет необходимости управлять серверами, обновлять программное обеспечение или беспокоиться о совместимости.
