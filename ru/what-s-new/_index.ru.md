# Самый важный релиз

- **Самая новая версия Aspose.Cells Cloud 4.0 уже доступна. Этот выпуск был переработан для повышения эффективности и простоты, обеспечивая стабильный и надежный опыт использования.**
- **Самый новый SDK объединяет все API из Aspose.Cells Cloud 3.0 и 4.0, упрощая процесс разработки и делая его более практичным и удобным.**
