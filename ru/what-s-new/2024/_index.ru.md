Добро пожаловать в раздел документации «Что нового в Aspose.Cells Cloud». Используйте эту страницу для быстрого поиска последних изменений. Данный журнал изменений содержит краткое описание основных улучшений, исправлений ошибок и новых API, представленных в каждом релизе Aspose.Cells Cloud в 2024 году.

## Улучшения в версии 24.12

- Добавлен новый **API удаления дубликатов**.  
- Добавлен новый **API извлечения текста**.  
- Исправлена ошибка, при которой создание сводного фильтра могло завершиться неудачей.

## Улучшения в версии 24.11

- Добавлена функция преобразования текста в `TextProcessingController`.

## Улучшения в версии 24.10

- Добавлена функция удаления символов в `TextProcessingController`.

## Улучшения в версии 24.9

- Добавлена функция изменения регистра слов в `TextProcessingController`.  
- Поддержка экспорта рабочего листа в HTML с указанием адресов ячеек или их идентификаторов.

## Улучшения в версии 24.8

- Добавлена функция обрезки текста в службах Cells Cloud.

## Улучшения в версии 24.7

- Введён API **AddTextContent** для вставки произвольного текста в рабочий лист.  
- Добавлена возможность получения токена доступа с использованием идентификатора клиента и секрета клиента.

## Улучшения в версии 24.6.1

- Исправлены расширенные параметры запроса для API.

## Улучшения в версии 24.6.0

- Оптимизированы этапы преобразования данных.  
- Оптимизирована функция загрузки данных для преобразования данных.  
- Расширена поддержка .NET Framework 4.2.5 и .NET Standard 2.0.

## Улучшения в версии 24.5.1

- Добавлен метод слияния запросов для загрузки данных в преобразовании данных.  
- Оптимизирована модель данных диаграммы.  
- Обновлена конечная точка получения токена доступа.

## Улучшения в версии 24.4

- Поддержана функция преобразования данных в службах Aspose.Cells Cloud.

## Улучшения в версии 24.3

- Поддержана дедупликация данных (усовершенствованная).  
- Поддержана заполнение данных.  
- Поддержана удаление неполных строк.  
- Поддержана очистка данных.

## Улучшения в версии 24.2.1

- Поддержана дедупликация данных (первоначальная поддержка, расширена в последующих версиях).

## Улучшения в версии 24.1.1

- Исправлены орфографические ошибки в нескольких функциях.  
- Добавлен метод `PostFitTallToPages` в `PageSetupController`.  
- Добавлен метод `PostFitWideToPages` в `PageSetupController`.  
- Оптимизированы параметры постраничного сохранения.
