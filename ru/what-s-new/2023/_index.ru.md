Добро пожаловать в раздел «Что нового» в документации Aspose.Cells Cloud. На этой странице представлены **новые функции Aspose.Cells Cloud за 2023 год**, а также представлена возможность быстро найти последние изменения.

**Последнее обновление:** июль 2026 г.

## Улучшения в версии 23.12.0

- Добавлен параметр `region` в API конвертации.  
- Добавлен параметр `region` в API защиты.  
- Добавлен параметр `region` в API сборки данных.  
- Добавлен параметр `region` в API объединения файлов.  
- Добавлен параметр `region` в API разделения файлов.  
- Добавлен параметр `region` в API импорта данных.  
- Добавлен параметр `region` в API водяных знаков.  
- Добавлен параметр `region` в API очистки объектов.  
- Добавлен параметр `region` в API обратного преобразования данных.  
- Добавлен параметр `region` в API вращения данных.  

## Улучшения в версии 23.11

- Оптимизирован импорт данных XML в файлы Excel.  
- Оптимизирован импорт данных JSON в файлы Excel.  
- Удалены устаревшие функции, классы и тестовые сценарии.  

## Улучшения в версии 23.10

- Исправлен запрос на защиту книги.  
- Исправлен API копирования диапазона.  
- Оптимизирован API защиты книги.  

## Улучшения в версии 23.9

- Добавлена поддержка сортировки данных в контроллере диапазона.  
- Добавлена функция удаления дублирующихся данных для объектов списка.  
- Добавлена вставка срезов для объектов списка.  
- Оптимизированы объекты списка и связанные компоненты.  

## Улучшения в версии 23.8

- Добавлена поддержка API блокировки.  
- Оптимизирован API защиты.  

## Aspose.Cells Cloud 23.7

- Добавлена поддержка восстановления файлов.  
- Оптимизированы функции конвертации.  

## Aspose.Cells Cloud 23.6

- Добавлена пакетная разблокировка для нескольких файлов.

- Добавлена пакетная разбивка для нескольких файлов.

- Исправлены опечатки в именах методов.  

## Aspose.Cells Cloud 23.4
