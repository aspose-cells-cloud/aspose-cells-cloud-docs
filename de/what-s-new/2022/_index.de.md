Willkommen bei „Was ist neu in Aspose.Cells Cloud“ in der Dokumentation. Nutzen Sie diese Seite, um die neuesten Änderungen schnell zu finden.

## Aspose.Cells Cloud 22.12

- Unterstützung für Diagramm-Achsenoperationen.

## Aspose.Cells Cloud 22.11

- Neue API zum Konvertieren in JSON hinzugefügt.
- Neue API zum Konvertieren in SQL hinzugefügt.
- Neue API zum Konvertieren in CSV hinzugefügt.

## Aspose.Cells Cloud 22.10

- Neue API zum Konvertieren in PPTX hinzugefügt.
- Neue API zum Konvertieren in Markdown hinzugefügt.
- Neue API zum Konvertieren in HTML hinzugefügt.

## Aspose.Cells Cloud 22.9

- Unterstützung beim Exportieren von Seiten in andere Dateiformate.
- Neue API zum Konvertieren in PDF hinzugefügt.
- Neue API zum Konvertieren in PNG hinzugefügt.
- Neue API zum Konvertieren in DOCX hinzugefügt.

## Aspose.Cells Cloud 22.8

- Unterstützung beim Transponieren von Excel-Zeilen in Spalten.

## Aspose.Cells Cloud 22.7

- Verbesserung der Save-API in den Cells-Clouddiensten (vier weitere Save-Optionen hinzugefügt).
- Optimierung des LightCellsController in Cells Cloud.

## Aspose.Cells Cloud 22.6

- [Verbesserung der Cells-Cloud-APIs.](/cells/aspose-cells-cloud-22-6-release-notes/)
- Unterstützung zum Konvertieren von Dateien innerhalb eines ZIP-Pakets in verschiedene Formate.

## Aspose.Cells Cloud 22.5

- [Verbesserung der Export-API.](https://docs.aspose.cloud/cells/export/)
- [Verbesserung der Clear-API.](https://docs.aspose.cloud/cells/clear/)

## Aspose.Cells Cloud 22.4

- Behebung einiger Fehler.
- [Verbesserung der Swagger-UI.](https://apireference.aspose.cloud/cells/)

## Aspose.Cells Cloud 22.3

- [Neue API zur Erstellung von Codegen-Spezifikationen hinzugefügt.](https://api.aspose.cloud/v3.0/cells/codegen/spec)
- [Unterstützung zum Hinzufügen einer digitalen Signatur für Aspose.Cells Cloud.](/cells/workbook/digital-signature/)
