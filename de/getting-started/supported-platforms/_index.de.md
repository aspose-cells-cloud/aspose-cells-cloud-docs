Aspose.Cells Cloud bietet eine plattformunabhängige, echte REST API zur Dokumentbearbeitung an. Sie funktioniert mit jeder Sprache, die HTTP-Anfragen senden kann, wie z. B. Go, Java, .NET, Node.js, Perl, PHP, Python, Ruby und vielen weiteren. Da der Dienst über standardmäßige REST-Aufrufe aufgerufen wird, bestehen keine sprach- oder Plattformabhängigkeitseinschränkungen. Sie können die API aus Web-, Desktop-, Mobile- oder Cloud-Umgebungen heraus aufrufen. Die API lässt sich zudem nahtlos in andere Cloud-Dienste integrieren und bietet so die Flexibilität, die für die Verarbeitung von Excel-, PDF-, CSV-, JSON- und weiteren Dokumentformaten in sämtlichen Geschäftsprozessen erforderlich ist.

Der Dienst unterstützt die neuesten Versionen von Windows, gängige Linux-Distributionen (Ubuntu, CentOS, Debian) sowie macOS. SDKs stehen für .NET, Java, Python, PHP, Ruby, Go und Node.js zur Verfügung; jedes davon enthält umfangreiche Codebeispiele. Docker-Images werden bereitgestellt, um die Bereitstellung in containerisierten Umgebungen zu vereinfachen und es Ihnen so zu ermöglichen, die API lokal oder in der Cloud mit minimalem Konfigurationsaufwand auszuführen.
