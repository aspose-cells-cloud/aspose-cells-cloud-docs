## Excel-Textmanipulations-APIs

Aspose.Cells Cloud bietet eine Sammlung von REST-Endpunkten, mit denen Sie Text in Excel-Arbeitsblättern bearbeiten können. Diese Vorgänge decken alltägliche Aufgaben wie das Trimmen von Leerzeichen, das Aufteilen von Zeichenfolgen, das Konvertieren von Groß-/Kleinschreibung, das Extrahieren von Teilzeichenfolgen und das Entfernen unerwünschter Zeichen ab.

**Voraussetzungen:** Alle Anfragen müssen mithilfe eines gültigen Zugriffstokens authentifiziert werden, das im `Authorization`-Header übergeben wird. Einzelheiten zum Abrufen und Verwenden von Tokens finden Sie in der Authentifizierungsanleitung.
