## Arbeiten mit Aufgaben

Aspose.Cells Cloud bietet eine **Task API**, mit der Entwickler eine Vielzahl von Vorgängen an Excel-Arbeitsmappen durchführen können, z. B. das Konvertieren von Dateiformaten, das Importieren von Daten, das Ausführen von SmartMarker-Vorlagen und das Speichern von Ergebnissen. Aufgaben werden asynchron ausgeführt: Sie erstellen eine Aufgabe, führen sie aus und rufen das Ergebnis ab.

**Voraussetzungen:** Ein Aspose Cloud-Konto mit gültigem API-Schlüssel, unterstützte Excel-Dateiformate sowie die neueste Version der Cells API (v3.0+).

- [Support Request File in der Task API](/cells/support-request-file-in-task-api/) – Ermöglicht das Hochladen einer Datei in den Cloud-Speicher und deren Verweisnahme in nachfolgenden Aufgaben, sodass die Datei für die Verarbeitung verfügbar ist.
- [Arbeiten mit der CellsObjectOperate-Aufgabe](/cells/working-with-cellsobjectoperate-task/) – Führt Vorgänge an Zellobjekten (z. B. Zeilen, Spalten) innerhalb einer Arbeitsmappe aus, z. B. Hinzufügen, Löschen oder Aktualisieren von Zellwerten.
- [Arbeiten mit der Konvertierungsaufgabe](/cells/working-with-convert-task/) – Konvertiert eine Arbeitsmappe in die Formate PDF, HTML, CSV oder JSON, mit Optionen für Seitenbereich, Passwortschutz sowie benutzerdefinierte Konvertierungseinstellungen.
- [Arbeiten mit der ImportData-Aufgabe](/cells/working-with-importdata-task/) – Importiert Daten aus CSV-, JSON- oder XML-Dateien in ein Arbeitsblatt, wobei Spalten Zellen zugeordnet werden und optional die Startzeile sowie -spalte angegeben werden können.
- [Arbeiten mit der SaveResult-Aufgabe](/cells/working-with-saveresult-task/) – Speichert das Ergebnis einer zuvor ausgeführten Aufgabe (z. B. einer konvertierten Datei) erneut im Cloud-Speicher oder gibt es in der Antwort zurück.
- [Arbeiten mit der SmartMarker-Aufgabe](/cells/working-with-smartmarker-task/) – Verarbeitet eine Arbeitsmappe, die SmartMarker-Tags (z. B. `{{Customer.Name}}`) enthält, mithilfe einer JSON-Datenquelle, um einen ausgefüllten Bericht zu generieren.
- [Arbeiten mit WorksheetOperates in der Task API](/cells/working-with-worksheetoperates-in-task-api/) – Führt arbeitsblattübergreifende Vorgänge wie Hinzufügen, Löschen oder Umbenennen von Arbeitsblättern im Rahmen eines Aufgaben-Workflows aus.

Für vollständige Methodenspezifikationen – einschließlich HTTP-Verben, Endpunkt-URLs, Anfrage-/Antwort-Schemata, Parameter-Tabellen und Beispiel-Payloads – verweisen Sie auf die oben verlinkten einzelnen Aufgabenseiten. Diese detaillierte API-Referenz hilft Entwicklern, die Tasks API schnell und zuverlässig zu integrieren.
