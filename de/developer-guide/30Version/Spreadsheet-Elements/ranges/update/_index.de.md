## Arbeiten mit der Aktualisierung von Bereichsinhalten in einer Excel-Arbeitsmappe

Bevor Sie die Aktualisierungsvorgänge verwenden, stellen Sie sicher, dass Sie ein gültiges Aspose.Cells Cloud API-Token besitzen und die Zielarbeitsmappe in Ihrem Cloud-Speicher gespeichert ist. Die API steht über SDKs für Android, .NET, Go, Java, Node.js, Perl, PHP, Python, Ruby und Swift zur Verfügung.

Eine knappe Zusammenfassung der vier Hauptaktualisierungsaktionen ist nachfolgend dargestellt. Diese Tabelle bietet Entwicklern eine schnelle Übersicht über die HTTP-Methode, das Endpoint-Muster, die wichtigsten Parameter und die typische Erfolgsantwort (200-OK) für jeden Vorgang.

| Aktion             | HTTP-Methode | Endpoint-Muster                                                                                      | Wichtige Parameter           | 200‑OK-Antwort             |
|--------------------|--------------|------------------------------------------------------------------------------------------------------|------------------------------|----------------------------|
| Formatierung setzen | PUT          | `/cells/{fileName}/worksheets/{sheetName}/ranges/{range}/style`                                      | `style`-Objekt               | Aktualisierte Bereichsformatierung |
| Werte setzen       | POST         | `/cells/{fileName}/worksheets/{sheetName}/ranges/{range}/values`                                    | `values`-Array               | Aktualisierte Bereichswerte |
| Zeilenhöhe         | PUT          | `/cells/{fileName}/worksheets/{sheetName}/ranges/{range}/rowheight`                                 | `height`-Zahl                | Aktualisierte Zeilenhöhe    |
| Spaltenbreite      | PUT          | `/cells/{fileName}/worksheets/{sheetName}/ranges/{range}/columnwidth`                               | `width`-Zahl                 | Aktualisierte Spaltenbreite |

Diese Seite bietet schnellen Zugriff auf die vier Hauptaktualisierungsaktionen: Festlegen der Formatierung eines Bereichs, Festlegen der Werte eines Bereichs, Anpassen der Zeilenhöhen und Anpassen der Spaltenbreiten.
