## Zusammenführen und Teilen mit Excel-Dateien

Die folgenden Anleitungen zeigen, wie Sie mehrere Excel-Arbeitsmappen in einer einzigen Datei zusammenführen oder eine Arbeitsmappe in mehrere Dateien aufteilen können – mithilfe von Aspose.Cells Cloud.

- **Mehrere Dateien zusammenführen:** [So führen Sie mehrere Excel-Dateien in einer einzigen Arbeitsmappe zusammen](/cells/merge-multi-files-into-excel/) – Verschmelzen Sie mehrere Arbeitsmappen zu einer einzigen konsolidierten Arbeitsmappe.  
- **In vorhandene Arbeitsmappe zusammenführen:** [So führen Sie eine Excel-Arbeitsmappe in eine andere Arbeitsmappe zusammen](/cells/merge-an-excel-file-into-the-excel-file/) – Fügen Sie den Inhalt einer Arbeitsmappe in eine bestehende Arbeitsmappe ein.  
- **Mehrere Dateien teilen:** [So teilen Sie mehrere Excel-Dateien](/cells/split-multi-excel-files/) – Trennen Sie eine Sammlung von Arbeitsmappen in einzelne Dateien.  
- **In mehrere Dateien teilen:** [So teilen Sie eine Excel-Arbeitsmappe in mehrere Dateien](/cells/split-an-excel-file-to-multi-files/) – Zerlegen Sie eine einzelne Arbeitsmappe in mehrere kleinere Arbeitsmappen.
