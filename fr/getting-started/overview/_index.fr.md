Aspose.Cells Cloud est une API REST qui permet d’accomplir une grande variété de tâches de traitement de documents, telles que la création, la manipulation, la conversion et la restitution de documents Excel dans le cloud. Vous pouvez aisément convertir des fichiers Excel vers divers formats, notamment :

- PDF  
- HTML  
- ODS  
- XPS  
- CSV  
- et d’autres formats populaires  

**Prérequis :** Pour utiliser ce service, vous devez disposer d’un compte Aspose Cloud et d’une clé API valide. Ces identifiants sont requis pour toutes les requêtes authentifiées.

## **SDK**

L’utilisation d’un SDK (client API) accélère le développement en gérant les détails de bas niveau liés aux requêtes et à la gestion des réponses, ce qui permet aux développeurs de se concentrer sur le code spécifique à leur projet. Consultez notre <a href="https://github.com/aspose-cells-cloud" rel="noopener noreferrer">dépôt GitHub</a> pour obtenir la liste complète des SDK Aspose.Cells, accompagnée d’exemples fonctionnels afin d’accélérer le développement de votre projet. Reportez-vous à notre article « [SDK disponibles](/cells/available-sdks/) » pour apprendre comment intégrer un SDK dans votre projet.

## **Explorateur d’API**

L’<a href="https://apireference.aspose.cloud/cells/" rel="noopener noreferrer">Explorateur d’API Aspose.Cells Cloud</a> propose une méthode intuitive pour expérimenter directement les API depuis votre navigateur. Il permet d’interagir et de tester de façon fluide chaque opération mise à disposition par le service. Pour démarrer rapidement, vous pouvez essayer l’exemple « Convertir un classeur », qui illustre une simple requête POST permettant de convertir un fichier Excel en PDF.

### **Sécurité et authentification**

Les API Aspose.Cells Cloud sont sécurisées et exigent une <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">authentification basée sur un jeton JWT</a>.
