Aspose.Cells Cloud propose une API REST indépendante de la plateforme, véritable API RESTful, destinée à la manipulation de documents. Elle fonctionne avec tout langage capable d’envoyer des requêtes HTTP, tels que Go, Java, .NET, Node.js, Perl, PHP, Python, Ruby, et bien d’autres encore. Comme le service est accessible via des appels REST standard, aucune limitation liée au langage ou à la plateforme n’existe. Vous pouvez invoquer l’API à partir d’environnements web, de bureau, mobiles ou cloud. L’API s’intègre également à d’autres services cloud, offrant ainsi la flexibilité nécessaire au traitement des formats de documents Excel, PDF, CSV, JSON et bien d’autres, dans toutes les scénarios métier.

Le service prend en charge les dernières versions de Windows, les distributions Linux les plus populaires (Ubuntu, CentOS, Debian) ainsi que macOS. Des SDK sont disponibles pour .NET, Java, Python, PHP, Ruby, Go et Node.js, chacun accompagné d’exemples de code complets. Des images Docker sont également fournies afin de simplifier le déploiement dans des environnements conteneurisés, vous permettant d’exécuter l’API localement ou dans le cloud avec une configuration minimale.
