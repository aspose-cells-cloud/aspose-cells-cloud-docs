La fonctionnalité **Recherche et remplacement** de l’API Cloud Aspose.Cells permet aux développeurs de localiser et de remplacer de manière programmatique du texte, des formules ou des liens hypertexte dans des classeurs Excel stockés dans le cloud.

- **[Remplacer le contenu dans une feuille de calcul distante](https://docs.aspose.cloud/cells/replace-content-in-remote-spreadsheet/)** – Remplace toutes les occurrences d’une chaîne spécifiée dans un classeur stocké sur le stockage Aspose Cloud.  
- **[Remplacer le contenu d’une plage dans une feuille de calcul distante](https://docs.aspose.cloud/cells/replace-content-in-remote-range/)** – Remplace le contenu dans une plage de cellules définie d’un classeur distant.  
- **[Remplacer le contenu d’une feuille de calcul](https://docs.aspose.cloud/cells/replace-spreadsheet-content/)** – Fournit une opération de remplacement en masse pour l’ensemble de la feuille de calcul.  
- **[Remplacer le contenu d’une feuille dans une feuille de calcul distante](https://docs.aspose.cloud/cells/replace-content-in-remote-worksheet/)** – Remplace du texte dans une feuille spécifique d’un classeur distant.  
- **[Rechercher les liens hypertexte brisés dans une plage d’une feuille de calcul distante](https://docs.aspose.cloud/cells/search-broken-links-in-remote-range/)** – Localise et signale les liens hypertexte brisés dans une plage définie.  
- **[Rechercher les liens hypertexte brisés dans une feuille d’une feuille de calcul distante](https://docs.aspose.cloud/cells/search-broken-links-in-remote-worksheet/)** – Détecte les liens brisés sur l’ensemble d’une feuille.  
- **[Rechercher du contenu dans une feuille de calcul distante](https://docs.aspose.cloud/cells/search-content-in-remote-spreadsheet/)** – Recherche du texte, des formules ou des valeurs spécifiques dans un classeur distant.  
- **[Rechercher les liens hypertexte brisés dans des feuilles de calcul distantes](https://docs.aspose.cloud/cells/search-broken-links-in-remote-spreadsheet/)** – Analyse plusieurs classeurs à la recherche de liens hypertexte brisés.  
- **[Rechercher le contenu d’une plage dans une feuille de calcul distante](https://docs.aspose.cloud/cells/search-content-in-remote-range/)** – Recherche dans une plage de cellules spécifique.  
- **[Rechercher les liens hypertexte brisés dans une feuille de calcul](https://docs.aspose.cloud/cells/search-spreadsheet-broken-links/)** – Fournit une liste complète des liens brisés sur l’ensemble d’une feuille de calcul.  
- **[Rechercher le contenu d’une feuille de calcul](https://docs.aspose.cloud/cells/search-spreadsheet-content/)** – Recherche générale de contenu sur l’ensemble de la feuille de calcul.  
- **[Rechercher le contenu d’une feuille dans une feuille de calcul distante](https://docs.aspose.cloud/cells/search-content-in-remote-worksheet/)** – Recherche du contenu dans une feuille spécifique.
