## API de manipulation de texte Excel

Aspose.Cells Cloud propose une collection d’endpoints REST qui vous permettent de manipuler du texte à l’intérieur des feuilles de calcul Excel. Ces opérations couvrent des tâches courantes telles que le découpement des espaces blancs, le découpage des chaînes, la conversion de la casse, l’extraction de sous-chaînes et la suppression de caractères indésirables.

**Prérequis :** Toutes les requêtes doivent être authentifiées à l’aide d’un jeton d’accès valide fourni dans l’en-tête `Authorization`. Reportez-vous au guide d’authentification pour plus de détails sur l’obtention et l’utilisation des jetons.
