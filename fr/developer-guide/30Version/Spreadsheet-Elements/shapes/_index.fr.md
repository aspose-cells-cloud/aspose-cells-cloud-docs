## Travail avec les formes sur un fichier Excel

Les formes représentent des objets de dessin tels que des lignes, des rectangles, des zones de texte et des images pouvant être placés sur une feuille de calcul Excel. Elles sont utiles pour visualiser des données, ajouter des annotations ou créer des éléments interactifs au sein d’une feuille de calcul. Cette page fournit des liens rapides vers les opérations les plus courantes liées aux formes, chacune accompagnée d’une brève description.

**Prérequis :** Pour utiliser les opérations sur les formes, vous devez disposer d’une clé API valide Aspose.Cells Cloud ainsi que d’un classeur existant téléchargé dans le cloud.

- [Comment obtenir toutes les formes sur une feuille de calcul Excel.](/fr/cells/shapes/get-all/) – Récupère l’ensemble complet des formes présentes dans la feuille de calcul.
- [Comment obtenir une forme par son index sur une feuille de calcul Excel.](/fr/cells/shapes/get/) – Renvoie la forme située à l’index spécifié.
- [Comment ajouter une forme sur une feuille de calcul Excel.](/fr/cells/shapes/add/) – Insère une nouvelle forme (par exemple, un rectangle, une ligne ou une image) dans la feuille de calcul.
- [Comment supprimer toutes les formes sur une feuille de calcul Excel.](/fr/cells/shapes/clear/) – Supprime toutes les formes de la feuille de calcul en une seule opération.
- [Comment supprimer une forme par son index sur une feuille de calcul Excel.](/fr/cells/shapes/delete/) – Supprime la forme située à l’index indiqué.
- [Comment convertir une forme en image sur une feuille de calcul Excel.](/fr/cells/shapes/conversion/) – Convertit la forme sélectionnée en fichier image (PNG, JPEG, etc.) pour une utilisation externe.
