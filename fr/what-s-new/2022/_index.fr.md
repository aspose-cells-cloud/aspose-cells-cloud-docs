Bienvenue sur la page des nouveautés d'Aspose.Cells Cloud. Utilisez cette page pour retrouver rapidement les dernières modifications.

## Aspose.Cells Cloud 22.12

- Prise en charge des opérations sur les axes des graphiques.

## Aspose.Cells Cloud 22.11

- Ajout d'une nouvelle API pour convertir vers JSON.
- Ajout d'une nouvelle API pour convertir vers SQL.
- Ajout d'une nouvelle API pour convertir vers CSV.

## Aspose.Cells Cloud 22.10

- Ajout d'une nouvelle API pour convertir vers PPTX.
- Ajout d'une nouvelle API pour convertir vers Markdown.
- Ajout d'une nouvelle API pour convertir vers HTML.

## Aspose.Cells Cloud 22.9

- Prise en charge de l'exportation d'une page vers un fichier dans un autre format.
- Ajout d'une nouvelle API pour convertir vers PDF.
- Ajout d'une nouvelle API pour convertir vers PNG.
- Ajout d'une nouvelle API pour convertir vers DOCX.

## Aspose.Cells Cloud 22.8

- Prise en charge du transposition des lignes Excel en colonnes.

## Aspose.Cells Cloud 22.7

- Amélioration de l’API Save sur les services cloud Cells (ajout de quatre options d’enregistrement).
- Optimisation de LightCellsController sur les services cloud Cells.

## Aspose.Cells Cloud 22.6

- [Amélioration des API Cells Cloud.](/cells/aspose-cells-cloud-22-6-release-notes/)
- Prise en charge de la conversion de fichiers contenus dans un package ZIP vers divers formats.

## Aspose.Cells Cloud 22.5

- [Amélioration de l’API d’export.](https://docs.aspose.cloud/cells/export/)
- [Amélioration de l’API de nettoyage.](https://docs.aspose.cloud/cells/clear/)

## Aspose.Cells Cloud 22.4

- Correction de quelques bugs.
- [Amélioration de l’interface utilisateur Swagger.](https://apireference.aspose.cloud/cells/)

## Aspose.Cells Cloud 22.3

- [Ajout d'une nouvelle API relative à la génération de spécifications de codegen.](https://api.aspose.cloud/v3.0/cells/codegen/spec)
- [Prise en charge de l'ajout d'une signature numérique pour Aspose.Cells Cloud.](/cells/workbook/digital-signature/)
