# Release la plus importante

- **La dernière version d’Aspose.Cells Cloud 4.0 est désormais disponible. Cette version a été repensée pour être plus simplifiée et efficace, garantissant une expérience stable et fiable.**
- **Le dernier SDK regroupe toutes les API d’Aspose.Cells Cloud 3.0 et 4.0, simplifiant ainsi le processus de développement et le rendant plus pratique et convivial.**
