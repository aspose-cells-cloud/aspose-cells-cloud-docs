Bienvenido a la sección de novedades en la documentación de Aspose.Cells Cloud. Esta página destaca las **nuevas funciones de Aspose.Cells Cloud en 2023** y te permite localizar rápidamente los cambios más recientes.

**Última actualización:** julio de 2026  

## Mejoras en la versión 23.12.0

- Se agregó el parámetro `region` a la API de conversión.  
- Se agregó el parámetro `region` a la API de protección.  
- Se agregó el parámetro `region` a la API de ensamblado de datos.  
- Se agregó el parámetro `region` a la API de combinación de archivos.  
- Se agregó el parámetro `region` a la API de división de archivos.  
- Se agregó el parámetro `region` a la API de importación de datos.  
- Se agregó el parámetro `region` a la API de marca de agua.  
- Se agregó el parámetro `region` a la API de limpieza de objetos.  
- Se agregó el parámetro `region` a la API de inversión de datos.  
- Se agregó el parámetro `region` a la API de rotación de datos.  

## Mejoras en la versión 23.11

- Se optimizó la importación de datos XML en archivos de Excel.  
- Se optimizó la importación de datos JSON en archivos de Excel.  
- Se eliminaron funciones, clases y casos de prueba obsoletos.  

## Mejoras en la versión 23.10

- Se corrigió la solicitud de protección de libro.  
- Se corrigió la API de copia de rango.  
- Se optimizó la API de protección de libro.  

## Mejoras en la versión 23.9

- Se agregó soporte para ordenación de datos en el controlador de rango.  
- Se agregó eliminación de datos duplicados para objetos de lista.  
- Se agregó inserción de segmentadores para objetos de lista.  
- Se optimizaron los objetos de lista y componentes relacionados.  

## Mejoras en la versión 23.8

- Se agregó soporte para la API de bloqueo.  
- Se optimizó la API de protección.  

## Aspose.Cells Cloud 23.7

- Se agregó soporte para reparación de archivos.  
- Se optimizaron las funciones de conversión.  

## Aspose.Cells Cloud 23.6

- Se agregó bloqueo por lotes para múltiples archivos.  
- Se agregó desbloqueo por lotes para múltiples archivos.  
- Se agregó protección por lotes para múltiples archivos.  
- Se agregó división por lotes para múltiples archivos.  
- Se corrigió la API PUT de propiedades de documento.  

## Aspose.Cells Cloud 23.5

- Se corrigieron nombres de métodos mal escritos.  

## Aspose.Cells Cloud 23.4

- Se agregó soporte para importación y exportación de datos XML.  

## Aspose.Cells Cloud 23.3

- Se optimizaron las propiedades de hipervínculo.  

## Aspose.Cells Cloud 23.2

- Se optimizó la API de reemplazo.  
- Se optimizó la interfaz Swagger UI.  

## Aspose.Cells Cloud 23.1

- Se corrigió un error en el método `PostCellCharacters`.
