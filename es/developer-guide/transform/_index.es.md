API robustas para manipular datos de Excel, diseñadas para la gestión profesional de hojas de cálculo. Eliminan automáticamente columnas, filas y hojas en blanco, e intercambian datos entre rangos de forma fluida. Úselas para preparar hojas de cálculo para análisis, informes o integración, sin necesidad de instalar Excel.

## API para limpieza y optimización de datos en Excel

**Prerrequisitos** – Antes de llamar a cualquier API de transformación, obtenga un token de autenticación válido y asegúrese de que el libro esté almacenado en una ubicación compatible (por ejemplo, en el almacenamiento de Aspose Cloud o en una URL pública). El token debe pasarse en el encabezado `Authorization` de cada solicitud.

### Limpieza de contenido en blanco

- **[Eliminar columnas en blanco](https://docs.aspose.cloud/cells/delete-spreadsheet-blank-columns/)** – Identifique y elimine automáticamente columnas que no contengan datos, fórmulas ni objetos.  
- **[Eliminar filas en blanco](https://docs.aspose.cloud/cells/delete-spreadsheet-blank-rows/)** – Elimine todas las filas vacías preservando la estructura de la hoja.  
- **[Eliminar hojas en blanco](https://docs.aspose.cloud/cells/delete-spreadsheet-blank-worksheets/)** – Realice una limpieza de hojas vacías para reducir el tamaño del archivo y mejorar la organización.

### Manipulación y reorganización de datos

- **[Intercambiar datos entre rangos](https://docs.aspose.cloud/cells/swap-range/)** – Intercambie datos entre dos rangos, columnas, filas o celdas individuales dentro de un archivo de Excel.
