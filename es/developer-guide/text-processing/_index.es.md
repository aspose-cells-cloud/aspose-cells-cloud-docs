## APIs para manipulación de texto en Excel

Aspose.Cells Cloud ofrece una colección de puntos finales REST que le permiten manipular texto dentro de hojas de cálculo de Excel. Estas operaciones cubren tareas cotidianas como recortar espacios en blanco, dividir cadenas, convertir mayúsculas y minúsculas, extraer subcadenas y eliminar caracteres no deseados.

**Requisitos previos:** Todas las solicitudes deben estar autenticadas con un token de acceso válido proporcionado en el encabezado `Authorization`. Consulte la guía de autenticación para obtener más información sobre cómo adquirir y utilizar tokens.
