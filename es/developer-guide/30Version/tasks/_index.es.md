## Trabajar con tareas

Aspose.Cells Cloud proporciona una **API de Tareas** que permite a los desarrolladores realizar diversas operaciones en libros de Excel, como convertir formatos, importar datos, ejecutar plantillas SmartMarker y guardar resultados. Las tareas se ejecutan de forma asíncrona: se crea una tarea, se ejecuta y se recupera el resultado.

**Prerrequisitos:** una cuenta de Aspose Cloud con una clave de API válida, formatos de archivo de Excel compatibles y la versión más reciente de la API de Cells (v3.0 o superior).

- [Solicitar archivo de soporte en la API de Tareas](/cells/support-request-file-in-task-api/) – Le permite cargar un archivo en el almacenamiento en la nube y hacer referencia a él en tareas posteriores, asegurando que el archivo esté disponible para su procesamiento.
- [Trabajar con la tarea CellsObjectOperate](/cells/working-with-cellsobjectoperate-task/) – Ejecuta operaciones sobre objetos de celdas (por ejemplo, filas, columnas) dentro de un libro, como agregar, eliminar o actualizar valores de celdas.
- [Trabajar con la tarea Convert](/cells/working-with-convert-task/) – Convierte un libro a formatos PDF, HTML, CSV o JSON, con opciones para rango de páginas, protección con contraseña y configuraciones personalizadas de conversión.
- [Trabajar con la tarea ImportData](/cells/working-with-importdata-task/) – Importa datos desde archivos CSV, JSON o XML a una hoja de cálculo, asignando columnas a celdas y especificando opcionalmente la fila y columna inicial.
- [Trabajar con la tarea SaveResult](/cells/working-with-saveresult-task/) – Guarda el resultado de una tarea previamente ejecutada (por ejemplo, un archivo convertido) nuevamente en el almacenamiento en la nube o lo devuelve en la respuesta.
- [Trabajar con la tarea SmartMarker](/cells/working-with-smartmarker-task/) – Procesa un libro que contiene etiquetas SmartMarker (por ejemplo, `{{Customer.Name}}`) utilizando una fuente de datos JSON para generar un informe rellenado.
- [Trabajar con WorksheetOperates en la API de Tareas](/cells/working-with-worksheetoperates-in-task-api/) – Realiza operaciones a nivel de hoja de cálculo, como agregar, eliminar o renombrar hojas de cálculo, como parte de un flujo de trabajo de tareas.

Para obtener especificaciones completas de los métodos —incluyendo verbos HTTP, URLs de puntos de conexión, esquemas de solicitud y respuesta, tablas de parámetros y ejemplos de carga útil— consulte las páginas individuales de tareas enlazadas anteriormente. Esta referencia detallada de la API ayuda a los desarrolladores a integrar la API de Tareas de forma rápida y fiable.
