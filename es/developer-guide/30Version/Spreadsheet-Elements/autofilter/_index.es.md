El Filtro Automático es la forma más rápida de mostrar solo los elementos que necesita de una hoja de cálculo. La función de Filtro Automático permite a los usuarios filtrar una lista según criterios especificados: por texto, números o fechas.

**Diferentes tipos de filtros**

Aspose.Cells Cloud proporciona múltiples API para aplicar diversos tipos de filtros, como Filtro por Color, Filtro por Fecha, Filtro por Número, Filtro por Texto, Filtro por Celdas en Blanco y Filtro por Celdas No en Blanco.
