Realiza automáticamente cálculos como **SUMA**, **CONTAR**, **PROMEDIO**, **MÍN** y **MÁX** en hojas de cálculo de Excel mediante la API REST de Aspose.Cells Cloud: no es necesario realizar filtros manuales ni utilizar software local de hojas de cálculo. La API está disponible en **Aspose.Cells Cloud**, utiliza autenticación estándar (OAuth 2.0 o JWT), devuelve los resultados en formato JSON y proporciona códigos de error claros para intervalos inválidos o problemas de autenticación. Para obtener la sintaxis detallada de las solicitudes, consulta la referencia oficial de la API REST.

- **[Calcular por color de celda](https://docs.aspose.cloud/cells/aggregate-cells-by-color/)** – Recupera totales agrupados por color de fondo o de fuente en una única solicitud.
- **[Cálculo rápido en hoja de cálculo](https://docs.aspose.cloud/cells/math-calculate/)** – Calcula instantáneamente SUMA, CONTAR, PROMEDIO, MÍN, MÁX (y operaciones aritméticas básicas) en cualquier rango.
