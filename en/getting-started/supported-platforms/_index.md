Aspose.Cells Cloud provides a platform‑independent, true REST API for document manipulation. It works with any language that can send HTTP requests, such as Go, Java, .NET, Node.js, Perl, PHP, Python, Ruby, and many others. Because the service is accessed via standard REST calls, there are no language‑ or platform‑specific limitations. You can invoke the API from web, desktop, mobile, or cloud environments. The API also integrates with other cloud services, offering the flexibility required for processing Excel, PDF, CSV, JSON, and other document formats across all business scenarios.

## Supported Operating Systems

The service supports the latest long‑term supported (LTS) versions of major operating systems:

- **Windows**: Windows 10 and Windows 11  
- **macOS**: macOS 12 (Monterey), macOS 13 (Ventura), and macOS 14 (Sonoma)  
- **Linux**: Ubuntu 20.04 LTS, 22.04 LTS, and 24.04 LTS; CentOS 7 and 8; Debian 11 (Bullseye) and 12 (Bookworm)

> **Note**: Platform support is validated quarterly. Last updated: May 2024.

> {{< note >}}  
> Aspose.Cells Cloud is tested against *current* LTS releases. For non‑LTS or pre‑release OS versions, contact support.  
> {{< /note >}}

## Docker Images

Docker images are provided to simplify deployment in containerized environments, enabling you to run the API locally or in the cloud with minimal configuration. See the [Docker deployment guide](/docker-deployment/) for setup instructions and best practices.

## Cross‑Platform Compatibility Notes

Because Aspose.Cells Cloud is accessed via standard HTTP/HTTPS requests, it is fully language‑ and platform‑agnostic. Whether you’re building a Windows desktop app, a Linux‑hosted web service, or a macOS mobile companion, you can rely on consistent behavior across environments.

> **Deprecation Warning**: macOS 11 (Big Sur) is no longer supported as of Q1 2024. Users relying on older platforms are encouraged to upgrade to ensure continued compatibility and security updates.
