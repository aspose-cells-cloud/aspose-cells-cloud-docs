## Working with shapes on an Excel file

Shapes represent drawing objects such as lines, rectangles, text boxes, and images that can be placed on an Excel worksheet. They are useful for visualizing data, adding annotations, or creating interactive elements within a spreadsheet. This page provides quick links to the most common shape‑related operations, each accompanied by a brief description.

- [How to get all shapes on an Excel worksheet.](/cells/shapes/get-all/) – Retrieves a complete collection of shapes present in the worksheet.
- [How to get a shape by index on an Excel worksheet.](/cells/shapes/get/) – Returns the shape located at the specified index.
- [How to add a shape on an Excel worksheet.](/cells/shapes/add/) – Inserts a new shape (e.g., rectangle, line, or image) into the worksheet.
- [How to delete all shapes on an Excel worksheet.](/cells/shapes/clear/) – Removes every shape from the worksheet in a single operation.
- [How to delete a shape by index on an Excel worksheet.](/cells/shapes/delete/) – Deletes the shape at the given index.
- [How to convert a shape to an image on an Excel worksheet.](/cells/shapes/conversion/) – Converts a selected shape into an image file (PNG, JPEG, etc.) for external use.

### Prerequisites

Before proceeding with shape operations, ensure you have:

- An active Aspose.Cells Cloud account.
- A valid Client ID and Client Secret obtained from the [Aspose.Cloud dashboard](https://dashboard.aspose.cloud/).
- An Excel workbook uploaded to your cloud storage.
