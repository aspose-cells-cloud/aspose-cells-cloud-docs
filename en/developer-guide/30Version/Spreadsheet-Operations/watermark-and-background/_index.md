## Working with Backgrounds and Watermarks

This guide shows how to programmatically insert and remove backgrounds and watermarks in Excel workbooks using the Aspose.Cells Cloud API.

This page provides quick links to tutorials for managing workbook backgrounds and watermarks using Aspose.Cells Cloud:

- [How to add a background on an Excel workbook.](/cells/add-background-in-excel-file/)
- [How to delete a background on an Excel workbook.](/cells/delete-background-in-excel-file/)
- [How to add a watermark on an Excel workbook.](/cells/add-watermark-into-excel-files/)

> **Note**: Ensure you have an active [Aspose.Cells Cloud API key](https://dashboard.aspose.cloud/) and have installed the appropriate SDK (e.g., .NET, Java, Python, Node.js) before following the examples in the linked tutorials. For clarity, distinguish between _page background_ (cell fill), _worksheet background image_, and _watermark_ (semi-transparent overlay). The linked tutorials cover each scenario with code samples and screenshots.
