## Merge and Split Excel Workbooks

This guide demonstrates how to programmatically merge multiple Excel workbooks into a single file or split a workbook into separate files using the Aspose.Cells Cloud REST API. All operations can be completed in under 5 minutes with supported SDKs for Android, .NET, Go, Java, Node.js, Perl, PHP, Python, Ruby, and Swift.

- **Merge multiple files:** [How to merge multiple Excel files into a single workbook](/cells/merge-multi-files-into-excel/) – Combine several workbooks into one consolidated workbook.  
- **Merge into existing workbook:** [How to merge an Excel workbook into another workbook](/cells/merge-an-excel-file-into-the-excel-file/) – Add the contents of one workbook to an existing workbook.  
- **Split multiple files:** [How to split multiple Excel files](/cells/split-multi-excel-files/) – Separate a collection of workbooks into individual files.  
- **Split into multiple files:** [How to split an Excel workbook into multiple files](/cells/split-an-excel-file-to-multi-files/) – Divide a single workbook into several smaller workbooks.

### Prerequisites

- An Aspose.Cells Cloud account ([sign up for free](https://dashboard.aspose.cloud/)).  
- Client ID and Client Secret from the [Aspose Cloud Dashboard](https://dashboard.aspose.cloud/).  
- Aspose.Cells Cloud SDK for your preferred language (see [SDKs](/cells/)).  

> **Note**: As of v24.3, Aspose.Cells Cloud supports merging `.xlsx`, `.xlsb`, and `.xlsm` formats. For full format support, see [Supported File Formats](/cells/supported-file-formats/).

For additional context on Excel file formats, refer to the [Excel File Format Specification on Microsoft Learn](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-excel/) or the [Microsoft Excel Wikipedia page](https://en.wikipedia.org/wiki/Microsoft_Excel#File_formats).
