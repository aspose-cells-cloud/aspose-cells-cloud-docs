Aspose.Cells Cloud은 플랫폼 독립적인 진정한 REST API를 제공하여 문서 조작을 가능하게 합니다. 이는 HTTP 요청을 보낼 수 있는 모든 언어(Go, Java, .NET, Node.js, Perl, PHP, Python, Ruby 등)와 함께 작동합니다. 이 서비스는 표준 REST 호출을 통해 접근하므로 언어 또는 플랫폼에 특화된 제한이 없습니다. 웹, 데스크톱, 모바일, 클라우드 환경에서 모두 API를 호출할 수 있습니다. 또한 API는 다른 클라우드 서비스와도 통합되어, 모든 비즈니스 시나리오에서 Excel, PDF, CSV, JSON 및 기타 문서 형식을 처리할 수 있는 유연성을 제공합니다.

이 서비스는 최신 Windows 버전, 주요 Linux 배포판(Ubuntu, CentOS, Debian) 및 macOS를 지원합니다. SDK는 .NET, Java, Python, PHP, Ruby, Go, Node.js용으로 제공되며, 각 SDK에는 포괄적인 코드 샘플이 포함되어 있습니다. Docker 이미지도 제공되어 컨테이너화된 환경에서의 배포를 간소화하며, 최소한의 설정으로 API를 로컬 또는 클라우드 환경에서 실행할 수 있습니다.
