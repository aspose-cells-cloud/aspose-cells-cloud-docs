Aspose.Cells Cloud는 클라우드에서 엑셀 문서를 생성, 조작, 변환, 렌더링 등 다양한 문서 처리 작업을 수행할 수 있도록 해주는 REST API입니다. 다음을 포함한 여러 형식으로 엑셀 파일을 손쉽게 변환할 수 있습니다:

- PDF  
- HTML  
- ODS  
- XPS  
- CSV  
- 기타 다양한 일반적인 형식  

**사전 요구 사항:** 해당 서비스를 사용하려면 Aspose Cloud 계정과 유효한 API 키가 필요합니다. 이러한 자격 증명은 모든 인증된 요청에 필수적입니다.

## **SDK**

SDK(API 클라이언트)를 활용하면 요청 생성 및 응답 관리와 같은 저수준 세부 사항을 처리해 개발자가 프로젝트 고유 코드 작성에 집중할 수 있어 개발 속도가 빨라집니다. 프로젝트 개발을 가속화할 수 있는 작동 예제가 포함된 <a href="https://github.com/aspose-cells-cloud" rel="noopener noreferrer">GitHub 저장소</a>에서 Aspose.Cells SDK의 전체 목록을 확인하세요. SDK를 프로젝트에 통합하는 방법은 "[사용 가능한 SDK](/cells/available-sdks/)" 문서를 참조하세요.

## **API 탐색기**

<a href="https://apireference.aspose.cloud/cells/" rel="noopener noreferrer">Aspose.Cells Cloud API 참조</a>를 사용하면 브라우저에서 API를 직접 실험할 수 있는 사용자 친화적인 방법을 제공합니다. 이를 통해 서비스에서 제공하는 모든 작업을 원활하게 상호 작용하고 테스트할 수 있습니다. 빠른 시작을 원한다면, 엑셀 파일을 PDF로 변환하는 간단한 POST 요청을 보여주는 “워크시트 변환” 예제를 시도해 보세요.

### **보안 및 인증**

Aspose.Cells Cloud API는 <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">JWT 토큰 기반 인증</a>을 요구하는 안전한 방식으로 설계되었습니다.
