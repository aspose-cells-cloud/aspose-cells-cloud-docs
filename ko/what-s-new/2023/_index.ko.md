- 보안 API에 지역(region) 매개변수 추가  
- 데이터 집계 API에 지역(region) 매개변수 추가  
- 파일 병합 API에 지역(region) 매개변수 추가  
- 파일 분할 API에 지역(region) 매개변수 추가  
- 데이터 가져오기 API에 지역(region) 매개변수 추가  
- 워터마크 API에 지역(region) 매개변수 추가  
- 객체 지우기 API에 지역(region) 매개변수 추가  
- 데이터 반전 API에 지역(region) 매개변수 추가  
- 데이터 회전 API에 지역(region) 매개변수 추가  

## 버전 23.11의 개선 사항

- Excel 파일로 XML 데이터를 가져올 때 성능 최적화  
- Excel 파일로 JSON 데이터를 가져올 때 성능 최적화  
- 사용 중단된 함수, 클래스 및 테스트 케이스 제거  

## 버전 23.10의 개선 사항

- 워크시트 보호 요청 오류 수정  
- 범위 복사 API 오류 수정  
- 워크시트 보호 API 성능 최적화  

## 버전 23.9의 개선 사항

- 범위 컨트롤러에서 데이터 정렬 기능 추가  
- 목록 객체의 중복 데이터 제거 기능 추가  
- 목록 객체에 슬라이서 삽입 기능 추가  
- 목록 객체 및 관련 구성 요소 성능 최적화  

## 버전 23.8의 개선 사항

- 잠금(lock) API 지원 추가  
- 보호(protect) API 성능 최적화  

## Aspose.Cells Cloud 23.7

- 파일 복구 기능 추가  
- 변환 기능 성능 최적화

- 여러 파일에 대한 일괄 분할 기능 추가
