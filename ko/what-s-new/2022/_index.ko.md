Aspose.Cells Cloud 문서의 신규 기능 안내에 오신 것을 환영합니다. 이 페이지를 사용하여 최신 변경 사항을 빠르게 확인하세요.

## Aspose.Cells Cloud 22.12

- 차트 축 조작 지원

## Aspose.Cells Cloud 22.11

- JSON으로 변환하는 새로운 API 추가
- SQL로 변환하는 새로운 API 추가
- CSV로 변환하는 새로운 API 추가

## Aspose.Cells Cloud 22.10

- PPTX로 변환하는 새로운 API 추가
- Markdown으로 변환하는 새로운 API 추가
- HTML로 변환하는 새로운 API 추가

## Aspose.Cells Cloud 22.9

- 페이지를 다른 형식 파일로 내보내기 지원
- PDF로 변환하는 새로운 API 추가
- PNG로 변환하는 새로운 API 추가
- DOCX로 변환하는 새로운 API 추가

## Aspose.Cells Cloud 22.8

- Excel 시트의 행을 열로 전치 지원

## Aspose.Cells Cloud 22.7

- Cells Cloud 서비스의 Save API 개선 (4가지 저장 옵션 추가)
- Cells Cloud의 LightCellsController 최적화

- [Cells Cloud API 개선](/cells/aspose-cells-cloud-22-6-release-notes/)
- ZIP 패키지 내 파일을 다양한 형식으로 변환 지원
