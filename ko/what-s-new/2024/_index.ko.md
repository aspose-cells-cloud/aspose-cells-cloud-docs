Aspose.Cells Cloud 문서의 신규 기능 안내에 오신 것을 환영합니다. 이 페이지를 통해 최신 변경 사항을 빠르게 확인할 수 있습니다. 이 변경 로그는 2024년 각 릴리스에서 도입된 주요 개선 사항, 버그 수정 및 신규 API를 요약합니다.

## 버전 24.12의 개선 사항

- 신규 **중복 제거 API** 추가.  
- 신규 **텍스트 추출 API** 추가.  
- 피벗 필터 생성 시 실패할 수 있던 버그 수정.

## 버전 24.11의 개선 사항

- `TextProcessingController`에 텍스트 변환 기능 추가.

## 버전 24.10의 개선 사항

- `TextProcessingController`에 문자 제거 기능 추가.

## 버전 24.9의 개선 사항

- `TextProcessingController`에 단어 대문자/소문자 변환 기능 추가.  
- 워크시트를 셀 주소 또는 ID와 함께 HTML로 내보내기 기능 지원.

## 버전 24.8의 개선 사항

- Cells Cloud Services에 텍스트 공백 제거 기능 추가.

## 버전 24.7의 개선 사항

- 워크시트에 임의의 텍스트를 삽입하는 **AddTextContent API** 도입.  
- 클라이언트 ID 및 클라이언트 비밀번호를 사용하여 액세스 토큰을 획득할 수 있는 기능 추가.

## 버전 24.6.1의 개선 사항

- API의 확장 쿼리 매개변수 수정.

## 버전 24.6.0의 개선 사항

- 데이터 변환 단계 최적화.  
- 데이터 변환을 위한 데이터 로드 기능 최적화.  
- .NET Framework 4.2.5 및 .NET Standard 2.0 지원 확대.

## 버전 24.5.1의 개선 사항

- 데이터 변환 시 데이터 로드를 위한 쿼리 병합 메서드 추가.  
- 차트 데이터 모델 최적화.  
- 액세스 토큰 엔드포인트 업데이트.

## 버전 24.4의 개선 사항

- Aspose.Cells Cloud Services에 데이터 변환 기능 지원.

## 버전 24.3의 개선 사항

- 데이터 중복 제거 기능 지원(개선).  
- 데이터 채우기 기능 지원.  
- 불완전한 행 삭제 기능 지원.  
- 데이터 정제 기능 지원.

## 버전 24.2.1의 개선 사항

- 데이터 중복 제거 기능 지원(초기 지원, 이후 버전에서 확장됨).

## 버전 24.1.1의 개선 사항

- 여러 함수의 철자 오류 수정.  
- PageSetupController에 `PostFitTallToPages` 메서드 추가.  
- PageSetupController에 `PostFitWideToPages` 메서드 추가.  
- 페이지 나누기 저장 옵션 최적화.
