Aspose.Cells Cloud REST API를 통해 엑셀 워크시트에서 **SUM**, **COUNT**, **AVERAGE**, **MIN**, **MAX** 등의 계산을 자동으로 수행하세요—수동 필터링이나 로컬 스프레드시트 소프트웨어가 필요 없습니다. 이 API는 **Aspose.Cells Cloud**에서 지원되며, 표준 인증(OAuth 2.0 또는 JWT)을 사용하고, JSON 형식으로 결과를 반환하며, 범위 오류나 인증 문제에 대해 명확한 오류 코드를 제공합니다. 자세한 요청 구문은 공식 REST API 참조 문서를 확인하세요.

- **[셀 색상별로 계산](https://docs.aspose.cloud/cells/aggregate-cells-by-color/ko/)** – 단일 요청으로 배경색 또는 글꼴 색상별로 합계를 조회합니다.
- **[스프레드시트 빠른 계산](https://docs.aspose.cloud/cells/math-calculate/ko/)** – 임의의 범위에서 SUM, COUNT, AVERAGE, MIN, MAX(및 기본 산술 연산)을 즉시 계산합니다.
