전문적인 스프레드시트 관리를 위한 강력한 Excel 데이터 조작 API입니다. 이 API는 자동으로 빈 열, 행 및 워크시트를 삭제하고, 범위 간 데이터를 원활하게 교체할 수 있습니다. Excel을 설치하지 않고도 스프레드시트를 분석, 보고서 작성 또는 통합을 위해 준비하는 데 사용할 수 있습니다.

## Excel 데이터 정리 및 최적화 API

**필수 조건** – 변환 API를 호출하기 전에 유효한 인증 토큰을 획득하고, 워크북이 지원되는 위치(예: Aspose Cloud 스토리지 또는 공개 URL)에 저장되어 있는지 확인해야 합니다. 토큰은 각 요청의 `Authorization` 헤더에 포함되어 전달되어야 합니다.

### 빈 콘텐츠 정리

- **[빈 열 삭제](https://docs.aspose.cloud/cells/delete-spreadsheet-blank-columns/)** – 데이터, 수식 또는 개체가 포함되어 있지 않은 열을 자동으로 식별하여 제거합니다.  
- **[빈 행 삭제](https://docs.aspose.cloud/cells/delete-spreadsheet-blank-rows/)** – 워크시트 구조를 유지한 채 모든 빈 행을 삭제합니다.  
- **[빈 워크시트 삭제](https://docs.aspose.cloud/cells/delete-spreadsheet-blank-worksheets/)** – 파일 크기를 줄이고 구성 유지를 위해 빈 워크시트를 정리합니다.

### 데이터 조작 및 재구성

- **[범위 데이터 교체](https://docs.aspose.cloud/cells/swap-range/)** – Excel 파일 내에서 임의의 두 범위, 열, 행 또는 개별 셀 간에 데이터를 교환합니다.
