**필수 조건**  
엔드포인트를 호출하기 전에 적절한 권한이 부여된 활성화된 Aspose Cloud 액세스 토큰과 API 버전(`v3.0`)을 획득해야 합니다.

### Aspose.Cells Cloud REST API를 사용하여 용지 크기 설정하는 방법

```bash
curl -X PUT "https://api.aspose.cloud/v3.0/cells/Workbook/worksheets/Sheet1/pageSetup" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{"PaperSize":"PaperA4"}'
```

**요청 세부 정보**  
- **메서드:** `PUT`  
- **엔드포인트:** `/cells/Workbook/worksheets/{sheetName}/pageSetup`  
- **경로 매개변수:** `sheetName` – 워크시트 이름(문자열, 필수)  
- **요청 본문:** `PaperSize` 속성을 포함하는 JSON 객체. 값은 위 표에 나열된 상수 중 하나여야 합니다. 예: `"PaperA4"`.

**응답**  
- `200 OK` – 페이지 설정이 성공적으로 업데이트됨  
- `400 Bad Request` – 잘못된 `PaperSize` 값  
- `401 Unauthorized` – 인증 실패 또는 토큰 누락  
- `404 Not Found` – 지정된 워크시트가 존재하지 않음

**예제 SDK(C\#)**  
```csharp
var api = new CellsApi("client_id", "client_secret");
var request = new PageSetup { PaperSize = PaperSizeEnum.PaperA4 };
api.PutWorksheetPageSetup("Book1.xlsx", "Sheet1", request);
```

완전한 OpenAPI 정의는 <a href="https://api.aspose.cloud/v3.0/swagger.json" target="_blank" rel="noopener">Aspose.Cells Cloud Swagger 사양</a>을 참조하세요.

가장자리 여백, 방향 및 기타 레이아웃 옵션을 구성하려면 [페이지 설정 문서](/page-setup/)도 참조하세요.
