## Excel 파일에서 피벗 테이블 작업하기

피벗 테이블은 Excel에서 대규모 데이터 세트를 동적으로 집계, 필터링 및 분석할 수 있도록 해주는 강력한 데이터 요약 도구입니다. Aspose.Cells Cloud API는 피벗 테이블을 프로그래밍 방식으로 생성, 조회, 수정 및 삭제할 수 있도록 해주는 엔드포인트를 제공하여 애플리케이션에 원활하게 통합할 수 있습니다.

**필수 조건** – 유효한 Aspose.Cells Cloud 인증 토큰과 프로젝트에 설치된 지원되는 SDK(.NET, Java, Python, Go, Node.js, PHP, Ruby, Swift 등)가 필요합니다.

**예제 API 호출** – 특정 워크시트의 모든 피벗 테이블을 조회하려면 다음과 같은 GET 요청을 보냅니다:

```http
GET https://api.aspose.cloud/v3.0/cells/{fileName}/worksheets/{sheetName}/pivottables
```

**참고사항** – 이러한 작업은 Aspose.Cells Cloud 버전 3.0 이상이 필요합니다.
