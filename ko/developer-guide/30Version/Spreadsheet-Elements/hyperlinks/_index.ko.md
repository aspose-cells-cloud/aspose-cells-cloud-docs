엑셀의 하이퍼링크를 사용하면 사용자가 워크시트, 파일, 폴더 또는 웹페이지로 이동하는 바로가기를 만들 수 있으며, 특정 위치로 빠르게 이동할 수 있습니다.

**필수 조건:** 유효한 API 토큰([인증 가이드](/ko/authentication/)) 및 Cells.Cloud SDK 설치 필요.

## 엑셀 파일에서 하이퍼링크 작업하기

- [엑셀 워크시트에서 하이퍼링크 설명을 가져오는 방법](/ko/cells/hyperlinks/get/) – 주소 및 표시 텍스트를 포함한 단일 하이퍼링크의 세부 정보를 검색합니다.  
- [엑셀 워크시트에서 모든 하이퍼링크 설명을 가져오는 방법](/ko/cells/hyperlinks/get-all/) – 워크시트에 정의된 모든 하이퍼링크와 해당 속성을 나열합니다.  
- [엑셀 워크시트에 하이퍼링크를 추가하는 방법](/ko/cells/hyperlinks/add/) – 대상 URL과 셀 범위를 지정하여 워크시트에 새 하이퍼링크를 삽입합니다.  
- [엑셀 워크시트의 하이퍼링크를 업데이트하는 방법](/ko/cells/hyperlinks/update/) – 기존 하이퍼링크의 주소, 표시 텍스트 또는 대상 셀을 수정합니다.  
- [엑셀 워크시트에서 모든 하이퍼링크를 삭제하는 방법](/ko/cells/hyperlinks/clear/) – 단일 작업으로 워크시트의 모든 하이퍼링크를 제거합니다.  
- [엑셀 워크시트에서 하이퍼링크를 삭제하는 방법](/ko/cells/hyperlinks/delete/) – 인덱스 또는 셀 참조로 식별된 특정 하이퍼링크를 삭제합니다.
