## 작업 다루기

Aspose.Cells 클라우드는 **작업(Task) API**를 제공하여, 사용자가 엑셀 워크북에 대해 다양한 작업을 수행할 수 있도록 지원합니다. 예를 들어, 파일 형식 변환, 데이터 임포트, SmartMarker 템플릿 실행, 결과 저장 등이 가능합니다. 작업은 비동기적으로 실행되며, 작업을 생성한 후 실행하고 결과를 가져오는 방식으로 동작합니다.

**필수 조건:** 유효한 API 키가 있는 Aspose Cloud 계정, 지원되는 엑셀 파일 형식, 최신 버전의 Cells API(v3.0 이상).

- [작업 API에서 요청 파일 지원하기](/cells/support-request-file-in-task-api/) – 클라우드 스토리지에 파일을 업로드하고, 이후 작업에서 해당 파일을 참조할 수 있도록 하여 처리 대상 파일을 확보합니다.
- [CellsObjectOperate 작업 다루기](/cells/working-with-cellsobjectoperate-task/) – 워크북 내 셀 객체(예: 행, 열)에 대한 작업(예: 추가, 삭제, 셀 값 업데이트 등)을 실행합니다.
- [변환(Convert) 작업 다루기](/cells/working-with-convert-task/) – 워크북을 PDF, HTML, CSV, JSON 형식으로 변환하며, 페이지 범위, 암호 보호, 사용자 정의 변환 설정 옵션을 제공합니다.
- [ImportData 작업 다루기](/cells/working-with-importdata-task/) – CSV, JSON, XML 파일의 데이터를 워크시트로 임포트하며, 열을 셀에 매핑하고 선택적으로 시작 행과 열을 지정할 수 있습니다.
- [SaveResult 작업 다루기](/cells/working-with-saveresult-task/) – 이전에 실행된 작업(예: 변환된 파일)의 결과를 클라우드 스토리지에 저장하거나 응답으로 반환합니다.
- [SmartMarker 작업 다루기](/cells/working-with-smartmarker-task/) – `{{Customer.Name}}`과 같은 SmartMarker 태그가 포함된 워크북을 JSON 데이터 소스로 처리하여 채워진 보고서를 생성합니다.
- [작업 API에서 워크시트 작업(WorksheetOperates) 다루기](/cells/working-with-worksheetoperates-in-task-api/) – 워크시트 추가, 삭제, 이름 변경 등 워크시트 수준의 작업을 작업 워크플로우의 일부로 수행합니다.

HTTP 메서드, 엔드포인트 URL, 요청/응답 스키마, 파라미터 테이블, 예제 페이로드 등 전체 메서드 사양은 위 링크된 각 작업 페이지에서 확인할 수 있습니다. 이 세부 API 참조는 개발자가 Tasks API를 빠르고 안정적으로 통합하는 데 도움을 줍니다.
