## Excel 텍스트 조작 API

Aspose.Cells Cloud는 Excel 워크시트 내 텍스트를 조작할 수 있는 REST 엔드포인트 모음을 제공합니다. 이러한 작업에는 공백 제거, 문자열 분할, 대문자/소문자 변환, 부분 문자열 추출, 불필요한 문자 제거 등 일반적인 작업이 포함됩니다.

**필수 조건:** 모든 요청은 `Authorization` 헤더에 유효한 액세스 토큰을 제공하여 인증되어야 합니다. 토큰 획득 및 사용 방법에 대해서는 인증 가이드를 참조하세요.
