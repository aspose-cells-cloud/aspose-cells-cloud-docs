## 스프레드시트 변환 툴킷

Aspose.Cells Cloud API를 사용하여 다중 형식 스프레드시트 변환을 손쉽게 수행하세요. 워크시트, 테이블, 차트, 데이터 범위에 대한 포괄적인 형식 내보내기를 지원하며, PDF, 이미지, CSV, JSON 등이 포함됩니다. 클라우드 기반 처리로 설치가 필요 없으며, REST API 및 SDK를 지원합니다.

- **[스프레드시트 전체를 다른 형식 파일로 내보내기](https://docs.aspose.cloud/cells/export-spreadsheet-as-format/)**
