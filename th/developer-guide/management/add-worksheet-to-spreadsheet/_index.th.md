เพิ่มชีตลงในไฟล์ Excel ด้วยการควบคุมประเภทและตำแหน่งของชีตอย่างเต็มที่ แทรกชีตมาตรฐาน ชีตแผนภูมิ หรือชีตมาโครที่ตำแหน่งใดก็ได้ในสมุดงาน การดำเนินการ RESTful นี้ช่วยให้การจัดการและจัดระเบียบสมุดงาน Excel เป็นไปโดยอัตโนมัติ

**ข้อกำหนดเบื้องต้น**

- บัญชี Aspose.Cells Cloud ที่ใช้งานอยู่พร้อมโทเคน JWT ที่ถูกต้อง
- ชื่อพื้นที่จัดเก็บบนคลาวด์ที่กำหนดค่าไว้แล้ว (เช่น `CompanyOneDrive`) ซึ่งจะใช้บันทึกสมุดงาน
- สมุดงานเป้าหมายต้องเข้าถึงได้ในพื้นที่จัดเก็บที่ระบุ และหากมีการป้องกันด้วยรหัสผ่าน ต้องระบุรหัสผ่านที่ถูกต้อง

| **ประเภทชีต**          | คำอธิบาย                                         |
| :--------------------- | :----------------------------------------------- |
| **VB**                 | โมดูล Visual Basic                              |
| **Worksheet**          | ชีตมาตรฐาน                                      |
| **Chart**              | ชีตแผนภูมิ                                       |
| **BIFF4Macro**         | ชีตมาโครแบบ BIFF4                               |
| **InternationalMacro** | ชีตมาโครแบบสากล                                 |
| **Other**              | ชีตแบบกำหนดเองหรือที่ไม่ค่อยพบในรายการข้างต้น |
| **Dialog**             | ชีตกล่องโต้ตอบ                                   |

## **API เพิ่มชีตในสเปรดชีต**

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/spreadsheet/add/worksheet
```

### **ความปลอดภัยและการพิสูจน์ตัวตน**

Aspose.Cells Cloud APIs มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การพิสูจน์ตัวตนด้วยโทเคน JWT</a>

### พารามิเตอร์คำขอ

| พารามิเตอร์         | ประเภท   | ตำแหน่ง | คำอธิบาย                                                                                                                                                                                          |
| :------------------ | :------- | :------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Spreadsheet**     | ไฟล์    | FormData | **จำเป็น** สมุดงาน Excel (.xlsx, .xls ฯลฯ) ที่จะเพิ่มชีตใหม่                                                                                                                                     |
| **sheetType**       | สายอักขระ | Query    | **ไม่บังคับ** ประเภทของชีตที่จะสร้าง ค่าที่รับได้คือ `worksheet` (ค่าเริ่มต้น), `chartsheet`, `macrosheet`, `vbmodule`, และ `dialog`                                                              |
| **position**        | จำนวนเต็ม | Query    | **ไม่บังคับ** ดัชนีแบบเริ่มต้นที่ 0 ที่จะแทรกชีตใหม่ `0` แทรกก่อนชีตแรก `2` แทรกเป็นชีตที่สาม ละไว้ถ้าต้องการให้ชีตถูกเพิ่มท้ายสุด                                                         |
| **sheetName**       | สายอักขระ | Query    | **ไม่บังคับ** ชื่อสำหรับชีตใหม่ ต้องไม่ซ้ำกับชื่อชีตอื่นในสมุดงาน หากไม่ระบุ จะใช้ชื่อเริ่มต้นเช่น “SheetX”                                                                                      |
| **outPath**         | สายอักขระ | Query    | **ไม่บังคับ** ไดเรกทอรีเป้าหมายในพื้นที่จัดเก็บบนคลาวด์ที่จะบันทึกสมุดงานที่แก้ไขแล้ว หากเป็น `null` หรือไม่ระบุ สมุดงานจะถูกบันทึกไว้ที่เดียวกับไฟล์ต้นฉบับหรือในพาธเริ่มต้น             |
| **outStorageName**  | สายอักขระ | Query    | **จำเป็น** ตัวระบุของพื้นที่จัดเก็บบนคลาวด์ที่กำหนดค่าไว้แล้ว (เช่น `CompanyOneDrive`) ที่จะเขียนไฟล์ผลลัพธ์                                                                                   |
| **region**          | สายอักขระ | Query    | **ไม่บังคับ** การตั้งค่าภูมิภาค (เช่น `en‑CA`) ซึ่งอาจส่งผลต่อรูปแบบและกฎตามภูมิภาคในชีตใหม่                                                                                                   |
| **password**        | สายอักขระ | Query    | **ไม่บังคับ** รหัสผ่านสำหรับถอดรหัสและแก้ไขสมุดงานที่ป้องกันด้วยรหัสผ่าน ไม่ต้องระบุหากไฟล์ไม่ได้เข้ารหัส                                                                                       |

### การตอบกลับ

เมื่อสำเร็จ API จะส่งกลับ **HTTP 200 OK** (หรือ **201 Created** หากสร้างไฟล์ใหม่) พร้อมกับไฟล์สมุดงานที่อัปเดตแล้ว

```json
{
  "Name": "ResponseFile",
  "DataType": {
    "Identifier": "File",
    "Reference": "Stream"
  }
}
```

**รหัสสถานะ HTTP**

| รหัส | ความหมาย                | คำอธิบาย                                                   |
| ---- | ------------------------ | ---------------------------------------------------------- |
| 200  | สำเร็จ (OK)             | กรองถูกใช้งานเรียบร้อยแล้ว; การตอบกลับมีรายละเอียดของการดำเนินการ |
| 400  | คำขอไม่ถูกต้อง (Bad Request) | พารามิเตอร์ขาดหายหรือไม่ถูกต้อง (เช่น ประเภทไฟล์ที่ไม่รองรับ) |
| 401  | ไม่ได้รับอนุญาต (Unauthorized) | โทเคน JWT ไม่ถูกต้องหรือขาดหาย                                |
| 413  | ข้อมูลส่งไปใหญ่เกินไป (Payload Too Large) | ไฟล์ที่อัปโหลดมีขนาดเกินขีดจำกัด                               |
| 500  | ข้อผิดพลาดภายในเซิร์ฟเวอร์ (Internal Server Error) | ข้อผิดพลาดที่ไม่คาดคิดของเซิร์ฟเวอร์                            |

## ควรใช้ API เพิ่มชีตในสเปรดชีตในกรณีใด?

- **การสร้างรายงานแบบอัตโนมัติ** – สร้างและแทรกชีตรายเดือนแบบไดนามิก (เช่น `2024‑05`) ระหว่างการสร้างงบการเงิน
- **การเริ่มต้นเทมเพลตแบบแบตช์** – เพิ่มชีตวิเคราะห์เฉพาะสำหรับลูกค้าหรือโครงการใหม่แต่ละรายเมื่อสร้างใบเสนอราคาหรือข้อเสนอการขายจำนวนมาก
- **การขยายแดชบอร์ดแบบไดนามิก** – แทรกชีตแผนภูมิใหม่แบบเรียลไทม์เมื่อมีมิติข้อมูลใหม่ปรากฏขึ้น
- **การเก็บรักษาหลักฐานเพื่อการปฏิบัติตามกฎระเบียบและการตรวจสอบ** – แทรกชีตการเก็บรวบรวมหลักฐานโดยอัตโนมัติระหว่างการตรวจสอบประจำปี โดยแยกแต่ละจุดการตรวจสอบไว้ชัดเจน
- สำหรับการลบชีต ดูการดำเนินการ **[ลบชีต](/delete-worksheet/)**
- สำหรับการย้ายชีต ดูการดำเนินการ **[ย้ายชีต](/move-worksheet/)**

## ทำไมควรใช้ API เพิ่มชีตในสเปรดชีต?

- **เป็นมิตรกับนักพัฒนา** – Aspose.Cells Cloud มี SDK รองรับหลายภาษา ลดความพยายามในการพัฒนาและมีเอกสารประกอบอย่างครอบคลุม
- **ลดต้นทุนแรงงาน** – ไม่จำเป็นต้องสร้างชีตด้วยตนเองหรือทำซ้ำการคัดลอก-วาง
- **จ่ายตามการใช้งานจริง** – จ่ายเฉพาะค่า API ที่เรียกใช้งานจริงเท่านั้น
- **ไม่มีการบำรุงรักษา** – ไม่มีเซิร์ฟเวอร์ที่ต้องจัดการ ไม่มีอัปเดตซอฟต์แวร์ และไม่มีปัญหาความเข้ากันได้

### ข้อกำหนด API เพิ่มชีตในสเปรดชีต

[ข้อกำหนด API เพิ่มชีตในสเปรดชีต](https://reference.aspose.cloud/cells/#/ManagementController/AddWorksheetToSpreadsheet) นิยามอินเทอร์เฟซโปรแกรมที่เข้าถึงได้แบบสาธารณะ และอนุญาตให้คุณดำเนินการ REST ผ่านเว็บเบราว์เซอร์โดยตรง

คุณสามารถใช้เครื่องมือ cURL จากบรรทัดคำสั่งเพื่อเข้าถึงบริการเว็บของ Aspose.Cells ได้อย่างง่ายดาย ตัวอย่างต่อไปนี้แสดงวิธีการเรียกใช้ Cloud API ด้วย cURL
