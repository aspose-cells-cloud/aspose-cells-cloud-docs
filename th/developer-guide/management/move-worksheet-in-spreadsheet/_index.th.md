ย้ายแผ่นงานภายในสมุดงาน Excel โดยใช้ Aspose.Cells Cloud API เปลี่ยนตำแหน่งแผ่นงาน จัดลำดับแท็บใหม่ และปรับปรุงโครงสร้างสมุดงานผ่านคำสั่งเรียก RESTful API เหมาะสำหรับการใช้ระบบอัตโนมัติในการจัดระเบียบสเปรดชีตและสร้างโครงรูปแบบสมุดงานมาตรฐาน

## **ย้ายแผ่นงานจาก API สเปรดชีต**

### Web API

```http
PUT http://api.aspose.cloud/v4.0/cells/spreadsheet/move/worksheet?sheetName={sheetName}&position={position}&outPath={outPath}&outStorageName={outStorageName}&region={region}&password={password}
```

### **ความปลอดภัยและการยืนยันตัวตน**

Aspose.Cells Cloud APIs มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การยืนยันตัวตนด้วย JWT token</a>

```bash
-H "Authorization: Bearer {access_token}"
```

### **พารามิเตอร์คำขอ:**

| ชื่อพารามิเตอร์ | ประเภท   | Path/Query String/HTTPBody | คำอธิบาย                                                                                                                                                          |
| :------------- | :------ | :------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet    | ไฟล์    | FormData                   | **จำเป็น**. ไฟล์สมุดงาน Excel ต้นทาง (.xlsx, .xls เป็นต้น) ที่มีแผ่นงานที่ต้องการย้ายตำแหน่ง                                                                     |
| worksheet      | สตริง   | Query                      | **จำเป็น**. ชื่อแผ่นงานที่ต้องการย้ายอย่างแม่นยำ (เช่น `Summary`, `RawData_2024`)                                                                                 |
| position       | จำนวนเต็ม | Query                      | **จำเป็น**. ตำแหน่งใหม่ในรูปแบบดัชนีเริ่มต้นที่ 0 สำหรับแผ่นงาน เช่น `0` ย้ายไปตำแหน่งแรก, `2` ย้ายให้อยู่เป็นแผ่นที่สาม                                        |
| outPath        | สตริง   | Query                      | **ไม่บังคับ**. ตำแหน่งโฟลเดอร์เป้าหมายในพื้นที่จัดเก็บบนคลาวด์ที่จะบันทึกสมุดงานที่จัดระเบียบแล้ว หากเป็น `null` หรือไม่ระบุ จะใช้โฟลเดอร์เดียวกับไฟล์ต้นทางโดยอัตโนมัติ |
| outStorageName | สตริง   | Query                      | **จำเป็น**. ชื่อระบุตัวตนของบริการพื้นที่จัดเก็บบนคลาวด์ที่กำหนดค่าไว้ของคุณ (เช่น `TeamDrive`) ที่จะบันทึกไฟล์ผลลัพธ์                                             |
| region         | สตริง   | Query                      | **ไม่บังคับ**. การตั้งค่าภาษา和地区 (เช่น `th-TH`) ที่จะใช้ ซึ่งอาจมีผลต่อกฎการจัดรูปแบบบางอย่างขณะดำเนินการบันทึก                                               |
| password       | สตริง   | Query                      | **ไม่บังคับ**. รหัสผ่านถอดรหัสที่จำเป็นสำหรับการเปิดและแก้ไขสมุดงานที่มีการป้องกันด้วยรหัสผ่าน ไม่ต้องระบุหากไฟล์ไม่ได้ถูกเข้ารหัส                                 |

### **การตอบกลับ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**รหัสสถานะ HTTP**

| รหัส | ความหมาย               | คำอธิบาย                                                           |
| ---- | --------------------- | ----------------------------------------------------------------- |
| 200  | สำเร็จ (OK)           | ใช้ตัวกรองเรียบร้อยแล้ว; คำตอบประกอบด้วยรายละเอียดการดำเนินการ |
| 400  | คำขอไม่ถูกต้อง (Bad Request) | พารามิเตอร์ขาดหายหรือไม่ถูกต้อง (เช่น ไฟล์ประเภทที่ไม่รองรับ)      |
| 401  | ไม่ได้รับอนุญาต (Unauthorized) | JWT token ไม่ถูกต้องหรือไม่ได้ระบุ                                    |
| 413  | ข้อมูลส่งไปมีขนาดใหญ่เกินไป (Payload Too Large) | ไฟล์ที่อัปโหลดมีขนาดเกินขีดจำกัด                                       |
| 500  | ข้อผิดพลาดภายในเซิร์ฟเวอร์ (Internal Server Error) | เกิดข้อผิดพลาดที่ไม่คาดคิดของเซิร์ฟเวอร์                               |

## ควรใช้ API ย้ายแผ่นงานในสเปรดชีตในกรณีใด?

- **การสร้างรายงานแบบมาตรฐาน**: หลังจากสร้างรายงานรายเดือนหรือรายไตรมาสโดยอัตโนมัติแล้ว ย้ายแผ่นงาน `Summary` หรือ `Executive Overview` ไปอยู่ด้านบนสุดของสมุดงาน เพื่อให้สรุปผลหลักปรากฏขึ้นทันทีเมื่อเปิดไฟล์
- **ระบบการประมวลผลข้อมูล (Data Processing Pipeline)**: หลังจากประมวลผลแผ่นงานข้อมูลดิบจากแหล่งข้อมูลต่างๆ ในขั้นตอน ETL ย้ายแผ่นงาน `Processed_Data` ที่ผ่านการปรับปรุงและแปลงข้อมูลแล้วไปยังตำแหน่งที่มีเหตุผลในสมุดงาน (เช่น อยู่ตรงกลาง) เพื่อสร้างโครงสร้างกระบวนการที่ชัดเจน โดยมีข้อมูลต้นฉบับและผลลัพธ์การวิเคราะห์จัดเรียงอย่างเป็นระบบ
- **การส่งมอบไฟล์แบบปรับแต่งตามผู้ใช้**: หลังจากผู้ใช้เลือกเค้าโครงที่ต้องการผ่านอินเทอร์เฟซการกำหนดค่า (เช่น วางหน้าแผนภาพไว้ด้านบนสุด) ระบบจะจัดลำดับแผ่นงานในสมุดงานใหม่โดยอัตโนมัติตามการเลือก และส่งไฟล์ที่ปรับแต่งให้

## เหตุใดจึงควรใช้ API ย้ายแผ่นงานในสเปรดชีต?

- **ใช้งานง่ายสำหรับนักพัฒนา**: Aspose.Cells Cloud มี SDK ให้ใช้งานในหลายภาษา ช่วยให้พัฒนาแอปพลิเคชันได้อย่างรวดเร็ว และมีเอกสารประกอบที่ครบถ้วน เมื่อเทียบกับการสร้างโซลูชันแบบปรับแต่งเอง วิธีนี้ช่วยลดภาระงานพัฒนาอย่างมาก
- **ลดค่าใช้จ่ายแรงงาน**: ลดความจำเป็นในการจ้างบุคลากรเฉพาะด้านในการรวมเอกสาร
- **จ่ายตามการใช้งานจริง (Pay-per-Use)**: ไม่ต้องลงทุนล่วงหน้า จ่ายเฉพาะเมื่อเรียกใช้ API เท่านั้น
- **ไม่มีค่าใช้จ่ายในการดูแลรักษา**: ไม่ต้องดูแลเซิร์ฟเวอร์ ไม่ต้องอัปเดตซอฟต์แวร์ และไม่ต้องจัดการปัญหาความเข้ากันได้

### ข้อมูลจำเพาะ API ย้ายแผ่นงานในสเปรดชีต

[ข้อมูลจำเพาะ API ย้ายแผ่นงานในสเปรดชีต](https://reference.aspose.cloud/cells/#/ManagementController/MoveWorksheetInSpreadsheet) มีอินเทอร์เฟซโปรแกรมที่เปิดให้เข้าถึงได้ เพื่อให้สามารถโต้ตอบกับ REST โดยตรงผ่านเว็บเบราว์เซอร์ได้
