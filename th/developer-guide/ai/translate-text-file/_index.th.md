ปลายทาง **TranslateTextFile** ใช้บริการปัญญาประดิษฐ์ของ Aspose.Cells Cloud เพื่อแปลเนื้อหาของไฟล์ข้อความเป็นภาษาเป้าหมายที่ระบุ โดยรองรับโหมดการทำงานสองแบบ: (1) **โหมดการอัปโหลดไฟล์** – ส่งไฟล์ข้อความผ่าน multipart/form-data และรับไฟล์ที่แปลแล้วกลับมา; (2) **โหมดเนื้อหาโดยตรง** – ส่งข้อความดิบในส่วนของเนื้อหาคำขอ (request body) และรับข้อความที่แปลแล้วกลับโดยตรง บริการนี้รักษาการขึ้นบรรทัดใหม่และการจัดรูปแบบต้นฉบับไว้ ใส่คำว่า "\_translated" ต่อท้ายชื่อไฟล์โดยอัตโนมัติ และส่งผลลัพธ์กลับมาในรูปแบบสตรีมที่สามารถดาวน์โหลดได้ เหมาะสำหรับการแปลเอกสารเป็นชุด, การผนวกเข้ากับเวิร์กโฟลว์แบบหลายภาษา หรือการแปลเนื้อหาที่ผู้ใช้สร้างขึ้นแบบเรียลไทม์

## **API แปลงไฟล์ข้อความ**

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/ai/translate/text-file
```

### **พารามิเตอร์คำขอ:**

| ชื่อพารามิเตอร์ | ประเภท | ตำแหน่ง | จำเป็น/ไม่บังคับ | คำอธิบาย                                                                                                                                                                                                 |
| :------------- | :----- | :------- | :---------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet    | ไฟล์   | จำเป็น   | FormData          | ไฟล์ข้อความต้นฉบับที่ต้องการแปล ต้องเป็นไฟล์ข้อความธรรมดา (.txt) หรือรูปแบบสเปรดชีตที่รองรับ ตัวอย่าง: อัปโหลด `document.txt` ผ่านฟิลด์ "file" ของ multipart/form-data                                |
| targetLanguage | สตริง | จำเป็น   | Query             | โค้ดภาษา ISO‑639‑1 ของภาษาที่ต้องการส่งออก (เช่น "es" สำหรับสเปน, "fr" สำหรับฝรั่งเศส, "de" สำหรับเยอรมัน) โค้ดนี้ไม่คำนึงถึงตัวพิมพ์เล็ก/ใหญ่                                                                     |
| region         | สตริง | ไม่บังคับ | Query             | ตัวระบุพื้นที่ของสเปรดชีตซึ่งส่งผลต่อการจัดรูปแบบตามภูมิภาค เช่น วันที่ ตัวเลข และสกุลเงิน ค่าทั่วไป: "US", "EU", "CN" หากไม่ระบุ ระบบจะใช้การตั้งค่าภูมิภาคเดิมของสมุดงานแทน |
| password       | สตริง | ไม่บังคับ | Query             | รหัสผ่านที่จำเป็นสำหรับเปิดไฟล์สเปรดชีตที่เข้ารหัสไว้ ไม่จำเป็นสำหรับไฟล์ข้อความธรรมดา                                                                                                                     |

### **การตอบกลับ**

การตอบกลับที่สำเร็จ (200 OK)
ส่วนหัว:
Content-Type: application/octet-stream // สตรีมไบนารีของไฟล์ที่แปลแล้ว
Content-Disposition: attachment; filename="<original_name>\_translated.txt"
Content-Length: <ขนาดเป็นไบต์>

เนื้อหา: สตรีมไบนารีที่มีข้อความที่แปลแล้ว ซึ่งรักษาการขึ้นบรรทัดใหม่และการจัดรูปแบบต้นฉบับไว้

**โค้ดสถานะ HTTP**

| โค้ด | ความหมาย                 | คำอธิบาย                                                       |
| ---- | --------------------- | ----------------------------------------------------------------- |
| 200  | สำเร็จ (OK)            | ใช้ตัวกรองสำเร็จ; การตอบกลับมีรายละเอียดของการดำเนินการ |
| 400  | คำขอไม่ถูกต้อง (Bad Request) | พารามิเตอร์ขาดหายหรือไม่ถูกต้อง (เช่น ประเภทไฟล์ที่ไม่รองรับ)      |
| 401  | ไม่ได้รับอนุญาต (Unauthorized) | JWT token ไม่ถูกต้องหรือขาดหาย                                     |
| 413  | เนื้อหาคำขอมีขนาดใหญ่เกินไป (Payload Too Large) | ไฟล์ที่อัปโหลดเกินขีดจำกัดขนาด                                     |
| 500  | ข้อผิดพลาดภายในเซิร์ฟเวอร์ (Internal Server Error) | เกิดข้อผิดพลาดที่ไม่คาดคิดของเซิร์ฟเวอร์                                          |

## ควรใช้ API แปลงไฟล์ข้อความในกรณีใด?

- **พอร์ทัลเอกสารหลายภาษา** – แปลคู่มือผู้ใช้หรือไฟล์ช่วยเหลือที่ผู้ใช้อัปโหลดเป็นไฟล์ข้อความโดยอัตโนมัติ และส่งเวอร์ชันท้องถิ่นตามที่ต้องการ
- **ระบบจัดการเนื้อหา (CMS)** – ผนวกเข้ากับเวิร์กโฟลว์ของ CMS เพื่อแปลบล็อกโพสต์หรือบทความก่อนเผยแพร่สู่ผู้อ่านต่างชาติ
- **ท่อข้อมูลขององค์กร** – ใช้ในงานแบตช์ที่ประมวลผลรายงาน CSV หรือ TXT จำนวนมาก แปลงเป็นภาษาของสำนักงานสาขาในแต่ละภูมิภาค ขณะเดียวกันก็รักษาการจัดรูปแบบต้นฉบับไว้
- **แพลตฟอร์มการสนับสนุนลูกค้า** – แปลตั๋วร้องเรียนหรือบันทึกการแชตแบบข้อความดิบแบบเรียลไทม์ เพื่อช่วยให้ทีมบริการลูกค้าที่ใช้ภาษาต่างกันสามารถทำงานได้ดีขึ้น

## เหตุใดควรใช้ API แปลงไฟล์ข้อความ?

- **ความแม่นยำด้วยปัญญาประดิษฐ์** – ใช้แบบจำลองการแปลด้วยเครือข่ายประสาทเทียมขั้นสูงสุด เพื่อให้ได้ข้อความที่เป็นธรรมชาติและเข้าใจบริบท
- **ความยืดหยุ่นในการรับข้อมูลสองรูปแบบ** – รองรับทั้งการอัปโหลดไฟล์และส่งเนื้อหาข้อความดิบ ทำให้การผนวกเข้ากับแอปพลิเคชันไคลเอนต์หลากหลายชนิดทำได้ง่าย
- **รักษาเค้าโครงต้นฉบับไว้** – รักษาการขึ้นบรรทัดใหม่ การเยื้อง และอักขระพิเศษไว้ ไม่จำเป็นต้องปรับแต่งเพิ่มเติมหลังการแปล
- **จัดการไฟล์ได้อย่างราบรื่น** – ส่งคืนไฟล์ที่พร้อมดาวน์โหลดทันที โดยใส่คำว่า "\_translated" ต่อท้ายชื่อโดยอัตโนมัติ ลดความซับซ้อนของโค้ดฝั่งไคลเอนต์
