**endpoint  TranslateSpreadsheet** ซึ่งเป็นส่วนหนึ่งของ **API แปลสมุดงาน** จะอ่านองค์ประกอบข้อความทุกส่วนในสมุดงาน ส่งเนื้อหาไปยังบริการแปลที่ขับเคลื่อนด้วย AI และส่งกลับไฟล์สมุดงานใหม่ที่ข้อมูลข้อความทั้งหมดแสดงใน **targetLanguage** ที่ระบุ การดำเนินการนี้จะรักษาเค้าโครงต้นฉบับ สไตล์เซลล์ สูตร และโครงสร้างหลายแผ่นไว้ครบถ้วน จึงเหมาะสำหรับการปรับเนื้อหาให้ใช้ได้ทั่วโลก เช่น รายงาน แดชบอร์ด และเอกสารที่ขับเคลื่อนด้วยข้อมูล รูปแบบไฟล์ที่รองรับได้แก่ XLS, XLSX, XLSM, CSV และ ODS ระบบจะส่งข้อผิดพลาดกลับมาเมื่อพบโค้ดภาษาไม่ถูกต้อง การยืนยันตัวตนล้มเหลว หรือบริการแปลขัดข้อง

## **API แปลสมุดงาน**

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/ai/translate/spreadsheet
```

### **พารามิเตอร์คำขอ:**

| ชื่อพารามิเตอร์ | ชนิดข้อมูล | ตำแหน่ง | จำเป็น/ไม่บังคับ | คำอธิบาย                                                                                                                                                                                                 |
| :------------- | :----- | :------- | :---------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet    | ไฟล์   | จำเป็น | FormData          | สมุดงาน Excel ที่ต้องการแปล นามสกุลไฟล์ที่รับได้: .xls, .xlsx, .xlsm, .csv, .ods ขนาดไฟล์สูงสุด: 50 MB ตัวอย่าง: `budget.xlsx`.                                                               |
| targetLanguage | string | จำเป็น | Query             | โค้ดภาษาตามมาตรฐาน ISO 639-1 สำหรับภาษาที่ต้องการเป็นผลลัพธ์ (เช่น "es" สำหรับสเปน, "fr" สำหรับฝรั่งเศส, "de" สำหรับเยอรมัน) ต้องเป็นภาษาที่บริการ AI ข้างล่างรองรับ                              |
| region         | string | ไม่บังคับ | Query             | ตัวระบุภูมิภาคของสมุดงานซึ่งมีผลต่อการจัดรูปแบบตามภูมิภาค เช่น วันที่ ตัวเลข และสกุลเงิน ค่าที่พบบ่อย: "US", "EU", "CN" หากไม่ระบุ จะใช้การตั้งค่าภูมิภาคดั้งเดิมของสมุดงาน |
| password       | string | ไม่บังคับ | Query             | รหัสผ่านสำหรับเปิดสมุดงานที่ได้รับการป้องกัน ปล่อยให้ว่างเปล่าเมื่อไฟล์ไม่ได้รับการป้องกันด้วยรหัสผ่าน                                                                                                             |

### **การตอบกลับ**

การตอบกลับที่สำเร็จ (200 OK)  
ส่วนหัว:  
Content-Type: application/octet-stream // หรือ text/csv เมื่อร้องขอผลลัพธ์ CSV  
Content-Disposition: attachment; filename="translated.xlsx"  
Content-Length: <ขนาดเป็นไบต์>

เนื้อหา:  
<สตรีมไบนารีที่มีไฟล์สมุดงานที่แปลแล้ว>

การตอบกลับที่มีข้อผิดพลาดจะเป็นไปตามโมเดลข้อผิดพลาดมาตรฐานของ Aspose.Cells Cloud (application/json) โดยมีฟิลด์ `code`, `message` และ `details` (ถ้ามี)

**รหัสสถานะ HTTP**

| รหัส | ความหมาย               | คำอธิบาย                                                       |
| ---- | --------------------- | ----------------------------------------------------------------- |
| 200  | OK                    | ใช้ตัวกรองสำเร็จ; การตอบกลับมีรายละเอียดการดำเนินการ          |
| 400  | Bad Request           | พารามิเตอร์ขาดหายหรือไม่ถูกต้อง (เช่น ประเภทไฟล์ที่ไม่รองรับ)  |
| 401  | Unauthorized          | JWT token ไม่ถูกต้องหรือขาดหาย                                   |
| 413  | Payload Too Large     | ไฟล์ที่อัปโหลดเกินขีดจำกัดขนาด                                  |
| 500  | Internal Server Error | ข้อผิดพลาดของเซิร์ฟเวอร์ที่ไม่คาดคิด                             |

## ควรใช้ API แปลสมุดงานในกรณีใด?

- **การรายงานทางการเงินระดับสากล** – แปลรายงาน Excel รายไตรมาสเป็นหลายภาษาสำหรับสำนักงานในภูมิภาคต่างๆ โดยรักษาสูตรและเค้าโครงแผนภูมิไว้เหมือนเดิม
- **แดชบอร์ดการตลาดแบบหลายภาษา** – สร้างเวอร์ชันท้องถิ่นของแดชบอร์ดแสดงผลการขายให้กับทีมงานทั่วโลกโดยอัตโนมัติ
- **การจัดส่งเนื้อหาการศึกษา** – แปลสมุดบันทึกคะแนน แบบฝึกหัด หรือสมุดงานหลักสูตรสำหรับนักเรียนในประเทศต่างๆ โดยไม่ต้องคัดลอกและวางด้วยตนเอง
- **การปฏิบัติตามกฎระเบียบ** – สร้างสมุดงานที่ปฏิบัติตามกฎระเบียบในภาษาท้องถิ่น โดยรักษากฎการตรวจสอบและรายการตรวจสอบข้อมูลไว้เหมือนเดิม

## ทำไมควรใช้ API แปลสมุดงาน?

- **ความแม่นยำด้วย AI** – ใช้แบบจำลองการแปลแบบนิวรัลขั้นสูงสุด เพื่อการแปลภาษาคุณภาพสูงที่เข้าใจบริบท
- **ไม่รบกวนเค้าโครง** – รักษาสูตรเซลล์ การจัดรูปแบบแบบมีเงื่อนไข แผนภูมิ และลำดับแผ่นงานไว้เหมือนเดิมทุกประการ
- **ประมวลผลหลายแผ่นด้วยคำขอเดียว** – แปลแผ่นงานทุกแผ่นในคำขอเดียว โดยไม่ต้องใช้การวนลูปแบบแผ่นต่อแผ่น
- **ผสานรวมบนคลาวด์ได้อย่างราบรื่น** – ทำงานร่วมกับการยืนยันตัวตนของ Aspose.Cells Cloud ช่วยให้สร้างระบบอัตโนมัติใน CI/CD, ฟังก์ชันแบบเซิร์ฟเลส หรือแบ็กเอนด์องค์กรได้
