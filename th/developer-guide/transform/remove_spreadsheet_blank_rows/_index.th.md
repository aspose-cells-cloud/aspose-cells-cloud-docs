## การลบแถวว่างในสเปรดชีตของ Aspose.Cells Cloud Web Services

เมธอดนี้จะลบแถวที่ว่างเปล่าทั้งหมดออกจากสเปรดชีต โดยไม่มีข้อมูลหรือวัตถุใดๆ เลยวางอยู่ ระบบจะสแกนผ่านชีตทั้งหมดเพื่อระบุแถวที่ทุกเซลล์ว่างเปล่า การดำเนินการจะทำโดยตรงกับสเปรดชีต โดยจะลบเฉพาะแถวที่ไม่มีเนื้อหาใดๆ เท่านั้น วิธีนี้ช่วยทำความสะอาดสเปรดชีตและลบแถวว่างที่ไม่จำเป็นออก ทำให้ข้อมูลมีระเบียบมากขึ้นและจัดการได้ง่ายขึ้น ผู้ใช้ควรสำรองสเปรดชีตก่อนดำเนินการนี้ เนื่องจากแถวที่ถูกลบไปแล้วจะไม่สามารถกู้คืนได้

### จุดสิ้นสุดของเว็บ API

```http
PUT https://api.aspose.cloud/v4.0/cells/remove/blank-rows
```

### **ความปลอดภัยและการพิสูจน์ตัวตน**

Aspose.Cells Cloud APIs มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การพิสูจน์ตัวตนแบบ JWT token</a>

### พารามิเตอร์ของคำขอ

| ชื่อพารามิเตอร์ | ชนิดข้อมูล | Path/Query String/HTTP Body | คำอธิบาย |
|----------------|--------|-----------------------------|-------------|
| Spreadsheet    | ไฟล์   | FormData                    | อัปโหลดไฟล์สเปรดชีต |
| outPath        | สายอักขระ | Query                       | (ไม่บังคับ) เส้นทางโฟลเดอร์ที่เก็บเวิร์กบุ๊ก ค่าเริ่มต้นคือ null |
| outStorageName | สายอักขระ | Query                       | ชื่อ Storage สำหรับไฟล์ผลลัพธ์ |
| region         | สายอักขระ | Query                       | การตั้งค่าภูมิภาค/ภาษาของสเปรดชีต (เช่น `en-US`, `fr-FR`) ส่งผลต่อรูปแบบตัวเลข การแปลงวันที่ และพฤติกรรมที่ขึ้นกับการตั้งค่าภูมิภาค |
| password       | สายอักขระ | Query                       | รหัสผ่านสำหรับเปิดไฟล์สเปรดชีต |

### พารามิเตอร์ของเนื้อหาคำขอ

| ชื่อพารามิเตอร์ | ชนิดข้อมูล | คำอธิบาย |
| -------------- | ---- | ----------- |
| Spreadsheet    | ไฟล์ | อัปโหลดไฟล์สเปรดชีต |

### **การตอบกลับคำขอ**

```json
{
  "ResponseFile": "สตรีมไฟล์ไบนารี"
}
```

**รหัสสถานะการตอบกลับ**

| รหัส | ความหมาย | คำอธิบาย |
|------|---------|-------------|
| 200 | สำเร็จ | ส่งคืนไฟล์สเปรดชีตที่ประมวลผลแล้วโดยลบแถวว่างออกแล้ว |
| 400 | คำขอไม่ถูกต้อง | URL หรือพารามิเตอร์ของคำขอไม่ถูกต้อง |
| 401 | ไม่ได้รับอนุญาต | การพิสูจน์ตัวตนล้มเหลว หรือไม่ได้ระบุข้อมูลยืนยันตัวตน |
| 404 | ไม่พบ | ไม่สามารถเข้าถึงไฟล์ต้นทางได้ |
| 413 | เนื้อหาคำขอใหญ่เกินไป | เนื้อหาคำขอเกินขนาดที่กำหนด |
| 500 | ข้อผิดพลาดภายในเซิร์ฟเวอร์ | สเปรดชีตมีปัญหาขณะดึงข้อมูล |

## วิธีใช้การลบแถวว่างในสเปรดชีตด้วย SDK

### ข้อมูลจำเพาะการลบแถวว่างในสเปรดชีต

[ข้อมูลจำเพาะ API การลบแถวว่างในสเปรดชีต](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Transform/RemoveSpreadsheetBlankRows) กำหนดอินเทอร์เฟซโปรแกรมที่เข้าถึงได้แบบสาธารณะ และช่วยให้คุณดำเนินการ REST ได้โดยตรงจากเว็บเบราว์เซอร์

คุณสามารถใช้เครื่องมือ cURL จากบรรทัดคำสั่งเพื่อเข้าถึง Aspose.Cells web services ได้อย่างง่ายดาย ตัวอย่างต่อไปนี้แสดงวิธีการเรียกใช้ Cloud API ด้วย cURL

{< tabs tabTotal="2" tabID="1" tabName1="คำขอ" tabName2="การตอบกลับ" >}
{< tab tabNum="1" >}
```bash
# ใช้ HTTPS เพื่อการเชื่อมต่อที่ปลอดภัย
curl -v "https://api.aspose.cloud/v4.0/cells/remove/blank-rows?outPath=outputFolder&outStorageName=MyStorage&region=en-US&password=12345" \
  -X PUT \
  -H "Content-Type: multipart/form-data" \
  -H "Accept: application/octet-stream" \
  -H "Authorization: Bearer <jwt token>" \
  -F 'Spreadsheet=@sample.xlsx'
```
