แบ่งสมุดงาน Excel ขนาดใหญ่ที่จัดเก็บในคลาวด์ออกเป็นไฟล์แยกต่างหากตามแผ่นงาน และส่งออกแต่ละไฟล์เป็นรูปแบบเอาต์พุตมากกว่า 30 รูปแบบ เช่น PDF, CSV, JSON, ODS และ XPS โดยใช้ Aspose.Cells Cloud

## **API แยกสเปรดชีตในระยะไกล**

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/{name}/split/spreadsheet
```

### **ความปลอดภัยและการยืนยันตัวตน**

Aspose.Cells Cloud APIs มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การยืนยันตัวตนด้วยโทเคน JWT</a>

### **พารามิเตอร์คำขอ:**

| ชื่อพารามิเตอร์ | ชนิดข้อมูล | เส้นทาง/สตริงคำค้นหา/เนื้อหา HTTP | คำอธิบาย |
| :------------- | :------ | :-------------------------- | :------------------------------------------------------------------------------------------------------------------------------------ |
| name           | String  | Path                        | ชื่อไฟล์สมุดงาน (เช่น `data.xlsx`) ที่ต้องการแยก ซึ่งอยู่ในโฟลเดอร์พื้นที่จัดเก็บข้อมูลคลาวด์ที่ระบุ |
| folder         | String  | Query                       | เส้นทางโฟลเดอร์พื้นที่จัดเก็บข้อมูลคลาวด์ที่เก็บสมุดงานต้นทางไว้ |
| from           | Integer | Query                       | ดัชนีแผ่นงานเริ่มต้น (เริ่มต้นที่ 0) สำหรับการดำเนินการแยก เช่น `0` หมายถึงแผ่นงานแรก |
| to             | Integer | Query                       | ดัชนีแผ่นงานสิ้นสุด (เริ่มต้นที่ 0) สำหรับการดำเนินการแยก เช่น `2` หมายถึงการแยกแผ่นงานที่ 0, 1 และ 2 |
| outFormat      | String  | Query                       | รูปแบบไฟล์เอาต์พุตสำหรับไฟล์ที่แยกออก มีรูปแบบที่รองรับ เช่น `XLSX`, `PDF`, `CSV`, `JSON`, `HTML` และอีกมากกว่า 30 รูปแบบ |
| storageName    | String  | Query                       | _(ไม่บังคับ)_ ชื่อพื้นที่จัดเก็บข้อมูลคลาวด์ที่สมุดงานต้นทางอยู่ ถ้าไม่ระบุ จะใช้พื้นที่จัดเก็บข้อมูลคลาวด์เริ่มต้น |
| outPath        | String  | Query                       | _(ไม่บังคับ)_ เส้นทางโฟลเดอร์คลาวด์เป้าหมายที่จะบันทึกไฟล์ที่แยกออก ถ้าไม่ระบุ ไฟล์จะถูกบันทึกไว้ในโฟลเดอร์ต้นทาง |
| outStorageName | String  | Query                       | ชื่อพื้นที่จัดเก็บข้อมูลคลาวด์ที่จะเก็บไฟล์ที่แยกออก |
| fontsLocation  | String  | Query                       | _(ไม่บังคับ)_ ระบุเส้นทางโฟลเดอร์คลาวด์ที่มีไฟล์ฟอนต์เพื่อให้การแสดงผลข้อความในเอาต์พุต PDF/รูปภาพถูกต้อง |
| region         | String  | Query                       | _(ไม่บังคับ)_ ตั้งค่าการตั้งค่าภูมิภาคสำหรับการจัดรูปแบบตัวเลข วันที่ และสกุลเงินในไฟล์เอาต์พุต (เช่น `"en-US"`, `"zh-CN"`, `"de-DE"`) |
| password       | String  | Query                       | _(ไม่บังคับ)_ หากสมุดงานต้นทางมีการป้องกันด้วยรหัสผ่าน ให้ระบุรหัสผ่านเพื่อเปิดไฟล์ |

## **การตอบกลับ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream",
      "Name": "file"
    }
  }
]
```

ไฟล์สามารถดาวน์โหลดโดยตรงหรือบันทึกไปยังตำแหน่งที่ระบุใน `outPath`

**รายละเอียดการตอบกลับที่สำเร็จ**

| โค้ดสถานะ | Content‑Type               | คำอธิบาย |
| ----------- | -------------------------- | ------------------------------------------ |
| 200 OK      | `application/octet-stream` | สตรีมไบนารีของไฟล์สมุดงานที่รวมแล้ว |

**โค้ดสถานะ HTTP**

| โค้ด | ความหมาย               | คำอธิบาย |
| ---- | --------------------- | ----------------------------------------------------------------- |
| 200  | OK                    | ใช้ตัวกรองสำเร็จ; การตอบกลับมีรายละเอียดการดำเนินการ |
| 400  | Bad Request           | พารามิเตอร์ขาดหายหรือไม่ถูกต้อง (เช่น ประเภทไฟล์ที่ไม่รองรับ) |
| 401  | Unauthorized          | โทเคน JWT ไม่ถูกต้องหรือขาดหาย |
| 413  | Payload Too Large     | ไฟล์ที่อัปโหลดมีขนาดเกินขีดจำกัด |
| 500  | Internal Server Error | เกิดข้อผิดพลาดภายในเซิร์ฟเวอร์ที่ไม่คาดคิด |

## ควรใช้ API แยกสเปรดชีตในระยะไกลในกรณีใด?

- **การกระจายข้อมูลตามแผนก**: แยกสมุดงานรวมที่มีข้อมูลจากหลายแผนกออกเป็นไฟล์เฉพาะตามแผนก
- **การกระจายรายงานตามภูมิภาค**: แยกรายงานการขายระดับประเทศออกเป็นไฟล์รายงานเฉพาะภูมิภาคตามภูมิภาค
- **การกระจายข้อมูลลูกค้าแบบปิดบัง**: แยกสมุดงานที่มีข้อมูลที่เป็นความลับออกเป็นไฟล์เฉพาะสำหรับมุมมองของลูกค้า
- **การแยกรายงานตามช่วงเวลา**: แยกรายงานสรุปออกเป็นรายงานรายสัปดาห์หรือรายวันโดยอัตโนมัติทุกเดือน
- **การกระจายหลายรูปแบบ**: แยกไฟล์ Excel หนึ่งไฟล์ออกเป็นหลายเวอร์ชันของรูปแบบ เช่น PDF, CSV, JSON เป็นต้น พร้อมกัน
- **การแยกตามเทมเพลต**: แยกไฟล์ข้อมูลออกเป็นไฟล์เอาต์พุตมาตรฐานตามเทมเพลตที่กำหนดไว้ล่วงหน้า
- **การประมวลผลข้อมูลต้นทาง**: แยกไฟล์ Excel ออกเป็นไฟล์ CSV มาตรฐานก่อนโหลดข้อมูลเข้าฐานข้อมูล
- **การเตรียมข้อมูลสำหรับ API**: แยกชุดข้อมูลขนาดใหญ่ออกเป็นส่วนย่อยที่เหมาะสมสำหรับการส่งผ่าน API
- **การกระจายข้อมูลแบบไมโครเซอร์วิส**: แยกไฟล์ข้อมูลกลางออกเป็นไฟล์ข้อมูลแยกต่างหากที่แต่ละไมโครเซอร์วิสต้องการ

## เหตุใดจึงควรใช้ API แยกสเปรดชีตในระยะไกล?

- **เป็นมิตรกับนักพัฒนา**: Aspose.Cells Cloud มี SDK ให้ใช้งานในหลายภาษา ช่วยให้พัฒนาได้อย่างรวดเร็ว และมาพร้อมเอกสารประกอบที่ครบถ้วน เมื่อเทียบกับการสร้างโซลูชันเรนเดอร์กราฟิกแบบกำหนดเอง นี่จะช่วยลดภาระงานพัฒนาได้อย่างมาก
- **ลดต้นทุนแรงงาน**: ลดความจำเป็นในการจ้างบุคลากรเฉพาะสำหรับการรวมเอกสาร
- **จ่ายตามการใช้งาน**: ไม่ต้องลงทุนล่วงหน้า จ่ายเฉพาะเมื่อมีการเรียกใช้ API จริง
- **ไม่มีต้นทุนการดูแลรักษา**: ไม่จำเป็นต้องดูแลเซิร์ฟเวอร์ อัปเดตซอฟต์แวร์ หรือจัดการปัญหาความเข้ากันได้
- **คงรูปแบบ Excel ที่ซับซ้อนไว้ในรูปแบบ PDF ที่เข้าถึงได้ทั่วไป**

### ข้อมูลเฉพาะ API แยกสเปรดชีตในระยะไกล

[ข้อมูลเฉพาะ API แยกสเปรดชีตในระยะไกล](https://reference.aspose.cloud/cells/#/DataProcessingController/SplitRemoteSpreadsheet) กำหนดอินเทอร์เฟซการเขียนโปรแกรมที่สามารถเข้าถึงได้แบบสาธารณะ และเปิดให้สามารถโต้ตอบกับ REST API ได้โดยตรงจากเว็บเบราว์เซอร์
