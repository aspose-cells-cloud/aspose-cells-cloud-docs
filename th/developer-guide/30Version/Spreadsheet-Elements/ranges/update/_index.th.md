## การทำงานกับการอัปเดตเนื้อหาช่วงข้อมูลในแผ่นงาน Excel

ก่อนใช้งานการดำเนินการอัปเดต คุณต้องมีโทเคน API ของ Aspose.Cells Cloud ที่ถูกต้อง และแน่ใจว่างาน Excel เป้าหมายถูกจัดเก็บไว้ในพื้นที่จัดเก็บข้อมูลบนคลาวด์ของคุณแล้ว API นี้พร้อมใช้งานผ่าน SDK สำหรับ Android, .NET, Go, Java, Node.js, Perl, PHP, Python, Ruby และ Swift

สรุปสั้นๆ ของการดำเนินการอัปเดตหลัก 4 ประเภทมีดังนี้ ตารางนี้ช่วยให้นักพัฒนาสามารถดูข้อมูลสำคัญได้อย่างรวดเร็ว ได้แก่ วิธี HTTP, รูปแบบจุดปลาย (endpoint pattern), พารามิเตอร์หลัก และการตอบกลับที่ประสบความสำเร็จโดยทั่วไปสำหรับแต่ละการดำเนินการ

| การดำเนินการ | วิธี HTTP | รูปแบบจุดปลาย (Endpoint Pattern)                                                                     | พารามิเตอร์หลัก              | การตอบกลับ 200‑OK             |
|---------------|-----------|------------------------------------------------------------------------------------------------------|-------------------------------|------------------------------|
| ตั้งค่ารูปแบบ  | PUT       | `/cells/{fileName}/worksheets/{sheetName}/ranges/{range}/style`                                      | วัตถุ `style`                 | รูปแบบช่วงข้อมูลที่อัปเดต    |
| ตั้งค่าค่า      | POST      | `/cells/{fileName}/worksheets/{sheetName}/ranges/{range}/values`                                    | อาเรย์ `values`                | ค่าช่วงข้อมูลที่อัปเดต        |
| ความสูงแถว     | PUT       | `/cells/{fileName}/worksheets/{sheetName}/ranges/{range}/rowheight`                                 | ตัวเลข `height`               | ความสูงแถวที่อัปเดต           |
| ความกว้างคอลัมน์ | PUT       | `/cells/{fileName}/worksheets/{sheetName}/ranges/{range}/columnwidth`                               | ตัวเลข `width`                | ความกว้างคอลัมน์ที่อัปเดต     |

หน้านี้จัดเตรียมการเข้าถึงอย่างรวดเร็วสำหรับการดำเนินการอัปเดตหลัก 4 ประเภท ได้แก่ การตั้งค่ารูปแบบช่วงข้อมูล การตั้งค่าค่าช่วงข้อมูล การปรับความสูงแถว และการปรับความกว้างคอลัมน์
