ลิงก์ใน Excel ช่วยให้ผู้ใช้สามารถสร้างทางลัดไปยังแผ่นงาน ไฟล์ โฟลเดอร์ หรือหน้าเว็บ เพื่อการนำทางไปยังตำแหน่งที่ต้องการได้อย่างรวดเร็ว

**ข้อกำหนดเบื้องต้น:** โทเคน API ที่ถูกต้อง (ดูได้ที่[คู่มือการยืนยันตัวตน](/th/authentication/)) และ SDK ของ Cells.Cloud ที่ติดตั้งแล้ว

## การจัดการลิงก์ในไฟล์ Excel

- [วิธีดึงคำอธิบายลิงก์จากแผ่นงาน Excel](/th/cells/hyperlinks/get/) – ดึงข้อมูลรายละเอียดของลิงก์เดียว รวมถึงที่อยู่และข้อความที่แสดง  
- [วิธีดึงคำอธิบายลิงก์ทั้งหมดจากแผ่นงาน Excel](/th/cells/hyperlinks/get-all/) – แสดงรายการลิงก์ทั้งหมดที่กำหนดไว้ในแผ่นงานพร้อมคุณสมบัติที่เกี่ยวข้อง  
- [วิธีเพิ่มลิงก์ในแผ่นงาน Excel](/th/cells/hyperlinks/add/) – แทรกลิงก์ใหม่ลงในแผ่นงาน โดยระบุ URL เป้าหมายและช่วงเซลล์  
- [วิธีแก้ไขลิงก์ในแผ่นงาน Excel](/th/cells/hyperlinks/update/) – แก้ไขที่อยู่ ข้อความที่แสดง หรือเซลล์เป้าหมายของลิงก์ที่มีอยู่  
- [วิธีลบลิงก์ทั้งหมดออกจากแผ่นงาน Excel](/th/cells/hyperlinks/clear/) – ลบลิงก์ทั้งหมดออกจากแผ่นงานในคำสั่งเดียว  
- [วิธีลบลิงก์ออกจากแผ่นงาน Excel](/th/cells/hyperlinks/delete/) – ลบลิงก์เฉพาะเจาะจงที่ระบุด้วยดัชนีหรือการอ้างอิงเซลล์
