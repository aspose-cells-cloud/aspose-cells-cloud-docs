**ข้อกำหนดเบื้องต้น**  
ก่อนเรียกใช้จุดปลายทาง (endpoint) จำเป็นต้องได้รับโทเค็นการเข้าถึง Aspose Cloud ที่ใช้งานอยู่พร้อมสิทธิ์ที่เหมาะสม และเวอร์ชัน API (`v3.0`)

### วิธีการตั้งค่าขนาดกระดาษด้วย Aspose.Cells Cloud REST API

```bash
curl -X PUT "https://api.aspose.cloud/v3.0/cells/Workbook/worksheets/Sheet1/pageSetup" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{"PaperSize":"PaperA4"}'
```

**รายละเอียดคำขอ**  
- **เมธอด:** `PUT`  
- **จุดปลายทาง (Endpoint):** `/cells/Workbook/worksheets/{sheetName}/pageSetup`  
- **พารามิเตอร์เส้นทาง (Path Parameters):** `sheetName` – ชื่อของชีตงาน (สตริง, จำเป็นต้องระบุ)  
- **เนื้อหาคำขอ (Request Body):** ออบเจกต์ JSON ที่มีคุณสมบัติ `PaperSize` โดยค่าของคุณสมบัตินี้ต้องเป็นหนึ่งในค่าคงที่ที่ระบุในตารางข้างต้น เช่น `"PaperA4"`

**การตอบกลับ**  
- `200 OK` – อัปเดตการตั้งค่าหน้ากระดาษเรียบร้อยแล้ว  
- `400 Bad Request` – ค่า `PaperSize` ไม่ถูกต้อง  
- `401 Unauthorized` – การยืนยันตัวตนล้มเหลวหรือไม่มีโทเค็น  
- `404 Not Found` – ไม่มีชีตงานที่ระบุ

**ตัวอย่าง SDK (C#)**  
```csharp
var api = new CellsApi("client_id", "client_secret");
var request = new PageSetup { PaperSize = PaperSizeEnum.PaperA4 };
api.PutWorksheetPageSetup("Book1.xlsx", "Sheet1", request);
```
