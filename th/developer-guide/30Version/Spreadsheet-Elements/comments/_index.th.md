เมื่อสร้างสมุดงาน Excel ผู้ใช้สามารถเพิ่มข้อคิดเห็นได้เพื่อวัตถุประสงค์ต่างๆ ตัวอย่างทั่วไปคือการอธิบายสูตรในเซลล์ โดยเฉพาะเมื่อไฟล์จะถูกแชร์กับผู้อื่น ข้อคิดเห็นยังสามารถใช้เป็นการเตือนความจำ โน้ตสำหรับผู้ร่วมงาน หรือเป็นเครื่องมืออ้างอิงข้ามสมุดงานอื่นๆ หลังจากเพิ่มข้อคิดเห็นแล้ว Excel อนุญาตให้ผู้ใช้ปรับขนาด ปรับรูปร่าง และจัดรูปแบบกล่องข้อคิดเห็นให้สอดคล้องกับรูปแบบที่ตนเองต้องการ การจัดการข้อคิดเห็นอย่างมีประสิทธิภาพจะช่วยให้ผู้ใช้ใช้ประโยชน์จากฟีเจอร์นี้ได้อย่างเต็มที่

**ข้อกำหนดเบื้องต้น**

- บัญชี Aspose.Cells Cloud ที่ยังไม่หมดอายุ  
- **โทเคนการเข้าถึง** ที่ถูกต้องซึ่งได้รับผ่าน OAuth 2.0  
- เวอร์ชัน API **v3.0** (ปลายทางที่ใช้ในคู่มือนี้อยู่ในเวอร์ชันนี้)  
- ทางเลือก: SDK ของ Aspose.Cells สำหรับภาษาที่คุณเลือก เพื่อช่วยให้การสร้างคำขอทำได้ง่ายขึ้น  

**เวอร์ชัน**

ตัวอย่างด้านล่างใช้ **Aspose.Cells Cloud REST API เวอร์ชัน 3.0** การปล่อย API ในอนาคตอาจเพิ่มพารามิเตอร์ใหม่หรือแก้ไขโครงสร้างของคำตอบ โปรดตรวจสอบเอกสารอ้างอิง API ล่าสุดเพื่อรับรายละเอียดที่เป็นปัจจุบันเสมอ

**การเพิ่มข้อคิดเห็น**

ในการเพิ่มข้อคิดเห็น ส่งคำขอแบบ **POST** ไปยังปลายทางต่อไปนี้:

```
POST https://api.aspose.cloud/v3.0/cells/{file}/worksheets/{sheet}/comments
Authorization: Bearer {access_token}
Content-Type: application/json
```

**พารามิเตอร์ในเส้นทาง**

| พารามิเตอร์ | ประเภท | จำเป็น | คำอธิบาย |
|-------------|--------|--------|----------|
| `file` | สตริง | จำเป็น | ชื่อไฟล์สมุดงาน (รวมนามสกุลด้วย) |
| `sheet` | สตริง | จำเป็น | ชื่อworksheet ที่จะเพิ่มข้อคิดเห็น |

**โครงสร้างเนื้อหาคำขอ**

| ฟิลด์ | ประเภท | จำเป็น | คำอธิบาย |
|-------|--------|--------|----------|
| `CellName` | สตริง | จำเป็น | ที่อยู่แบบ A1-style ของเซลล์ (เช่น **B2**) |
| `Comment` | สตริง | จำเป็น | ข้อความของข้อคิดเห็นที่จะจัดเก็บ |
| `Author` | สตริง | ไม่จำเป็น | ชื่อผู้เขียนข้อคิดเห็น |

**ตัวอย่างเนื้อหาคำขอ**

```json
{
  "CellName": "B2",
  "Comment": "ต้องตรวจสอบ",
  "Author": "John Doe"
}
```

**ตัวอย่างการตอบกลับที่สำเร็จ** (`200 OK`)

```json
{
  "Code": 200,
  "Status": "OK",
  "Comment": {
    "CellName": "B2",
    "Author": "John Doe",
    "HtmlComment": "ต้องตรวจสอบ",
    "Note": "ต้องตรวจสอบ"
  }
}
```

**รหัสข้อผิดพลาดที่พบบ่อย**

| รหัส | ความหมาย |
|------|-----------|
| 400 | ที่อยู่เซลล์หรือเนื้อหาคำขอไม่ถูกต้อง |
| 401 | ไม่ได้รับอนุญาต – โทเคนหายไปหรือไม่ถูกต้อง |
| 404 | ไม่พบสมุดงานหรือworksheet |

**การดึงข้อมูลข้อคิดเห็น**

ดึงข้อมูลข้อคิดเห็นทั้งหมดจาก worksheet:

```
GET https://api.aspose.cloud/v3.0/cells/{file}/worksheets/{sheet}/comments
Authorization: Bearer {access_token}
```

**พารามิเตอร์ในเส้นทาง**

| พารามิเตอร์ | ประเภท | จำเป็น | คำอธิบาย |
|-------------|--------|--------|----------|
| `file` | สตริง | จำเป็น | ชื่อไฟล์สมุดงาน |
| `sheet` | สตริง | จำเป็น | ชื่อ worksheet |

**ตัวอย่างการตอบกลับ**

```json
{
  "Code": 200,
  "Status": "OK",
  "Comments": [
    {
      "CellName": "A1",
      "Author": "Alice",
      "HtmlComment": "ค่าเริ่มต้น",
      "Note": "ค่าเริ่มต้น"
    },
    {
      "CellName": "B2",
      "Author": "John Doe",
      "HtmlComment": "ต้องตรวจสอบ",
      "Note": "ต้องตรวจสอบ"
    }
  ]
}
```

**การปรับปรุงข้อคิดเห็น**

ในการแก้ไขข้อคิดเห็นที่มีอยู่ ส่งคำขอแบบ **PUT** ข้อคิดเห็นจะถูกระบุด้วย **ดัชนี** ของมันในคอลเลกชันข้อคิดเห็นของ worksheet (เริ่มต้นที่ 0)

```
PUT https://api.aspose.cloud/v3.0/cells/{file}/worksheets/{sheet}/comments/{commentIndex}
Authorization: Bearer {access_token}
Content-Type: application/json
```

**พารามิเตอร์ในเส้นทาง**

| พารามิเตอร์ | ประเภท | จำเป็น | คำอธิบาย |
|-------------|--------|--------|----------|
| `file` | สตริง | จำเป็น | ชื่อไฟล์สมุดงาน |
| `sheet` | สตริง | จำเป็น | ชื่อ worksheet |
| `commentIndex` | ตัวเลขเต็ม | จำเป็น | ดัชนีของข้อคิดเห็นที่จะปรับปรุง (เริ่มต้นที่ 0) |

**โครงสร้างเนื้อหาคำขอ**

| ฟิลด์ | ประเภท | จำเป็น | คำอธิบาย |
|-------|--------|--------|----------|
| `Comment` | สตริง | จำเป็น | ข้อความข้อคิดเห็นใหม่ |
| `Author` | สตริง | ไม่จำเป็น | ชื่อผู้เขียนที่ปรับปรุงแล้ว (ไม่บังคับ) |

**ตัวอย่างเนื้อหาคำขอ**

```json
{
  "Comment": "ข้อความโน้ตที่ปรับปรุงแล้ว",
  "Author": "John Doe"
}
```

การตอบกลับจะมีโครงสร้างเดียวกับการตอบกลับในการ **เพิ่มข้อคิดเห็น**

**การลบข้อคิดเห็น**

ลบข้อคิดเห็นเดียวโดยใช้ดัชนีของมัน:

```
DELETE https://api.aspose.cloud/v3.0/cells/{file}/worksheets/{sheet}/comments/{commentIndex}
Authorization: Bearer {access_token}
```

**พารามิเตอร์ในเส้นทาง**

| พารามิเตอร์ | ประเภท | จำเป็น | คำอธิบาย |
|-------------|--------|--------|----------|
| `file` | สตริง | จำเป็น | ชื่อไฟล์สมุดงาน |
| `sheet` | สตริง | จำเป็น | ชื่อ worksheet |
| `commentIndex` | ตัวเลขเต็ม | จำเป็น | ดัชนีของข้อคิดเห็นที่จะลบ (เริ่มต้นที่ 0) |

การลบสำเร็จจะส่งกลับ:

```json
{
  "Code": 200,
  "Status": "OK"
}
```

**การลบข้อคิดเห็นทั้งหมด**

เพื่อล้างข้อคิดเห็นทั้งหมดจาก worksheet:

```
DELETE https://api.aspose.cloud/v3.0/cells/{file}/worksheets/{sheet}/comments
Authorization: Bearer {access_token}
```

**พารามิเตอร์ในเส้นทาง**

| พารามิเตอร์ | ประเภท | จำเป็น | คำอธิบาย |
|-------------|--------|--------|----------|
| `file` | สตริง | จำเป็น | ชื่อไฟล์สมุดงาน |
| `sheet` | สตริง | จำเป็น | ชื่อ worksheet |

**คำแนะนำการจัดการข้อผิดพลาด**

- **404 Not Found** – ตรวจสอบให้แน่ใจว่า ID สมุดงาน ชื่อ worksheet และดัชนีข้อคิดเห็นถูกต้อง  
- **400 Bad Request** – ตรวจสอบไวยากรณ์ JSON และฟิลด์ที่จำเป็น (`CellName`, `Comment`)  
- **429 Too Many Requests** – ใช้การหน่วงเวลาแบบ exponential back-off และเคารพ header `Retry-After`

**สรุป**

- ข้อคิดเห็นใน Excel ใช้เพื่อ [เพิ่มโน้ตหรืออธิบายสูตรในเซลล์](/cells/comments/add/)  
- Excel ให้ความยืดหยุ่นแก่ผู้ใช้ในการ [แก้ไข](/cells/comments/update/) [ลบ](/cells/comments/delete/) และ [แสดง](/cells/comments/get/) หรือ [ซ่อน](/cells/comments/update/) ข้อคิดเห็นใน worksheet  
- ผู้ใช้ยังสามารถ [ปรับขนาด](/cells/comments/update/) และ [ย้าย](/cells/comments/update/) กล่องข้อคิดเห็นได้อีกด้วย
