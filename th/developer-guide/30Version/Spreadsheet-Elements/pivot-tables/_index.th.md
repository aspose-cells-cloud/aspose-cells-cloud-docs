## การใช้งาน PivotTable ในไฟล์ Excel

PivotTable เป็นเครื่องมือที่ทรงพลังสำหรับการสรุปข้อมูลใน Excel ซึ่งช่วยให้นักพัฒนาสามารถรวม คัดกรอง และวิเคราะห์ชุดข้อมูลขนาดใหญ่ได้อย่างยืดหยุ่น API ของ Aspose.Cells Cloud มีเอนด์พอยต์ให้ใช้งานสำหรับการสร้าง ดึงข้อมูล แก้ไข และลบ PivotTable แบบเขียนโปรแกรม ทำให้สามารถผสานรวมเข้ากับแอปพลิเคชันของคุณได้อย่างราบรื่น

**ข้อกำหนดเบื้องต้น** – คุณต้องมีโทเคนยืนยันตัวตนที่ถูกต้องของ Aspose.Cells Cloud และติดตั้ง SDK ที่รองรับ (เช่น .NET, Java, Python, Go, Node.js, PHP, Ruby, Swift) ในโครงการของคุณ

**ตัวอย่างการเรียก API** – เพื่อดึงข้อมูล PivotTable ทั้งหมดในแผ่นงานที่ระบุ ให้ส่งคำขอ GET ดังนี้:

```http
GET https://api.aspose.cloud/v3.0/cells/{fileName}/worksheets/{sheetName}/pivottables
```
