ไฟล์ Excel สามารถจัดเก็บข้อมูลเมตาต่างๆ ซึ่งช่วยในการระบุ จัดระเบียบ และจัดการเอกสาร แอสโพส (Aspose.Cells) Cloud มี REST API ที่ใช้งานง่ายสำหรับการอ่าน เพิ่ม อัปเดต และลบข้อมูลเมตาเหล่านี้ ช่วยให้นักพัฒนาสามารถผสานการจัดการคุณสมบัติของเอกสารเข้ากับแอปพลิเคชันของตนได้ คู่มือนี้ครอบคลุมสองหมวดหมู่หลักของคุณสมบัติ—คุณสมบัติมาตรฐานและคุณสมบัติที่กำหนดเอง—อธิบายวิธีการใช้งานคุณสมบัติเหล่านี้ และจัดเตรียมลิงก์โดยตรงไปยังจุดสิ้นสุด API ที่เกี่ยวข้อง นอกจากนี้คุณยังจะพบตารางอ้างอิง API ที่กระชับพร้อมรายละเอียดคำขอ เพื่อเร่งการนำไปใช้งาน

**อัปเดตล่าสุด:** 8 กรกฎาคม พ.ศ. 2569  

**ประเภทของคุณสมบัติของเอกสาร**

ก่อนเรียนรู้วิธีใช้ API ของ Aspose.Cells Cloud เพื่อดู แก้ไข และลบคุณสมบัติของเอกสาร (ข้อมูลเมตา) ใน Excel ขออธิบายประเภทของคุณสมบัติที่เอกสาร Excel สามารถมีได้

- **คุณสมบัติมาตรฐาน** เป็นคุณสมบัติที่มีร่วมกันใน Excel ซึ่งประกอบด้วยข้อมูลพื้นฐาน เช่น ชื่อเรื่อง (Title), หัวเรื่องย่อย (Subject), ผู้เขียน (Author), หมวดหมู่ (Category) เป็นต้น คุณสามารถกำหนดค่าข้อความที่เป็นค่ากำหนดเองให้กับคุณสมบัติเหล่านี้ เพื่อทำให้ไฟล์ค้นหาง่ายขึ้น

- **คุณสมบัติที่กำหนดเอง** เป็นคุณสมบัติที่ผู้ใช้กำหนดเอง ซึ่งช่วยให้คุณสามารถเพิ่มข้อมูลเมตาเพิ่มเติมให้กับเอกสาร Excel ได้

**การอ้างอิง API (โดยไม่ใช้พื้นที่จัดเก็บ)**  

| เมธอด | จุดสิ้นสุด | คำอธิบาย |
|--------|----------|-------------|
| **GET** | `GET https://api.aspose.cloud/v3.0/cells/metadata` | ดึงคุณสมบัติของเอกสารทั้งหมดของสมุดงานที่จัดเก็บไว้ในคลาวด์ |
| **GET** | `GET https://api.aspose.cloud/v3.0/cells/metadata/{propertyName}` | ดึงค่าของคุณสมบัติที่ระบุ (มาตรฐานหรือที่กำหนดเอง) โดยระบุด้วย `propertyName` |
| **PUT** | `PUT https://api.aspose.cloud/v3.0/cells/metadata/{propertyName}` | อัปเดตค่าของคุณสมบัติที่มีอยู่ ซึ่งค่าใหม่จะถูกส่งมาในรูปแบบ JSON ในเนื้อหาคำขอ |
| **DELETE** | `DELETE https://api.aspose.cloud/v3.0/cells/metadata/{propertyName}` | ลบคุณสมบัติที่ระบุออกจากสมุดงาน |
| **DELETE** | `DELETE https://api.aspose.cloud/v3.0/cells/metadata` | ล้างคุณสมบัติทั้งหมดทั้งมาตรฐานและที่กำหนดเองออกจากสมุดงาน |

*คำขอทั้งหมดต้องมีโทเค็นการเข้าถึง OAuth 2.0 และอาจรวมพารามิเตอร์คำสั่งแบบเลือก เช่น `storage` และ `folder` เมื่อใช้ตำแหน่งพื้นที่จัดเก็บที่ระบุ*
