การตรวจสอบข้อมูลใน Excel เป็นคุณสมบัติของ Microsoft Excel ที่ใช้ควบคุมสิ่งที่ผู้ใช้สามารถป้อนลงในเซลล์ของเวิร์กชีตได้ ซึ่งสามารถจำกัดการป้อนข้อมูลให้อยู่ในช่วงวันที่ที่กำหนด เฉพาะตัวเลขจำนวนเต็ม หรือแม้แต่สร้างรายการแบบดรอปดาวน์เพื่อประหยัดพื้นที่และแสดงค่าในเซลล์เดียวได้ คุณยังสามารถกำหนดข้อความแบบกำหนดเองที่จะปรากฏเมื่อผู้ใช้ป้อนค่าที่ไม่ถูกต้องหรือรูปแบบที่ไม่ถูกต้อง

ตัวอย่างเช่น ผู้ใช้สามารถระบุการประชุมที่กำหนดเวลาไว้ระหว่าง 9:00 น. ถึง 18:00 น.

การตรวจสอบข้อมูลสามารถใช้เพื่อให้แน่ใจว่าค่าที่ป้อนเป็นจำนวนบวก เป็นวันที่ระหว่างวันที่ 15 ถึง 30 ของเดือน เป็นวันที่ภายใน 30 วันข้างหน้า หรือข้อความที่มีจำนวนอักขระน้อยกว่า 25 ตัว เป็นต้น

### สรุป API

| การดำเนินการ | วิธี HTTP | จุดปลายทาง | คำอธิบาย |
|--------------|-----------|------------|----------|
| เพิ่ม | POST | `/cells/{file}/worksheets/{sheet}/validations` | สร้างกฎการตรวจสอบ |
| ดึงข้อมูล | GET | `/cells/{file}/worksheets/{sheet}/validations/{index}` | ดึงข้อมูลกฎที่ระบุ |
| ดึงข้อมูลทั้งหมด | GET | `/cells/{file}/worksheets/{sheet}/validations` | แสดงรายการกฎทั้งหมด |
| ปรับปรุง | PUT | `/cells/{file}/worksheets/{sheet}/validations/{index}` | แก้ไขกฎ |
| ลบ | DELETE | `/cells/{file}/worksheets/{sheet}/validations/{index}` | ลบกฎ |
| ล้าง | POST | `/cells/{file}/worksheets/{sheet}/validations/clear` | ลบกฎทั้งหมด |
