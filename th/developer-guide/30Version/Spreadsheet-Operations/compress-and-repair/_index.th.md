การบีบอัดสมุดงาน Excel จะช่วยลดขนาดไฟล์โดยการลบรูปแบบ รูปภาพ และสตริงที่ใช้ร่วมกันที่ไม่ได้ใช้งาน ส่วนการซ่อมแซมจะคืนความสมบูรณ์ให้กับสมุดงานที่เสียหาย API ของ Aspose.Cells Cloud มีจุดปลายทาง (endpoint) ที่จัดทำขึ้นเฉพาะสำหรับการดำเนินการทั้งสองนี้

- **[บีบอัดข้อมูลในไฟล์ Excel](https://docs.aspose.cloud/cells/compress-excel-files/)**
- **[ซ่อมแซมไฟล์ Excel](https://docs.aspose.cloud/cells/repair-excel-files/)**

**API สำหรับการบีบอัดสมุดงาน**  
การดำเนินการ **บีบอัด (Compress)** ใช้คำขอแบบ POST อย่างง่ายดาย โดยมีรายละเอียดของคำขอและคำตอบดังตารางต่อไปนี้:

| เมธอด | จุดปลายทาง | พารามิเตอร์ที่จำเป็น | เนื้อหาคำขอ | ตัวอย่างการตอบกลับ | โค้ดสถานะที่พบบ่อย |
|--------|----------|---------------------|--------------|-----------------|----------------------|
| POST   | `/cells/compress` | `file` (ไบนารี) – สมุดงานที่ต้องการบีบอัด; `outPath` (สตริง) – ตำแหน่งที่จะบันทึก (ไม่บังคับ) | *ไม่มี* (ไฟล์ส่งผ่านรูปแบบ multipart/form‑data) | `{ "compressedSize": 12456, "originalSize": 45678 }` | `200 OK`, `400 Bad Request`, `401 Unauthorized` |

**API สำหรับการซ่อมแซมสมุดงาน**  
การดำเนินการ **ซ่อมแซม (Repair)** ก็ใช้คำขอแบบ POST เช่นกัน โดยมีรายละเอียดดังตารางต่อไปนี้:

| เมธอด | จุดปลายทาง | พารามิเตอร์ที่จำเป็น | เนื้อหาคำขอ | ตัวอย่างการตอบกลับ | โค้ดสถานะที่พบบ่อย |
|--------|----------|---------------------|--------------|-----------------|----------------------|
| POST   | `/cells/repair` | `file` (ไบนารี) – สมุดงานที่เสียหาย; `outPath` (สตริง) – ตำแหน่งที่จะบันทึกไฟล์ที่ซ่อมแซมแล้ว (ไม่บังคับ) | *ไม่มี* (ไฟล์ส่งผ่านรูปแบบ multipart/form‑data) | `{ "isRepaired": true, "message": "Workbook repaired successfully." }` | `200 OK`, `400 Bad Request`, `415 Unsupported Media Type` |

ตารางเหล่านี้ให้ข้อมูลสำคัญที่นักพัฒนาจำเป็นต้องรู้เพื่อเรียกใช้ API ได้โดยตรงโดยไม่ต้องค้นหาข้อมูลเพิ่มเติมจากที่อื่น

**แหล่งข้อมูลเพิ่มเติม**  
- ดูคู่มือ **[บีบอัดไฟล์ Excel](/compress-excel-files/)** แบบเต็มรูปแบบเพื่อเรียนรู้ตัวเลือกขั้นสูง เช่น การลบแถวและคอลัมน์ที่ไม่ได้ใช้งาน  
- ทบทวนเอกสาร **[ซ่อมแซมไฟล์ Excel](/repair-excel-files/)** เพื่อรับคำแนะนำในการแก้ไขปัญหาและการอธิบายโค้ดข้อผิดพลาด  
- สำรวจการดำเนินการที่เกี่ยวข้อง เช่น **[รับข้อมูลไฟล์](/file-info/)** และ **[การดำเนินการกับสเปรดชีต](/spreadsheet-operations/)** เพื่อความเข้าใจที่กว้างขึ้นเกี่ยวกับ Aspose.Cells Cloud API
