# คุณสมบัติของ SaveOptions

SaveOptions ช่วยให้คุณควบคุมวิธีการบันทึกสมุดงานเมื่อใช้ Aspose.Cells Cloud REST API ด้วยการกำหนดค่าตัวเลือกเหล่านี้ คุณสามารถเปิดใช้งานการบีบอัด HTTP, ระบุรูปแบบไฟล์ปลายทาง, จัดการที่จัดเก็บชั่วคราว และควบคุมพฤติกรรมอื่นๆ เช่น การรีเฟรชแคชของกราฟและการสร้างไดเรกทอรีโดยอัตโนมัติ

**ข้อกำหนดเบื้องต้น**  
- วาระการใช้งาน Aspose.Cells Cloud ที่ผ่านการยืนยันตัวตน (OAuth 2.0 หรือ JWT)  
- สมุดงานปลายทางต้องถูกโหลดหรือสร้างผ่าน API ก่อนการบันทึก

| ชื่อ                      | ประเภท       | คำอธิบาย                                                                                        | หมายเหตุ      |
| ------------------------- | ---------- | -------------------------------------------------------------------------------------------------- | ---------- |
| **EnableHTTPCompression** | **bool?**  | เปิดใช้งานการบีบอัด HTTP สำหรับการตอบกลับ                                                               | [ไม่บังคับ] |
| **SaveFormat**            | **string** | ระบุรูปแบบไฟล์ปลายทางสำหรับการบันทึกสมุดงาน                                                          | [ไม่บังคับ] |
| **ClearData**             | **bool?**  | ทำให้สมุดงานว่างเปล่าหลังจากบันทึกไฟล์                                                                   | [ไม่บังคับ] |
| **CachedFileFolder**      | **string** | ไดเรกทอรีสำหรับเก็บข้อมูลขนาดใหญ่ชั่วคราว                                                                  | [ไม่บังคับ] |
| **ValidateMergedAreas**   | **bool?**  | ระบุว่าจะตรวจสอบพื้นที่ที่ผสานก่อนบันทึกไฟล์หรือไม่ ค่าเริ่มต้นคือ false                                   | [ไม่บังคับ] |
| **RefreshChartCache**     | **bool?**  | รีเฟรชข้อมูลแคชของกราฟก่อนการบันทึก                                                                          | [ไม่บังคับ] |
| **CreateDirectory**       | **bool?**  | หากเป็น true และไดเรกทอรียังไม่มีอยู่ จะถูกสร้างขึ้นโดยอัตโนมัติก่อนบันทึกไฟล์                                  | [ไม่บังคับ] |
| **SortNames**             | **bool?**  | เรียงลำดับช่วงที่ตั้งชื่อไว้ตามพจนานุกรมขณะบันทึก                                                           | [ไม่บังคับ] |

**คำขอ**  
- **เมธอด:** `POST` (หรือ `PUT` ขึ้นอยู่กับการดำเนินการ)  
- **จุดปลายทาง:** `/cells/workbook/save`  
- **ส่วนหัว:**  
  - `Authorization: Bearer <access_token>`  
  - `Content-Type: application/json`  
- **เนื้อหา:** การแทนค่า JSON ของโมเดล `SaveOptions` (ตารางด้านบน) รวมกับข้อมูลหรือข้อมูลอ้างอิงของสมุดงาน

**ตัวอย่างการตอบกลับ**  
```json
{
  "status": "OK",
  "downloadUrl": "https://api.aspose.cloud/v3.0/cells/workbook/save/result.xlsx",
  "message": "บันทึกสมุดงานเรียบร้อยแล้ว"
}
```

**รหัสสถานะ HTTP**

| รหัส | ความหมาย                     | คำอธิบาย                                      |
|------|-----------------------------|--------------------------------------------------|
| 200  | OK                          | กรองถูกใช้งานเรียบร้อยแล้ว; การตอบกลับมีรายละเอียดของการดำเนินการ |
| 400  | Bad Request                 | พารามิเตอร์ขาดหายหรือไม่ถูกต้อง (เช่น ประเภทไฟล์ที่ไม่รองรับ) |
| 401  | Unauthorized                | โทเคน JWT ไม่ถูกต้องหรือขาดหาย |
| 413  | Payload Too Large           | ไฟล์ที่อัปโหลดมีขนาดเกินขีดจำกัด |
| 500  | Internal Server Error       | เกิดข้อผิดพลาดของเซิร์ฟเวอร์ที่ไม่คาดคิด |

**หมายเหตุ / ข้อสังเกต**  
- เมื่อตั้งค่า **CreateDirectory** เป็น `true` API จะสร้างโฟลเดอร์ปลายทางโดยอัตโนมัติหากยังไม่มีอยู่  
- การเปิดใช้งาน **EnableHTTPCompression** สามารถลดขนาดของข้อมูลที่ส่งได้สำหรับสมุดงานที่มีขนาดใหญ่ แต่ไคลเอนต์ต้องรองรับการถอดรหัส gzip/deflate  
- ควรใช้ **RefreshChartCache** เมื่อกราฟขึ้นอยู่กับข้อมูลแบบไดนามิกที่อาจเปลี่ยนแปลงไปตั้งแต่สมุดงานถูกสร้างขึ้น
