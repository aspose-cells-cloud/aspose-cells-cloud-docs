Aspose.Cells Cloud API มีเอนด์พอยต์แบบแบตช์ที่ช่วยให้คุณสามารถดำเนินการทั่วไปต่างๆ กับไฟล์ Excel หลายไฟล์ในคำขอเดียว ด้านล่างนี้คือภาพรวมโดยย่อของฟังก์ชันการประมวลผลแบบแบตช์ที่มีอยู่ พร้อมด้วยข้อมูลเฉพาะของ API สำหรับแต่ละฟังก์ชัน

- **["แปลงไฟล์ Excel แบบแบตช์"](https://docs.aspose.cloud/cells/batch/convert "แปลงไฟล์ Excel แบบแบตช์")**  
  *แปลงไฟล์ Excel หลายไฟล์ไปยังรูปแบบผลลัพธ์ที่เลือกในคำขอเดียว*  

  **รายละเอียดของ API**  
  ```http
  POST /cells/batch/convert
  Content-Type: multipart/form-data
  Authorization: Bearer {access_token}
  ```  

  **พารามิเตอร์**  

  | ชื่อพารามิเตอร์ | ประเภท | คำอธิบาย                                      |
  |------------------|--------|-----------------------------------------------|
  | files            | file[] | หนึ่งไฟล์หรือหลายไฟล์ Excel ที่ต้องการแปลง   |
  | outputFormat     | string | รูปแบบผลลัพธ์ที่ต้องการ (เช่น pdf, csv, html) |
  | storage          | string | (ไม่บังคับ) ชื่อพื้นที่จัดเก็บบนคลาวด์         |

  **การตอบกลับ**  

  | โค้ด | คำอธิบาย                                     |
  |------|----------------------------------------------|
  | 200  | การแปลงสำเร็จ; ส่งคืนไฟล์                   |
  | 400  | พารามิเตอร์ที่ส่งมามีข้อผิดพลาด              |
  | 401  | ไม่ได้รับอนุญาต – ไม่มีโทเค็นหรือโทเค็นไม่ถูกต้อง |
  | 500  | ข้อผิดพลาดภายในเซิร์ฟเวอร์                    |

- **["ล็อกไฟล์ Excel แบบแบตช์"](https://docs.aspose.cloud/cells/batch/lock "ล็อกไฟล์ Excel แบบแบตช์")**  
  *ใช้รหัสผ่านเพื่อล็อกไฟล์ Excel หลายไฟล์พร้อมกัน*  

  **รายละเอียดของ API**  
  ```http
  POST /cells/batch/lock
  Content-Type: application/json
  Authorization: Bearer {access_token}
  ```  

  **พารามิเตอร์**  

  | ชื่อพารามิเตอร์ | ประเภท | คำอธิบาย                                  |
  |------------------|--------|-------------------------------------------|
  | files            | array  | รายการตัวระบุไฟล์หรือ URL                  |
  | password         | string | รหัสผ่านที่จะใช้ล็อกสมุดงาน                |
  | storage          | string | (ไม่บังคับ) ชื่อพื้นที่จัดเก็บบนคลาวด์      |

  **การตอบกลับ**  

  | โค้ด | คำอธิบาย                                     |
  |------|----------------------------------------------|
  | 200  | การล็อกไฟล์สำเร็จ                            |
  | 400  | พารามิเตอร์ขาดหายหรือไม่ถูกต้อง             |
  | 401  | การเข้าถึงโดยไม่ได้รับอนุญาต                |
  | 500  | เกิดข้อผิดพลาดที่เซิร์ฟเวอร์                 |

- **["ป้องกันไฟล์ Excel แบบแบตช์"](https://docs.aspose.cloud/cells/batch/protect "ป้องกันไฟล์ Excel แบบแบตช์")**  
  *เพิ่มการตั้งค่าการป้องกัน (เช่น อ่านอย่างเดียว, โครงสร้าง) ให้กับสมุดงานหลายเล่มพร้อมกัน*  

  **รายละเอียดของ API**  
  ```http
  POST /cells/batch/protect
  Content-Type: application/json
  Authorization: Bearer {access_token}
  ```  

  **พารามิเตอร์**  

  | ชื่อพารามิเตอร์ | ประเภท | คำอธิบาย                                        |
  |------------------|--------|-------------------------------------------------|
  | files            | array  | รายการตัวระบุไฟล์หรือ URL                       |
  | protection       | object | ตัวเลือกการป้องกัน (เช่น readOnly, structure)  |
  | storage          | string | (ไม่บังคับ) ชื่อพื้นที่จัดเก็บบนคลาวด์          |

  **การตอบกลับ**  

  | โค้ด | คำอธิบาย                                     |
  |------|----------------------------------------------|
  | 200  | การใช้การป้องกันสำเร็จ                       |
  | 400  | ข้อมูลคำขอไม่ถูกต้อง                         |
  | 401  | การตรวจสอบสิทธิ์ล้มเหลว                      |
  | 500  | เกิดข้อผิดพลาดที่เซิร์ฟเวอร์โดยไม่คาดคิด     |

- **["แยกไฟล์แบบแบตช์"](https://docs.aspose.cloud/cells/batch/split "แยกไฟล์แบบแบตช์")**  
  *แบ่งสมุดงาน Excel ขนาดใหญ่ออกเป็นไฟล์ย่อยตามแผ่นงานหรือช่วงของแถว*  

  **รายละเอียดของ API**  
  ```http
  POST /cells/batch/split
  Content-Type: application/json
  Authorization: Bearer {access_token}
  ```  

  **พารามิเตอร์**  

  | ชื่อพารามิเตอร์ | ประเภท | คำอธิบาย                                      |
  |------------------|--------|-----------------------------------------------|
  | files            | array  | ไฟล์ที่ต้องการแยก                              |
  | splitBy          | string | เกณฑ์: "worksheet" หรือ "rowRange"            |
  | criteria         | object | รายละเอียดของวิธีการแยกที่เลือก               |
  | storage          | string | (ไม่บังคับ) ชื่อพื้นที่จัดเก็บบนคลาวด์         |

  **การตอบกลับ**  

  | โค้ด | คำอธิบาย                                     |
  |------|----------------------------------------------|
  | 200  | การดำเนินการแยกเสร็จสมบูรณ์; ส่งคืนส่วนย่อย   |
  | 400  | พารามิเตอร์การแยกไม่ถูกต้อง                  |
  | 401  | คำขอไม่ได้รับอนุญาต                           |
  | 500  | เกิดข้อผิดพลาดในการประมวลผล                 |

- **["ปลดล็อกไฟล์แบบแบตช์"](https://docs.aspose.cloud/cells/batch/unlock "ปลดล็อกไฟล์แบบแบตช์")**  
  *นำการป้องกันด้วยรหัสผ่านออกจากไฟล์ Excel หลายไฟล์ในคำขอเดียว*  

  **รายละเอียดของ API**  
  ```http
  POST /cells/batch/unlock
  Content-Type: application/json
  Authorization: Bearer {access_token}
  ```  

  **พารามิเตอร์**  

  | ชื่อพารามิเตอร์ | ประเภท | คำอธิบาย                                  |
  |------------------|--------|-------------------------------------------|
  | files            | array  | รายการตัวระบุไฟล์หรือ URL ที่ถูกล็อกไว้   |
  | password         | string | รหัสผ่านปัจจุบันของไฟล์                    |
  | storage          | string | (ไม่บังคับ) ชื่อพื้นที่จัดเก็บบนคลาวด์      |

  **การตอบกลับ**  

  | โค้ด | คำอธิบาย                                     |
  |------|----------------------------------------------|
  | 200  | การปลดล็อกไฟล์สำเร็จ                         |
  | 400  | รหัสผ่านผิดหรือไฟล์ขาดหาย                   |
  | 401  | การเข้าถึงโดยไม่ได้รับอนุญาต                |
  | 500  | ความล้มเหลวที่ฝั่งเซิร์ฟเวอร์                |
