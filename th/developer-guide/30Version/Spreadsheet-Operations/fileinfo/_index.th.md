## คุณสมบัติ FileInfo


| ชื่อ            | ชนิดข้อมูล | คำอธิบาย                                             |
| --------------- | ---------- | ---------------------------------------------------- |
| **FileName**    | string     | ชื่อไฟล์ รวมถึงส่วนขยาย                              |
| **FileSize**    | long       | ขนาดไฟล์เป็นไบต์                                     |
| **FileContent** | string     | เก็บข้อมูลดิบของไฟล์ Excel ที่เข้ารหัสในรูปแบบ Base64 |

การตอบกลับจะถูกส่งกลับในรูปแบบ JSON พร้อมคุณสมบัติทั้งสามข้างต้น ดังตัวอย่าง:

```json
{
  "FileName": "MyWorkbook.xlsx",
  "FileSize": 254312,
  "FileContent": "UEsDBBQABgAIAAAAIQD..."
}
```

### ข้อผิดพลาด

| โค้ด HTTP | ความหมาย                | เกิดขึ้นเมื่อ                                   |
| --------- | ----------------------- | --------------------------------------------- |
| 200       | สำเร็จ – คำขอร้องประสบความสำเร็จ | การตอบกลับปกติ                                 |
| 401       | ไม่ได้รับอนุญาต          | ไม่มีโทเคนยืนยันตัวตนหรือโทเคนไม่ถูกต้อง    |
| 404       | ไม่พบ                    | ไฟล์ที่ระบุไม่มีอยู่                            |
| 500       | ข้อผิดพลาดภายในเซิร์ฟเวอร์ | เกิดข้อผิดพลาดที่ไม่คาดคิดฝั่งเซิร์ฟเวอร์      |

สำหรับแต่ละข้อผิดพลาด โปรดตรวจสอบให้แน่ใจว่าโทเคนยืนยันตัวตนถูกต้อง (401) ตรวจสอบเส้นทางไฟล์ (404) หรืออ้างอิงคู่มือการจัดการข้อผิดพลาดทั่วไปเพื่อใช้กลยุทธ์การลองใหม่ (500)
