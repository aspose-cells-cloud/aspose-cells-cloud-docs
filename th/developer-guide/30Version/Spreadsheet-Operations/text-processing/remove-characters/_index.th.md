## เว็บ API สำหรับการลบอักขระจาก Excel

ชุดเครื่องมือที่ครอบคลุมสำหรับการล้างข้อความภายในเซลล์ที่เลือก API จะลบอักขระที่ระบุ ชุดอักขระที่กำหนดไว้ล่วงหน้า หรือสตริงย่อย เพื่อให้มั่นใจว่าข้อความในแผ่นงานมีรูปแบบมาตรฐานและไม่มีสัญลักษณ์ที่ไม่ต้องการ

**ข้อกำหนดเบื้องต้น**

- บัญชี Aspose Cloud ที่ยังไม่หมดอายุ  
- เท็กซ์โทเค็น JWT ที่ถูกต้อง ซึ่งได้มาตามที่อธิบายไว้ในคู่มือการยืนยันตัวตน  
- ต้องอัปโหลดไฟล์ Excel ไปยังที่เก็บข้อมูลก่อนเรียกใช้จุดปลายทางนี้  
- รูปแบบไฟล์ที่รองรับ ได้แก่ `.xlsx`, `.xls`, `.xlsm` และรูปแบบ Excel ทั่วไปอื่นๆ

```http
POST https://api.aspose.cloud/v3.0/cells/removecharacters
```

### **ความปลอดภัยและการยืนยันตัวตน**

API ของ Aspose.Cells Cloud มีความปลอดภัย และต้องใช้<a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การยืนยันตัวตนแบบใช้โทเค็น JWT</a>

### คำอธิบายฟังก์ชัน

- **ลบอักขระแบบกำหนดเอง** – ระบุอักขระใดก็ได้ที่ต้องการลบ ใส่แต่ละอักขระในช่อง _ลบอักขระแบบกำหนดเอง_ API จะลบทุกตัวอักขระที่ตรงกันในเซลล์ที่เลือก  
- **ลบชุดอักขระ** – เลือกจากชุดที่กำหนดไว้ล่วงหน้า:  
  - **อักขระที่ไม่แสดงผล** – ลบการขึ้นบรรทัดใหม่และอักขระ ASCII ที่ไม่แสดงผล 32 ตัวแรก (0–31) รวมถึงโค้ดเพิ่มเติม (127, 129, 141, 143, 144, 157)  
  - **อักขระตัวอักษร** – ลบตัวอักษรทั้งหมด  
  - **อักขระตัวเลข** – ลบตัวเลขทั้งหมด  
  - **สัญลักษณ์** – ลบสัญลักษณ์ทางคณิตศาสตร์ เรขาคณิต วิศวกรรม เงินตรา และสัญลักษณ์ที่คล้ายตัวอักษร เช่น “?”, “1”, และ “™”  
  - **เครื่องหมายวรรคตอน** – ลบเครื่องหมายวรรคตอนทั้งหมด  
- **ลบสตริงย่อย** – ลบสตริงย่อยที่ระบุ (เช่น คำ) จากเซลล์ที่เลือก

### พารามิเตอร์คำขอ

| ชื่อพารามิเตอร์         | ชนิดข้อมูล | ตำแหน่ง | คำอธิบาย                                                                 |
| ----------------------- | --------- | ------- | ------------------------------------------------------------------------ |
| removeCharactersOptions | คลาส      | เนื้อหาคำขอ | ตัวเลือกที่กำหนดว่าจะลบอักขระ ชุดอักขระ หรือสตริงย่อยใดบ้าง           |

**โครงสร้างของ `removeCharactersOptions`**

| คุณสมบัติ         | ชนิดข้อมูล | จำเป็น | คำอธิบาย                                                                                      |
| ---------------- | -------- | ----- | ---------------------------------------------------------------------------------------------- |
| Range            | สตริง    | จำเป็น | ระบุตำแหน่งเซลล์ในรูปแบบ A‑1 หรือชื่อช่วง (เช่น `"A1:C10"`) ที่ต้องการประมวลผล              |
| CustomCharacters | สตริง    | ไม่บังคับ | สตริงที่ประกอบด้วยอักขระแบบกำหนดเองที่ต้องการลบ (เช่น `"@#$"`)                                |
| CharacterSet     | สตริง    | ไม่บังคับ | ค่าอีนัม (enum) ที่ระบุชุดอักขระที่กำหนดไว้ล่วงหน้า (`"NonPrinting"`, `"Text"`, `"Numeric"`, `"Symbols"`, `"Punctuation"`) |
| Substring        | สตริง    | ไม่บังคับ | สตริงย่อยที่ต้องการลบอย่างตรงจุด (เช่น `"USD"`)                                               |
| IgnoreCase       | บูลีน   | ไม่บังคับ | เมื่อตั้งค่าเป็น `true` การลบอักขระจะไม่คำนึงถึงตัวพิมพ์เล็ก/ใหญ่                               |

**ตัวอย่างเนื้อหาคำขอ JSON**

```json
{
  "Range": "A1:B20",
  "CustomCharacters": "@#$",
  "CharacterSet": "NonPrinting",
  "Substring": "USD",
  "IgnoreCase": true
}
```

**ตัวอย่างคำขอ cURL**

```bash
curl -X POST "https://api.aspose.cloud/v3.0/cells/removecharacters" \
     -H "Authorization: Bearer {access_token}" \
     -H "Content-Type: application/json" \
     -d '{
           "Range": "A1:B20",
           "CustomCharacters": "@#$",
           "CharacterSet": "NonPrinting",
           "Substring": "USD",
           "IgnoreCase": true
         }'
```

### **การตอบกลับ**

```json
{
    "Status" : "OK",
    "Code" : 200,
    "Filename" : "[ชื่อไฟล์ที่รวมแล้ว]",
    "Filesize" : [ขนาดไฟล์],
    "FileContent" : "[Base64String]"
}
```

**โค้ดสถานะ HTTP**

| โค้ด | ความหมาย                     | คำอธิบาย                                               |
|------|-----------------------------|--------------------------------------------------------|
| 200  | สำเร็จ (OK)                 | ใช้ตัวกรองสำเร็จ; การตอบกลับจะประกอบด้วยรายละเอียดของปฏิบัติการ |
| 400  | คำขอไม่ถูกต้อง (Bad Request) | พารามิเตอร์ขาดหายหรือไม่ถูกต้อง (เช่น รูปแบบไฟล์ที่ไม่รองรับ) |
| 401  | ไม่ได้รับอนุญาต (Unauthorized) | โทเค็น JWT ไม่ถูกต้องหรือขาดหาย                           |
| 413  | ข้อมูลคำขอใหญ่เกินไป (Payload Too Large) | ไฟล์ที่อัปโหลดมีขนาดเกินขีดจำกัดที่กำหนด                 |
| 500  | ข้อผิดพลาดภายในเซิร์ฟเวอร์ (Internal Server Error) | เกิดข้อผิดพลาดที่ไม่คาดคิดของเซิร์ฟเวอร์                |
