**API การตรวจสอบวัตถุ** ช่วยให้นักพัฒนาสามารถระบุได้ว่าไฟล์หรือโฟลเดอร์ที่ระบุมีอยู่ในพื้นที่จัดเก็บ Aspose.Cells Cloud หรือไม่ โดยจะส่งค่า Boolean กลับมาเพื่อระบุว่ามีอยู่จริงหรือไม่ และว่าพาธชี้ไปยังโฟลเดอร์หรือไม่

## **API สำหรับ Excel: การตรวจสอบวัตถุ**

### Web API

```http
GET https://api.aspose.cloud/v5.0/cells/storage/exist/{path}
```

_`{path}`_ คือพาธเต็มไปยังไฟล์หรือโฟลเดอร์ในพื้นที่จัดเก็บ

### **การรักษาความปลอดภัยและการยืนยันตัวตน**

Aspose.Cells Cloud APIs มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การยืนยันตัวตนด้วย JWT token</a>

### พารามิเตอร์คำขอ

| ชื่อพารามิเตอร์ | ประเภทข้อมูล | ตำแหน่ง | จำเป็น | คำอธิบาย                                                                 |
| ---------------- | ------------ | -------- | ------ | ------------------------------------------------------------------------ |
| `path`           | string       | Path     | ใช่    | พาธเต็มไปยังไฟล์หรือโฟลเดอร์                                           |
| `storageName`    | string       | Query    | ไม่ใช่ | ชื่อของพื้นที่จัดเก็บ; จะใช้พื้นที่จัดเก็บหลักโดยค่าเริ่มต้นหากไม่ระบุ |
| `versionId`      | string       | Query    | ไม่ใช่ | ตัวระบุเวอร์ชันเฉพาะของไฟล์ (หากเปิดใช้งานการจัดเวอร์ชัน)             |

**โค้ดสถานะ HTTP**

| โค้ด HTTP | สถานะ HTTP            | คำอธิบาย                                                                 |
| --------- | --------------------- | ------------------------------------------------------------------------ |
| 200       | OK (สำเร็จ)           | เรียกใช้ Web API สำเร็จ; การตอบกลับมีรายละเอียดของคำสั่งทำงาน         |
| 400       | Bad Request (คำขอไม่ถูกต้อง) | พารามิเตอร์ขาดหายหรือไม่ถูกต้อง (เช่น ประเภทไฟล์ที่ไม่รองรับ)        |
| 401       | Unauthorized (ไม่ได้รับอนุญาต) | JWT token ไม่ถูกต้องหรือขาดหาย                                      |
| 413       | Payload Too Large (ข้อมูลส่งไปมีขนาดใหญ่เกินไป) | ไฟล์ที่อัปโหลดมีขนาดเกินขีดจำกัดที่กำหนด                         |
| 500       | Internal Server Error (ข้อผิดพลาดภายในเซิร์ฟเวอร์) | เกิดข้อผิดพลาดที่ไม่คาดคิดบนเซิร์ฟเวอร์                           |

### **การตอบกลับ**

การเรียกใช้ที่สำเร็จจะส่งค่า JSON payload ที่มีคุณสมบัติ 2 ประการกลับมา:

```json
{
  "Exists": true,
  "IsFolder": false
}
```

- **Exists** – `true` หากไฟล์หรือโฟลเดอร์มีอยู่ มิฉะนั้นเป็น `false`
- **IsFolder** – `true` หากพาธชี้ไปยังโฟลเดอร์; `false` หากเป็นไฟล์

## ข้อมูลจำเพาะ OpenAPI

[ข้อมูลจำเพาะ OpenAPI](https://reference.aspose.cloud/cells/#/StorageController/ObjectExists) กำหนดอินเทอร์เฟซโปรแกรมที่สามารถเข้าถึงได้แบบสาธารณะ และช่วยให้คุณสามารถดำเนินการแบบ REST ผ่านเว็บเบราว์เซอร์ได้โดยตรง

คุณสามารถใช้เครื่องมือ cURL ผ่านคำสั่งบรรทัดคำสั่งเพื่อเข้าถึงบริการเว็บของ Aspose.Cells ได้อย่างง่ายดาย ตัวอย่างต่อไปนี้แสดงวิธีการเรียกใช้ Cloud API ด้วย cURL
