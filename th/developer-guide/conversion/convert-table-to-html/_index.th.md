**สรุปอย่างย่อ** – จุดปลายทางนี้อ่านสมุดงาน Excel ที่อยู่ในเครื่อง ดึงข้อมูล **ตาราง** ที่ระบุ แปลงเป็นไฟล์ **HTML** และส่งผลลัพธ์กลับมาในรูปแบบสตรีมที่สามารถดาวน์โหลดได้ โดยไม่จำเป็นต้องอัปโหลดไฟล์ไปยังพื้นที่จัดเก็บของ Aspose Cloud ล่วงหน้า

## ConvertTableToHTML API

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/table/html
```

### **ความปลอดภัยและการตรวจสอบสิทธิ์**

API ของ Aspose.Cells Cloud มีความปลอดภัยและบังคับใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การตรวจสอบสิทธิ์ด้วย JWT token</a>

### พารามิเตอร์คำขอ

| ชื่อพารามิเตอร์   | ตำแหน่ง   | ชนิดข้อมูล | จำเป็น | คำอธิบาย                                                                                 |
| ------------------ | --------- | ---------- | ------ | ----------------------------------------------------------------------------------------- |
| **Spreadsheet**    | Form‑Data | `File`     | **ใช่** | สมุดงาน Excel ที่มีตารางที่ต้องการแปลง                                                                  |
| **worksheet**      | Query     | `String`   | **ใช่** | ชื่อของแผ่นงานที่มีตารางที่ต้องการ                                                                     |
| **tableName**      | Query     | `String`   | **ใช่** | ชื่อที่แน่นอนของตารางที่ต้องการแปลง                                                                   |
| **outPath**        | Query     | `String`   | ไม่จำเป็น | เส้นทางโฟลเดอร์ในพื้นที่จัดเก็บของ Aspose Cloud ที่จะบันทึกไฟล์ HTML (ไม่บังคับ)                          |
| **outStorageName** | Query     | `String`   | ไม่จำเป็น | ชื่อพื้นที่จัดเก็บสำหรับไฟล์ผลลัพธ์ (ไม่บังคับ)                                                          |
| **fontsLocation**  | Query     | `String`   | ไม่จำเป็น | เส้นทางไปยังโฟลเดอร์ที่เก็บฟอนต์แบบกำหนดเองซึ่งจำเป็นสำหรับการแปลง                                    |
| **region**         | Query     | `String`   | ไม่จำเป็น | ตัวระบุภาษา和地区 (เช่น `en-US`, `fr-FR`) ซึ่งมีผลต่อรูปแบบตัวเลข/วันที่                                |
| **password**       | Query     | `String`   | ไม่จำเป็น | รหัสผ่านสำหรับเปิดสมุดงานที่มีการป้องกันไว้                                                           |
| **AutoRowsFit**    | Query     | `Boolean`  | ไม่จำเป็น | ปรับความสูงของแถวทั้งหมดในแผ่นงานอัตโนมัติ (`true`/`false`)                                            |
| **AutoColumnsFit** | Query     | `Boolean`  | ไม่จำเป็น | ปรับความกว้างของคอลัมน์ทั้งหมดในแผ่นงานอัตโนมัติ (`true`/`false`)                                       |

### **การตอบกลับ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**รหัสสถานะ HTTP**

| รหัส | ความหมาย               | คำอธิบาย                                                                 |
| ---- | ----------------------- | ------------------------------------------------------------------------- |
| 200  | สำเร็จ (OK)            | กรองข้อมูลเสร็จสมบูรณ์; คำตอบประกอบด้วยรายละเอียดของการดำเนินการ      |
| 400  | คำขอไม่ถูกต้อง (Bad Request) | พารามิเตอร์ขาดหายหรือไม่ถูกต้อง (เช่น ประเภทไฟล์ที่ไม่รองรับ)                 |
| 401  | ไม่ได้รับอนุญาต (Unauthorized) | JWT token ไม่ถูกต้องหรือขาดหาย                                               |
| 413  | ข้อมูลส่งมากเกินไป (Payload Too Large) | ไฟล์ที่อัปโหลดมีขนาดเกินขีดจำกัดที่กำหนด                                     |
| 500  | ข้อผิดพลาดภายในเซิร์ฟเวอร์ (Internal Server Error) | เกิดข้อผิดพลาดที่ไม่คาดคิดบนเซิร์ฟเวอร์                                     |

## ควรใช้ API แปลงตารางเป็น HTML ในกรณีใด?

- **เนื้อหาเว็บแบบไดนามิก** – ฝังตารางราคา ตารางเวลา หรือรายการสินค้าลงในหน้าเว็บหรือ CMS โดยตรง
- **เทมเพลตอีเมล** – สร้างส่วนย่อยของ HTML สำหรับสรุปรายการสั่งซื้อหรือรายงานที่แสดงผลได้สม่ำเสมอในไคลเอนต์อีเมลต่างๆ
- **แดชบอร์ดและเครื่องมือรายงาน** – แสดงข้อมูลจากสเปรดชีตแบบเรียลไทม์โดยไม่ต้องโหลดสมุดงานทั้งหมดหรือใช้คอมโพเนนต์ตารางหนักๆ
- **การดูตัวอย่างเอกสาร** – ให้ภาพตัวอย่างที่รวดเร็วและรักษาฟอร์แมตของส่วนที่ระบุในสเปรดชีตไว้
