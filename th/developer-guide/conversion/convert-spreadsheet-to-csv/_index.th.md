เอ็นพอยต์ **ConvertSpreadsheetToCsv** อ่านไฟล์สเปรดชีตที่อัปโหลดจากไดรฟ์ในเครื่อง ดำเนินการแปลงทั้งหมดบนเซิร์ฟเวอร์ของ Aspose.Cells Cloud และส่งคืนไฟล์ CSV ที่ได้ในรูปแบบสตรีมไบนารี การดำเนินการบนคลาวด์นี้ช่วยลดความจำเป็นในการอัปโหลดไฟล์ต้นฉบับไปยังพื้นที่เก็บข้อมูลบนคลาวด์ ลดค่าใช้จ่ายในการจัดเก็บ และทำให้กระบวนการพัฒนาสำหรับการแปลงไฟล์สเปรดชีตเป็น CSV อย่างรวดเร็วเป็นไปอย่างง่ายดาย รูปแบบที่รองรับขึ้นอยู่กับไลบรารีพื้นฐานที่ใช้ และจำเป็นต้องมีสิทธิ์ที่เหมาะสมในการอ่านไฟล์ต้นฉบับ ข้อผิดพลาด เช่น ไฟล์ไม่พบ คำขอไม่ถูกต้อง หรือการแปลงล้มเหลว จะถูกส่งกลับพร้อมโค้ดสถานะ HTTP มาตรฐาน

## **API สำหรับแปลงสเปรดชีตเป็น CSV**

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/spreadsheet/csv
```

### **การรักษาความปลอดภัยและการตรวจสอบสิทธิ์**

API ของ Aspose.Cells Cloud มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การตรวจสอบสิทธิ์ด้วยโทเค็น JWT</a>

### **พารามิเตอร์คำขอ:**

| ชื่อพารามิเตอร์ | ประเภท | ตำแหน่ง | ความจำเป็น | คำอธิบาย                                                                                                                                                        |
| :-------------- | :----- | :------- | :---------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet     | ไฟล์   | FormData | จำเป็น     | ไฟล์สเปรดชีตที่ต้องการแปลง รองรับรูปแบบทั่วไป เช่น .xls, .xlsx, .xlsm ต้องส่งในรูปแบบ multipart/form‑data ตัวอย่าง: `myWorkbook.xlsx`                              |
| outPath         | สตริง | Query    | ไม่บังคับ   | เส้นทางโฟลเดอร์ปลายทางที่จะบันทึกไฟล์ CSV ที่แปลงแล้ว หากไม่ระบุ CSV จะถูกส่งกลับโดยตรงในเนื้อหาการตอบกลับ ตัวอย่าง: `/output/reports/`                              |
| outStorageName  | สตริง | Query    | ไม่บังคับ   | ชื่อของบริการพื้นที่เก็บข้อมูลบนคลาวด์ที่จะใช้บันทึกไฟล์ผลลัพธ์ หากไม่ระบุ จะใช้พื้นที่เก็บข้อมูลเริ่มต้นที่กำหนดไว้สำหรับบัญชี Aspose.Cells                     |
| fontsLocation   | สตริง | Query    | ไม่บังคับ   | เส้นทางไปยังโฟลเดอร์ที่เก็บฟอนต์ที่กำหนดเองซึ่งสเปรดชีตต้องการ ช่วยให้การแสดงผลของเซลล์ที่ใช้ฟอนต์ที่ไม่ใช่แบบมาตรฐานถูกต้อง                                         |
| region          | สตริง | Query    | ไม่บังคับ   | การตั้งค่าภูมิภาค/ภาษาของสเปรดชีต (เช่น `en-US`, `fr-FR`) มีผลต่อการจัดรูปแบบตัวเลข การแปลงวันที่ และพฤติกรรมเฉพาะของท้องถิ่น                                         |
| password        | สตริง | Query    | ไม่บังคับ   | รหัสผ่านสำหรับเปิดไฟล์สเปรดชีตที่ป้องกันด้วยรหัสผ่าน หากไฟล์ถูกเข้ารหัสและไม่ระบุหรือระบุรหัสผ่านไม่ถูกต้อง จะส่งกลับข้อผิดพลาด 400/401                                   |

### **การตอบกลับ**

เมื่อสำเร็จ API จะส่งกลับ **HTTP 200** (หรือ **202** สำหรับการประมวลผลแบบไม่พร้อมก) พร้อมส่วนหัว `Content-Type: application/octet-stream` เนื้อหาการตอบกลับจะประกอบด้วยไฟล์ CSV ที่สร้างขึ้นในรูปแบบสตรีมไบนารี

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**โค้ดสถานะ HTTP**

| โค้ด | ความหมาย              | คำอธิบาย                                                            |
| ---- | ---------------------- | -------------------------------------------------------------------- |
| 200  | สำเร็จ (OK)           | ดำเนินการกรองสำเร็จ การตอบกลับมีรายละเอียดการดำเนินการ             |
| 400  | คำขอไม่ถูกต้อง (Bad Request) | พารามิเตอร์ขาดหายหรือไม่ถูกต้อง (เช่น รูปแบบไฟล์ที่ไม่รองรับ)            |
| 401  | ไม่ได้รับอนุญาต (Unauthorized) | โทเค็น JWT ไม่ถูกต้องหรือขาดหาย                                           |
| 413  | ข้อมูลส่งไปมีขนาดใหญ่เกินไป (Payload Too Large) | ไฟล์ที่อัปโหลดมีขนาดเกินขีดจำกัดที่กำหนด                                |
| 500  | ข้อผิดพลาดของเซิร์ฟเวอร์ภายใน (Internal Server Error) | เกิดข้อผิดพลาดที่ไม่คาดคิดบนเซิร์ฟเวอร์                                   |

## ควรใช้ API แปลงสเปรดชีตเป็น CSV ในกรณีใด?

- **การส่งออกข้อมูลเพื่อใช้ในระบบรายงาน** – สร้างไฟล์ CSV จากรายงานที่สร้างจาก Excel เพื่อนำไปใช้กับเครื่องมือ BI หรือคลังข้อมูลโดยไม่ต้องจัดการไฟล์ด้วยตนเอง
- **การประมวลผลแบบแบตช์อัตโนมัติ** – แปลงสเปรดชีตจำนวนมากที่จัดเก็บในเครื่องเป็น CSV ผ่านงานฝั่งเซิร์ฟเวอร์ จากนั้นส่งผลลัพธ์โดยตรงไปยังบริการขั้นตอนถัดไป
- **แอปพลิเคชันเว็บที่มีการอัปโหลดไฟล์** – ให้ผู้ใช้สามารถอัปโหลดไฟล์ Excel และได้รับไฟล์ CSV ทันทีเพื่อใช้ในการวิเคราะห์เพิ่มเติมหรือนำเข้าสู่แพลตฟอร์มอื่น
- **การบูรณาการระบบเก่า** – แปลงรูปแบบสเปรดชีตเก่าเป็น CSV สำหรับระบบที่รับเฉพาะไฟล์ที่เป็นข้อความธรรมดาที่คั่นด้วยเครื่องหมายกำกับ

## ทำไมควรใช้ API แปลงสเปรดชีตเป็น CSV?

- **สถาปัตยกรรมแบบไม่ต้องอัปโหลดไปยังคลาวด์** – ไม่จำเป็นต้องจัดเก็บไฟล์ต้นฉบับไว้ในพื้นที่เก็บข้อมูลบนคลาวด์ การแปลงเกิดขึ้นโดยตรงจากสตรีมที่อัปโหลด ช่วยประหยัดเวลาและค่าใช้จ่ายในการจัดเก็บ
- **การประมวลผลบนคลาวด์ที่มีประสิทธิภาพสูง** – ใช้เครื่องมือแปลงที่ได้รับการปรับแต่งของ Aspose.Cells บนเซิร์ฟเวอร์บนคลาวด์ที่มีความยืดหยุ่นสูง ให้ผลลัพธ์ CSV ที่รวดเร็วแม้กับสมุดงานขนาดใหญ่
- **การบูรณาการที่เรียบง่าย** – คำขอ PUT เพียงคำขอเดียวพร้อมพารามิเตอร์คิวรีที่ไม่บังคับ ส่งคืน CSV ในรูปแบบสตรีมไบนารีที่พร้อมดาวน์โหลด ไม่ต้องดำเนินการขั้นตอนหลังการประมวลผลเพิ่มเติม
- **การรองรับฟีเจอร์แบบครบถ้วน** – รองรับไฟล์ที่ป้องกันด้วยรหัสผ่าน ฟอนต์ที่กำหนดเอง และการตั้งค่าเฉพาะภูมิภาค ช่วยให้การแปลงสเปรดชีตที่ซับซ้อนได้อย่างถูกต้อง

### ข้อมูลจำเพาะ API แปลงสเปรดชีตเป็น CSV

[ข้อมูลจำเพาะ API แปลงสเปรดชีตเป็น CSV](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Conversion/ConvertSpreadsheetToCsv) จัดเตรียมอินเทอร์เฟซการเขียนโปรแกรมที่สามารถเข้าถึงได้โดยสาธารณะสำหรับการโต้ตอบ REST โดยตรงจากเว็บเบราว์เซอร์

คุณสามารถใช้เครื่องมือ cURL ผ่านคำสั่งบรรทัดคำสั่งเพื่อเข้าถึงบริการเว็บของ Aspose.Cells ได้อย่างง่ายดาย ตัวอย่างต่อไปนี้แสดงวิธีการเรียกใช้ Cloud API ด้วย cURL
