ส่งออกช่วงข้อมูลที่ระบุจากไฟล์ Excel ที่อยู่ในเครื่องเป็น CSV โดยใช้ Aspose.Cells Cloud API

## **API สำหรับแปลงช่วงเป็น CSV**

**ข้อกำหนดเบื้องต้น**  
ในการเรียกใช้จุดปลายทางนี้ คุณต้องมี **Client ID** และ **Client Secret** ของ Aspose Cloud ที่ถูกต้อง ขอ **โทเค็น JWT** และตรวจสอบให้แน่ใจว่าไฟล์สเปรดชีตต้นทางอยู่ในรูปแบบ **XLSX** หรือ **XLS**

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/range/csv
```

**ตัวอย่าง cURL**

```bash
curl -X PUT "https://api.aspose.cloud/v4.0/cells/convert/range/csv?worksheet=Sheet1&range=A1:C10" \
     -H "Authorization: Bearer {access_token}" \
     -F "Spreadsheet=@sample.xlsx"
```

### **ความปลอดภัยและการยืนยันตัวตน**

Aspose.Cells Cloud APIs มีความปลอดภัยและบังคับใช้การยืนยันตัวตนแบบใช้โทเค็น <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">JWT token-based authentication</a>

### **พารามิเตอร์คำขอ:**

| ชื่อพารามิเตอร์ | ประเภท | Path/Query String/HTTPBody | คำอธิบาย                                                                                 |
| :------------- | :----- | :------------------------- | :---------------------------------------------------------------------------------------- |
| Spreadsheet    | ไฟล์   | FormData                   | อัปโหลดไฟล์สเปรดชีต                                                                      |
| worksheet      | สตริง | Query                      | ชื่อแผ่นงานของสเปรดชีต                                                                  |
| range          | สตริง | Query                      | ระบุพื้นที่เซลล์ (เช่น A1:C10)                                                           |
| outPath        | สตริง | Query                      | เส้นทางโฟลเดอร์ที่จะจัดเก็บสมุดงาน (ไม่บังคับ) ค่าเริ่มต้นคือ null                     |
| outStorageName | สตริง | Query                      | ชื่อพื้นที่จัดเก็บผลลัพธ์                                                               |
| fontsLocation  | สตริง | Query                      | ระบุแบบอักษรที่กำหนดเองหากจำเป็น                                                       |
| region         | สตริง | Query                      | กำหนดการตั้งค่าภูมิภาคของสเปรดชีต                                                      |
| password       | สตริง | Query                      | รหัสผ่านที่จำเป็นสำหรับการเปิดไฟล์สเปรดชีต                                              |

### **คำตอบ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

_ตัวอย่างเนื้อหา CSV ที่ส่งกลับมา (ไม่กี่แถวแรก):_

```csv
Name,Date,Amount
John Doe,2023-01-15,1250.00
Jane Smith,2023-01-16,980.50
```

**โค้ดสถานะ HTTP**

| โค้ด | ความหมาย               | คำอธิบาย                                                             |
| ---- | --------------------- | -------------------------------------------------------------------- |
| 200  | สำเร็จ (OK)          | ใช้ตัวกรองเรียบร้อยแล้ว; คำตอบประกอบด้วยรายละเอียดของการดำเนินการ |
| 400  | คำขอไม่ถูกต้อง (Bad Request) | พารามิเตอร์ขาดหายหรือไม่ถูกต้อง (เช่น ประเภทไฟล์ที่ไม่รองรับ)      |
| 401  | ไม่ได้รับอนุญาต (Unauthorized) | โทเค็น JWT ไม่ถูกต้องหรือขาดหาย                                   |
| 413  | ข้อมูลส่งมาขนาดใหญ่เกินไป (Payload Too Large) | ไฟล์ที่อัปโหลดมีขนาดเกินขีดจำกัด                                   |
| 500  | ข้อผิดพลาดภายในเซิร์ฟเวอร์ (Internal Server Error) | ข้อผิดพลาดที่ไม่คาดคิดของเซิร์ฟเวอร์                              |

## คุณควรใช้ API สำหรับแปลงช่วงเป็น CSV ในกรณีใด?

### **1. สถานการณ์การส่งออกและย้ายข้อมูล**

- **การผสานรวมฐานข้อมูล**: ส่งออกช่วงข้อมูลที่ระบุจาก Excel โดยตรงไปยังระบบฐานข้อมูล
- **การผสานรวมแอปพลิเคชัน**: ส่งข้อมูลสเปรดชีตที่เลือกไปยังแอปพลิเคชัน SaaS
- **การย้ายระบบ**: ย้ายช่วงข้อมูลที่ระบุระหว่างระบบเดิมและระบบสมัยใหม่
- **การแชร์ข้ามแพลตฟอร์ม**: แชร์ชุดข้อมูลที่เน้นเฉพาะให้กับแพลตฟอร์มต่างๆ

### **2. การสร้างรายงานและการวิเคราะห์ข้อมูล**

- **รายงานแบบเจาะจง**: ส่งออกส่วนรายงานที่ระบุเป็น CSV เพื่อการวิเคราะห์อย่างเฉพาะเจาะจง
- **การจัดส่งข้อมูลให้แดชบอร์ด**: ส่งข้อมูลช่วงที่ระบุให้กับเครื่องมือแดชบอร์ด BI
- **ตัวชี้วัดประสิทธิภาพ**: ดึงช่วง KPI สำหรับระบบที่ติดตามประสิทธิภาพ
- **การรายงานทางการเงิน**: ส่งออกส่วนของงบการเงินเพื่อการตรวจสอบจากภายนอก

### **3. การพัฒนาและการทดสอบ**

- **การจัดการข้อมูลทดสอบ**: ส่งออกช่วงข้อมูลที่ระบุเพื่อการทดสอบ
- **สภาพแวดล้อมการพัฒนา**: แชร์ช่วงข้อมูลตัวอย่างกับทีมพัฒนา
- **การทดสอบ API**: สร้างข้อมูลทดสอบ CSV จากส่วนของสเปรดชีตที่ระบุ
- **การพัฒนาโปรโตไทป์**: จัดเตรียมชุดข้อมูลที่เน้นเฉพาะสำหรับโปรโตไทป์แอปพลิเคชัน

### **4. การดำเนินงานทางธุรกิจ**

- **การแชร์ข้อมูลแบบเลือกสรร**: แชร์ช่วงข้อมูลที่ระบุกับพันธมิตรภายนอก
- **การสำรองข้อมูลบางส่วน**: สำรองช่วงข้อมูลสำคัญในรูปแบบ CSV
- **การโอนย้ายข้อมูลภายในแผนก**: แชร์ข้อมูลเฉพาะระหว่างแผนกต่างๆ
- **การรายงานเพื่อการปฏิบัติตามข้อบังคับ**: ส่งออกช่วงข้อมูลเชิงกฎระเบียบเพื่อการส่งรายงานการปฏิบัติตามข้อบังคับ

### **5. ขั้นตอนอัตโนมัติ**

- **การส่งออกช่วงแบบตามกำหนดเวลา**: ส่งออกช่วงข้อมูลที่ระบุโดยอัตโนมัติตามกำหนดเวลา
- **การดึงข้อมูลแบบตามเงื่อนไข**: ส่งออกช่วงข้อมูลตามเหตุการณ์ทางธุรกิจหรือเงื่อนไขที่กำหนด
- **การผสานรวมในขั้นตอนการทำงาน**: ผสานการส่งออกช่วงเข้ากับขั้นตอนการทำงานทางธุรกิจ
- **การประมวลผลหลายช่วงพร้อมกัน**: ประมวลผลหลายช่วงข้อมูลพร้อมกันในโหมดแบตช์

## เหตุใดคุณจึงควรใช้ API สำหรับแปลงช่วงเป็น CSV?

- คุณสามารถแปลงช่วงข้อมูลในสเปรดชีตโดยไม่ต้องอัปโหลดสมุดงานก่อน ซึ่งช่วยประหยัดพื้นที่จัดเก็บและลดค่าใช้จ่าย
- การพัฒนาสามารถทำได้อย่างรวดเร็วด้วย SDK ที่มีอยู่ของ Aspose.Cells Cloud
- **การผสานรวมที่ง่าย**: REST API พร้อมเอกสารอธิบายที่ชัดเจน
- **สถาปัตยกรรมที่ปรับขยายได้**: รองรับทั้งการดำเนินงานขนาดเล็กไปจนถึงระดับองค์กร

## วิธีการใช้ API สำหรับแปลงช่วงเป็น CSV ด้วย SDK?

### ข้อมูลจำเพาะ OpenAPI

[ข้อมูลจำเพาะ OpenAPI](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Conversion/ConvertRangeToCSV) ระบุ API ที่สามารถเข้าถึงได้โดยสาธารณะ ซึ่งช่วยให้สามารถโต้ตอบผ่าน REST ได้โดยตรงจากเว็บเบราว์เซอร์

## ใช้ SDK ของ Aspose.Cells Cloud

การใช้ SDK เป็นวิธีที่เร็วที่สุดในการพัฒนา เพราะช่วยซ่อนรายละเอียดระดับต่ำไว้ ทำให้คุณสามารถแปลงช่วงข้อมูลเป็นไฟล์ CSV ได้ด้วยโค้ดเพียงไม่กี่บรรทัด  
ดูรายการ SDK ของ Aspose.Cells Cloud แบบครบถ้วนได้ที่ [GitHub repository](https://github.com/aspose-cells-cloud)

ตัวอย่างโค้ดต่อไปนี้แสดงวิธีการเรียกใช้บริการเว็บของ Aspose.Cells โดยใช้ SDK ต่างๆ หากการโหลดจาก Gist ถูกบล็อก คุณสามารถดาวน์โหลดตัวอย่างโดยตรงจาก repository ได้
