ส่งออกช่วงข้อมูลจากสเปรดชีตหรือ Excel บนคลาวด์ไปยังไฟล์รูปแบบหนึ่งๆ โดยไฟล์รูปแบบสามารถบันทึกไว้บนคลาวด์หรือนำออกมายังที่จัดเก็บในเครื่องได้

## API ส่งออกช่วงเป็นรูปแบบ

### Web API

```http
GET https://api.aspose.cloud/v4.0/cells/{name}/worksheets/{worksheet}/ranges/{range}
```

### **ความปลอดภัยและการยืนยันตัวตน**

API ของ Aspose.Cells Cloud มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การยืนยันตัวตนแบบ JWT token</a>

### พารามิเตอร์คำขอ

| ชื่อพารามิเตอร์   | ชนิดข้อมูล | ตำแหน่ง | คำอธิบาย                                                                                                                                           |
| :---------------- | :------- | :------- | :-------------------------------------------------------------------------------------------------------------------------------------------------- |
| **name**          | String   | Path     | (จำเป็น) ชื่อไฟล์สมุดบันทึกที่ต้องการดึงข้อมูล                                                                                                     |
| **worksheet**     | String   | Path     | ชื่อแผ่นงานของสเปรดชีต                                                                                                                            |
| **range**         | String   | Path     | ช่วงข้อมูลที่ต้องการแปลง (เช่น `A1:C12`)                                                                                                          |
| **format**        | String   | Query    | (จำเป็น) รูปแบบไฟล์ผลลัพธ์ที่ต้องการ (เช่น `pdf`, `png`, `svg`)                                                                                     |
| **folder**        | String   | Query    | (ไม่บังคับ) เส้นทางโฟลเดอร์ที่เก็บสมุดบันทึก                                                                                                      |
| **storageName**   | String   | Query    | (ไม่บังคับ) ชื่อพื้นที่จัดเก็บกรณีใช้คลาวด์สตอเรจแบบกำหนดเอง                                                                                    |
| **outPath**       | String   | Query    | (ไม่บังคับ) เส้นทางสำหรับไฟล์ผลลัพธ์ในพื้นที่จัดเก็บบนคลาวด์                                                                                      |
| **outStorageName**| String   | Query    | (ไม่บังคับ) ชื่อพื้นที่จัดเก็บสำหรับไฟล์ผลลัพธ์                                                                                                    |
| **fontsLocation** | String   | Query    | (ไม่บังคับ) ตำแหน่งที่เก็บฟอนต์แบบกำหนดเอง                                                                                                       |
| **region**        | String   | Query    | (ไม่บังคับ) การตั้งค่าภูมิภาค/ภาษาของสเปรดชีต (เช่น `en-US`, `fr-FR`) ซึ่งส่งผลต่อการจัดรูปแบบตัวเลข การแยกวิเคราะห์วันที่ และพฤติกรรมเฉพาะของภูมิภาค |
| **password**      | String   | Query    | (ไม่บังคับ) รหัสผ่านที่จำเป็นสำหรับการเปิดไฟล์สเปรดชีต                                                                                            |

### คำตอบ

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**โค้ดสถานะ HTTP**

| โค้ด | ความหมาย                 | คำอธิบาย                                                                   |
| ---- | ------------------------- | --------------------------------------------------------------------------- |
| 200  | OK (สำเร็จ)              | ใช้ตัวกรองสำเร็จ; คำตอบประกอบด้วยรายละเอียดของ operation                |
| 400  | Bad Request               | พารามิเตอร์ขาดหายหรือไม่ถูกต้อง (เช่น ไฟล์ที่ไม่รองรับ)                   |
| 401  | Unauthorized              | JWT token ไม่ถูกต้องหรือขาดหาย                                             |
| 413  | Payload Too Large         | ไฟล์ที่อัปโหลดมีขนาดเกินขีดจำกัด                                          |
| 500  | Internal Server Error     | เกิดข้อผิดพลาดภายในเซิร์ฟเวอร์โดยไม่คาดคิด                              |

## ควรใช้ API ส่งออกช่วงข้อมูลไปยังรูปแบบอื่นๆ ในกรณีใด?

### สถานการณ์การส่งออกและย้ายข้อมูล

- **การผนวกกับฐานข้อมูล** – ส่งออกช่วงข้อมูลใน Excel ไปยังระบบฐานข้อมูลโดยตรง
- **การผนวกกับแอปพลิเคชัน** – ส่งข้อมูลที่เลือกจากสเปรดชีตไปยังแอปพลิเคชันแบบ SaaS
- **การย้ายระบบ** – ย้ายช่วงข้อมูลเฉพาะระหว่างระบบเดิมกับระบบใหม่
- **การแชร์ข้ามแพลตฟอร์ม** – แชร์ชุดข้อมูลที่เลือกไว้ระหว่างแพลตฟอร์มที่ต่างกัน

### การรายงานและวิเคราะห์ข้อมูล

- **การรายงานแบบเจาะจง** – ส่งออกส่วนรายงานเฉพาะไปยังรูปแบบอื่นเพื่อการวิเคราะห์ที่เจาะจง
- **การป้อนข้อมูลให้แดชบอร์ด** – จัดหาช่วงข้อมูลเฉพาะให้กับเครื่องมือแดชบอร์ด BI
- **ตัวชี้วัดประสิทธิภาพ** – ดึงช่วง KPI สำหรับระบบติดตามประสิทธิภาพ
- **การรายงานทางการเงิน** – ส่งออกส่วนของงบการเงินเพื่อการตรวจสอบจากภายนอก

### การพัฒนาและการทดสอบ

- **การจัดการข้อมูลสำหรับการทดสอบ** – ส่งออกช่วงข้อมูลเฉพาะเพื่อวัตถุประสงค์ในการทดสอบ
- **สภาพแวดล้อมการพัฒนา** – แชร์ช่วงข้อมูลตัวอย่างให้กับทีมพัฒนา
- **การทดสอบ API** – สร้างข้อมูลทดสอบในรูปแบบ CSV จากส่วนสเปรดชีตที่เลือก
- **การพัฒนาต้นแบบ** – จัดเตรียมชุดข้อมูลเฉพาะสำหรับต้นแบบแอปพลิเคชัน

### การดำเนินงานธุรกิจ

- **การแชร์ข้อมูลแบบเลือกสรร** – แชร์ช่วงข้อมูลเฉพาะกับพันธมิตรภายนอก
- **การสำรองข้อมูลบางส่วน** – สำรองช่วงข้อมูลสำคัญในรูปแบบที่เลือก
- **การโอนย้ายข้อมูลระหว่างแผนก** – แชร์ข้อมูลเฉพาะระหว่างแผนกต่างๆ
- **การรายงานเพื่อการปฏิบัติตามข้อบังคับ** – ส่งออกช่วงข้อมูลตามข้อบังคับเพื่อการส่งรายงานเพื่อการปฏิบัติตามข้อบังคับ

### ระบบอัตโนมัติแบบเวิร์กโฟลว์

- **การส่งออกช่วงตามกำหนดเวลา** – ส่งออกช่วงข้อมูลเฉพาะโดยอัตโนมัติตามกำหนดเวลา
- **การดึงข้อมูลตามเงื่อนไข** – ส่งออกช่วงข้อมูลตามเหตุการณ์หรือเงื่อนไขทางธุรกิจ
- **การผนวกกับเวิร์กโฟลว์** – ผนวกการส่งออกช่วงข้อมูลเข้ากับเวิร์กโฟลว์ของกระบวนการทำงาน
- **การประมวลผลช่วงแบบแบทช์** – ประมวลผลช่วงข้อมูลหลายช่วงพร้อมกันในโหมดแบทช์

## เหตุใดจึงควรใช้ API ส่งออกช่วงข้อมูลไปยังรูปแบบอื่นๆ?

- **เป็นมิตรกับนักพัฒนา** – Aspose.Cells Cloud มี SDK ให้ใช้งานในหลายภาษา ช่วยให้การพัฒนาเป็นไปอย่างรวดเร็วพร้อมเอกสารประกอบที่ครบถ้วน เมื่อเทียบกับการสร้างโซลูชันสำหรับการเรนเดอร์กราฟิกแบบกำหนดเอง วิธีนี้ช่วยลดภาระงานพัฒนาอย่างมาก
- **ลดค่าใช้จ่ายแรงงาน** – ลดความจำเป็นในการจ้างบุคลากรเฉพาะด้านในการรวมเอกสาร
- **จ่ายตามการใช้งานจริง** – ไม่ต้องลงทุนล่วงหน้า; คุณจ่ายเฉพาะค่า API call ที่ใช้งานจริงเท่านั้น
- **ไม่ต้องดูแลเซิร์ฟเวอร์** – ไม่มีเซิร์ฟเวอร์ให้ดูแล ไม่มีการอัปเดตซอฟต์แวร์ และไม่มีปัญหาความเข้ากันได้
- **รักษาการจัดรูปแบบ Excel ที่ซับซ้อน** – ไฟล์ผลลัพธ์ยังคงรักษารูปแบบของสเปรดชีตต้นฉบับไว้

## วิธีใช้ API ส่งออกช่วงข้อมูลสเปรดชีตเป็นรูปแบบด้วย SDK?

### ข้อมูลเฉพาะของ API ส่งออกช่วงเป็นรูปแบบ

<a href="https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Conversion/ExportRangeAsFormat" rel="noopener noreferrer">ข้อมูลเฉพาะของ API ส่งออกช่วงเป็นรูปแบบ</a> ให้ส่วนติดต่อการโปรแกรมที่เข้าถึงได้สาธารณะ ช่วยให้คุณโต้ตอบกับ REST API ได้โดยตรงจากเว็บเบราว์เซอร์
