## ชุดเครื่องมือการแปลงสเปรดชีต

ใช้ Aspose.Cells Cloud API ในการแปลงสเปรดชีตให้รองรับหลายรูปแบบได้อย่างง่ายดาย รองรับการส่งออกข้อมูลในรูปแบบต่างๆ สำหรับแผ่นงาน ตาราง แผนภูมิ และช่วงข้อมูล (data ranges) รวมถึง PDF, รูปภาพ, CSV, JSON และอื่นๆ ประมวลผลผ่านคลาวด์ ไม่ต้องติดตั้ง anything เพิ่มเติม มี REST API และ SDK รองรับ

### การแปลงช่วงข้อมูล (Range Conversion)

- **[แปลงช่วงข้อมูลของสเปรดชีตเป็นไฟล์ CSV](https://docs.aspose.cloud/cells/convert-range-to-csv/)**
- **[แปลงช่วงข้อมูลของสเปรดชีตเป็นไฟล์ HTML](https://docs.aspose.cloud/cells/convert-range-to-html/)**
- **[แปลงช่วงข้อมูลของสเปรดชีตเป็นไฟล์ JSON](https://docs.aspose.cloud/cells/convert-range-to-json/)**
- **[แปลงช่วงข้อมูลของสเปรดชีตเป็นไฟล์ PDF](https://docs.aspose.cloud/cells/convert-range-to-pdf/)**
- **[ส่งออกช่วงข้อมูลของสเปรดชีตเป็นไฟล์ในรูปแบบอื่น](https://docs.aspose.cloud/cells/export-range-as-format/)**
- **[ส่งออกสเปรดชีตทั้งหมดเป็นไฟล์ในรูปแบบอื่น](https://docs.aspose.cloud/cells/export-spreadsheet-as-format/)**
- **[แปลงช่วงข้อมูลของสเปรดชีตเป็นรูปภาพ](https://docs.aspose.cloud/cells/convert-range-to-image/)**

- **[แปลงแผนภูมิของสเปรดชีตเป็นไฟล์ PDF](https://docs.aspose.cloud/cells/convert-chart-to-pdf/)**
- **[ส่งออกแผนภูมิของสเปรดชีตเป็นไฟล์ในรูปแบบอื่น](https://docs.aspose.cloud/cells/export-chart-as-format/)**
