ส่งออกกราฟจากไฟล์ Excel ที่อยู่ในเครื่องไปยังรูปแบบ [PDF](https://docs.fileformat.com/pdf/) โดยใช้ Cloud API

## **แปลงกราฟเป็น PDF ผ่าน Web API**

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/convert/chart/pdf
```

### **การรักษาความปลอดภัยและการตรวจสอบสิทธิ์**

Aspose.Cells Cloud APIs มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การตรวจสอบสิทธิ์แบบใช้ JWT token</a>

### **พารามิเตอร์คำขอ:**

| ชื่อพารามิเตอร์ | ประเภท | Path/Query String/HTTPBody | คำอธิบาย |
| -------------- | ------- | -------------------------- | ----------------------------------------------------------------------------------- |
| Spreadsheet    | ไฟล์    | FormData                   | อัปโหลดไฟล์สมุดงาน |
| worksheet      | สตริง  | Query                      | ชื่อของแผ่นงานที่มีกราฟ |
| chartIndex     | จำนวนเต็ม | Query                      | ดัชนีของกราฟที่ต้องการแปลง |
| outPath        | สตริง  | Query                      | (ไม่บังคับ) ตำแหน่งโฟลเดอร์ที่จะบันทึกไฟล์ที่แปลงแล้ว ค่าเริ่มต้นคือ null |
| outStorageName | สตริง  | Query                      | ชื่อที่เก็บไฟล์ผลลัพธ์ |
| fontsLocation  | สตริง  | Query                      | ใช้ฟอนต์ที่กำหนดเองหากจำเป็น |
| region         | สตริง  | Query                      | การตั้งค่าภูมิภาคของสมุดงาน |
| password       | สตริง  | Query                      | รหัสผ่านสำหรับเปิดไฟล์สมุดงาน |

### **การตอบกลับ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

**โค้ดสถานะ HTTP**

| โค้ด | ความหมาย               | คำอธิบาย |
| ---- | --------------------- | ----------------------------------------------------------------- |
| 200  | สำเร็จ (OK)           | กรองข้อมูลสำเร็จ; การตอบกลับประกอบด้วยรายละเอียดของการดำเนินการ |
| 400  | คำขอไม่ถูกต้อง (Bad Request) | พารามิเตอร์ขาดหายหรือไม่ถูกต้อง (เช่น ไฟล์ที่ไม่รองรับ) |
| 401  | ไม่ได้รับอนุญาต (Unauthorized) | JWT token ไม่ถูกต้องหรือขาดหาย |
| 413  | ข้อมูลในคำขอมีขนาดใหญ่เกินไป (Payload Too Large) | ไฟล์ที่อัปโหลดมีขนาดเกินขีดจำกัด |
| 500  | ข้อผิดพลาดภายในเซิร์ฟเวอร์ (Internal Server Error) | เกิดข้อผิดพลาดที่ไม่คาดคิดบนเซิร์ฟเวอร์ |

## ควรใช้ Convert Chart to PDF API ในกรณีใด?

### **1. การทำรายงานธุรกิจและการอัตโนมัติ**

- **แผนกการเงิน**: กราฟรายงานการเงินรายเดือน → จัดเก็บเป็น PDF
- **ทีมขาย**: กราฟแนวโน้มผลประกอบการ → รายงานลูกค้าในรูปแบบ PDF
- **วิเคราะห์การตลาด**: กราฟผลประสิทธิภาพแคมเปญ → สรุปสำหรับผู้บริหารในรูปแบบ PDF
- **บริหารจัดการด้านการดำเนินงาน**: กราฟการติดตามการผลิต → เอกสารตรวจสอบความสอดคล้องในรูปแบบ PDF

### **2. การพัฒนาซอฟต์แวร์และการผสานรวม**

- **แอปพลิเคชัน SaaS**: ข้อมูลกราฟที่ผู้ใช้สร้าง → รายงาน PDF ที่ดาวน์โหลดได้
- **ระบบองค์กร**: กราฟจากระบบ ERP/CRM → เอกสารบันทึกการตรวจสอบในรูปแบบ PDF
- **แอปพลิเคชันมือถือ**: กราฟการวิเคราะห์ภายในแอป → ไฟล์ PDF ที่แชร์ได้
- **แอปพลิเคชันเว็บ**: กราฟแดชบอร์ด → ฟังก์ชันการส่งออกเป็น PDF

### **3. กระบวนการทำงานด้านการประมวลผลเอกสาร**

- **การประมวลผลแบบแบทช์**: แปลงกราฟจากไฟล์ Excel หลายไฟล์เป็น PDF พร้อมกัน
- **งานตามกำหนดเวลา**: สร้างรายงานกราฟรายวัน/รายสัปดาห์โดยอัตโนมัติ
- **การสร้างเนื้อหาตามเทมเพลต**: รูปแบบกราฟมาตรฐาน → เอกสาร PDF
- **การประกอบเอกสาร**: รวมกราฟเข้ากับเนื้อหาอื่นในรูปแบบ PDF

### **4. แอปพลิเคชันเฉพาะอุตสาหกรรม**

- **สถาบันวิจัย**: กราฟข้อมูลการทดลอง → รูปภาพสำหรับบทความวิจัยในรูปแบบ PDF
- **ภาคการศึกษา**: กราฟสื่อการสอน → สื่อการเรียนการสอนในรูปแบบ PDF
- **บริษัทที่ปรึกษา**: กราฟการวิเคราะห์ → เอกสารส่งมอบให้ลูกค้าในรูปแบบ PDF
- **อุตสาหกรรมการผลิต**: กราฟควบคุมคุณภาพ → รายงานการตรวจสอบในรูปแบบ PDF
- **ภาคการแพทย์**: กราฟข้อมูลผู้ป่วย → บันทึกทางการแพทย์ในรูปแบบ PDF
- **ภาครัฐ**: กราฟสถิติ → เอกสารเผยแพร่ทางการในรูปแบบ PDF

### **5. การจัดการและเผยแพร่เนื้อหา**

- **การจัดการสินทรัพย์ดิจิทัล**: การจัดเก็บกราฟในรูปแบบ PDF มาตรฐาน
- **ฐานความรู้**: เอกสารประกอบทางเทคนิคที่มีกราฟ PDF ฝังอยู่
- **พอร์ทัลลูกค้า**: ส่งมอบรายงาน PDF อย่างปลอดภัยให้ผู้มีส่วนได้ส่วนเสีย
- **การปฏิบัติตามข้อบังคับ**: การสร้างเอกสาร PDF พร้อมสำหรับการตรวจสอบ

## เหตุใดจึงควรใช้ Convert Chart to PDF API?

- คุณสามารถแปลงกราฟได้ **โดยไม่จำเป็นต้องอัปโหลดสมุดงานก่อน** ซึ่งช่วยประหยัดพื้นที่จัดเก็บและลดค่าใช้จ่าย
- การพัฒนาสามารถทำได้อย่างรวดเร็วผ่าน SDK ของ Aspose.Cells Cloud ที่มีอยู่แล้ว
- **การผสานรวมที่ง่าย**: REST API พร้อมเอกสารที่ชัดเจน
- **สถาปัตยกรรมที่ปรับขนาดได้**: รองรับปริมาณงานได้ตั้งแต่ขนาดเล็กไปจนถึงระดับองค์กร
