ดำเนินการแทนที่ข้อความจำนวนมากในไฟล์ Excel บนคลาวด์ ค้นหาและอัปเดตสตริงข้อความที่ระบุได้อย่างมีประสิทธิภาพโดยใช้ Aspose.Cells Find & Replace API สำหรับสมุดงานบนคลาวด์


## **แทนที่เนื้อหาในสมุดงาน Excel แบบเรียลไทม์ผ่าน API**

### **Web API**

```http
PUT https://api.aspose.cloud/v4.0/cells/{name}/replace/content
```

### **ความปลอดภัยและการยืนยันตัวตน**

Aspose.Cells Cloud APIs มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การยืนยันตัวตนด้วย JWT token</a>

```bash
-H "Authorization: Bearer {access_token}"
```

### พารามิเตอร์ของคำขอ

| ชื่อพารามิเตอร์ | ชนิดข้อมูล | ตำแหน่ง | คำอธิบาย                                                                                                                                                   |
| ---------------- | --------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **name**         | String    | Path     | ชื่อไฟล์สมุดงานที่เก็บไว้ในพื้นที่จัดเก็บบนคลาวด์ซึ่งต้องการแก้ไข (เช่น `"report.xlsx"`)                                                                  |
| **searchText**   | String    | Query    | สตริงที่ต้องการค้นหาภายในสมุดงานทั้งหมด การค้นหานี้แยกแยะตัวพิมพ์เล็ก-ใหญ่ และใช้กับแผ่นงานทั้งหมดเว้นแต่จะมีข้อจำกัดโดยพารามิเตอร์อื่นๆ                     |
| **replaceText**  | String    | Query    | สตริงที่จะมาแทนที่ทุกกรณีของ `searchText`                                                                                                                 |
| **folder**       | String    | Query    | ตำแหน่งโฟลเดอร์ในพื้นที่จัดเก็บบนคลาวด์ที่มีสมุดงานต้นฉบับ (เช่น `"/documents/quarterly/"`)                                                             |
| **storageName**  | String    | Query    | _(ไม่บังคับ)_ ชื่อของพื้นที่จัดเก็บบนคลาวด์แบบกำหนดเอง (เช่น `"MyS3Bucket"`) หากไม่ระบุ จะใช้พื้นที่จัดเก็บเริ่มต้นที่กำหนดไว้สำหรับบัญชี                   |
| **region**       | String    | Query    | _(ไม่บังคับ)_ ตัวระบุภาษาและภูมิภาค ซึ่งอาจส่งผลต่อการเข้ารหัสอักขระและพฤติกรรมการค้นหาแบบเฉพาะภาษา (เช่น `"en-US"`)                                    |
| **password**     | String    | Query    | _(ไม่บังคับ)_ รหัสผ่านสำหรับเปิดสมุดงานที่ได้รับการป้องกัน                                                                                                  |

### คำตอบ (Response)

คำตอบที่สำเร็จโดยทั่วไปจะส่งกลับสถานะของคำขอและจำนวนการแทนที่ที่ดำเนินการ:

```json
{
  "Code": 200,
  "Status": "OK"
}
```

### รหัสข้อผิดพลาด

- **400 Bad Request** – URI ของ Aspose.Cells Cloud API ไม่ถูกต้อง
- **401 Unauthorized** – ไม่มีหรือ OAuth 2.0 access token ไม่ถูกต้อง
- **404 Not Found** – ไม่สามารถเข้าถึงไฟล์สมุดงานที่ระบุได้
- **500 Server Error** – เกิดข้อผิดพลาดที่ไม่คาดคิดฝั่งเซิร์ฟเวอร์ขณะประมวลผลคำขอ

## เมื่อใดควรใช้ Replace Content in Remote Spreadsheet API?

- **การอัปเดตไฟล์บนคลาวด์แบบแบทช์** – แก้ไขเนื้อหาของไฟล์ Excel หลายไฟล์ที่เก็บไว้ในพื้นที่จัดเก็บบนคลาวด์ เช่น AWS S3 หรือ Azure Blob
- **เติมข้อมูลลงในเทมเพลตบนคลาวด์แบบไดนามิก** – เติมข้อมูลล่าสุดลงในเทมเพลตรายงานที่เก็บไว้บนคลาวด์
- **ซิงค์ไฟล์ข้ามภูมิภาค** – ทำให้ไฟล์ Excel มีความสอดคล้องกันข้ามพื้นที่จัดเก็บบนคลาวด์ที่ตั้งอยู่ในภูมิภาคต่างๆ

## เหตุใดจึงควรใช้ Replace Content in Remote Spreadsheet API?

- **เป็นมิตรกับนักพัฒนา** – Aspose.Cells Cloud มี SDK สำหรับภาษาโปรแกรมต่างๆ มากมาย ช่วยลดความพยายามในการพัฒนาเทียบกับการสร้างโซลูชันแบบกำหนดเอง
- **ลดค่าใช้จ่ายแรงงาน** – ลดความจำเป็นในการจ้างบุคลากรเฉพาะเพื่อรวมเอกสารด้วยตนเอง
- **จ่ายตามการใช้งาน (Pay-per-Use)** – ไม่ต้องลงทุนล่วงหน้า ชำระค่าบริการเฉพาะเมื่อเรียกใช้ API จริง
- **ไม่มีค่าใช้จ่ายในการดูแลรักษา** – ไม่ต้องจัดการเซิร์ฟเวอร์ ไม่ต้องอัปเดตซอฟต์แวร์ และไม่มีปัญหาด้านความเข้ากันได้
- **คงรูปแบบเซลล์ สูตร และแผนภูมิไว้ครบถ้วน** – การดำเนินการนี้คงโครงร่างและการคำนวณของสมุดงานต้นฉบับไว้หลังจากแทนที่ข้อความแล้ว
