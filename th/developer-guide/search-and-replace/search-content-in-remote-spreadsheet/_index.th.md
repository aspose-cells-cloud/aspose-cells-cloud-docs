### **API ค้นหาเนื้อหาในสมุดงานระยะไกล**

ค้นหาข้อความเฉพาะภายในสมุดงาน Excel ใดๆ โดยใช้ Aspose.Cells Cloud API ค้นหาข้อความ ตัวเลข หรือสูตรในไฟล์ที่จัดเก็บไว้ในพื้นที่จัดเก็บบนคลาวด์ API แบบ RESTful นี้ช่วยให้สามารถดำเนินการค้นหาข้อมูลอัตโนมัติ วิเคราะห์เนื้อหา และตรวจสอบสมุดงานได้อย่างมีประสิทธิภาพ

### **Web API**

```bash
PUT https://api.aspose.cloud/v4.0/cells/{name}/search/content
```

### **ความปลอดภัยและการยืนยันตัวตน**

API ของ Aspose.Cells Cloud มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การยืนยันตัวตนแบบ JWT token</a>

```bash
-H "Authorization: Bearer {access_token}"
```

### **พารามิเตอร์คำขอ:**

| ชื่อพารามิเตอร์ | ประเภท | Path/Query String/HTTPBody | คำอธิบาย                                                                                                                                                      |
| :------------- | :------ | :------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| name           | String  | Path                       | **จำเป็น**. ชื่อไฟล์ของสมุดงาน Excel (รวมนามสกุลไฟล์) ที่จะดำเนินการค้นหาข้อความ เช่น `sales_data.xlsx`                                                                                         |
| searchText     | String  | Query                      | **จำเป็น**. สตริง ตัวเลข หรือเนื้อหาบางส่วนที่ต้องการค้นหาในสมุดงานหรือเวิร์กชีตทั้งหมด                                                                               |
| ignoringCase   | Boolean | Query                      | **ไม่บังคับ**. กำหนดความละเอียดในการจับคู่ตัวพิมพ์เล็ก-ใหญ่ ตั้งค่าเป็น `true` เพื่อค้นหาแบบไม่คำนึงถึงตัวพิมพ์เล็ก-ใหญ่ (เช่น “Report” จะจับคู่กับ “REPORT”) ค่าเริ่มต้นคือ `false`                    |
| folder         | String  | Query                      | **ไม่บังคับ**. เส้นทางไปยังไดเรกทอรีในพื้นที่จัดเก็บบนคลาวด์ที่มีสมุดงานเป้าหมาย หากไม่ระบุ จะถือว่าใช้โฟลเดอร์ราก                                                                 |
| storageName    | String  | Query                      | **ไม่บังคับ**. ตัวระบุชื่อสำหรับบริการพื้นที่จัดเก็บบนคลาวด์ที่กำหนดค่าเอง หากไม่ระบุ API จะใช้พื้นที่จัดเก็บเริ่มต้นที่เชื่อมโยงกับบัญชีนั้น                      |
| region         | String  | Query                      | **ไม่บังคับ**. การตั้งค่าภาษา和地区 (เช่น `th-TH`) ที่ใช้ในการค้นหา ซึ่งอาจส่งผลต่อการปรับรูปแบบข้อความหรือกฎการจัดเรียงข้อมูล                               |
| password       | String  | Query                      | **ไม่บังคับ**. รหัสผ่านถอดรหัสที่จำเป็นในการเข้าถึงไฟล์ Excel ที่มีการป้องกันด้วยรหัสผ่าน ละเว้นพารามิเตอร์นี้หากไฟล์ไม่ได้รับการเข้ารหัส                      |

**คำอธิบายศัพท์**

- **searchText** – สตริงที่ต้องการค้นหา อาจเป็นการจับคู่บางส่วนได้
- **ignoringCase** – `true` ทำให้การค้นหาไม่คำนึงถึงตัวพิมพ์เล็ก-ใหญ่ `false` บังคับให้จับคู่ตามตัวพิมพ์เล็ก-ใหญ่
- **folder** – เส้นทางไปยังไดเรกทอรีที่เก็บสมุดงานไว้
- **storageName** – ตัวระบุสำหรับการกำหนดค่าพื้นที่จัดเก็บแบบกำหนดเอง
- **region** – รหัสภาษา和地区ที่มีผลต่อกฎการเปรียบเทียบข้อความ
- **password** – รหัสผ่านถอดรหัสสำหรับสมุดงานที่มีการป้องกัน

### **การตอบกลับ**

```json
{
  "Code": 200,
  "Status": "OK",
  "TextItems": [
    {
      "Filename": "string",
      "Worksheet": "string",
      "Position": "string",
      "Content": "string"
    }
  ]
}
```

การตอบกลับจะประกอบด้วยรายการของเซลล์ (`CellName`) ที่พบข้อความที่ค้นหา พร้อมชื่อเวิร์กชีตและข้อความที่จับคู่ได้ หากไม่พบการจับคู่ใดๆ เลย อาเรย์ `Cells` จะว่างเปล่า แต่คำขอยังคงส่งคืนสถานะ HTTP 200 OK

### รหัสข้อผิดพลาด

- **400 Bad Request** – URI ของ Aspose.Cells Cloud API ไม่ถูกต้อง  
  ```json
  {"code":400,"message":"Invalid request URI"}
  ```
- **401 Unauthorized** – โทเคนการเข้าถึง ไคลเอนต์ ID หรือไคลเอนต์ซีเคร็ตไม่ถูกต้อง  
  ```json
  {"code":401,"message":"Invalid access token"}
  ```
- **404 Not Found** – ไม่สามารถเข้าถึงไฟล์สมุดงานได้  
  ```json
  {"code":404,"message":"File not found"}
  ```
- **500 Server Error** – เงื่อนไขที่ไม่คาดคิดทำให้ API ไม่สามารถดำเนินการคำขอให้เสร็จสมบูรณ์  
  ```json
  {"code":500,"message":"Internal server error"}
  ```

## ควรใช้ API ค้นหาเนื้อหาในสมุดงานในกรณีใด?

- **การตรวจสอบความสอดคล้องของสมุดงานแบบครอบคลุม** – สแกนไฟล์ Excel ทั้งหมดอย่างรวดเร็วเพื่อระบุคำสำคัญที่ละเอียดอ่อนทั้งหมด (เช่น “ข้อกำหนดความลับ”, “ข้อมูลภายใน”) สำหรับการตรวจสอบความปลอดภัยของข้อมูลองค์กรและการปฏิบัติตามข้อบังคับ
- **การค้นหาความสัมพันธ์ของข้อมูลข้ามเวิร์กชีต** – เมื่อข้อมูลโครงการกระจัดกระจายอยู่ในหลายเวิร์กชีต ค้นหาหมายเลขโครงการหรือชื่อลูกค้าเฉพาะเพื่อค้นหาข้อมูลที่เกี่ยวข้องทั้งหมดได้ทันที
- **การตรวจสอบเนื้อหาเทมเพลตแบบแบทช์** – หลังการสร้างรายงานอัตโนมัติ สแกนไฟล์ Excel หลายไฟล์ในแบบแบทช์เพื่อยืนยันว่าตัวยึดตำแหน่งที่กำหนดไว้ล่วงหน้า (เช่น `{{Date}}`) ถูกแทนที่อย่างถูกต้อง ทำให้มั่นใจได้ว่ารายงานมีความสมบูรณ์และแม่นยำ
- **การจัดเก็บและขุดข้อมูลเชิงประวัติศาสตร์** – วิเคราะห์ไฟล์เก่า ค้นหาโค้ดเหตุการณ์หรือคำศัพท์ทางธุรกิจเฉพาะ และเข้าใจตรรกะทางธุรกิจในอดีตได้อย่างรวดเร็วเพื่อใช้ในการวิเคราะห์ข้อมูลเชิงประวัติศาสตร์

## ทำไมจึงควรใช้ API ค้นหาเนื้อหาในสมุดงาน?

- **เป็นมิตรกับนักพัฒนา** – Aspose.Cells Cloud มี SDK รองรับหลายภาษา ช่วยให้การพัฒนาทำได้อย่างรวดเร็วพร้อมเอกสารประกอบที่ครบถ้วน เมื่อเทียบกับการสร้างโซลูชันเฉพาะเอง ช่วยลดความพยายามในการพัฒนาอย่างมาก
- **ลดต้นทุนแรงงาน** – ทำให้ภารกิจค้นหาซ้ำๆ อัตโนมัติ ปลดปล่อยนักพัฒนาให้พ้นจากงานดึงข้อมูลด้วยตนเอง
- **จ่ายตามการใช้งานจริง** – ไม่ต้องลงทุนล่วงหน้า จ่ายเฉพาะค่า API ที่ใช้งานจริงเท่านั้น
- **ไม่ต้องดูแลรักษา** – Aspose จัดการเซิร์ฟเวอร์ การอัปเดต และความเข้ากันได้ให้ คุณจึงสามารถมุ่งเน้นไปที่ตรรกะของแอปพลิเคชันของคุณ
- **รักษารูปแบบ Excel ที่ซับซ้อน** – ผลลัพธ์สามารถส่งออกเป็นรูปแบบ PDF ที่เข้าถึงได้ทั่วไป โดยคงรูปแบบต้นฉบับไว้
