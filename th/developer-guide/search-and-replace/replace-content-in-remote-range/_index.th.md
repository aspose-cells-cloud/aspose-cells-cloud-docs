ดำเนินการแทนที่ข้อความแบบแบตช์ในไฟล์ Excel ระยะไกลที่จัดเก็บไว้บนคลาวด์ ค้นหาและอัปเดตสตริงข้อความที่ระบุภายในช่วงที่เลือกได้อย่างมีประสิทธิภาพโดยใช้ Aspose.Cells Find and Replace API

## **แทนที่เนื้อหาในช่วงระยะไกล API**

### Web API

```
PUT https://api.aspose.cloud/v4.0/cells/{name}/worksheets/{worksheet}/ranges/{cellArea}/replace/content
```

### **ความปลอดภัยและการตรวจสอบสิทธิ์**

Aspose.Cells Cloud APIs มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การตรวจสอบสิทธิ์แบบ JWT token</a>

```bash
-H "Authorization: Bearer {access_token}"
```

### **พารามิเตอร์คำขอ**

| ชื่อพารามิเตอร์ | ประเภท | Path/Query String/HTTP Body | คำอธิบาย                                                                                                                                               |
| :------------- | :----- | :-------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------- |
| name           | String | Path                        | ชื่อไฟล์สมุดคิด (workbook) ที่จัดเก็บไว้ในคลาวด์สโตเรจซึ่งจะถูกแก้ไข (เช่น `"report.xlsx"`)                                                            |
| searchText     | String | Query                       | สตริงข้อความที่ต้องการค้นหาภายในชีตงานและช่วงเซลล์ที่ระบุ รองรับการจับคู่ข้อความแบบตรงกันทุกประการ                                                |
| replaceText    | String | Query                       | สตริงข้อความที่จะแทนที่ทุกกรณีของ `searchText` ภายในช่วงที่ระบุ                                                                                      |
| worksheet      | String | Path                        | ชื่อชีตงานที่จะดำเนินการค้นหาและแทนที่                                                                                                                |
| cellArea       | String | Path                        | ช่วงเซลล์ที่ระบุ (เช่น `"A1:D20"`) ซึ่งจะมีการค้นหาและแทนที่ข้อความ                                                                                |
| folder         | String | Query                       | ตำแหน่งโฟลเดอร์ในคลาวด์สโตเรจที่สมุดคิดต้นทางอยู่                                                                                                     |
| storageName    | String | Query                       | _(ไม่บังคับ)_ ชื่อของคลาวด์สโตเรจที่สมุดคิดนั้นอยู่ หากไม่ระบุ จะใช้คลาวด์สโตเรจเริ่มต้น                                                               |
| region         | String | Query                       | _(ไม่บังคับ)_ ตั้งค่าภาษาท้องถิ่นสำหรับการจัดการข้อความ ซึ่งอาจส่งผลต่อความไวต่อตัวพิมพ์เล็ก-ใหญ่และการเข้ารหัสอักขระในการค้นหา (เช่น `"en-US"`, `"tr-TR"`) |
| password       | String | Query                       | _(ไม่บังคับ)_ หากสมุดคิดมีการป้องกันด้วยรหัสผ่าน ให้ระบุรหัสผ่านเพื่อเปิดและแก้ไขไฟล์                                                                |

### **การตอบกลับ**

```json
{
  "Name": "CellsCloudResponse",
  "Type": "Class",
  "Properties": [
    {
      "Name": "Code",
      "DataType": {
        "Identifier": "Integer"
      }
    },
    {
      "Name": "Status",
      "DataType": {
        "Identifier": "String"
      }
    }
  ]
}
```

การเรียกที่สำเร็จจะส่งกลับ JSON payload แบบ concrete ดังนี้:

```json
{
  "Code": 200,
  "Status": "OK"
}
```


### โค้ดข้อผิดพลาด

| โค้ด | ข้อความ      | เกิดขึ้นเมื่อใด                                        |
| ---- | ------------ | ------------------------------------------------------ |
| 400  | Bad Request  | URI ของคำขอหรือพารามิเตอร์มีรูปแบบไม่ถูกต้อง          |
| 401  | Unauthorized | ไม่มีหรือโทเคนการตรวจสอบสิทธิ์ไม่ถูกต้อง             |
| 404  | Not Found    | ไม่สามารถค้นหาหรือเข้าถึงสมุดคิดที่ระบุได้             |
| 500  | Server Error | เกิดข้อผิดพลาดภายในเซิร์ฟเวอร์ขณะประมวลผลสมุดคิด   |

## ควรใช้ API แทนที่เนื้อหาในช่วงของสเปรดชีตระยะไกลในกรณีใด?

- **การอัปเดตไฟล์บนคลาวด์แบบแบตช์**: แก้ไขเนื้อหาของไฟล์ Excel หลายไฟล์ที่จัดเก็บไว้ในคลาวด์สโตเรจ เช่น AWS S3 และ Azure Blob
- **การเติมข้อมูลแบบไดนามิกให้กับเทมเพลตบนคลาวด์**: เติมข้อมูลแบบแบตช์ให้กับเทมเพลตรายงานที่จัดเก็บไว้บนคลาวด์
- **การซิงค์ไฟล์ข้ามภูมิภาค**: ทำให้เนื้อหาของไฟล์ Excel ในคลาวด์สโตเรจสอดคล้องกันข้ามภูมิภาคต่างๆ

## เหตุใดจึงควรใช้ API แทนที่เนื้อหาในช่วงของสเปรดชีตระยะไกล?

- **เป็นมิตรกับนักพัฒนา**: Aspose.Cells Cloud มี SDK ให้ใช้งานในหลายภาษา ช่วยให้พัฒนาได้อย่างรวดเร็วและมีเอกสารประกอบที่ครบถ้วน เมื่อเทียบกับการสร้างโซลูชันแบบกำหนดเอง วิธีนี้ลดภาระงานพัฒนาอย่างมาก
- **ลดต้นทุนแรงงาน**: ลดความจำเป็นในการจ้างบุคลากรเฉพาะด้านสำหรับการรวมเอกสาร
- **จ่ายตามการใช้งาน**: ไม่ต้องลงทุนล่วงหน้า จ่ายเฉพาะค่า API ที่เรียกใช้งานจริงเท่านั้น
- **ไม่มีต้นทุนการดูแลรักษา**: ไม่ต้องดูแลเซิร์ฟเวอร์ อัปเดตซอฟต์แวร์ หรือจัดการกับปัญหาความเข้ากันได้
- **คงรูปแบบ Excel ที่ซับซ้อนไว้ในรูปแบบ PDF ที่เข้าถึงได้ทั่วโลก**

## วิธีใช้ API แทนที่เนื้อหาในช่วงของสเปรดชีตระยะไกลด้วย SDK

### ข้อกำหนด OpenAPI

[OpenAPI Specification](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/Search/ReplaceContentInRemoteRange) นิยามอินเทอร์เฟซโปรแกรมที่เข้าถึงได้แบบสาธารณะ และอนุญาตให้คุณดำเนินการ REST interaction ได้โดยตรงจากเว็บเบราว์เซอร์

### ใช้ Aspose.Cells Cloud SDK

การใช้ SDK เป็นวิธีที่ดีที่สุดในการเร่งความเร็วการพัฒนา SDK จัดการรายละเอียดเบื้องต้นให้ ทำให้คุณสามารถใช้โค้ดเพียงไม่กี่บรรทัดเพื่อแทนที่เนื้อหาในสเปรดชีตได้ โปรดดูที่ [GitHub repository](https://github.com/aspose-cells-cloud) เพื่อดูรายชื่อ SDK ของ Aspose.Cells Cloud ทั้งหมด
