ฟีเจอร์ **การค้นหาและแทนที่** ของ Aspose.Cells Cloud API ช่วยให้นักพัฒนาสามารถค้นหาและแทนที่ข้อความ สูตร หรือไฮเปอร์ลิงก์ภายในสมุดงาน Excel ที่จัดเก็บไว้ในคลาวด์ได้อย่างเป็นโปรแกรม

- **[แทนที่เนื้อหาในสเปรดชีตระยะไกล](https://docs.aspose.cloud/cells/replace-content-in-remote-spreadsheet/)** – แทนที่สตริงที่ระบุทั้งหมดในสมุดงานที่จัดเก็บไว้ในพื้นที่จัดเก็บของ Aspose Cloud  
- **[แทนที่เนื้อหาในช่วงที่กำหนดของสเปรดชีตระยะไกล](https://docs.aspose.cloud/cells/replace-content-in-remote-range/)** – แทนที่เนื้อหาภายในช่วงของเซลล์ที่กำหนดในสมุดงานระยะไกล  
- **[แทนที่เนื้อหาสเปรดชีต](https://docs.aspose.cloud/cells/replace-spreadsheet-content/)** – ดำเนินการแทนที่แบบหลายรายการสำหรับทั้งสเปรดชีต  
- **[แทนที่เนื้อหาของworksheetในสเปรดชีตระยะไกล](https://docs.aspose.cloud/cells/replace-content-in-remote-worksheet/)** – แทนที่ข้อความในworksheetที่ระบุของสมุดงานระยะไกล  
- **[ค้นหาไฮเปอร์ลิงก์ที่เสียในช่วงของสเปรดชีตระยะไกล](https://docs.aspose.cloud/cells/search-broken-links-in-remote-range/)** – ค้นหาและรายงานไฮเปอร์ลิงก์ที่เสียภายในช่วงที่กำหนด  
- **[ค้นหาไฮเปอร์ลิงก์ที่เสียในworksheetของสเปรดชีตระยะไกล](https://docs.aspose.cloud/cells/search-broken-links-in-remote-worksheet/)** – ตรวจจับลิงก์ที่เสียทั่วทั้งworksheet  
- **[ค้นหาเนื้อหาในสเปรดชีตระยะไกล](https://docs.aspose.cloud/cells/search-content-in-remote-spreadsheet/)** – ค้นหาข้อความ สูตร หรือค่าที่ระบุในสมุดงานระยะไกล  
- **[ค้นหาไฮเปอร์ลิงก์ที่เสียในสเปรดชีตระยะไกล](https://docs.aspose.cloud/cells/search-broken-links-in-remote-spreadsheet/)** – สแกนสมุดงานหลายเล่มเพื่อหาไฮเปอร์ลิงก์ที่เสีย  
- **[ค้นหาเนื้อหาในช่วงของสเปรดชีตระยะไกล](https://docs.aspose.cloud/cells/search-content-in-remote-range/)** – ค้นหาภายในช่วงของเซลล์ที่กำหนด  
- **[ค้นหาไฮเปอร์ลิงก์ที่เสียในสเปรดชีต](https://docs.aspose.cloud/cells/search-spreadsheet-broken-links/)** – ให้รายการลิงก์ที่เสียทั้งหมดทั่วทั้งสเปรดชีต  
- **[ค้นหาเนื้อหาสเปรดชีต](https://docs.aspose.cloud/cells/search-spreadsheet-content/)** – การค้นหาเนื้อหาทั่วทั้งสเปรดชีต  
- **[ค้นหาเนื้อหาworksheetในสเปรดชีตระยะไกล](https://docs.aspose.cloud/cells/search-content-in-remote-worksheet/)** – ค้นหาเนื้อหาภายในworksheetที่ระบุ
