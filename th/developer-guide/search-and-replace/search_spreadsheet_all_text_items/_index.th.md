## การค้นหาข้อความทั้งหมดในสเปรดชีตของเว็บเซอร์วิส Aspose.Cells Cloud

เมธอดนี้ใช้ค้นหาข้อความทั้งหมดภายในไฟล์สเปรดชีตในเครื่องของคุณ โดยรองรับการค้นหาผ่านทุกชีตและเซลล์ของสมุดงาน ระบุตำแหน่งที่พบคำค้นหา การดำเนินการนี้ทำบนเซิร์ฟเวอร์คลาวด์ โดยไม่จำเป็นต้องใช้พื้นที่จัดเก็บข้อมูลบนคลาวด์ ตรวจสอบให้แน่ใจว่าคุณมีสิทธิ์อ่านไฟล์ต้นทาง หากไม่สามารถเข้าถึงไฟล์ต้นทางหรือเกิดข้อผิดพลาดระหว่างกระบวนการค้นหา (เช่น รูปแบบไฟล์ที่ไม่รองรับ) จะเกิดข้อยกเว้นที่เหมาะสมขึ้น เมธอดนี้อาจส่งคืนตำแหน่งของผลลัพธ์ที่ตรงกัน (เช่น ชื่อชีต พิกัดเซลล์) ขึ้นอยู่กับรายละเอียดการปรับใช้งาน

### จุดจบของเว็บ API

```http
PUT https://api.aspose.cloud/v4.0/cells/search/content/all-textitems
```

### **ความปลอดภัยและการยืนยันตัวตน**

Aspose.Cells Cloud APIs มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การยืนยันตัวตนแบบ JWT token</a>

### พารามิเตอร์ของคำขอ

| ชื่อพารามิเตอร์ | ชนิดข้อมูล | Path/Query String/HTTP Body | คำอธิบาย |
|----------------|------|-----------------------------|-------------|
| Spreadsheet | ไฟล์ | FormData | อัปโหลดไฟล์สเปรดชีต |
| region | สตริง | Query | การตั้งค่าภูมิภาค/ภาษาของสเปรดชีต (เช่น `en-US`, `fr-FR`) มีผลต่อการจัดรูปแบบตัวเลข การแยกวิเคราะห์วันที่ และพฤติกรรมที่ขึ้นกับภูมิภาค |
| password | สตริง | Query | รหัสผ่านสำหรับเปิดไฟล์สเปรดชีต |

### **การตอบกลับ**

```json
{
  "SearchResults": [
    {
      "SheetName": "Sheet1",
      "CellName": "A1",
      "Text": "Sample text"
    }
    // ... รายการเพิ่มเติม
  ],
  "TotalCount": 42
}
```

**รหัสสถานะของการตอบกลับ**

| รหัส | ความหมาย | คำอธิบาย |
|------|---------|-------------|
| 200 | สำเร็จ | คำขอกลายเป็นผลสำเร็จ และการตอบกลับมีข้อความที่พบทั้งหมด |
| 400 | คำขอไม่ถูกต้อง | URL ไม่ถูกต้องหรือพารามิเตอร์ของคำขอผิดรูปแบบ |
| 401 | ไม่ได้รับอนุญาต | การยืนยันตัวตนล้มเหลวหรือไม่ได้ระบุข้อมูลรับรอง |
| 404 | ไม่พบ | ไฟล์ต้นทางไม่สามารถเข้าถึงได้ |
| 413 | เนื้อหาที่ส่งมามีขนาดใหญ่เกินไป | ไฟล์ที่อัปโหลดมีขนาดเกินขีดจำกัดที่อนุญาต |
| 500 | ข้อผิดพลาดภายในเซิร์ฟเวอร์ | สเปรดชีตเกิดข้อผิดพลาดในการดึงข้อมูล |

## วิธีใช้การค้นหาข้อความทั้งหมดในสเปรดชีตด้วย SDK

### ข้อมูลจำเพาะของการค้นหาข้อความทั้งหมดในสเปรดชีต

[ข้อมูลจำเพาะของ API การค้นหาข้อความทั้งหมดในสเปรดชีต](https://reference.aspose.cloud/cells/?urls.primaryName=API+v4#/{SearchController}/{SearchSpreadsheetAllTextItems}) กำหนดอินเทอร์เฟซโปรแกรมที่เข้าถึงได้โดยสาธารณะ และช่วยให้คุณสามารถโต้ตอบผ่าน REST ได้โดยตรงจากเว็บเบราว์เซอร์

คุณสามารถใช้เครื่องมือ cURL ที่ใช้ในบรรทัดคำสั่งเพื่อเข้าถึงเว็บเซอร์วิสของ Aspose.Cells ได้อย่างง่ายดาย ตัวอย่างต่อไปนี้แสดงวิธีเรียกใช้ Cloud API ด้วย cURL

{< tabs tabTotal="2" tabID="1" tabName1="คำขอ" tabName2="การตอบกลับ" >}

{< tab tabNum="1" >}

```bash
# ใช้ HTTPS เพื่อการเชื่อมต่อที่ปลอดภัย
curl -v "https://api.aspose.cloud/v4.0/cells/search/content/all-textitems?region=en-US&password=myPassword" \
  -X PUT \
  -H "Content-Type: multipart/form-data" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer <jwt token>" \
  -F "Spreadsheet=@sample.xlsx"
```
