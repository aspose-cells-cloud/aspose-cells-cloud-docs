## **ค้นหาเนื้อหาในเวิร์กชีตระยะไกล**

ค้นหาข้อความที่ระบุภายในเวิร์กชีต Excel ใดๆ ได้อย่างเป็นโปรแกรมโดยใช้ Aspose.Cells Cloud API บริการนี้สามารถค้นหาข้อความ ตัวเลข หรือสูตรในไฟล์ระยะไกลที่จัดเก็บไว้ในพื้นที่เก็บข้อมูลบนคลาวด์ ช่วยให้สามารถใช้งานอัตโนมัติในการค้นหาข้อมูล วิเคราะห์เนื้อหา และตรวจสอบระบบสเปรดชีตได้

### **เว็บ API**

```curl
PUT https://api.aspose.cloud/v4.0/cells/{name}/worksheets/{worksheet}/search/content
```

### **ความปลอดภัยและการตรวจสอบสิทธิ์**

Aspose.Cells Cloud APIs มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การตรวจสอบสิทธิ์ด้วย JWT token</a>

```bash
-H "Authorization: Bearer {access_token}"
```

### **พารามิเตอร์คำขอ**

| ชื่อพารามิเตอร์ | ชนิดข้อมูล | Path/Query String/HTTP Body | คำอธิบาย                                                                                               |
| --------------- | ---------- | --------------------------- | ------------------------------------------------------------------------------------------------------ |
| name            | String     | Path                        | **จำเป็น** ชื่อไฟล์ของสมุดงานเป้าหมาย (เช่น `annual_report.xlsx`)                                      |
| worksheet       | String     | Path                        | **จำเป็น** ชื่อเวิร์กชีตภายในสมุดงานที่ดำเนินการค้นหา                                                  |
| searchText      | String     | Query                       | **จำเป็น** ข้อความหรือตัวเลขที่ต้องการค้นหาแบบตรงกัน                                                   |
| ignoreCase      | Boolean    | Query                       | **ไม่บังคับ** เมื่อตั้งค่าเป็น `true` การค้นหาจะไม่คำนึงถึงตัวพิมพ์เล็ก-ใหญ่ ค่าเริ่มต้นคือ `false`    |
| folder          | String     | Query                       | **ไม่บังคับ** เส้นทางไปยังโฟลเดอร์ที่เก็บสมุดงาน หากไม่ระบุ จะใช้โฟลเดอร์รากเป็นค่าเริ่มต้น            |
| storageName     | String     | Query                       | **ไม่บังคับ** ชื่อของพื้นที่เก็บข้อมูลบนคลาวด์ที่กำหนดค่าเอง หากไม่ระบุ จะใช้พื้นที่เก็บข้อมูลเริ่มต้น |
| region          | String     | Query                       | **ไม่บังคับ** การตั้งค่าภาษาและภูมิภาค (เช่น `ja-JP`) ซึ่งอาจส่งผลต่อการเปรียบเทียบข้อความ             |
| password        | String     | Query                       | **ไม่บังคับ** รหัสผ่านสำหรับสมุดงานที่มีการป้องกัน ไม่ต้องระบุหากไฟล์ไม่ได้เข้ารหัส                    |

### **การตอบกลับ**

```json
{
  "textItems": [
    {
      "cellName": "A1",
      "text": "Total",
      "occurrences": 1
    },
    {
      "cellName": "B5",
      "text": "Total",
      "occurrences": 2
    }
  ],
  "code": 200,
  "status": "OK"
}
```

- **textItems** – อาเรย์ของผลลัพธ์ที่ตรงกัน แต่ละรายการประกอบด้วยที่อยู่เซลล์ (`cellName`) ข้อความที่ตรงกัน (`text`) และจำนวนครั้งที่ปรากฏในเซลล์นั้น (`occurrences`)
- **code** – รหัสสถานะ HTTP ที่ส่งคืนโดยบริการ
- **status** – คำอธิบายแบบข้อความของผลลัพธ์

### **รหัสข้อผิดพลาด**

- **400 Bad Request** – URI ของ API ไม่ถูกต้องหรือพารามิเตอร์ผิดรูปแบบ
- **401 Unauthorized** – ไม่มีหรือโทเคน OAuth 2.0 ไม่ถูกต้อง
- **404 Not Found** – ไม่พบสมุดงานหรือเวิร์กชีต
- **500 Server Error** – เกิดข้อผิดพลาดที่ไม่คาดคิดขณะประมวลผลคำขอ

## **ควรใช้การค้นหาเนื้อหาในเวิร์กชีตของ Spreadsheet API อย่างไร?**

- **การตรวจสอบความสอดคล้องของสมุดงาน:** ค้นหาคำที่ละเอียดอ่อน (เช่น “Confidential”) ได้อย่างรวดเร็วทั่วทั้งไฟล์
- **การเชื่อมโยงข้อมูลข้ามเวิร์กชีต:** ค้นหาหมายเลขโครงการหรือชื่อลูกค้าที่ปรากฏในหลายเวิร์กชีต
- **การตรวจสอบเทมเพลต:** หลังจากสร้างรายงานแล้ว ยืนยันว่าตัวยึดตำแหน่งเช่น `{{Date}}` ถูกแทนที่เรียบร้อยแล้ว
- **การขุดข้อมูลเชิงประวัติศาสตร์:** ค้นหาโค้ดเหตุการณ์เฉพาะในสเปรดชีตรุ่นเก่าเพื่อทำความเข้าใจตรรกะทางธุรกิจในอดีต

## **เหตุใดจึงควรใช้การค้นหาเนื้อหาในเวิร์กชีตของ Spreadsheet API?**

- **เป็นมิตรกับนักพัฒนา:** SDK สำหรับภาษาต่างๆ ช่วยเร่งการพัฒนาและมีเอกสารประกอบอย่างสมบูรณ์
- **ลดต้นทุนแรงงาน:** ลดความจำเป็นในการจ้างบุคลากรเพื่อทำงานรวบรวมข้อมูลด้วยตนเอง
- **จ่ายตามการใช้งาน:** จ่ายเฉพาะสำหรับการเรียกใช้งาน API ที่คุณดำเนินการจริง
- **ไม่ต้องดูแลรักษา:** ไม่มีเซิร์ฟเวอร์ให้จัดการ ไม่มีโปรแกรมอัปเดต และไม่มีปัญหาด้านความเข้ากันได้
- **รักษารูปแบบ Excel ที่ซับซ้อน** ไว้เมื่อนำส่งผลลัพธ์เป็น PDF หรือรูปแบบอื่นๆ

## **วิธีใช้การค้นหาลิงก์ที่ใช้การไม่ได้ในเวิร์กชีตของ Spreadsheet API ด้วย SDK**

### **สเปค OpenAPI**

[OpenAPI Specification](https://reference.aspose.cloud/cells/#/SearchControllor/SearchContentInRemoteWorksheet) นิยามอินเทอร์เฟซโปรแกรมที่เข้าถึงได้แบบสาธารณะ และเปิดให้ใช้งาน REST ได้โดยตรงจากเว็บเบราว์เซอร์

### **ใช้งาน Aspose.Cells Cloud SDK**

การใช้งาน SDK เป็นวิธีที่ดีที่สุดในการเร่งการพัฒนา SDK จัดการรายละเอียดระดับล่างไว้ให้คุณเพียงแต่ใช้งานการค้นหาเนื้อหาในเวิร์กชีตของสเปรดชีตด้วยโค้ดเพียงเล็กน้อย โปรดดูที่ [GitHub repository](https://github.com/aspose-cells-cloud) เพื่อดูรายชื่อ SDK ของ Aspose.Cells Cloud ทั้งหมด
