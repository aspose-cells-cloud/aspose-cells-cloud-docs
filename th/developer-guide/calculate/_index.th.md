ดำเนินการคำนวณอัตโนมัติ เช่น **SUM**, **COUNT**, **AVERAGE**, **MIN** และ **MAX** บนแผ่นงาน Excel ผ่าน Aspose.Cells Cloud REST API—ไม่จำเป็นต้องกรองด้วยตนเองหรือใช้ซอฟต์แวร์สเปรดชีตในเครื่อง API นี้รองรับโดย **Aspose.Cells Cloud** ใช้การยืนยันตัวตนแบบมาตรฐาน (OAuth 2.0 หรือ JWT) ส่งคืนผลลัพธ์ในรูปแบบ JSON และจัดเตรียมโค้ดข้อผิดพลาดที่ชัดเจนสำหรับช่วงข้อมูลที่ไม่ถูกต้องหรือปัญหาการยืนยันตัวตน สำหรับไวยากรณ์คำขอโดยละเอียด โปรดดูเอกสารอ้างอิง REST API อย่างเป็นทางการ

- **[คำนวณตามสีของเซลล์](https://docs.aspose.cloud/cells/aggregate-cells-by-color/)** – รับผลรวมที่จัดกลุ่มตามสีพื้นหลังหรือสีตัวอักษรในคำข้อเดียว
- **[การคำนวณด่วนสำหรับสเปรดชีต](https://docs.aspose.cloud/cells/math-calculate/)** – คำนวณ SUM, COUNT, AVERAGE, MIN, MAX (และคณิตศาสตร์พื้นฐาน) ทั่วช่วงข้อมูลใดๆ ได้ทันที
