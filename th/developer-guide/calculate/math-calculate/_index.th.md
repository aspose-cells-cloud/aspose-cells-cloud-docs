## **บทนำ**: การคำนวณด่วนในสเปรดชีต – สูตรบวก คูณ ลบ หาร และเปอร์เซ็นต์ ผ่าน API เดียว

_ดำเนินการคำนวณแบบเป็นกลุ่มกับคอลัมน์ แถว หรือตารางทั้งหมดโดยไม่จำเป็นต้องเขียนสูตร_

- **คณิตศาสตร์พื้นฐาน**: บวก ลบ คูณ หรือหารค่าในทุกเซลล์ภายในช่วงด้วยตัวเลขใดๆ
- **เปอร์เซ็นต์**: เพิ่ม/ลดค่าตามเปอร์เซ็นต์ หรือหาค่าเปอร์เซ็นต์ของจำนวนหนึ่ง (เช่น +15% -8% หรือ 20% ของ...)
- **ประมวลผลแบบเป็นกลุ่ม**: ประมวลผลได้ทันทีกับพันๆ เซลล์ โดยไม่ต้องลากเติม ไม่ต้องใช้สูตรอาเรย์ และไม่ต้องใช้ VBA

| **ประเภทการคำนวณ** | คำอธิบาย |
| :------------------ | :------- |
| **บวก**             | +        |
| **ลบ**              | -        |
| **คูณ**             | \*       |
| **หาร**             | /        |
| **เปอร์เซ็นต์**     | %        |

## **API คำนวณทางคณิตศาสตร์**

```http
PUT https://api.aspose.cloud/v4.0/cells/calculate/math
```

### **ความปลอดภัยและการยืนยันตัวตน**

API ของ Aspose.Cells Cloud มีความปลอดภัยสูงและต้องใช้การยืนยันตัวตนแบบ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">โทเคน JWT</a>

### **พารามิเตอร์คำขอ:**

| ชื่อพารามิเตอร์ | ชนิดข้อมูล | Path/Query String/HTTP Body | คำอธิบาย |
| :--------------- | :-------- | :-------------------------- | :------- |
| Spreadsheet      | ไฟล์     | FormData                    | อัปโหลดไฟล์สเปรดชีตเพื่อประมวลผล |
| operation        | สตริง     | Query                       | ประเภทการคำนวณทางคณิตศาสตร์ที่ต้องการดำเนินการ (Add, Subtract, Multiply, Divide, Percentage) |
| value            | สตริง     | Query                       | ค่าที่ใช้ในการคำนวณ (ถ้ามี) |
| worksheet        | สตริง     | Query                       | ชื่อของแผ่นงานที่ต้องการดำเนินการ |
| range            | สตริง     | Query                       | ช่วงของเซลล์ที่ต้องการรวมไว้ในการคำนวณ |
| region           | สตริง     | Query                       | การตั้งค่าภูมิภาคของสเปรดชีต |
| password         | สตริง     | Query                       | รหัสผ่านสำหรับเปิดไฟล์สเปรดชีต (ถ้ามีการป้องกันไว้) |

### **การตอบกลับ**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream",
      "Name": "file"
    }
  }
]
```

**รหัสสถานะ HTTP**

| รหัส | ความหมาย               | คำอธิบาย |
| ---- | ---------------------- | -------- |
| 200  | สำเร็จ (OK)            | ใช้ตัวกรองเรียบร้อยแล้ว โดยการตอบกลับจะมีรายละเอียดของการดำเนินการ |
| 400  | คำขอไม่ถูกต้อง (Bad Request) | พารามิเตอร์ไม่ครบหรือไม่ถูกต้อง (เช่น ไฟล์ที่ไม่รองรับ) |
| 401  | ไม่ได้รับอนุญาต (Unauthorized) | โทเคน JWT ไม่ถูกต้องหรือไม่มีการส่งมา |
| 413  | ข้อมูลส่งไปมีขนาดใหญ่เกินไป (Payload Too Large) | ไฟล์ที่อัปโหลดมีขนาดเกินขีดจำกัด |
| 500  | ข้อผิดพลาดภายในเซิร์ฟเวอร์ (Internal Server Error) | เกิดข้อผิดพลาดที่ไม่คาดคิดภายในเซิร์ฟเวอร์ |

## ควรใช้ Math Calculate API ในกรณีใด?

- **การเงิน**: เพิ่มภาษีมูลค่าเพิ่ม (VAT) 13% ให้กับคอลัมน์ราคาซื้อทั้งหมด
- **การจัดการสินค้าคงคลัง**: คูณคอลัมน์น้ำหนักเป็นกิโลกรัมด้วย 2.2046 เพื่อแปลงเป็นปอนด์แบบเป็นกลุ่ม
- **การเงินเดือน**: เพิ่มโบนัสคงที่ 1,000 บาทให้กับคอลัมน์โบนัสสำหรับพนักงานทุกคน
- **การแปลงสกุลเงินต่างประเทศ**: หารคอลัมน์ยอดขายด้วยอัตราแลกเปลี่ยนแบบเรียลไทม์ เพื่อคำนวณเป็นหน่วยดอลลาร์สหรัฐ
- **การให้คะแนน**: ลบ 5 คะแนนออกจากคะแนนของนักเรียนทุกคนเนื่องจากขาดเรียน
- **อีคอมเมิร์ซ**: ใช้ส่วนลดโปรโมชัน 15% โดยลดราคาสินค้าทั้งหมดในคลิกเดียว

## เหตุใดจึงควรใช้ Math Calculate API?

- **การคำนวณ Excel ที่รวดเร็ว** – สร้างรายงานสิ้นเดือนภายในไม่กี่วินาที
- **เพิ่มค่าเป็นเปอร์เซ็นต์แบบเป็นกลุ่มใน Excel** – ปรับราคา แผนการณ์ และค่าคอมมิชชันในคลิกเดียว
- **บวกค่าคงที่ให้กับคอลัมน์ทั้งหมดใน Excel** – ใช้กับสินค้าคงคลัง การแปลงสกุลเงิน และการแปลงหน่วย
- **ใช้ Excel โดยไม่ต้องใช้สูตร** – ผู้ใช้ทั่วไปชื่นชอบความเรียบง่ายของฟีเจอร์นี้
- **การพัฒนาสามารถเสร็จสิ้นได้อย่างรวดเร็ว** ผ่าน SDK ที่มีอยู่แล้ว

**หมายเหตุ**  
ขนาดไฟล์สูงสุดที่รองรับคือ 200 เมกะไบต์ พารามิเตอร์ `range` ต้องเป็นที่อยู่ Excel ที่ถูกต้อง (เช่น A1:B10) แผ่นงานที่มีขนาดใหญ่มากอาจใช้เวลารองรับเพิ่มเติม

## วิธีใช้ Math Calculate API ผ่าน SDK

### **สเปคของ Math Calculate API**

[สเปคของ Math Calculate API](https://reference.aspose.cloud/cells/#/CalculateController/MathCalculate) กำหนดอินเทอร์เฟซการเขียนโปรแกรมที่สามารถเข้าถึงได้จากสาธารณะ ซึ่งช่วยให้นักพัฒนาสามารถโต้ตอบกับ API โดยตรงจากเว็บเบราว์เซอร์

### **ใช้ SDK ของ Aspose.Cells Cloud**

การใช้ SDK เป็นวิธีที่เร็วที่สุดในการพัฒนา เนื่องจาก SDK ซ่อนรายละเอียดระดับต่ำไว้ให้แล้ว ทำให้คุณสามารถดำเนินการคำนวณทางคณิตศาสตร์กับเซลล์ได้ด้วยโค้ดเพียงไม่กี่บรรทัด
