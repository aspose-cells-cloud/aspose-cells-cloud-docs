ลบซับสตริงที่ซ้ำกันออกจากเซลล์ Excel ด้วยการตรวจจับอัจฉริยะ รักษาการจัดรูปแบบเดิมไว้โดยไม่เปลี่ยนแปลงขณะกำจัดข้อความที่ซ้ำกันด้วย Aspose.Cells deduplication API

## **บทนำ**: ลบอักขระที่ไม่ต้องการอย่างแม่นยำ

API ตัวล้างซับสตริงซ้ำ (Repeat Substring Cleaner API) ลบซับสตริงที่ซ้ำกันภายในเซลล์แต่ละเซลล์ของช่วงข้อมูลใน Excel โดยรักษาการจัดรูปแบบเซลล์ การตรวจสอบข้อมูล และโครงสร้างสมุดงานอื่นๆ ไว้ การประมวลผลจะทำกับแต่ละเซลล์อย่างอิสระ โดยเก็บเฉพาะครั้งแรกของซับสตริงที่ซ้ำกันไว้เท่านั้น


### **ตัวเลือกแหล่งข้อมูล**

| ฟิลด์      | ชนิดข้อมูล | จำเป็น | คำอธิบาย                                             |
| ---------- | ---------- | ------ | ------------------------------------------------------- |
| `workbook` | ไฟล์      | ใช่    | ไฟล์สมุดงาน Excel (.xlsx, .xlsm)                     |
| `range`    | สตริง      | ใช่    | ช่วงข้อมูลที่ต้องการประมวลผล (เช่น "A1:D100", "Sheet1!A:D") |

### **ตัวเลือกตัวคั่น**

| ฟิลด์                               | ชนิดข้อมูล | ค่าเริ่มต้น | คำอธิบาย                                                                                                                                               |
| ----------------------------------- | ---------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `delimiters`                        | สตริง       | `"preset"`  | ตัวเลือก: `preset`, `custom`, `comma`, `semicolon`, `space`, `tab`, `line-break` หรือสตริงตัวคั่นแบบกำหนดเอง (ตัวอักษรหลายตัวจะถือว่าเป็นตัวคั่นแบบประกอบ) |
| `treatConsecutiveDelimitersAsOne`  | บูลีน       | `false`     | รวมตัวคั่นที่อยู่ติดกันเป็นตัวคั่นเดียว                                                                                                      |
| `caseSensitive`                    | บูลีน       | `false`     | กำหนดว่าการเปรียบเทียบมีการแยกแยะตัวพิมพ์เล็ก-ใหญ่หรือไม่ เมื่อตั้งค่าเป็น `false` จะไม่แยกแยะตัวพิมพ์เล็ก-ใหญ่ในการตรวจจับซ้ำกัน                                            |

## **API RemoveDuplicateSubstrings**

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/content/remove/duplicate-substrings
```

### **ความปลอดภัยและการรับรองความถูกต้อง**

API ของ Aspose.Cells Cloud มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การรับรองความถูกต้องด้วยโทเคน JWT</a>

```bash
-H "Authorization: Bearer {access_token}"
```

### พารามิเตอร์คำขอของ API **RemoveDuplicateSubstrings** มีดังนี้

| ชื่อพารามิเตอร์                 | ชนิดข้อมูล | ตำแหน่ง (Path/Query String/HTTPBody) | คำอธิบาย                                                                                                                                                                       |
| :------------------------------ | :--------- | :------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet                     | ไฟล์       | FormData                              | ไฟล์สเปรดชีตที่ต้องการประมวลผล รูปแบบที่รองรับ ได้แก่ XLSX, XLS, ODS, CSV เป็นต้น                                                                                             |
| delimiters                      | สตริง       | Query                                 | ระบุอักขระตัวคั่นหนึ่งหรือหลายตัวที่ใช้แบ่งเนื้อหาในเซลล์เป็นซับสตริงเพื่อการตรวจจับและลบซ้ำกัน สามารถระบุตัวคั่นหลายตัวได้ (เช่น `",;"`)                                        |
| treatConsecutiveDelimitersAsOne | บูลีน       | Query                                 | เมื่อตั้งค่าเป็น `true` อักขระตัวคั่นที่อยู่ติดกันจะถูกประมวลผลเป็นตัวคั่นเดียว เมื่อตั้งค่าเป็น `false` จะประมวลผลแต่ละตัวคั่นแยกกัน                                             |
| caseSensitive                   | บูลีน       | Query                                 | เมื่อตั้งค่าเป็น `true` การตรวจจับซ้ำจะพิจารณาตัวพิมพ์เล็ก-ใหญ่ (เช่น "Text" ≠ "text") เมื่อตั้งค่าเป็น `false` จะไม่แยกแยะตัวพิมพ์เล็ก-ใหญ่ในการเปรียบเทียบซ้ำกัน                        |
| worksheet                       | สตริง       | Query                                 | _(ไม่บังคับ)_ ชื่อของแผ่นงานที่จะใช้การลบซับสตริงซ้ำกัน หากไม่ระบุ การดำเนินการจะใช้กับแผ่นงานแรก                                     |
| range                           | สตริง       | Query                                 | _(ไม่บังคับ)_ ช่วงเซลล์ที่จะใช้การลบซับสตริงซ้ำกัน (เช่น `"A1:C10"`) หากไม่ระบุ การดำเนินการจะใช้กับเซลล์ที่ใช้งานทั้งหมดในแผ่นงานที่ระบุ                                      |
| outPath                         | สตริง       | Query                                 | _(ไม่บังคับ)_ เส้นทางโฟลเดอร์ในพื้นที่จัดเก็บบนคลาวด์ที่จะบันทึกสมุดงานที่ประมวลผลแล้ว หากไม่ระบุ ไฟล์จะถูกบันทึกในโฟลเดอร์ต้นทาง                                        |
| outStorageName                  | สตริง       | Query                                 | ชื่อของพื้นที่จัดเก็บบนคลาวด์ที่จะบันทึกไฟล์ผลลัพธ์                                                                                                                             |
| region                          | สตริง       | Query                                 | _(ไม่บังคับ)_ ตั้งค่าภาษาสำหรับการประมวลผลข้อความ ซึ่งอาจส่งผลต่อการตีความตัวคั่นและกฎการแยกแยะตัวพิมพ์เล็ก-ใหญ่สำหรับภาษาบางภาษา (เช่น `"en-US"`, `"tr-TR"`)                         |
| password                        | สตริง       | Query                                 | _(ไม่บังคับ)_ หากสเปรดชีตที่อัปโหลดมีการป้องกันด้วยรหัสผ่าน โปรดระบุรหัสผ่านเพื่อเปิดและประมวลผลไฟล์                                                                          |

**ตัวอย่างคำขอ (cURL)**

```bash
curl -X PUT "https://api.aspose.cloud/v4.0/cells/content/remove/duplicate-substrings?delimiters=comma&caseSensitive=false" \
     -H "Authorization: Bearer {access_token}" \
     -F "Spreadsheet=@Sample.xlsx" \
     -F "range=A1:D100"
```

## ควรใช้ API ลบซับสตริงที่ซ้ำกันในกรณีใด?

- **กรณีการชำระล้างและทำให้ข้อมูลเป็นมาตรฐาน**: ชำระล้างแท็กเช่น `"VIP,Premium,VIP,Gold"` → `"VIP,Premium,Gold"`
- **ข้อมูลทางเทคนิคและปฏิบัติการ**: ชำระล้างรายการบันทึกข้อผิดพลาดที่มีรหัสซ้ำกัน ลบตัวระบุถัง/ชั้นที่ซ้ำกัน เป็นต้น
- **การจัดการเนื้อหาและสื่อ**: ลบแท็กทักษะที่ซ้ำกัน ลบข้อมูลใบรับรองที่ซ้ำกัน

## เหตุใดจึงควรใช้ API ลบซับสตริงที่ซ้ำกัน?

- **อัตโนมัติแบบไม่ต้องทำด้วยมือ**: กำจัดการแก้ไขที่น่าเบื่อหน่ายและลดข้อผิดพลาดของมนุษย์
- **รักษาความสมบูรณ์ของข้อมูล**: สี เฟอนต์ เส้นขอบ และการจัดรูปแบบตามเงื่อนไขของเซลล์ยังคงไม่เปลี่ยนแปลง รายการแบบเลือกแบบหล่นลงและกฎการตรวจสอบข้อมูลยังคงใช้งานได้
- **การประมวลผลที่ยืดหยุ่น**: ไม่ขึ้นกับตัวคั่น มีการควบคุมการแยกแยะตัวพิมพ์เล็ก-ใหญ่และป้องกันส่วนหัวได้ตามต้องการ
- **เป็นมิตรกับนักพัฒนา**: Aspose.Cells Cloud มี SDK ให้ใช้งานในหลายภาษา ช่วยให้พัฒนาได้อย่างรวดเร็วพร้อมเอกสารประกอบที่ครบถ้วน
- **ประหยัดต้นทุน**: การดำเนินการนี้ทำบนคลาวด์ ไม่จำเป็นต้องจัดเก็บไฟล์ชั่วคราวไว้ในเครื่อง
