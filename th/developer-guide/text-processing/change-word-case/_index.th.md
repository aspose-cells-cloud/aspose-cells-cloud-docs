## **เปลี่ยนรูปแบบตัวพิมพ์ใหญ่-เล็กของคำ**

ใช้ Aspose.Cells Cloud Web API เพื่อแปลงรูปแบบตัวพิมพ์ใหญ่-เล็กของข้อความในสมุดงานของคุณทันที—เปลี่ยนระหว่างตัวพิมพ์ใหญ่ทั้งหมด, ตัวพิมพ์เล็กทั้งหมด, ตัวพิมพ์ใหญ่ตัวแรกของแต่ละคำ (ตัวพิมพ์ใหญ่ตัวแรกของแต่ละคำ) หรือตัวพิมพ์ใหญ่ตัวแรกของแต่ละประโยค (ตัวพิมพ์ใหญ่ตัวแรกของแต่ละประโยค) ทั่วทั้งช่วงที่เลือก โดยจะส่งผลต่อเซลล์ที่เป็นข้อความเท่านั้น ค่าตัวเลข, ค่าบูลีน, ค่าข้อผิดพลาด และเซลล์ว่างจะถูกละเว้น สูตร, การจัดรูปแบบ และการตรวจสอบข้อมูลจะไม่ได้รับผลกระทบ

- **UpperCase** – ตัวอักษรทั้งหมดเป็นตัวพิมพ์ใหญ่
- **LowerCase** – ตัวอักษรทั้งหมดเป็นตัวพิมพ์เล็ก
- **ProperCase** – ตัวอักษรตัวแรกของแต่ละคำเป็นตัวพิมพ์ใหญ่ ส่วนที่เหลือเป็นตัวพิมพ์เล็ก
- **SentenceCase** – ตัวอักษรตัวแรกของแต่ละประโยคเป็นตัวพิมพ์ใหญ่ ส่วนที่เหลือเป็นตัวพิมพ์เล็ก

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/content/wordcase
```


### **ความปลอดภัยและการยืนยันตัวตน**

Aspose.Cells Cloud APIs มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การยืนยันตัวตนด้วย JWT token</a>

```bash
-H "Authorization: Bearer {access_token}"
```

| ชื่อพารามิเตอร์ | ประเภท | ตำแหน่ง | คำอธิบาย                                                                                                                                                           |
| :------------- | :----- | :------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| spreadsheet    | ไฟล์   | FormData | ไฟล์สมุดงานที่ต้องการประมวลผล รูปแบบที่รองรับได้แก่ XLSX, XLS, ODS, CSV เป็นต้น                                                                             |
| wordCaseType   | สตริง | Query    | ระบุประเภทการแปลงรูปแบบตัวพิมพ์ใหญ่-เล็กของข้อความ: `UpperCase`, `LowerCase`, `ProperCase` หรือ `SentenceCase`                                                                   |
| worksheet      | สตริง | Query    | _(ไม่บังคับ)_ ชื่อของแผ่นงานที่จะใช้การแปลงรูปแบบตัวพิมพ์ใหญ่-เล็ก ถ้าไม่ระบุ การดำเนินการจะถูกประยุกต์ใช้กับแผ่นงานแรกของสมุดงาน                                               |
| range          | สตริง | Query    | _(ไม่บังคับ)_ ช่วงเซลล์ที่จะใช้การแปลงรูปแบบตัวพิมพ์ใหญ่-เล็ก (เช่น `"A1:C10"`) ถ้าไม่ระบุ การดำเนินการจะถูกประยุกต์ใช้กับเซลล์ที่มีข้อมูลทั้งหมดในแผ่นงานที่ระบุ |
| outPath        | สตริง | Query    | _(ไม่บังคับ)_ ตำแหน่งโฟลเดอร์ในคลาวด์ที่จะบันทึกสมุดงานที่ประมวลผลแล้ว ถ้าไม่ระบุ ไฟล์จะถูกบันทึกไว้ในโฟลเดอร์ต้นทาง                            |
| outStorageName | สตริง | Query    | ชื่อของคลาวด์สโตรเรจที่จะใช้เก็บไฟล์ผลลัพธ์                                                                                                   |
| region         | สตริง | Query    | _(ไม่บังคับ)_ ตั้งค่าการตั้งค่าภูมิภาคสำหรับกฎการแปลงรูปแบบตัวพิมพ์ใหญ่-เล็กของข้อความ โดยเฉพาะในกรณีที่เกี่ยวข้องกับการตัวพิมพ์ใหญ่เฉพาะภาษา (เช่น `"en-US"`, `"tr-TR"`)                 |
| password       | สตริง | Query    | _(ไม่บังคับ)_ ถ้าสมุดงานที่อัปโหลดมีการป้องกันด้วยรหัสผ่าน ให้ระบุรหัสผ่านเพื่อเปิดและประมวลผลไฟล์                                                    |

### การตอบกลับ

เมื่อสำเร็จ บริการจะส่งคืนสถานะ **200 OK** (หรือ **202 Accepted**) พร้อมข้อมูล JSON ที่มีสตรีมไบนารีของสมุดงานที่ประมวลผลแล้ว

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

### โค้ดข้อผิดพลาด

- **400 Bad Request** – URI ของ Aspose.Cells Cloud API ไม่ถูกต้อง
- **401 Unauthorized** – JWT token ไม่ถูกต้อง หรือข้อมูลประจำตัวไคลเอนต์ไม่ถูกต้อง
- **404 Not Found** – ไม่สามารถเข้าถึงไฟล์สมุดงานได้
- **500 Server Error** – สมุดงานเกิดข้อผิดพลาดภายในระหว่างการประมวลผล

## ควรใช้ API เปลี่ยนรูปแบบตัวพิมพ์ใหญ่-เล็กของคำในกรณีใด?

### การทำความสะอาดและมาตรฐานข้อมูล

- **การจัดการข้อมูลลูกค้า** – มาตรฐานรูปแบบตัวพิมพ์ใหญ่-เล็กของชื่อลูกค้าและข้อมูลที่อยู่ (เช่น `john doe` → `John Doe`)
- **การประมวลผลแคตал็อกสินค้า** – มาตรฐานรูปแบบชื่อสินค้าและข้อความคำอธิบาย (เช่น `IPHONE 15 PRO` → `iPhone 15 Pro`)
- **การสร้างรายงานทางการเงิน** – ทำให้ชื่อรายการและช่องข้อความคำอธิบายในงบการเงินเป็นมาตรฐานเดียวกัน

### การบูรณาการข้อมูลจากหลายแหล่ง

- **ETL คลังข้อมูล** – มาตรฐานรูปแบบข้อความขณะโหลดข้อมูลจากระบบต่างๆ
- **การรับข้อมูลจาก API** – จัดการข้อมูลที่มีรูปแบบตัวพิมพ์ใหญ่-เล็กไม่สม่ำเสมอที่ส่งกลับมาจาก API ภายนอก
- **การรวมข้อมูลข้ามแผนก** – มาตรฐานรูปแบบข้อความในรายงาน Excel จากแผนกต่างๆ

### ระบบจัดการเนื้อหา

- **การเผยแพร่ข่าวอัตโนมัติ** – จัดรูปแบบหัวข้อข่าวและเนื้อหาโดยอัตโนมัติ (กฎตัวพิมพ์ใหญ่สำหรับหัวข้อ)
- **การสร้างเอกสารผลิตภัณฑ์** – ทำให้รูปแบบคำศัพท์ในเอกสารเทคนิคสอดคล้องกัน
- **การดูแลฐานความรู้** – มาตรฐานรูปแบบข้อความของคำถามที่พบบ่อยและเอกสารช่วยเหลือ

### การบูรณาการแอปพลิเคชันองค์กร

- **การบูรณาการระบบ CRM** – จัดรูปแบบชื่อและข้อมูลบริษัทโดยอัตโนมัติขณะนำเข้า/ส่งออกข้อมูลลูกค้า
- **การประมวลผลข้อมูล ERP** – มาตรฐานฟิลด์สำคัญเช่น คำอธิบายวัสดุและชื่อผู้จัดจำหน่าย
- **ระบบจัดการทรัพยากรบุคคล** – มาตรฐานข้อมูลพนักงานและตำแหน่งงาน

### การประมวลผลเอกสารจำนวนมาก

- **การเตรียมเอกสารทางกฎหมาย** – ประมวลผลรูปแบบข้อความในสัญญาและข้อตกลงเป็นชุด
- **การสร้างสื่อการตลาด** – มาตรฐานรูปแบบข้อความของข้อความโฆษณาและเทมเพลตอีเมล
- **การจัดรูปแบบบทความทางวิชาการ** – มาตรฐานข้อกำหนดรูปแบบสำหรับรายการอ้างอิงและหัวข้อ

### การประมวลผลข้อมูลแบบเรียลไทม์

- **การตรวจสอบข้อมูลผู้ใช้** – จัดรูปแบบข้อมูลฟอร์มที่ผู้ใช้ส่งเข้ามาแบบเรียลไทม์
- **การตอบกลับแชทบอท** – มาตรฐานรูปแบบข้อความสำหรับคำตอบที่สร้างโดยอัตโนมัติ
- **การสร้างรายงานแบบไดนามิก** – สร้างรายงานธุรกิจที่จัดรูปแบบสม่ำเสมอแบบไดนามิก

### การปรับให้เข้ากับหลายภาษาและท้องถิ่น

- **การประมวลผลข้อมูลหลายภาษา** – จัดการความแตกต่างของกฎตัวพิมพ์ใหญ่-เล็กสำหรับข้อความในภาษาต่างๆ
- **การเตรียมเนื้อหาท้องถิ่น** – เตรียมเนื้อหาท้องถิ่นที่จัดรูปแบบแล้วสำหรับภูมิภาคต่างๆ
- **การจัดการโครงการแปลภาษา** – ทำให้รูปแบบข้อความสอดคล้องกันก่อนและหลังการแปล

## เหตุใดควรใช้ API เปลี่ยนรูปแบบตัวพิมพ์ใหญ่-เล็กของคำ?

- **เป็นมิตรกับนักพัฒนา** – Aspose.Cells Cloud มี SDK สำหรับภาษาต่างๆ หลายภาษา ทำให้สามารถพัฒนาได้อย่างรวดเร็วและมีเอกสารประกอบครบถ้วน เมื่อเทียบกับการสร้างโซลูชันแบบกำหนดเอง สิ่งนี้ช่วยลดภาระงานพัฒนาได้อย่างมาก
- **ประหยัดต้นทุน** – คุณสามารถเปลี่ยนรูปแบบตัวพิมพ์ใหญ่-เล็กของคำโดยไม่จำเป็นต้องอัปโหลดสมุดงานก่อน ซึ่งช่วยประหยัดพื้นที่จัดเก็บและลดต้นทุน
