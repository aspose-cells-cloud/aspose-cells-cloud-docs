ล้างข้อมูล Excel โดยการแปลงตัวเลขที่จัดรูปแบบเป็นข้อความให้เป็นค่าตัวเลขจริง แทนที่อักขระและตัวขึ้นบรรทัดใหม่ที่ไม่ต้องการ และทำให้ตัวอักษรเน้นเสียงเป็นมาตรฐานเป็นตัวอักษรธรรมดาด้วย Aspose.Cells API

## ภาพรวม

**แปลงตัวเลขที่จัดเก็บเป็นข้อความ ลบข้อมูลที่ไม่จำเป็น แทนที่ตัวเน้นเสียง—เพียงหนึ่งคำสั่ง ไม่ต้องใช้สูตรใดๆ**

- **แปลงตัวเลขที่จัดเก็บเป็นข้อความให้เป็นตัวเลข**: แปลงข้อมูลตัวเลขที่จัดเก็บในรูปแบบข้อความให้เป็นตัวเลขจริง เพื่อให้การคำนวณแม่นยำและการแสดงผลข้อมูลถูกต้อง
- **แทนที่อักขระเฉพาะ**: แทนที่อักขระที่ระบุทั้งหมดในเซลล์ที่เลือกในครั้งเดียว เพื่อทำให้ข้อมูลเป็นมาตรฐาน
- **แปลงตัวขึ้นบรรทัดใหม่เป็นช่องว่าง จุลภาค หรือเซมิโคลน**: เพิ่มความอ่านง่ายด้วยการแปลงตัวขึ้นบรรทัดใหม่เป็นช่องว่าง จุลภาค หรือเซมิโคลน เพื่อให้ข้อมูลดูเป็นระเบียบและสวยงามยิ่งขึ้น
- **แทนที่อักขระเน้นเสียง**: หากข้อมูลของคุณอยู่ในภาษาต่างๆ คุณสามารถแทนที่อักขระเน้นเสียง เช่น “é” หรือ “ü” ด้วยตัวอักษรไม่เน้นเสียง equivalents เพื่อเพิ่มความสอดคล้องและความชัดเจน

## **ConvertText API**

### Web API

```http
PUT https://api.aspose.cloud/v4.0/cells/content/convert/text
```

### **ความปลอดภัยและการยืนยันตัวตน**

Aspose.Cells Cloud APIs มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การยืนยันตัวตนด้วย JWT token</a>

```bash
-H "Authorization: Bearer {access_token}"
```

### พารามิเตอร์คำขอของ **convertText** API มีดังนี้

| ชื่อพารามิเตอร์ | ชนิดข้อมูล | Path/Query String/HTTPBody | คำอธิบาย                                                                                                                                                           |
| ---------------- | ---------- | -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spreadsheet      | ไฟล์       | FormData                   | ไฟล์สมุดบันทึกที่จะประมวลผล รูปแบบที่รองรับได้แก่ XLSX, XLS, ODS, CSV เป็นต้น                                                                                       |
| convertTextType  | สตริง       | Query                      | ระบุประเภทการแปลงข้อความที่จะใช้ เช่น การแปลงตัวเลขที่จัดรูปแบบเป็นข้อความให้เป็นค่าตัวเลขจริง หรือการแปลงอักขระเน้นเสียงให้เป็นตัวอักษรธรรมดา                 |
| sourceCharacters | สตริง       | Query                      | ระบุอักขระ สตริง หรือรูปแบบที่จะแทนที่หรือลบออกจากข้อความ (เช่น `"é,è,ê"`, `"#N/A"`, `"\\n"` สำหรับตัวขึ้นบรรทัดใหม่)                                                |
| targetCharacters | สตริง       | Query                      | ระบุอักขระหรือสตริงที่จะใช้แทนที่อักขระต้นทาง (เช่น `"e"` สำหรับตัวอักษรเน้นเสียง `""` สำหรับการลบ `" "` สำหรับตัวขึ้นบรรทัดใหม่)                                    |
| worksheet        | สตริง       | Query                      | _(ไม่บังคับ)_ ชื่อชีตที่จะใช้การแปลงข้อความ หากไม่ระบุ การดำเนินการจะใช้กับชีตแรก                                                                                 |
| range            | สตริง       | Query                      | _(ไม่บังคับ)_ ช่วงเซลล์ที่จะใช้การแปลงข้อความ (เช่น `"A1:C10"`) หากไม่ระบุ การดำเนินการจะใช้กับเซลล์ที่ใช้งานทั้งหมดในชีตที่ระบุ                                   |
| outPath          | สตริง       | Query                      | _(ไม่บังคับ)_ เส้นทางโฟลเดอร์ในคลาวด์สตอเรจที่จะบันทึกสมุดงานที่ประมวลผลแล้ว หากไม่ระบุ ไฟล์จะถูกบันทึกในโฟลเดอร์ต้นทาง                                          |
| outStorageName   | สตริง       | Query                      | ชื่อของคลาวด์สตอเรจที่จะบันทึกไฟล์ผลลัพธ์                                                                                                                           |
| region           | สตริง       | Query                      | _(ไม่บังคับ)_ ตั้งค่าการตั้งค่าภูมิภาคสำหรับกฎการแปลงข้อความ โดยเฉพาะอย่างยิ่งสำหรับการจัดการอักขระที่เกี่ยวข้องกับภาษา (เช่น `"en-US"`, `"fr-FR"`)                 |
| password         | สตริง       | Query                      | _(ไม่บังคับ)_ หากสมุดบันทึกที่อัปโหลดมีการป้องกันด้วยรหัสผ่าน ให้ระบุรหัสผ่านเพื่อเปิดและประมวลผลไฟล์                                                             |

### **คำตอบ (Response)**

```json
[
  {
    "Name": "ResponseFile",
    "DataType": {
      "Identifier": "File",
      "Reference": "Stream"
    }
  }
]
```

### รหัสข้อผิดพลาด

- **400 Bad Request**: URI ของ Aspose.Cells Cloud API ไม่ถูกต้อง
- **401 Unauthorized**: โทเคนการเข้าถึงไม่ถูกต้อง หรือ Client ID และ Secret ไม่ถูกต้อง
- **404 Not Found**: ไฟล์สมุดบันทึกไม่สามารถเข้าถึงได้
- **500 Server Error**: สมุดบันทึกเกิดข้อผิดพลาดขณะดึงข้อมูลการคำนวณ

## ควรใช้ Convert Text API กรณีใด?

- **แก้ไขรูปแบบตัวเลข**: แปลงตัวเลขที่จัดเก็บเป็นข้อความ (เช่น “123.45”) ให้อยู่ในรูปแบบตัวเลขที่เหมาะสมสำหรับการคำนวณ
- **ล้างอักขระพิเศษ**: ลบสัญลักษณ์พิเศษที่ไม่จำเป็น ช่องว่างส่วนเกิน หรืออักขระที่มองไม่เห็นออกจากข้อมูล
- **จัดการตัวขึ้นบรรทัดใหม่**: แทนที่ตัวขึ้นบรรทัดใหม่ในเซลล์ด้วยช่องว่างหรือตัวคั่นอื่นๆ
- **ทำให้ตัวอักษรเน้นเสียงเป็นมาตรฐาน**: แปลงตัวอักษรเน้นเสียง (เช่น “é”, “ñ”) ให้เป็นตัวอักษรมาตรฐาน (“e”, “n”)
- **การประมวลผลล่วงหน้าไฟล์ CSV**: ทำให้รูปแบบข้อความเป็นมาตรฐานก่อนนำเข้าไฟล์ CSV ลงใน Excel

## เหตุใดจึงควรใช้ Convert Text API?

- **การแปลงรูปแบบอัตโนมัติ**: แปลงตัวเลขที่จัดรูปแบบเป็นข้อความเป็นค่าที่สามารถคำนวณได้แบบหลายรายการพร้อมกันด้วยคำขอเพียงครั้งเดียว
- **มาตรฐานอักขระ**: จัดการอักขระพิเศษ ตัวเน้นเสียง และปัญหาการเข้ารหัสอย่างสม่ำเสมอ
- **ความสอดคล้องของข้อมูล**: ทำให้รูปแบบข้อความสอดคล้องกันอย่างสมบูรณ์ทั่วทั้งชุดข้อมูล
- **เป็นมิตรกับนักพัฒนา**: Aspose.Cells Cloud มี SDK สำหรับภาษาต่างๆ มากมาย ช่วยให้การพัฒนาทำได้รวดเร็วและมีเอกสารประกอบครบถ้วน เมื่อเทียบกับการสร้างโซลูชันการประมวลผลข้อความแบบกำหนดเอง วิธีนี้ช่วยลดภาระงานในการพัฒนาอย่างมาก
- **ประหยัดต้นทุน**: คุณสามารถแปลงข้อความได้โดยไม่จำเป็นต้องอัปโหลดสมุดงานก่อน ซึ่งช่วยประหยัดพื้นที่จัดเก็บและลดต้นทุน
