แทรกข้อความลงในเซลล์ Excel หลายเซลล์ในหนึ่งการดำเนินการ เติมคำนำหน้า คำต่อท้าย ป้ายกำกับ หรืออักขระแบบกำหนดเองที่จุดเริ่มต้น จุดสิ้นสุด หรือก่อน/หลังข้อความที่ระบุภายในเซลล์โดยใช้ Aspose.Cells API

## ภาพรวม

การแทรกข้อความแบบเป็นกลุ่มในคำขอเดียว สำหรับคำนำหน้า คำต่อท้าย หรือสตริงแบบยึดตำแหน่งลงในทุกเซลล์ของช่วงเป้าหมาย — ไม่มีสูตร ไม่มีคอลัมน์ช่วย

- แทรกข้อความแบบกำหนดเองที่ **ตำแหน่งใดก็ได้** ภายในแต่ละเซลล์

| ค่า              | คำอธิบาย                                                                                 |
| ---------------- | ----------------------------------------------------------------------------------------- |
| `None`           | แทนที่เนื้อหาเดิม                                                                         |
| `AtTheBeginning` | แทรกที่จุดเริ่มต้น (คำนำหน้า)                                                            |
| `AtTheEnd`       | แทรกที่จุดสิ้นสุด (คำต่อท้าย)                                                             |
| `BeforeText`     | แทรก **ก่อน** ตัวอย่างแรกของ `selectText`; ข้ามหากไม่พบ                                      |
| `AfterText`      | แทรก **หลัง** ตัวอย่างแรกของ `selectText`; ข้ามหากไม่พบ                                       |

- โหมดตำแหน่ง 4 แบบ: คำนำหน้า คำต่อท้าย ก่อน/หลังสับสตริง
- ข้ามเซลล์ว่างเพื่อหลีกเลี่ยงความยุ่งเหยิง
- API จัดการเฉพาะค่าที่เป็น **ชนิดสตริง** เท่านั้น; ตัวเลข ค่าบูลีน และสูตรจะถูกแปลงเป็นข้อความก่อน
- **เซลล์ว่าง**
  - `skipEmptyCells = true` → เซลล์ว่างจะถูกข้าม
  - `skipEmptyCells = false` → ข้อความจะถูกเติมลงในเซลล์ว่าง (เซลล์จะกลายเป็นชนิดข้อความ)

- **ไม่พบตัวยึดตำแหน่ง**: เมื่อ `position = BeforeText | AfterText` และ `selectText` **ไม่** มีอยู่ ค่าเซลล์จะไม่เปลี่ยนแปลง

### **เว็บ API**

```http
PUT https://api.aspose.cloud/v4.0/cells/content/add/text
```

### **ความปลอดภัยและการรับรองความถูกต้อง**

API ของ Aspose.Cells Cloud มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การรับรองความถูกต้องด้วยโทเค็น JWT</a>

```bash
-H "Authorization: Bearer {access_token}"
```

### พารามิเตอร์คำขอของ API **AddText** คือ

| ชื่อพารามิเตอร์ | ประเภท | Path/Query String/HTTPBody | คำอธิบาย                                                                                                                                                 | จำเป็น |
| :------------- | :----- | :------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------- | :----- |
| Spreadsheet    | ไฟล์  | FormData                   | ไฟล์สเปรดชีตที่จะประมวลผล รูปแบบที่รองรับ ได้แก่ XLSX, XLS, ODS, CSV เป็นต้น                                                                          | ใช่    |
| text           | สตริง | Query                      | เนื้อหาข้อความที่จะเพิ่มลงในเซลล์ที่ระบุในสเปรดชีต                                                                                                      | ใช่    |
| position       | สตริง | Query                      | ระบุตำแหน่งที่จะแทรกข้อความเมื่อเทียบกับเนื้อหาเซลล์เดิม ตัวเลือก: `AtTheBeginning`, `AtTheEnd`, `BeforeText`, `AfterText`, `None`                  | ใช่    |
| selectText     | สตริง | Query                      | _(ไม่จำเป็น)_ หากระบุไว้ ข้อความจะถูกเพิ่มเฉพาะในเซลล์ที่มีสับสตริงนี้ตรงกันเท่านั้น ใช้ร่วมกับพารามิเตอร์ `position`                                       | ไม่ใช่ |
| skipEmptyCells | บูลีน | Query                      | หากเป็น `true` จะข้ามเซลล์ว่าง; หากเป็น `false` จะเพิ่มข้อความลงในเซลล์ว่าง                                                                           | ไม่ใช่ |
| worksheet      | สตริง | Query                      | _(ไม่จำเป็น)_ ชื่อของเวิร์กชีตที่จะเพิ่มข้อความ หากไม่ระบุ การดำเนินการจะใช้กับเวิร์กชีตแรกตามค่าเริ่มต้น                                             | ไม่ใช่ |
| range          | สตริง | Query                      | _(ไม่จำเป็น)_ ช่วงเซลล์ที่จะเพิ่มข้อความ (เช่น `"A1:C10"`) หากไม่ระบุ การดำเนินการจะใช้กับเซลล์ที่ใช้งานทั้งหมดในเวิร์กชีตที่ระบุ                      | ไม่ใช่ |
| outPath        | สตริง | Query                      | _(ไม่จำเป็น)_ เส้นทางโฟลเดอร์ของพื้นที่จัดเก็บบนคลาวด์ที่จะบันทึกสมุดงานที่ประมวลผลแล้ว หากไม่ระบุ ไฟล์จะถูกบันทึกในโฟลเดอร์ต้นทาง                 | ไม่ใช่ |
| outStorageName | สตริง | Query                      | ชื่อของพื้นที่จัดเก็บบนคลาวด์ที่จะจัดเก็บไฟล์ผลลัพธ์                                                                                                   | ไม่ใช่ |
| region         | สตริง | Query                      | _(ไม่จำเป็น)_ ตั้งค่าการตั้งค่าภูมิภาคสำหรับการจัดรูปแบบตัวเลข วันที่ และสกุลเงินในไฟล์ผลลัพธ์ (เช่น `"en-US"`, `"zh-CN"`, `"de-DE"`)                   | ไม่ใช่ |
| password       | สตริง | Query                      | _(ไม่จำเป็น)_ หากสเปรดชีตที่อัปโหลดมีการป้องด้วยรหัสผ่าน โปรดระบุรหัสผ่านเพื่อเปิดและประมวลผลไฟล์                                                   | ไม่ใช่ |

**ตัวอย่าง cURL**

```bash
curl -X PUT "https://api.aspose.cloud/v4.0/cells/content/add/text?text=Report&position=AtTheBeginning&skipEmptyCells=true" \
  -H "Authorization: Bearer {access_token}" \
  -F "Spreadsheet=@/path/to/workbook.xlsx" \
  -F "outPath=output/workbook_modified.xlsx"
```

### โค้ดข้อผิดพลาด

| โค้ด | คำอธิบาย |
| ---- | ----------- |
| **400** Bad Request | URI ของ API Aspose.Cells Cloud ไม่ถูกต้องหรือขาดพารามิเตอร์ที่จำเป็น |
| **401** Unauthorized | โทเค็นการเข้าถึงไม่ถูกต้อง หรือ client ID และ secret ไม่ถูกต้อง |
| **404** Not Found | ไฟล์สเปรดชีตไม่สามารถเข้าถึงได้ |
| **500** Server Error | สเปรดชีตเกิดข้อผิดพลาดขณะรับข้อมูลการคำนวณ |

## ควรใช้ API เพิ่มข้อความสำหรับสเปรดชีตในกรณีใด?

- **การติดป้ายชื่อรายงานแบบไดนามิก**: เพิ่มหัวเรื่อง แท็กวันที่ หรือบันทึกย่อแบบไดนามิกลงในงบการเงินและรายงานการขายที่สร้างขึ้นโดยอัตโนมัติ
- **การลายน้ำไฟล์เป็นกลุ่ม**: เพิ่มโลโก้บริษัท ลายน้ำความลับ หรือข้อมูลเวอร์ชันลงในไฟล์ Excel หลายไฟล์พร้อมกัน
- **การเติมข้อมูลเทมเพลต**: ใส่ชื่อลูกค้า จำนวนเงิน และข้อความอื่นๆ ลงในตำแหน่งที่กำหนดของเทมเพลตสัญญาหรือใบแจ้งหนี้โดยอัตโนมัติ
- **การแท็กการจำแนกข้อมูล**: เพิ่มแท็กการจำแนกหรือป้ายสถานะ (เช่น "รอตรวจสอบ", "อนุมัติ") ลงในแถวข้อมูลโดยอัตโนมัติตามผลการวิเคราะห์
- **การบันทึกคำอธิบายคุณภาพข้อมูล**: เพิ่มบันทึกย่อสำหรับข้อมูลที่มีปัญหาในระหว่างการกำจัดข้อมูล
- **การจัดรูปแบบข้อความแบบเป็นกลุ่ม**: เพิ่มคำนำหน้าหรือคำต่อท้ายให้กับชื่อผลิตภัณฑ์หรือชื่อลูกค้าอย่างสม่ำเสมอ

## เหตุใดจึงควรใช้ API เพิ่มข้อความสำหรับสเปรดชีต?

- **การเพิ่มข้อความแบบเป็นกลุ่ม**: เพิ่มข้อความลงในเซลล์หรือไฟล์นับร้อยพร้อมกัน ช่วยประหยัดเวลาได้สูงสุด 95% เทียบกับการใช้แรงงานด้วยตนเอง
- **การควบคุมตำแหน่งที่แม่นยำ**: รองรับการแทรกข้อความอย่างแม่นยำที่หกตำแหน่ง ได้แก่ จุดเริ่มต้น จุดสิ้นสุด หรือก่อน/หลังข้อความที่ระบุภายในเซลล์
- **การจัดการเงื่อนไขแบบชาญฉลาด**: ตัดสินใจว่าจะเพิ่มข้อความหรือไม่โดยพิจารณาว่าเซลล์ว่างหรือมีข้อความที่ระบุหรือไม่
- **รองรับกลยุทธ์หลายตำแหน่ง**:
  - `AtTheBeginning`: เพิ่มข้อความเดียวกันก่อนเนื้อหาของเซลล์ที่เลือกทั้งหมด
  - `AtTheEnd`: เพิ่มข้อความหลังเนื้อหาของเซลล์ที่เลือกทั้งหมด
  - `BeforeText` / `AfterText`: เพิ่มข้อความก่อนหรือหลังเซลล์ที่มีข้อความที่ระบุเท่านั้น
  - `None`: แทนที่เนื้อหาเดิม
- **การควบคุมช่วงที่แม่นยำ**: อนุญาตให้ระบุเวิร์กชีตหรือช่วงเซลล์เฉพาะสำหรับการดำเนินการ
- **ตัวเลือกการข้ามตามเงื่อนไข**: รองรับการข้ามเซลล์ว่างเพื่อหลีกเลี่ยงการเพิ่มข้อความที่ไม่จำเป็น
- **เป็นมิตรกับนักพัฒนา**: Aspose.Cells Cloud มี SDK หลายภาษา ช่วยให้การพัฒนาทำได้อย่างรวดเร็ว และมาพร้อมเอกสารคู่มือที่ครบถ้วน เมื่อเทียบกับการสร้างโซลูชันเรนเดอร์กราฟิกแบบกำหนดเอง นี่จะลดภาระงานการพัฒนาอย่างมาก
- **ประหยัดต้นทุน**: สามารถเพิ่มข้อความในเซลล์ได้โดยไม่ต้องอัปโหลดสมุดงานก่อน ช่วยประหยัดพื้นที่จัดเก็บและลดต้นทุน
