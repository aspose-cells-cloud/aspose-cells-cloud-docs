## API สำหรับการจัดการข้อความใน Excel

Aspose.Cells Cloud มีชุดของ endpoint แบบ REST ที่ช่วยให้คุณสามารถจัดการข้อความภายในแผ่นงาน Excel ได้ ปฏิบัติการเหล่านี้ครอบคลุมงานทั่วไปเช่น การตัดช่องว่าง การแบ่งสตริง การแปลงรูปแบบตัวพิมพ์ใหญ่-เล็ก การดึงข้อความย่อย และการลบอักขระที่ไม่ต้องการ  

**ข้อกำหนดเบื้องต้น:** คำขอทั้งหมดต้องได้รับการยืนยันตัวตนด้วยโทเค็นการเข้าถึงที่ถูกต้องซึ่งส่งผ่านใน header `Authorization` โปรดดูคู่มือการยืนยันตัวตนสำหรับรายละเอียดเกี่ยวกับการรับและใช้งานโทเค็น
