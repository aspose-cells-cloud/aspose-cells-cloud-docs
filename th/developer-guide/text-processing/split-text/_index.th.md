แบ่งข้อความในเซลล์ Excel ออกเป็นหลายคอลัมน์ตามกฎการแบ่งที่กำหนดเอง โดยใช้ Web API การแบ่งข้อความของ Aspose.Cells Cloud เพื่อแยกเนื้อหาตาม delimiter และส่งผลลัพธ์ไปยังช่วงเป้าหมายที่ระบุ

## **บทนำ**: แบ่งข้อความ

API การแบ่งข้อความ (Text Segmentation API) แบ่งเนื้อหาเซลล์ออกเป็นหลายเซลล์ตาม delimiter, รูปแบบ หรือ line breaks ที่ระบุ และส่งผลลัพธ์ไปยังช่วงเป้าหมาย รองรับวิธีการแบ่งแบบยืดหยุ่น การส่งออกผลลัพธ์ไปยังทิศทางที่กำหนด (คอลัมน์หรือแถว) และตัวเลือกในการเก็บ delimiter ไว้ด้วย—เหมาะสำหรับการแยกข้อมูลที่เชื่อมกัน, เนื้อหาแบบ CSV หรือข้อความหลายบรรทัดให้อยู่ในรูปแบบที่มีโครงสร้าง

- **แบ่งเซลล์ตามอักขระที่กำหนด** – แยกเนื้อหาเซลล์ออกเป็นหลายเซลล์โดยเลือกอักขระใดก็ได้เป็น delimiter (เช่น จุลภาค, ช่องว่าง, อัฒภาค ฯลฯ)
- **แบ่งเซลล์ตามสตริง** – แยกเซลล์ตามชุดของอักขระที่คุณกำหนด
- **แบ่งข้อความตาม mask** – ใช้ wildcard เพื่อแบ่งข้อความตามรูปแบบที่กำหนด ซึ่งให้วิธีการแบ่งข้อความที่ยืดหยุ่นและมีประสิทธิภาพมากยิ่งขึ้น
- **แบ่งเนื้อหาเซลล์ตาม line break** – จัดระเบียบการแสดงผลโดยการแบ่งตาม line break
- **แบ่งเซลล์เป็นคอลัมน์หรือแถว** – เลือกว่าผลลัพธ์ที่ได้จะถูกเขียนลงในคอลัมน์หรือแถวตามลำดับ
- **ลบหรือเก็บ delimiter ไว้** – กำหนดว่า delimiter จะถูกลบออกหรือเก็บไว้ที่ต้นหรือท้ายของเซลล์ที่แบ่งแล้ว

## **SplitText API**

**ข้อกำหนดเบื้องต้น**: เพื่อใช้ API นี้ คุณจำเป็นต้องมี access token ที่ถูกต้องของ Aspose Cloud และไฟล์สมุดค่าที่ต้องประมวลผลต้องถูกอัปโหลดลงสู่พื้นที่เก็บข้อมูลบนคลาวด์ของ Aspose Cloud หรือส่งมาโดยตรงในคำขอ API รองรับรูปแบบไฟล์สเปรดชีตที่นิยม เช่น XLSX, XLS, ODS และ CSV

### Web API

```http
POST https://api.aspose.cloud/v4.0/cells/content/split/text
```

### **ความปลอดภัยและการพิสูจน์ตัวตน**

Aspose.Cells Cloud APIs มีความปลอดภัยและต้องใช้ <a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">การพิสูจน์ตัวตนด้วย JWT token</a>

```bash
-H "Authorization: Bearer {access_token}"
```

### โค้ดข้อผิดพลาด

- **400 Bad Request** – URI ของ Aspose.Cells Cloud API ไม่ถูกต้องหรือพารามิเตอร์ที่ส่งมามีรูปแบบไม่ถูกต้อง
- **401 Unauthorized** – ไม่มีหรือ access token (หรือ client-id/secret) ไม่ถูกต้อง
- **404 Not Found** – ไม่สามารถเข้าถึงไฟล์สเปรดชีตที่ระบุได้
- **500 Server Error** – เกิดข้อผิดพลาดภายในระหว่างการประมวลผลสเปรดชีต

## ควรใช้ Split Text API ในกรณีใด?

### **การปรับข้อมูลที่นำเข้าจาก CSV และไฟล์ข้อความ**

เมื่อนำเข้าข้อมูลจากระบบภายนอก ฟิลด์ต่างๆ มักถูกรวมไว้ในเซลล์เดียว:

- **การนำเข้าข้อมูลจาก ERP/CRM** – แยก `"John Doe;johndoe@email.com;555-1234"` เป็นคอลัมน์แยกกันสำหรับชื่อ, อีเมล และเบอร์โทรศัพท์
- **การส่งออกข้อมูลจากฐานข้อมูล** – แยกคีย์ที่รวมกันเช่น `"ORD-2024-001|Premium|Express"` เป็น ID คำสั่งซื้อ, ระดับ และวิธีการจัดส่ง
- **การวิเคราะห์ไฟล์ล็อก** – แยกข้อมูลล็อกที่มีโครงสร้างคร่าวๆ เช่น `"2024-01-15 10:30:00|ERROR|ConnectionTimeout"` เพื่อกรองข้อมูล

### **การย้ายระบบเก่า**

- ระบบเก่ามักบันทึกฟิลด์ที่มีค่าหลายค่าไว้ในเซลล์เดียว; ให้แบ่งออกเพื่อให้สอดคล้องกับโครงสร้างฐานข้อมูลใหม่
- แปลงไฟล์ส่งออกแบบ flat-file ให้เป็นตาราง Excel ที่เป็นมาตรฐานและพร้อมใช้งานกับ Power BI หรือ Tableau

### **การปรับปรุงและทำให้ข้อมูลเป็นมาตรฐาน**

- **ทำให้ delimiter เป็นมาตรฐาน** – แปลง delimiter ที่ผสมกัน (`"A,B;C|D"`) ให้เป็นรูปแบบเดียวกันโดยใช้การแบ่งด้วย delimiter หลายตัว
- **ทำความสะอาดช่องว่าง** – แบ่งด้วยช่องว่างเพื่อระบุและลบช่องว่างเกินระหว่างคำ
- **ข้อมูลทางการเงิน** – แยกโค้ดธุรกรรมที่รวมกัน เช่น `"DEP-CHK-3847"` เป็นประเภทธุรกรรม, แหล่งที่มา และเลขที่อ้างอิง
- **บันทึกทางการแพทย์** – แยกข้อมูลผู้ป่วยเช่น `"Smith,Jane_F_1985"` เป็นนามสกุล, ชื่อ, เพศ และปีเกิด

## ทำไมควรใช้ Split Text API?

- **อักขระเฉพาะ** – แบ่งตามอักขระเดี่ยวใดก็ได้ (จุลภาค, อัฒภาค, แท็บ, ช่องว่าง)
- **ชุดของสตริง** – ใช้ delimiter หลายตัวอักขระ เช่น `||`, `->` หรือ separator แบบกำหนดเอง
- **Line Breaks** – แยกเซลล์หลายบรรทัดออกเป็นแถวต่างหากทันที (ที่อยู่, ความคิดเห็น, คำอธิบาย)
- **Delimiter แบบกำหนดเอง** – กำหนดชุดของอักขระใดก็ได้เป็น delimiter สำหรับรูปแบบข้อมูลเฉพาะ
- **เป็นมิตรกับนักพัฒนา** – Aspose.Cells Cloud มี SDK ให้เลือกใช้ในหลายภาษา ช่วยให้พัฒนาแอปพลิเคชันได้อย่างรวดเร็ว และมีเอกสารประกอบอย่างครบถ้วน เมื่อเทียบกับการสร้างโซลูชันแบบกำหนดเอง วิธีนี้ช่วยลดภาระงานในการพัฒนาอย่างมาก
- **คุ้มค่า** – คุณสามารถลบอักขระที่ซ้ำกันออกได้โดยไม่ต้องอัปโหลดสมุดค่าก่อน ซึ่งช่วยประหยัดพื้นที่จัดเก็บและลดค่าใช้จ่าย
