Aspose.Cells Cloud มี REST API แบบไม่ขึ้นกับแพลตฟอร์มที่แท้จริงสำหรับการจัดการเอกสาร โดยทำงานร่วมกับภาษาใดก็ได้ที่สามารถส่งคำขอ HTTP เช่น Go, Java, .NET, Node.js, Perl, PHP, Python, Ruby และอื่นๆ อีกมากมาย เนื่องจากบริการนี้เข้าถึงผ่านคำขอ REST มาตรฐาน จึงไม่มีข้อจำกัดด้านภาษาหรือแพลตฟอร์ม คุณสามารถเรียกใช้ API ได้จากสภาพแวดล้อมต่างๆ เช่น เว็บ เดสก์ท็อป มือถือ หรือคลาวด์ API ยังสามารถบูรณาการกับบริการคลาวด์อื่นๆ ให้ความยืดหยุ่นที่จำเป็นสำหรับการประมวลผลรูปแบบเอกสารต่างๆ เช่น Excel, PDF, CSV, JSON และอื่นๆ ในทุกสถานการณ์ทางธุรกิจ

บริการนี้รองรับเวอร์ชันล่าสุดของวินโดวส์ ดิสทริบิวชันลินุกซ์ยอดนิยม (Ubuntu, CentOS, Debian) และแมกโอเอสดีเอ็กซ์ SDK มีให้สำหรับ .NET, Java, Python, PHP, Ruby, Go และ Node.js โดยแต่ละ SDK มาพร้อมกับตัวอย่างโค้ดแบบครบถ้วน พร้อมกันนี้ยังมีภาพ Docker ให้บริการเพื่อให้การปรับใช้ในสภาพแวดล้อมแบบคอนเทนเนอร์ทำได้ง่ายขึ้น ช่วยให้คุณสามารถเรียกใช้ API ได้ในเครื่องหรือบนคลาวด์โดยมีการตั้งค่าน้อยที่สุด
