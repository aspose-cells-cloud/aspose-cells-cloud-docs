## การสนับสนุนด้านเทคนิคของ Aspose.Cells Cloud

Aspose มีการให้การสนับสนุนด้านเทคนิคฟรีโดยไม่จำกัดจำนวนครั้งสำหรับผลิตภัณฑ์ทั้งหมดของบริษัทฯ การสนับสนุนนี้พร้อมให้บริการกับผู้ใช้ทุกคน รวมถึงผู้ที่กำลังทดสอบใช้งานบริการ

หากคุณต้องการความช่วยเหลือเกี่ยวกับ Aspose.Cells Cloud คุณสามารถใช้แหล่งข้อมูลต่อไปนี้:

- ช่องทางการสนับสนุนหลักคือ [ฟอรัมของ Aspose Cloud](https://forum.aspose.cloud/) โปรดโพสต์คำถามของคุณลงใน [ฟอรัม Aspose Cells Cloud](https://forum.aspose.cloud/c/cells) ซึ่งทีมพัฒนา Aspose.Cells Cloud จะตอบกลับภายในไม่กี่ชั่วโมง  
- กรุณาสังเกตว่า การสนับสนุนทางโทรศัพท์นั้นมีข้อจำกัดเฉพาะเรื่องการขายและการสั่งซื้อเท่านั้น ปัญหาด้านเทคนิคต้องดำเนินการผ่านฟอรัมเท่านั้น  
- ในระหว่างที่รอคำตอบจากฟอรัม โปรดพิจารณาความต่างของเขตเวลาด้วย
