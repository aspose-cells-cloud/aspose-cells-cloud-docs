# การเผยแพร่ที่สำคัญที่สุด

- **เวอร์ชันล่าสุดของ Aspose.Cells Cloud 4.0 พร้อมใช้งานแล้ว การเผยแพร่ครั้งนี้ได้รับการปรับปรุงใหม่ให้กระชับและมีประสิทธิภาพมากขึ้น เพื่อมั่นใจในประสบการณ์ที่มั่นคงและเชื่อถือได้**
- **SDK ล่าสุดรวมรวม API ทั้งหมดจาก Aspose.Cells Cloud 3.0 และ 4.0 เข้าด้วยกัน ช่วยทำให้กระบวนการพัฒนาเป็นไปอย่างเรียบง่าย ใช้งานได้จริงและสะดวกยิ่งขึ้น**

# การเผยแพร่ล่าสุด

ตารางด้านล่างนี้สรุปหัวข้อสำคัญของการเผยแพร่ล่าสุดของ Aspose.Cells Cloud อย่างกระชับ

| **ID** | **สรุป**                                                     | **ประเภท**     |

| 60912 | ใช้งาน Web API สำหรับยกเลิกการจัดกลุ่มข้อมูล (data unpivot) ใน Aspose Cells Cloud | ฟีเจอร์ใหม่ |
