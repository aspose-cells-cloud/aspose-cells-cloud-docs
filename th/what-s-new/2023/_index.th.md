ยินดีต้อนรับสู่เอกสารของ Aspose.Cells Cloud สำหรับข้อมูลใหม่ๆ ในปีนี้ หน้านี้เน้น **ฟีเจอร์ใหม่ของ Aspose.Cells Cloud ปี 2023** และช่วยให้คุณค้นหาการเปลี่ยนแปลงล่าสุดได้อย่างรวดเร็ว

**อัปเดตล่าสุด:** กรกฎาคม 2026  

## การปรับปรุงในเวอร์ชัน 23.12.0

- เพิ่มพารามิเตอร์ region ให้กับ Conversion API  
- เพิ่มพารามิเตอร์ region ให้กับ Protection API  
- เพิ่มพารามิเตอร์ region ให้กับ Assemble Data API  
- เพิ่มพารามิเตอร์ region ให้กับ Merge Files API  
- เพิ่มพารามิเตอร์ region ให้กับ Split Files API  
- เพิ่มพารามิเตอร์ region ให้กับ Import Data API  
- เพิ่มพารามิเตอร์ region ให้กับ Watermark API  
- เพิ่มพารามิเตอร์ region ให้กับ Clear Object API  
- เพิ่มพารามิเตอร์ region ให้กับ Reverse Data API  
- เพิ่มพารามิเตอร์ region ให้กับ Rotate Data API  

## การปรับปรุงในเวอร์ชัน 23.11

- ปรับปรุงการนำเข้าข้อมูล XML ลงในไฟล์ Excel  
- ปรับปรุงการนำเข้าข้อมูล JSON ลงในไฟล์ Excel  
- ลบฟังก์ชัน คลาส และเทสเคสที่เลิกใช้งานแล้ว  

## การปรับปรุงในเวอร์ชัน 23.10

- แก้ไขคำร้องขอการป้องกันสมุดงาน  
- แก้ไข Range Copy API  
- ปรับปรุง Workbook Protect API  

## การปรับปรุงในเวอร์ชัน 23.9

- เพิ่มการรองรับการจัดเรียงข้อมูลบน Range Controller  
- เพิ่มการลบข้อมูลที่ซ้ำกันสำหรับ List Objects  
- เพิ่มการแทรก Slicer สำหรับ List Objects  
- ปรับปรุง List Object และคอมโพเนนต์ที่เกี่ยวข้อง  

## การปรับปรุงในเวอร์ชัน 23.8

- เพิ่มการรองรับ Lock API  
- ปรับปรุง Protect API  

## Aspose.Cells Cloud 23.7

- เพิ่มการรองรับการซ่อมแซมไฟล์  
- ปรับปรุงฟังก์ชันการแปลง  

## Aspose.Cells Cloud 23.6

- เพิ่มการล็อกแบบแบทช์สำหรับหลายไฟล์  
- เพิ่มการยกเลิกการล็อกแบบแบทช์สำหรับหลายไฟล์  
- เพิ่มการป้องกันแบบแบทช์สำหรับหลายไฟล์  
- เพิ่มการแยกไฟล์แบบแบทช์สำหรับหลายไฟล์  
- แก้ไข PUT Document Property API  

## Aspose.Cells Cloud 23.5

- แก้ไขชื่อเมธอดที่สะกดผิด  

## Aspose.Cells Cloud 23.4

- เพิ่มการรองรับการนำเข้าและส่งออกข้อมูล XML  

## Aspose.Cells Cloud 23.3

- ปรับปรุงคุณสมบัติของ Hyperlink  

## Aspose.Cells Cloud 23.2

- ปรับปรุง Replace API  
- ปรับปรุง Swagger UI  

## Aspose.Cells Cloud 23.1

- แก้ไขบั๊กในเมธอด PostCellCharacters  

สำหรับข้อมูลเพิ่มเติมโดยละเอียด โปรดดูบันทึกการเผยแพร่แบบเต็มของแต่ละเวอร์ชัน หรือเยี่ยมชมเอกสารอ้างอิงของ Aspose.Cells Cloud API
