ยินดีต้อนรับสู่เอกสาร "มีอะไรใหม่ใน Aspose.Cells Cloud" ใช้หน้านี้เพื่อค้นหาการเปลี่ยนแปลงล่าสุดได้อย่างรวดเร็ว บันทึกการเปลี่ยนแปลงนี้สรุปการปรับปรุงหลัก การแก้ไขข้อผิดพลาด และ APIs ใหม่ที่เพิ่มเข้ามาในแต่ละเวอร์ชันของ Aspose.Cells Cloud ตลอดปี 2024

## การปรับปรุงในเวอร์ชัน 24.12

- เพิ่ม **Remove Duplicates API** ใหม่  
- เพิ่ม **Extract Text API** ใหม่  
- แก้ไขข้อผิดพลาดที่อาจทำให้การสร้าง pivot filter ล้มเหลว

## การปรับปรุงในเวอร์ชัน 24.11

- เพิ่มฟีเจอร์การแปลงข้อความให้กับ `TextProcessingController`

## การปรับปรุงในเวอร์ชัน 24.10

- เพิ่มฟีเจอร์การลบอักขระให้กับ `TextProcessingController`

## การปรับปรุงในเวอร์ชัน 24.9

- เพิ่มฟังก์ชันการเปลี่ยนรูปแบบตัวพิมพ์ใหญ่-เล็กของคำให้กับ `TextProcessingController`  
- รองรับการส่งออกworksheetเป็น HTML พร้อมทั้งที่อยู่หรือ ID ของเซลล์

## การปรับปรุงในเวอร์ชัน 24.8

- เพิ่มฟีเจอร์การตัดช่องว่างของข้อความให้กับ Cells Cloud Services

## การปรับปรุงในเวอร์ชัน 24.7

- แนะนำ **AddTextContent API** สำหรับแทรกข้อความที่กำหนดเองลงใน worksheet  
- เพิ่มความสามารถในการรับ access token โดยใช้ client ID และ client secret

## การปรับปรุงในเวอร์ชัน 24.6.1

- แก้ไขพารามิเตอร์คิวรีขั้นสูงสำหรับ APIs

## การปรับปรุงในเวอร์ชัน 24.6.0

- ปรับปรุงขั้นตอนการแปลงข้อมูล  
- ปรับปรุงฟังก์ชันการโหลดข้อมูลสำหรับการแปลงข้อมูล  
- เพิ่มการรองรับ .NET Framework 4.2.5 และ .NET Standard 2.0

## การปรับปรุงในเวอร์ชัน 24.5.1

- เพิ่มเมธอด merge-queries สำหรับการโหลดข้อมูลในการแปลงข้อมูล  
- ปรับปรุงข้อมูลโมเดลของกราฟ  
- อัปเดต endpoint สำหรับ access-token

## การปรับปรุงในเวอร์ชัน 24.4

- รองรับฟังก์ชันการแปลงข้อมูลสำหรับ Aspose.Cells Cloud Services

## การปรับปรุงในเวอร์ชัน 24.3

- รองรับการลดจำนวนข้อมูลที่ซ้ำกัน (ปรับปรุงแล้ว)  
- รองรับการเติมข้อมูล  
- รองรับการลบแถวที่ไม่สมบูรณ์  
- รองรับการ Cleansing ข้อมูล

## การปรับปรุงในเวอร์ชัน 24.2.1

- รองรับการลดจำนวนข้อมูลที่ซ้ำกัน (รองรับครั้งแรก ต่อมาขยายการรองรับในเวอร์ชันที่ตามมา)

## การปรับปรุงในเวอร์ชัน 24.1.1

- แก้ไขคำผิดของฟังก์ชันหลายตัว  
- เพิ่มเมธอด `PostFitTallToPages` ใน PageSetupController  
- เพิ่มเมธอด `PostFitWideToPages` ใน PageSetupController  
- ปรับปรุงตัวเลือกการบันทึกแบบแบ่งหน้า
