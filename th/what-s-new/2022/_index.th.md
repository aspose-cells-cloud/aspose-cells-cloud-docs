ยินดีต้อนรับสู่เอกสาร "มีอะไรใหม่ใน Aspose.Cells Cloud" ใช้หน้านี้เพื่อค้นหาการเปลี่ยนแปลงล่าสุดได้อย่างรวดเร็ว

## Aspose.Cells Cloud 22.12

- รองรับการดำเนินการแกนของแผนภูมิ

## Aspose.Cells Cloud 22.11

- เพิ่ม API ใหม่สำหรับการแปลงเป็น JSON
- เพิ่ม API ใหม่สำหรับการแปลงเป็น SQL
- เพิ่ม API ใหม่สำหรับการแปลงเป็น CSV

## Aspose.Cells Cloud 22.10

- เพิ่ม API ใหม่สำหรับการแปลงเป็น PPTX
- เพิ่ม API ใหม่สำหรับการแปลงเป็น Markdown
- เพิ่ม API ใหม่สำหรับการแปลงเป็น HTML

## Aspose.Cells Cloud 22.9

- รองรับการส่งออกหน้าไปยังไฟล์ในรูปแบบอื่น
- เพิ่ม API ใหม่สำหรับการแปลงเป็น PDF
- เพิ่ม API ใหม่สำหรับการแปลงเป็น PNG
- เพิ่ม API ใหม่สำหรับการแปลงเป็น DOCX

## Aspose.Cells Cloud 22.8

- รองรับการสลับแถวและคอลัมน์ของ Excel (Transpose)

## Aspose.Cells Cloud 22.7

- การปรับปรุง API การบันทึกในบริการ Cells Cloud (เพิ่มตัวเลือกการบันทึกสี่แบบ)
- การปรับปรุง LightCellsController ใน Cells Cloud
