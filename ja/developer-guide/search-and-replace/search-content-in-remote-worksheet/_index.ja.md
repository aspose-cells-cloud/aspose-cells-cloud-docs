## **リモートワークシート内のコンテンツを検索**

Aspose.Cells Cloud API を使用して、任意の Excel ワークシート内で特定のテキストをプログラムで検索します。このサービスは、クラウドストレージに保存されたリモートファイル内にあるテキスト、数値、または数式を検出でき、自動化されたデータ発見、コンテンツ分析、スプレッドシート監査ワークフローを可能にします。

### **Web API**

```curl
PUT https://api.aspose.cloud/v4.0/cells/{name}/worksheets/{worksheet}/search/content
```

### **セキュリティと認証**

Aspose.Cells Cloud API は安全であり、<a href="https://docs.aspose.cloud/total/getting-started/rest-api-overview/authenticating-api-requests/" rel="noopener noreferrer">JWT トークンベースの認証</a>が必要です。

```bash
-H "Authorization: Bearer {access_token}"
```

### **リクエストパラメータ**

| パラメータ名 | 型      | パス / クエリ文字列 / HTTP ボディ | 説明                                                                                     |
| ------------ | ------- | ------------------------------- | ---------------------------------------------------------------------------------------- |
| name         | 文字列  | パス                            | **必須。** 検索対象のワークブックのファイル名（例：`annual_report.xlsx`）。              |
| worksheet    | 文字列  | パス                            | **必須。** 検索を実行するワークブック内のワークシート名。                                |
| searchText   | 文字列  | クエリ                          | **必須。** 検索する正確なテキスト文字列または数値。                                      |
| ignoreCase   | 真偽値  | クエリ                          | **任意。** `true` の場合、大文字・小文字を区別せずに検索します。デフォルトは `false` です。 |
| folder       | 文字列  | クエリ                          | **任意。** ワークブックが格納されているフォルダのパス。省略した場合、ルートフォルダが使用されます。 |
| storageName  | 文字列  | クエリ                          | **任意。** カスタム設定されたクラウドストレージの名前。省略した場合、デフォルトストレージが使用されます。 |
| region       | 文字列  | クエリ                          | **任意。** ロケール設定（例：`ja-JP`）。テキスト比較に影響を与える可能性があります。       |
| password     | 文字列  | クエリ                          | **任意。** 保護されたワークブックのパスワード。ファイルが暗号化されていない場合は省略してください。 |

### **レスポンス**

```json
{
  "textItems": [
    {
      "cellName": "A1",
      "text": "Total",
      "occurrences": 1
    },
    {
      "cellName": "B5",
      "text": "Total",
      "occurrences": 2
    }
  ],
  "code": 200,
  "status": "OK"
}
```

- **textItems** – 一致した項目の配列。各項目にはセルアドレス（`cellName`）、一致した文字列（`text`）、およびそのセル内での出現回数（`occurrences`）が含まれます。
- **code** – サービスが返す HTTP ステータスコード。
- **status** – 結果のテキストによる説明。

### **エラーコード**

- **400 Bad Request（不良なリクエスト）** – 無効な API URI、または不正な形式のパラメータ。
- **401 Unauthorized（未承認）** – OAuth 2.0 トークンが欠落している、または無効です。
- **404 Not Found（見つかりません）** – ワークブックまたはワークシートが見つかりません。
- **500 Server Error（サーバーエラー）** – リクエストの処理中に予期しない状況が発生しました。

## スプレッドシート API のワークシート内でコンテンツを検索する用途は？

- **ワークブックのコンプライアンス監査：** 「機密」などのセンシティブな用語をファイル全体から迅速に検出します。
- **シート間データの関連付け：** 複数のシートに登場するプロジェクト番号や顧客名を検索します。
- **テンプレート検証：** レポート生成後、`{{Date}}` などのプレースホルダが正しく置換されたことを確認します。
- **履歴データのマイニング：** 古いスプレッドシート内に特定のイベントコードを検索し、過去のビジネスロジックを理解します。

## なぜスプレッドシート API のワークシート内でコンテンツを検索する必要がありますか？

- **開発者向け：** 多数の言語向けの SDK が提供されており、開発を迅速化し、完全なドキュメントが整っています。
- **人件費の削減：** 手動でのデータ集約作業に専任のスタッフを配置する必要が減ります。
- **ペイ・パー・ユース：** 実際に実行した API コールのみに課金されます。
- **メンテナンス不要：** サーバー管理やソフトウェア更新、互換性の懸念が一切ありません。
- **複雑な Excel 書式を保持：** 結果を PDF またはその他の形式にエクスポートする際に、複雑な Excel 書式を保持します。
