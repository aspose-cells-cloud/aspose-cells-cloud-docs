## Excel テキスト操作 API

Aspose.Cells Cloud は、Excel ワークシート内のテキストを操作できる一連の REST エンドポイントを提供します。これらの操作には、空白文字のトリム、文字列の分割、大文字・小文字の変換、部分文字列の抽出、不要な文字の削除など、日常的なタスクが含まれます。

**前提条件:** すべてのリクエストは、`Authorization` ヘッダーに有効なアクセス トークンを指定することで認証される必要があります。トークンの取得方法と使用方法の詳細については、認証ガイドを参照してください。
