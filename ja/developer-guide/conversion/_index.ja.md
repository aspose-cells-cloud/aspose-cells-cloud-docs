## スプレッドシート変換ツールキット

Aspose.Cells Cloud API を使用して、多様な形式へのスプレッドシート変換を簡単に実現できます。ワークシート、テーブル、チャート、データ範囲を PDF、画像、CSV、JSON など多様な形式でエクスポート可能。クラウドベースで処理されるためインストール不要。REST API と SDK をサポートしています。

### 範囲の変換

- **[スプレッドシートの範囲を CSV ファイルに変換する。](https://docs.aspose.cloud/cells/convert-range-to-csv/)**
- **[スプレッドシートの範囲を HTML ファイルに変換する。](https://docs.aspose.cloud/cells/convert-range-to-html/)**
- **[スプレッドシートの範囲を JSON ファイルに変換する。](https://docs.aspose.cloud/cells/convert-range-to-json/)**
- **[スプレッドシートの範囲を PDF ファイルに変換する。](https://docs.aspose.cloud/cells/convert-range-to-pdf/)**
- **[スプレッドシートの範囲を他の形式のファイルとしてエクスポートする。](https://docs.aspose.cloud/cells/export-range-as-format/)**
- **[スプレッドシート全体を他の形式のファイルとしてエクスポートする。](https://docs.aspose.cloud/cells/export-spreadsheet-as-format/)**
- **[スプレッドシートの範囲を画像としてエクスポートする。](https://docs.aspose.cloud/cells/convert-range-to-image/)**
