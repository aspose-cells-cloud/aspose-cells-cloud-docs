Excel のハイパーリンクを使用すると、ワークシート、ファイル、フォルダー、またはウェブページへのショートカットを作成でき、特定の場所へ素早く移動できます。

**前提条件:** 有効な API トークン（[認証ガイド](/ja/authentication/)を参照）および Cells.Cloud SDK のインストールが必要です。

## Excel ファイルにおけるハイパーリンクの操作

- [Excelワークシートからハイパーリンクの説明を取得する方法](/ja/cells/hyperlinks/get/) – アドレスや表示テキストなど、単一のハイパーリンクの詳細情報を取得します。  
- [Excelワークシートのすべてのハイパーリンクの説明を取得する方法](/ja/cells/hyperlinks/get-all/) – ワークシート内に定義されたすべてのハイパーリンクを、それぞれのプロパティとともに一覧表示します。  
- [Excelワークシートにハイパーリンクを追加する方法](/ja/cells/hyperlinks/add/) – 対象のURLとセル範囲を指定して、ワークシートに新しいハイパーリンクを挿入します。  
- [Excelワークシートのハイパーリンクを更新する方法](/ja/cells/hyperlinks/update/) – 既存のハイパーリンクのアドレス、表示テキスト、またはターゲットセルを変更します。  
- [Excelワークシートからすべてのハイパーリンクを削除する方法](/ja/cells/hyperlinks/clear/) – 単一の操作でワークシート内のすべてのハイパーリンクを削除します。  
- [Excelワークシートからハイパーリンクを削除する方法](/ja/cells/hyperlinks/delete/) – インデックスまたはセル参照で特定された特定のハイパーリンクを削除します。
