## Excel ファイル上の図形の操作

図形とは、Excel ワークシート上に配置できる直線、矩形、テキストボックス、画像などの描画オブジェクトを指します。図形はデータの可視化、注釈の追加、スプレッドシート内でのインタラクティブ要素の作成に役立ちます。このページでは、最も一般的な図形関連操作へのクイックリンクを、それぞれ簡潔な説明とともにご案内します。

**前提条件:** 図形操作を使用するには、有効な Aspose.Cells Cloud API キーと、クラウドにアップロード済みのワークブックが必要です。

- [Excel ワークシート上のすべての図形を取得する方法](/cells/shapes/get-all/) – ワークシート内に存在するすべての図形を完全なコレクションとして取得します。
- [Excel ワークシート上のインデックスで図形を取得する方法](/cells/shapes/get/) – 指定されたインデックス位置にある図形を返します。
- [Excel ワークシートに図形を追加する方法](/cells/shapes/add/) – 新しい図形（矩形、直線、画像など）をワークシートに挿入します。
- [Excel ワークシート上のすべての図形を削除する方法](/cells/shapes/clear/) – 1 回の操作でワークシート上のすべての図形を削除します。
- [Excel ワークシート上のインデックスで図形を削除する方法](/cells/shapes/delete/) – 指定されたインデックス位置の図形を削除します。
- [Excel ワークシート上の図形を画像に変換する方法](/cells/shapes/conversion/) – 選択した図形を外部で使用可能な画像ファイル（PNG、JPEG など）に変換します。
