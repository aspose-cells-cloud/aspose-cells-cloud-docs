**前提条件**  
エンドポイントを呼び出す前に、適切な権限を持つアクティブな Aspose Cloud アクセストークンと API バージョン（`v3.0`）を取得しておく必要があります。

### Aspose.Cells Cloud REST API で用紙サイズを設定する方法

```bash
curl -X PUT "https://api.aspose.cloud/v3.0/cells/Workbook/worksheets/Sheet1/pageSetup" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{"PaperSize":"PaperA4"}'
```

**リクエスト詳細**  
- **メソッド:** `PUT`  
- **エンドポイント:** `/cells/Workbook/worksheets/{sheetName}/pageSetup`  
- **パスパラメータ:** `sheetName` – ワークシート名（文字列、必須）  
- **リクエストボディ:** `PaperSize` プロパティを含む JSON オブジェクト。値は上記の表にある定数のいずれか（例: `"PaperA4"`）である必要があります。

**レスポンス**  
- `200 OK` – ページ設定が正常に更新されました。  
- `400 Bad Request` – 無効な `PaperSize` 値です。  
- `401 Unauthorized` – 認証に失敗したか、トークンがありません。  
- `404 Not Found` – 指定されたワークシートが存在しません。

**SDK の例（C#）**  
```csharp
var api = new CellsApi("client_id", "client_secret");
var request = new PageSetup { PaperSize = PaperSizeEnum.PaperA4 };
api.PutWorksheetPageSetup("Book1.xlsx", "Sheet1", request);
```

完全な OpenAPI 定義については、<a href="https://api.aspose.cloud/v3.0/swagger.json" target="_blank" rel="noopener">Aspose.Cells Cloud Swagger 仕様</a> を参照してください。

マージン、向き、その他のレイアウトオプションの設定については、[ページ設定のドキュメント](/page-setup/) も併せてご覧ください。
