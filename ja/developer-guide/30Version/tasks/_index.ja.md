## タスクの操作

Aspose.Cells Cloud は、**タスク API** を提供しており、開発者が Excel ワークブックに対して、フォーマット変換、データのインポート、SmartMarker テンプレートの実行、結果の保存など、多様な操作を実行できるようになります。タスクは非同期で実行されます：タスクを作成し、実行し、その結果を取得します。

**前提条件：** 有効な API キーを持つ Aspose Cloud アカウント、サポートされる Excel ファイル形式、および最新バージョンの Cells API（v3.0 以降）。

- [タスク API でのサポート対象ファイルのリクエスト](/ja/cells/support-request-file-in-task-api/) – クラウドストレージにファイルをアップロードし、後続のタスクでそのファイルを参照できるように設定し、処理用にファイルを確実に利用可能にします。
- [CellsObjectOperate タスクの操作](/ja/cells/working-with-cellsobjectoperate-task/) – ワークブック内のセルオブジェクト（例：行、列）に対して、セル値の追加・削除・更新などの操作を実行します。
- [変換タスクの操作](/ja/cells/working-with-convert-task/) – ワークブックを PDF、HTML、CSV、または JSON 形式に変換します。ページ範囲、パスワード保護、カスタム変換設定などのオプションが利用可能です。
- [ImportData タスクの操作](/ja/cells/working-with-importdata-task/) – CSV、JSON、または XML ファイルからワークシートへデータをインポートし、列をセルにマッピングします。また、オプションとして開始行と開始列を指定できます。
- [SaveResult タスクの操作](/ja/cells/working-with-saveresult-task/) – 実行済みタスク（例：変換されたファイル）の結果を、クラウドストレージへ再保存するか、レスポンスとして返却します。
- [SmartMarker タスクの操作](/ja/cells/working-with-smartmarker-task/) – JSON データソースを使用して、SmartMarker タグ（例：`{{Customer.Name}}`）を含むワークブックを処理し、データが埋め込まれたレポートを生成します。
- [タスク API でのワークシート操作](/ja/cells/working-with-worksheetoperates-in-task-api/) – タスクワークフローの一部として、ワークシートの追加・削除・名前変更などのワークシートレベルの操作を実行します。

HTTP メソッド、エンドポイント URL、リクエスト/レスポンススキーマ、パラメータテーブル、およびペイロードの例を含む完全なメソッド仕様については、上記の各タスクページを参照してください。この詳細な API リファレンスにより、開発者はタスク API を迅速かつ確実に統合できます。
