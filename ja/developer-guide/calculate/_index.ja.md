Aspose.Cells Cloud REST API を使用して、Excel ワークシート上で **SUM**、**COUNT**、**AVERAGE**、**MIN**、**MAX** などの計算を自動的に実行します。手動でのフィルタリングやローカルのスプレッドシートソフトウェアは不要です。この API は **Aspose.Cells Cloud** でサポートされており、標準的な認証（OAuth 2.0 または JWT）を使用し、結果を JSON 形式で返し、無効な範囲や認証に関する問題に対して明確なエラーコードを提供します。詳細なリクエスト構文については、公式の REST API リファレンスをご参照ください。

- **[セルの色別に計算](https://docs.aspose.cloud/cells/aggregate-cells-by-color/)** – 背景色またはフォント色ごとに集計された合計を、1回のリクエストで取得します。
- **[スプレッドシート クイック計算](https://docs.aspose.cloud/cells/math-calculate/)** – 任意の範囲に対して SUM、COUNT、AVERAGE、MIN、MAX（および基本的な算術演算）を即座に計算します。
