プロフェッショナルなスプレッドシート管理のための堅牢な Excel データ操作 API。これらの API は、空の列、行、ワークシートを自動的に削除し、範囲間のデータをシームレスに入れ替えます。Excel をインストールせずに、分析・レポート・統合のためのスプレッドシートを準備できます。

## Excel データのクリーンアップおよび最適化 API

**前提条件** – いずれの変換 API を呼び出す前に、有効な認証トークンを取得し、ワークブックが対応する場所（例：Aspose Cloud ストレージまたはパブリック URL）に保存されていることを確認してください。トークンは、各リクエストの `Authorization` ヘッダーに含めて送信する必要があります。

### 空白コンテンツのクリーンアップ

- **[空の列を削除](https://docs.aspose.cloud/cells/delete-spreadsheet-blank-columns/)** – データ、数式、オブジェクトのいずれも含まない列を自動的に特定して削除します。  
- **[空の行を削除](https://docs.aspose.cloud/cells/delete-spreadsheet-blank-rows/)** – ワークシートの構造を保持したまま、すべての空行を削除します。  
- **[空のワークシートを削除](https://docs.aspose.cloud/cells/delete-spreadsheet-blank-worksheets/)** – 空のワークシートを削除して、ファイルサイズを削減し、整理を改善します。

### データ操作と再構成

- **[範囲のデータを入れ替え](https://docs.aspose.cloud/cells/swap-range/)** – Excel ファイル内の任意の2つの範囲、列、行、または個別のセル間でデータを入れ替えます。
