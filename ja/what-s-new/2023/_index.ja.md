Aspose.Cells Cloud のドキュメントへようこそ。このページでは、**Aspose.Cells Cloud 2023 年の新機能**を紹介し、最新の変更を素早く確認できるようにしています。

**最終更新日：** 2026 年 7 月  

## バージョン 23.12.0 の機能強化

- 変換 API に地域パラメーターを追加しました。  
- 保護 API に地域パラメーターを追加しました。  
- データ集約 API に地域パラメーターを追加しました。  
- ファイル結合 API に地域パラメーターを追加しました。  
- ファイル分割 API に地域パラメーターを追加しました。  
- データインポート API に地域パラメーターを追加しました。  
- 透かし API に地域パラメーターを追加しました。  
- オブジェクトクリア API に地域パラメーターを追加しました。  
- データ逆変換 API に地域パラメーターを追加しました。  
- データ回転 API に地域パラメーターを追加しました。  

## バージョン 23.11 の機能強化

- Excel ファイルへの XML データのインポートを最適化しました。  
- Excel ファイルへの JSON データのインポートを最適化しました。  
- 非推奨となった関数、クラス、テストケースを削除しました。  

## バージョン 23.10 の機能強化

- ワークブック保護リクエストの修正を行いました。  
- 範囲コピー API の修正を行いました。  
- ワークブック保護 API の最適化を行いました。  

## バージョン 23.9 の機能強化

- 範囲コントローラーへのデータ並べ替えサポートを追加しました。  
- リストオブジェクトに対する重複データ削除機能を追加しました。  
- リストオブジェクトへのスライサー挿入機能を追加しました。  
- リストオブジェクトおよび関連コンポーネントの最適化を行いました。  

## バージョン 23.8 の機能強化

- ロック API サポートを追加しました。  
- 保護 API の最適化を行いました。  

## Aspose.Cells Cloud 23.7

- 変換機能の最適化を行いました。
