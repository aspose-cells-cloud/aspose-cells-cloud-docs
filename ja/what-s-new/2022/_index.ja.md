Aspose.Cells Cloud ドキュメントの新機能へようこそ。このページを使用して、最新の変更を素早く確認できます。

## Aspose.Cells Cloud 22.12

- チャートの軸操作をサポートしました。

## Aspose.Cells Cloud 22.11

- JSON への変換用の新 API を追加しました。
- SQL への変換用の新 API を追加しました。
- CSV への変換用の新 API を追加しました。

## Aspose.Cells Cloud 22.10

- PPTX への変換用の新 API を追加しました。
- Markdown への変換用の新 API を追加しました。
- HTML への変換用の新 API を追加しました。

## Aspose.Cells Cloud 22.9

- ページを他の形式のファイルにエクスポートすることをサポートしました。
- PDF への変換用の新 API を追加しました。
- PNG への変換用の新 API を追加しました。
- DOCX への変換用の新 API を追加しました。

## Aspose.Cells Cloud 22.8

- Excel の行と列を入れ替える（転置）機能をサポートしました。

## Aspose.Cells Cloud 22.7

- Cells Cloud サービスにおける Save API の改善（4 つの保存オプションを追加）。
- Cells Cloud 上の LightCellsController を最適化しました。

## Aspose.Cells Cloud 22.6

- [Cells Cloud API の改善](/cells/aspose-cells-cloud-22-6-release-notes/)
- ZIP パッケージ内のファイルをさまざまな形式に変換することをサポートしました。
