Aspose.Cells Cloud のドキュメントにおける「2024年の新機能」へようこそ。このページでは、最新の変更を素早く確認できます。この変更履歴では、2024年における各リリースで導入された主な改善点、バグ修正、新APIをまとめています。

## バージョン 24.12 の改善点

- 新しい **重複削除 API** を追加しました。  
- 新しい **テキスト抽出 API** を追加しました。  
- ピボットフィルターの作成に失敗するバグを修正しました。

## バージョン 24.11 の改善点

- `TextProcessingController` にテキスト変換機能を追加しました。

## バージョン 24.10 の改善点

- `TextProcessingController` に文字削除機能を追加しました。

## バージョン 24.9 の改善点

- `TextProcessingController` に単語の大文字・小文字変換機能を追加しました。  
- セルアドレスまたはセルIDを含むワークシートをHTMLへエクスポートする機能をサポートしました。

## バージョン 24.8 の改善点

- Cells Cloud Services にテキストトリム機能を追加しました。

## バージョン 24.7 の改善点

- ワークシートに任意のテキストを挿入するための **AddTextContent API** を導入しました。  
- クライアントIDとクライアントシークレットを使用してアクセストークンを取得する機能を追加しました。

## バージョン 24.6.1 の改善点

- API の拡張クエリパラメータを修正しました。

## バージョン 24.6.0 の改善点

- データ変換ステップを最適化しました。  
- データ変換用のデータ読み込み機能を最適化しました。  
- .NET Framework 4.2.5 および .NET Standard 2.0 のサポートを強化しました。

## バージョン 24.5.1 の改善点

- データ変換時のデータ読み込みに使用するクエリマージメソッドを追加しました。  
- チャートデータモデルを最適化しました。  
- アクセストークンエンドポイントを更新しました。

## バージョン 24.4 の改善点

- Aspose.Cells Cloud Services にデータ変換機能をサポートしました。

## バージョン 24.3 の改善点

- データ重複排除機能をサポートしました（強化版）。  
- データ入力機能をサポートしました。  
- 不完全な行の削除機能をサポートしました。  
- データクレンジング機能をサポートしました。

## バージョン 24.2.1 の改善点

- データ重複排除機能をサポートしました（初期サポート。以降のバージョンで拡張されました）。

## バージョン 24.1.1 の改善点

- 複数の機能におけるスペルミスを修正しました。  
- PageSetupController に `PostFitTallToPages` メソッドを追加しました。  
- PageSetupController に `PostFitWideToPages` メソッドを追加しました。  
- ページ分割保存オプションを最適化しました。
