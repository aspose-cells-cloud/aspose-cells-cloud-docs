# 最も重要なリリース

- **Aspose.Cells Cloud 4.0 の最新版が利用可能になりました。このリリースは、より簡潔かつ効率的になるよう再設計され、安定した信頼性の高いエクスペリエンスを提供します。**
- **最新の SDK は、Aspose.Cells Cloud 3.0 および 4.0 のすべての API を統合し、開発プロセスを合理化し、実用的かつ便利にします。**
